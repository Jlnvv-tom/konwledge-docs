系列文章规划：《全球智能体产品全景》

系列名称：智能体产品全景手册 IP名称：怕浪猫 追更理由：从对话到执行，从代码到机器人，全景式拆解全球 AI Agent 生态，怕浪猫带你一篇一类，读懂智能体

第1章：通用型 AI Agent 与对话助手——从"能聊"到"能干"的产品跃迁​

  • 1.1 从 ChatGPT 到 Manus：AI 产品进化的三个阶段
  • 1.2 通用型自主执行 Agent 深度拆解：Manus、Operator、AutoGLM、Lovart、OpenHands
  • 1.3 对话助手与大模型产品全景：ChatGPT、Claude、Gemini、DeepSeek、Kimi、豆包、通义千问、智谱清言、文心一言、腾讯元宝、MiniMax、Perplexity
  • 1.4 核心能力对比：多模态、长上下文、工具调用、推理能力的横向评测
  • 1.5 选型指南：不同场景下该选哪个 AI 助手

第2章：AI Agent 开发平台——零代码与低代码的智能体工厂​

  • 2.1 开发平台 vs 开发框架：两条路线的选择
  • 2.2 零代码平台深度拆解：Coze、Dify、腾讯 ADP、百度千帆、阿里云百炼、BetterYeah、腾讯元器、n8n
  • 2.3 平台核心架构解析：从 Prompt 编排到工作流引擎
  • 2.4 知识库与 RAG（Retrieval-Augmented Generation）搭建实战对比
  • 2.5 企业选型决策矩阵：成本、生态、私有化、扩展性

第3章：AI Agent 开发框架——代码级智能体编排​

  • 3.1 框架的核心抽象：Chain、Agent、Tool、Memory 四大组件
  • 3.2 LangChain 与 LangGraph：生态最大的 Agent 编排框架
  • 3.3 AutoGen 与 CrewAI：多 Agent 协作的两种范式
  • 3.4 LlamaIndex、Semantic Kernel、Google ADK、OpenClaw 对比
  • 3.5 框架选型决策树：项目该用哪个框架

第4章：编程智能体——AI 写代码的全景拆解​

  • 4.1 从 Copilot 到 Devin：编程 Agent 的三级进化
  • 4.2 AI 原生编辑器对决：Cursor vs Windsurf vs Trae
  • 4.3 自主软件工程师 Agent：Devin、Replit Agent、OpenHands
  • 4.4 GitHub Copilot 全家桶：从补全到 AgentHQ
  • 4.5 国产编程 Agent：通义灵码、CodeGeeX 的差异化路线

第5章：深度研究智能体与 AI 搜索——让 AI 替你做调研​

  • 5.1 Deep Research 赛道为什么爆发
  • 5.2 四大研究 Agent 拆解：OpenAI DR、Gemini DR、Perplexity DR、GPT Researcher
  • 5.3 AI 搜索引擎产品全景：Perplexity、New Bing、文小言、秘塔
  • 5.4 研究质量横向评测：准确率、覆盖度、引用规范、成本
  • 5.5 从搜索到研究：Agentic RAG（检索增强生成）的技术原理

第6章：计算机操作智能体与 RPA 超自动化——AI 操作电脑​

  • 6.1 CUA（Computer Use Agent）赛道起源与技术原理
  • 6.2 CUA 产品拆解：Claude Computer Use、OpenAI Operator、UI-TARS、AutoGLM-PC
  • 6.3 RPA + AI 的化学反应：从"录脚本"到"说人话"
  • 6.4 超自动化产品拆解：实在 Agent、UiPath、Automation Anywhere、Power Automate
  • 6.5 企业落地案例与 ROI（投资回报率）分析

第7章：企业级 AI Agent 平台与办公智能体——组织级部署​

  • 7.1 企业级平台的五层架构：模型层、编排层、知识层、渠道层、治理层
  • 7.2 国际平台拆解：Salesforce Agentforce、ServiceNow、Copilot Studio、IBM watsonx、Google Agent Space
  • 7.3 国内平台拆解：阿里云百炼、腾讯 ADP/TokenHub、百度文心、华为盘古
  • 7.4 办公智能体全景：Microsoft Copilot、钉钉 AI、飞书 AI、Notion AI、Sierra
  • 7.5 企业部署路径：从 POC（概念验证）到生产的四步走

第8章：垂直行业智能体——AI Agent 的行业纵深​

  • 8.1 垂直 Agent 为什么比通用 Agent 更早赚钱
  • 8.2 金融智能体：金智维 Ki-AgentS、恒生 LightGPT 的场景拆解
  • 8.3 医疗智能体：京医千询、百度灵医智惠的诊疗辅助逻辑
  • 8.4 电商、制造、法律、营销 Agent 全景
  • 8.5 行业 Agent 的通用架构：领域知识 + 工具链 + 合规层

第9章：AI 图像、视频与音乐生成——AIGC 创作工具全景​

  • 9.1 图像生成三巨头：Midjourney、DALL-E 3、Stable Diffusion 的技术路线差异
  • 9.2 视频生成三国杀：Sora 2、Kling、Runway、Pika 的核心模型对比
  • 9.3 音乐与音频生成：Suno、Udio、ElevenLabs 的产品逻辑
  • 9.4 AI 数字人与视频客服：HeyGen、Synthesia、D-ID、腾讯智影
  • 9.5 AIGC 工具链选型：创作场景到工作流的整合方案

第10章：具身智能与 AI Agent 协议——从虚拟到物理世界​

  • 10.1 具身智能的技术栈：感知、决策、控制、执行
  • 10.2 人形机器人 Agent 拆解：Figure AI、Tesla Optimus、NVIDIA GR00T、Skild AI、宇树科技
  • 10.3 Agent 协议之战：MCP（Model Context Protocol）与 A2A（Agent2Agent）
  • 10.4 AI Agent 基础设施：NVIDIA Nemotron、OpenClaw 与生态系统
