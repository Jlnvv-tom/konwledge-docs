第2章 AI视频创作工具——生成与编辑的开源利器

AI图片卷完，AI视频更卷。这4个开源模型和3个编辑工具，覆盖从生成到后期全链路。

我是怕浪猫，这是AI提效工具系列第2章。上章盘点了AI图片工具，这章聊视频。

2.1 AI视频生成模型：SVD、CogVideoX、Mochi 1、LTX-Video​

2025年开源AI视频生成领域，4个模型值得关注：

Stable Video Diffusion (SVD)

Stability AI出品，基于Stable Diffusion架构扩展到时序维度。

参数说明
输入单张图片（图生视频）
输出14-25帧，576x1024
显存需求12GB起
帧率约6fps（可插帧到24fps）
许可证Community License
优势与SD生态兼容，图生视频效果好

CogVideoX

智谱AI出品，支持文生视频和图生视频，中文理解能力强。

参数说明
输入文本/图片
输出6秒，720x480
显存需求8GB（2B模型）/ 16GB（5B模型）
许可证Apache 2.0（2B）/ 每日200次（5B）
优势中文提示词理解好，开源协议友好

Mochi 1

Genmo出品，2025年开源视频模型中运动质量最好之一。

参数说明
输入文本
输出5.4秒，848x480
显存需求4 H100 GPU（完整版）/ 1 GPU（量化版）
许可证Apache 2.0
优势运动流畅度高，物理逼真度好

LTX-Video

Lightricks出品，主打快速生成。

参数说明
输入文本/图片
输出5秒，768x512
显存需求12GB
生成速度30秒生成5秒视频（A100）
许可证开源
优势速度快，可在单卡上运行

4模型横评

维度SVDCogVideoXMochi 1LTX-Video
生成方式图生视频文/图生视频文生视频文/图生视频
视频长度2-4秒6秒5.4秒5秒
运动质量中中高中高
画面质量高中高中高中
上手难度低低中低
硬件门槛中低高中
中文支持否是否否

选视频模型像选相机：SVD适合从静态图"激活"视频，CogVideoX适合中文场景，Mochi 1追求运动质量，LTX-Video追求速度。

2.2 ComfyUI视频工作流：AnimateDiff与SVD实战​

ComfyUI不仅能做图片，视频工作流同样强大。

AnimateDiff

AnimateDiff是一个让SD模型生成动画的运动模块，原理是在现有SD模型上插入时序层。

特性说明
基础模型SD1.5/SDXL
输出16帧动画，可循环
显存8GB起
风格继承底模风格
适用动画风格短视频、循环GIF

SVD工作流

SVD在ComfyUI中的典型工作流：

步骤节点说明
1Load Image加载起始图片
2SVD Image Encoder编码图片特征
3SVD Sampler采样生成视频帧
4VAE Decode解码为像素帧
5Video Combine合并为MP4/GIF

ComfyUI视频工作流效率技巧

技巧效果
用LTX-Video替代SVD生成速度提升3倍
先低分辨率生成再超分显存节省40%
用ControlNet控制运动运动可预测性大幅提升
批量生成用API调度无人值守批量产出
AnimateDiff用循环帧生成无缝循环动画

2.3 AutoCut：用AI自动剪辑视频的开源神器​

视频剪辑最耗时的是什么？找素材、剪片段、加字幕。AutoCut用AI自动化这个过程。

AutoCut工作原理

输入AI处理输出
视频文件Whisper转录带时间码的文字稿
文字稿LLM分析关键段落自动剪辑决策
剪辑决策FFmpeg执行切割输出剪辑后视频

AutoCut vs 传统剪辑

维度AutoCut手动剪辑（Premiere/达芬奇）
转录自动（Whisper）手动或第三方工具
找片段AI标记关键内容手动浏览全部素材
剪辑选文字段即剪手动切割拼接
字幕自动生成手动输入
效率10分钟素材→5分钟出片10分钟素材→1小时出片
精度中高
适合口播/访谈/会议精品内容创作

安装与使用

# 安装
pip install autodoc-mp4

# 基本用法
autocut video.mp4  # 自动转录+剪辑
autocut video.mp4 --lang zh  # 指定中文

AutoCut不是要替代专业剪辑师，而是把"从素材到粗剪"这个最无聊的环节自动化。省下的时间用来做创意。

2.4 Whisper-WebUI：开源语音转文字与自动字幕​

Whisper是OpenAI开源的语音识别模型，Whisper-WebUI给它套了一个网页界面。

三种转录引擎对比

引擎速度显存精度推荐场景
标准Whisper标准中最高专业场景
faster-whisper快5倍低高日常使用
insanely-fast-whisper极速最低中高批量处理

Whisper-WebUI核心功能

功能说明
文件转录上传音频/视频文件转文字
YouTube转录输入链接直接转录
麦克风实时转录实时语音转文字
说话人识别区分不同说话人
背景音乐分离分离人声和BGM
多语言支持99种语言自动检测
输出格式TXT/SRT/VTT/JSON

部署方式

方式命令适合
Dockerdocker compose up推荐方式
WindowsInstall.bat非技术用户
Linux/Mac./Install.sh命令行用户
访问地址http://localhost:7860浏览器使用

Whisper模型选择指南

模型磁盘内存中文精度推荐场景
tiny75MB125MB低快速预览
base142MB210MB中低测试
small466MB600MB中日常使用
medium1.5GB2.1GB高专业字幕
large2.9GB3.3GB最高精确转录

中文转录建议至少用small模型，medium是性价比最高的选择。large在长音频上精度优势明显。

2.5 视频后处理工具链：插帧、超分与编码​

插帧工具

工具原理效果速度
RIFE光流+插值好快
FILM大运动插值很好中
AMT运动补偿好快
ComfyUI-Framer节点化集成好中

超分辨率工具

工具输入输出特点

GFPGAN人脸视频高清人脸人脸增强
CodeFormer低质量视频修复+增强极端质量恢复
Topaz Video AI任意视频8K商业工具（对比）

编码与输出

编码器压缩率速度兼容性
H.264 (x264)标准快所有设备
H.265 (x265)高50%中现代设备

完整后处理工作流

AI生成视频(576p/6fps)
    → RIFE插帧(6fps→24fps)
    → Real-ESRGAN超分(576p→4K)
    → x265编码输出
    → 成品(4K/24fps)
步骤工具耗时(10秒视频)
插帧RIFE约30秒
超分Real-ESRGAN约2分钟
编码x265约1分钟
合计-约4分钟

10秒低分辨率视频，4分钟后变成4K高清。这就是开源工具链的威力。
