第3章 AI写作与内容生成——开源写作助手盘点

不用翻墙，不用付费，5个开源工具搭建你的私有AI写作助手。

我是怕浪猫，AI提效工具系列第3章。上两章聊了图片和视频，这章讲文字。

3.1 Ollama+OpenWebUI：本地大模型对话平台​

Ollama：本地运行大模型的极简方案

Ollama把复杂的大模型部署简化到一行命令。

特性说明
安装方式一键安装（Mac/Windows/Linux）
模型管理ollama pull/ollama run
模型格式GGUF量化格式
API兼容OpenAI兼容API
模型库Llama、Qwen、DeepSeek、Mistral等

常用模型推荐

模型参数量显存需求写作能力中文能力
Qwen2.5-7B7B6GB好优秀
DeepSeek-R1-7B7B6GB好优秀
Llama3.1-8B8B7GB优秀中
Qwen2.5-14B14B10GB很好优秀
DeepSeek-R1-14B14B10GB很好优秀
Mistral-7B7B6GB好弱

中文写作首选Qwen和DeepSeek。7B模型在4-bit量化下只需6GB显存，集显笔记本也能跑。

OpenWebUI：给Ollama套上ChatGPT界面

功能说明
多模型切换下拉选择不同模型
对话管理多会话、历史记录
文档对话上传PDF/Word直接提问
联网搜索集成搜索增强回答
提示词库保存常用提示词模板
多用户支持团队使用
RAG内置检索增强生成

3步部署

步骤命令/操作说明
1. 装Ollamaollama pull qwen2.5:7b下载模型
2. 装OpenWebUIdocker run -d -p 3000:8080 ...Docker一行启动
3. 访问http://localhost:3000浏览器使用

3.2 AnythingLLM：文档对话与知识管理一体化​

AnythingLLM把"上传文档→AI问答"这个过程做到了极致。

核心能力

功能说明
文档对话PDF/Word/Excel/PPT直接提问
多模型支持OpenAI/Claude/Ollama/LocalAI
工作空间按项目分类管理文档
Agent能力可执行网页搜索、文档操作
向量数据库内置LanceDB，无需额外配置
桌面版Mac/Windows/Linux客户端

AnythingLLM vs OpenWebUI文档对话

维度AnythingLLMOpenWebUI
定位文档知识管理通用对话平台
文档解析强（复杂表格/图表）中
多文档工作空间分类管理简单列表
Agent支持不支持
部署桌面版/DockerDocker
适合企业知识库个人对话

如果你主要需求是"跟文档对话"，AnythingLLM体验更好。如果还需要通用聊天、提示词管理等，OpenWebUI更全面。

3.3 LibreChat：多模型对话与多端同步​

LibreChat是另一个开源的ChatGPT替代品，最大亮点是多端同步。

核心特性

功能说明
多模型OpenAI/Claude/Gemini/Ollama/本地模型
多端同步同一账号跨设备同步对话
Artifacts类似Claude的Artifacts功能
插件系统搜索、代码执行、图片生成
对话分支从任意消息分叉新对话
书签保存重要对话片段
导入导出对话数据可迁移

3款对话工具对比

维度OpenWebUIAnythingLLMLibreChat
定位本地模型对话文档知识管理多模型对话
多端同步否桌面版是
文档对话基础强基础
插件少Agent丰富
部署难度低低中
适合个人本地企业知识库团队协作

三个工具不是互斥的。怕浪猫自己同时用OpenWebUI做日常对话，AnythingLLM管文档，LibreChat做多模型对比。

3.4 沉浸式翻译：开源AI翻译工具​

沉浸式翻译（Immersive Translate）是2025年最火的开源翻译工具之一。

核心功能

功能说明
网页翻译浏览器实时双语翻译
PDF翻译保持排版的PDF翻译
视频字幕YouTube等平台实时字幕翻译
EPUB翻译电子书双语阅读
多引擎OpenAI/Claude/DeepL/Google/本地模型
自定义可配置提示词和翻译风格

翻译引擎对比

引擎质量速度成本隐私
OpenAI GPT-4o优秀中按Token云端
Claude优秀中按Token云端
DeepL很好快按字符云端
Google好快免费云端
本地Ollama好中免费本地

隐私敏感的文档用本地Ollama翻译，日常网页用Google或DeepL，重要文档用GPT-4o。沉浸式翻译支持按场景自动切换引擎。

安装方式

平台安装方式
ChromeChrome Web Store搜索安装
FirefoxAdd-ons搜索安装
油猴脚本Tampermonkey脚本安装
桌面版下载客户端（Mac/Windows）

3.5 实战：搭建私有AI写作助手​

把前面4个工具串起来，搭建一个完整的AI写作工作流。

架构设计

需求输入 → Ollama+OpenWebUI（创意生成）
    → AnythingLLM（素材检索+事实核查）
    → 沉浸式翻译（多语言版本）
    → 输出成品

各环节工具与职责

环节工具职责
创意生成OpenWebUI + Qwen2.5头脑风暴、大纲生成
初稿撰写OpenWebUI + DeepSeek-R1正文写作
素材检索AnythingLLM从知识库找支撑材料
事实核查AnythingLLM + 文档验证关键数据
多语言沉浸式翻译英文/日文版本
润色OpenWebUI + 自定义提示词风格优化

提示词模板示例

场景提示词模板
大纲生成"请为以下主题生成一个{N}部分的系列文章大纲，每部分包含3个要点：{主题}"
初稿撰写"请根据以下大纲撰写正文，风格{风格}，字数约{字数}，目标读者是{读者}：{大纲}"
风格润色"请将以下文字改写为{风格}风格，保持信息不变，增强可读性：{原文}"
事实核查"请检查以下陈述是否准确，标注不确定的部分：{陈述}"

效率提升数据

环节传统方式AI辅助提升幅度
大纲构思30分钟5分钟83%
初稿撰写3小时40分钟78%
素材查找1小时10分钟83%
多语言翻译2小时15分钟87%
润色修改1小时20分钟67%
合计7.5小时1.5小时80%

AI写作不是让AI替你写，而是让AI做80%的基础工作，你专注20%的创意和判断。

你日常写作最需要AI帮忙做什么？大纲、初稿还是润色？评论区说说。
