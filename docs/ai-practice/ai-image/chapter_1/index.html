第一章 AI图片生成概述

试了20多种AI生图工具后，我发现90%的人卡在第一步：不知道该选哪个，也不知道它们到底怎么工作的。

我是怕浪猫，一个在AI图片生成领域踩了无数坑的创作者。从最早用GAN生成模糊人脸，到现在每天用扩散模型出商业级海报，我经历了AI生图技术从"能看"到"好看"再到"能用"的完整跃迁。这个系列将带你从零开始，系统掌握AI图片创作的全部技能。

1.1 什么是AI图片生成​

文生图（Text-to-Image）技术简介​

AI图片生成，简单来说就是让机器根据输入信息自动产出图片。其中最核心的能力是文生图，即Text-to-Image，指通过自然语言文本描述来生成对应图像的技术。

你输入一句话，比如"一只橘猫坐在窗台上看着夕阳"，AI就能在几秒到几十秒内生成一张匹配描述的图片。这个过程的背后是深度学习模型对文本语义的理解和对图像像素的精确控制。

文生图的核心挑战在于：文本是抽象的符号，图像是具体的像素，如何把"橘猫"这个词翻译成猫的耳朵形状、毛发颜色、光影方向？这就需要模型同时理解语言和视觉两个维度。

文生图不是"搜索图片"，而是"从零创造图片"。每一张生成的图都是独一无二的。

一个完整的文生图系统包含三个核心模块。第一个是文本编码器（Text Encoder），负责把自然语言转换为模型能理解的向量表示。第二个是扩散模型（Diffusion Model），负责在潜空间中从噪声逐步去噪生成图像特征。第三个是解码器（Decoder），负责把潜空间的特征解码为最终的像素图像。

以Stable Diffusion为例，它的文本编码器使用的是CLIP（Contrastive Language-Image Pre-training，对比语言-图像预训练）模型。CLIP由OpenAI在2021年发布，它通过对比学习同时训练文本编码器和图像编码器，让两种模态的表示对齐到同一个向量空间中。

文生图系统的数据流：
输入文本 "一只橘猫坐在窗台"
    ↓
[文本编码器 CLIP] → text_embedding (维度: [1, 77, 768])
    ↓
[扩散模型 UNet] → latent (维度: [1, 4, 64, 64]) 从噪声逐步去噪
    ↓
[解码器 VAE] → output_image (维度: [3, 512, 512]) 像素级图像

图生图（Image-to-Image）技术简介​

图生图，即Image-to-Image，是文生图的延伸。它接受一张已有图片作为输入，结合文本指令，在原图基础上进行修改或变换。

常见应用场景包括：把素描变成成品图、把白天照片变成夜景、把真人照片转换成二次元风格。图生图的核心参数是去噪强度（Denoising Strength），它决定了AI在原图上保留多少、修改多少。

去噪强度为0时，输出和输入完全一样。去噪强度为1时，AI完全忽略原图，相当于文生图。通常0.3到0.6之间是最常用的区间，既能保持原图结构，又能实现有效变换。

图生图的技术原理与文生图相同，区别在于初始输入。文生图从纯随机噪声开始去噪，图生图则从"原图加部分噪声"开始。去噪强度控制的就是加多少噪声：值越小，加入的噪声越少，结果越接近原图；值越大，加入的噪声越多，AI的创作自由度越高。

# 图生图的核心逻辑（伪代码）
def image_to_image(model, input_image, prompt, denoising_strength=0.5):
    # 编码原图到潜空间
    latent = vae_encode(input_image)
    
    # 根据去噪强度决定从第几步开始去噪
    start_step = int(T * denoising_strength)
    
    # 给潜空间表示加噪声到start_step步
    noisy_latent = forward_diffusion(latent, start_step)
    
    # 从start_step开始反向去噪
    text_emb = clip_encode(prompt)
    for t in range(start_step, 0, -1):
        noise_pred = model(noisy_latent, t, text_emb)
        noisy_latent = denoise_step(noisy_latent, t, noise_pred)
    
    # 解码为像素图像
    output = vae_decode(noisy_latent)
    return output

图生图还有一种进阶用法叫局部重绘（Inpainting），就是只修改图片的某个区域，其余部分保持不变。用户通过蒙版（Mask）标记需要修改的区域，模型只在该区域内进行扩散去噪，蒙版外的像素完全保留。这在修复瑕疵、替换背景、移除路人等场景中非常实用。

另一种变体是向外扩展（Outpainting），也叫"图像延展"。它不是修改已有内容，而是沿着图片边界向外延伸，生成原图之外的画面。比如把一张正方形照片扩展成宽屏，或者把半身像扩展成全身像。

AI图片生成的核心原理：扩散模型（Diffusion Model）​

目前主流的AI图片生成工具几乎全部基于扩散模型，即Diffusion Model。这是一种通过逐步去噪来生成图像的深度学习模型。

理解扩散模型，可以用"雕刻"来类比。想象一块大理石，雕塑家逐步凿去多余的部分，最终露出里面的雕像。扩散模型做的事情类似：从一团纯噪声开始，逐步去除噪声，最终"露出"清晰的图像。

扩散模型的工作过程分为两个阶段。

前向扩散（Forward Diffusion） 是训练阶段。给一张清晰图片，逐步往里加噪声，经过T步之后，图片变成纯高斯噪声。这个过程的目的是学习"噪声如何破坏图像"，数学上是一个马尔可夫链（Markov Chain），每一步的噪声添加都是固定的。

可以想象前向扩散的过程：第一步，图片上出现极其微弱的噪点，肉眼几乎看不出变化。第十步，图片开始变得朦胧，细节模糊。第一百步，图片已经面目全非，只能看到大致色块。第五百步，完全变成了雪花屏。到第一千步，彻底变成没有任何信息的纯随机噪声。

这个过程的精妙之处在于它是确定性的：给定相同的原始图像和相同的随机种子，加噪的结果完全一样。这意味着模型可以精确学习每一步添加了什么样的噪声，进而在生成时精确地去除它们。

前向扩散的关键公式是：

x_t = sqrt(alpha_t) * x_{t-1} + sqrt(1 - alpha_t) * epsilon

其中：
  x_t     第t步的图像（越往后噪声越多）
  alpha_t 第t步的保留系数（预先设定的超参数）
  epsilon 从标准正态分布采样的噪声 ~ N(0, I)
  T       总步数（通常为1000）

通过数学推导可以得到一个重要性质：不需要逐步加噪，可以直接从原图跳到任意第t步：

x_t = sqrt(alpha_bar_t) * x_0 + sqrt(1 - alpha_bar_t) * epsilon

其中 alpha_bar_t = alpha_1 * alpha_2 * ... * alpha_t（累积乘积）

这个性质让训练变得高效：随机采样一个t值，直接计算x_t，然后训练模型预测噪声。

反向去噪（Reverse Diffusion） 是生成阶段。从纯噪声开始，训练一个神经网络来预测每一步添加的噪声，然后逐步减去这些噪声，最终恢复出清晰图像。

反向去噪的过程就像考古学家修复文物。文物的碎片埋在土里（噪声中的信号），考古学家逐步清理泥土（去噪），让文物的原貌逐渐显露。每一步去噪都需要非常精确：去多了会损坏文物（图像细节丢失），去少了泥土还在（噪声残留）。

在Stable Diffusion中，这个去噪网络使用的是UNet架构。UNet的特点是"先压缩再还原"：输入图像通过编码器逐层压缩（同时提取特征），到达最底层后再通过解码器逐层还原。由于每层的特征都通过跳跃连接（Skip Connection）传递给对应的解码层，网络能同时关注细节和全局信息。

在FLUX系列中，UNet被替换为Transformer。Transformer的自注意力机制（Self-Attention）让模型能更好地捕捉图像中远距离区域之间的关系，比如天空的色调和地面的阴影之间的关联。这是FLUX在画质和一致性上优于传统UNet模型的原因之一。

反向去噪的每一步可以表示为：

x_{t-1} = (1/sqrt(alpha_t)) * (x_t - (1-alpha_t)/sqrt(1-alpha_bar_t) * eps_theta(x_t, t))

其中 eps_theta(x_t, t) 是神经网络预测的噪声

公式看起来复杂，但核心逻辑很简单：用网络预测当前图像中的噪声，然后从当前图像中减去一部分噪声，得到比当前稍微清晰一点点的图像。重复这个过程T次，就从纯噪声变成了清晰图像。

这个去噪过程的每一步都不是完全确定的，而是带有一定的随机性。这种随机性来自采样的方差项，它让模型在每次生成时都能产出不同的结果。这也是为什么相同提示词、相同参数下，每次生成的图片都不一样的原因。

关键点在于：模型不是直接生成图像，而是学习"如何去噪"。一旦训练完成，从任意噪声出发都能生成合理图像。

扩散模型的本质不是"画图"，而是"去噪"。理解了这一点，后面所有的参数调优都会变得清晰。

扩散模型的核心训练目标可以用一段伪代码概括：

# DDPM（Denoising Diffusion Probabilistic Model）核心训练逻辑
import torch
import torch.nn.functional as F

def train_step(model, x_0, optimizer):
    """
    model: UNet神经网络，输入加噪图像和时间步，预测噪声
    x_0:   训练集中的清晰图像
    """
    batch_size = x_0.shape[0]
    
    # 1. 随机采样时间步 t
    t = torch.randint(0, T, (batch_size,))
    
    # 2. 采样高斯噪声
    noise = torch.randn_like(x_0)
    
    # 3. 前向扩散：直接计算第t步的加噪图像
    x_t = forward_diffusion_sample(x_0, t, noise)
    
    # 4. 网络预测噪声
    predicted_noise = model(x_t, t)
    
    # 5. 计算均方误差损失
    loss = F.mse_loss(noise, predicted_noise)
    
    # 6. 反向传播更新参数
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    
    return loss.item()

这段代码展示了扩散模型训练的核心思想：给图像加噪声，让网络学习预测加了什么噪声。训练越好，预测越准，生成的图像质量越高。

在DDPM之上，还有两个重要的改进。

第一个是DDIM（Denoising Diffusion Implicit Models，去噪扩散隐式模型），它通过修改采样过程，把生成所需的步数从1000步降到20-50步，速度提升数十倍。DDIM的核心思想是：前向扩散是马尔可夫链（每步只依赖前一步），但反向去噪不一定要严格按照马尔可夫链来。通过引入非马尔可夫的前向过程，DDIM允许在去噪时跳过一些步骤，从而大幅减少生成时间。

第二个是LDM（Latent Diffusion Model，潜空间扩散模型），由CompVis团队提出，把扩散过程从512x512的像素空间（约78万像素）压缩到64x64的潜空间（约1.6万值），计算量降低近50倍。Stable Diffusion就是基于LDM实现的。

LDM的思路是：与其在像素空间做扩散（计算量巨大），不如先用VAE把图像压缩到一个低维的潜空间，在这个小空间里做扩散，最后再用VAE解压回像素。这就像你是直接在一块大石头上雕刻，还是先做一个小模型再放大——小模型做起来快得多，细节再通过解码器补回来。

从GAN到Diffusion的技术演进脉络​

AI图片生成不是一夜之间冒出来的。在扩散模型称霸之前，这个领域经历了多次技术迭代。

2014年：GAN时代开启。 Ian Goodfellow提出生成对抗网络（Generative Adversarial Network，GAN），用两个神经网络互相对抗：生成器（Generator）负责造假图，判别器（Discriminator）负责辨别真假。训练到平衡时，生成器能产出相当逼真的图片。

GAN的核心思想用代码表示就是：

# GAN训练逻辑（概念示意）
def train_gan(generator, discriminator, real_images, optimizer_g, optimizer_d):
    # 训练判别器
    z = torch.randn(batch_size, latent_dim)        # 随机噪声
    fake_images = generator(z).detach()             # 生成假图（不回传到G）
    real_pred = discriminator(real_images)          # 判别真图
    fake_pred = discriminator(fake_images)          # 判别假图
    loss_d = -(torch.log(real_pred) + torch.log(1 - fake_pred)).mean()
    
    # 训练生成器
    z = torch.randn(batch_size, latent_dim)
    fake_images = generator(z)
    fake_pred = discriminator(fake_images)
    loss_g = -torch.log(fake_pred).mean()           # 让判别器认为假图是真的

GAN的优势是生成速度快（一步到位），缺点是训练不稳定、容易出现模式崩溃（Mode Collapse，即生成器只产出几种相似的图，缺乏多样性）。早期的AI生图工具如StyleGAN系列、BigGAN等都是基于GAN的。

2020年：DDPM横空出世。 UC Berkeley的Jonathan Ho等人发表了DDPM论文，证明了扩散模型能生成比GAN更高质量的图像，且训练更稳定。这标志着AI生图从GAN时代进入Diffusion时代。

2021年：GLIDE和Latent Diffusion。 OpenAI的GLIDE首次将文本条件引入扩散模型，让"用文字描述来生图"成为可能。德国CompVis团队提出Latent Diffusion Model（LDM），把扩散过程从像素空间移到潜空间（Latent Space），大幅降低计算量。这是后来Stable Diffusion的技术基础。

LDM的核心创新可以用一个简单的对比来理解：

像素空间扩散（Pixel-Space Diffusion）：
  输入维度: [3, 512, 512] = 786,432 个值需要去噪
  计算量: 极大，需要多张高端GPU

潜空间扩散（Latent-Space Diffusion）：
  先用VAE编码: [3, 512, 512] → [4, 64, 64] = 16,384 个值
  在潜空间去噪: 16,384 个值（计算量降低48倍）
  再用VAE解码: [4, 64, 64] → [3, 512, 512]
  计算量: 大幅降低，单张消费级GPU即可运行

2022年：Stable Diffusion开源。 Stability AI发布Stable Diffusion，这是第一个高质量且完全开源的扩散模型。任何人都可以免费下载模型并在本地运行，这直接引爆了AI生图领域的社区生态。同年Midjourney和DALL·E 2也相继发布，AI生图正式进入大众视野。

2023-2024年：ControlNet与LoRA生态爆发。 ControlNet（Control Network，条件控制网络）实现了对生成结果的精准控制——你可以用线稿、姿态图、深度图来约束AI的生成方向。LoRA（Low-Rank Adaptation，低秩适配）让普通用户也能用少量图片微调模型，训练出自己的专属风格。同年Stable Diffusion XL（SDXL）发布，分辨率提升到1024x1024，画质大幅提升。

2024-2025年：DiT架构与FLUX系列。 Black Forest Labs推出FLUX系列，采用Diffusion Transformer（DiT，扩散Transformer）架构，用Transformer替代传统UNet作为去噪网络。DiT的优势在于更好的全局注意力机制和更强大的文本理解能力，在画质和文字渲染上实现突破。

2025-2026年：FLUX.2与多模态融合。 FLUX.2支持多图参考融合（最多10张参考图）、4MP（兆像素）高分辨率生成、文字渲染与信息图表制作。AI生图进入实用商业级阶段，不再只是"看着好看"，而是"真的能用"。

从GAN到Diffusion，从像素空间到潜空间，从UNet到Transformer——每一次架构革新都让AI生图的能力跃升一个台阶。

1.2 主流AI图片生成工具一览​

了解了原理，接下来看工具。目前市面上有六大主流AI图片生成工具，各有特色。

Midjourney 由Midjourney Inc.开发，是目前艺术感最强的商业AI生图工具。它运行在Discord平台上，通过/imagine命令交互。优势是出图质量极高、风格表现力强，对提示词的要求相对宽松。劣势是需要付费订阅（最低10美元/月）、无法本地部署、对中文提示词支持有限、生成结果有一定随机性。适合追求艺术效果的设计师和创作者。

官网：https://www.midjourney.com

Midjourney的版本迭代非常快，从V1到V6，每个版本在画质、细节、文字渲染上都有显著提升。V6版本已经能在图片中渲染相对准确的英文文字，这在之前版本中几乎不可能。Midjourney还支持风格参考（Style Reference，--sref参数）和角色参考（Character Reference，--cref参数），可以在不同生成中保持风格和角色一致性。

Stable Diffusion 由Stability AI开源，是目前生态最丰富的AI生图模型。支持本地部署、模型可自定义、社区资源庞大（Civitai上有数万个模型和LoRA）。优势是免费开源、高度可控、LoRA和ControlNet生态完善、支持多种自定义模型。劣势是上手门槛较高、需要较好的硬件（推荐NVIDIA显卡至少8GB显存）、参数调优需要经验积累。适合技术用户和深度定制需求。

官网：https://stability.ai

Stable Diffusion的版本演进也很快：SD 1.5是社区使用最广的版本（轻量、兼容性好），SDXL提升了分辨率和画质，SD 3引入了DiT架构和改进的文本编码器。此外社区基于SD微调的衍生模型数不胜数，如Realistic Vision（写实人像）、Anything（动漫风格）、DreamShaper（通用增强）等，覆盖了几乎所有风格需求。

DALL·E 3 由OpenAI开发，集成在ChatGPT中。最大优势是自然语言理解能力极强，你不需要学复杂的提示词语法，用日常对话的方式就能生图。比如你可以直接说"帮我画一只在月球上弹吉他的猫"，DALL·E 3就能准确理解并生成。文字渲染能力也很出色，能在图片中生成相对准确的英文文字。劣势是只能通过ChatGPT或API使用、闭源、生成结果的精细控制不如SD。

官网：https://openai.com/dall-e-3

FLUX.2 由Black Forest Labs开发，团队成员是Stable Diffusion的核心作者。FLUX.2采用DiT架构，支持多图参考融合、4MP高清生成、文字渲染。开源版（dev）可本地部署，闭源版（pro）画质顶级。FLUX.2的四个版本覆盖了不同需求：pro面向顶级画质、flex面向开发者、dev面向开源社区、klein面向实时交互。劣势是模型体积大（32B参数）、硬件要求高（推荐24GB以上显存）。

官网：https://blackforestlabs.ai

ComfyUI 是一个开源的节点式AI生图工作流引擎，由社区开发者comfyanonymous维护。它本身不是生图模型，而是连接各种模型的"管道系统"。你可以在ComfyUI中搭建复杂的工作流：加载模型、输入提示词、连接ControlNet、应用LoRA、放大图像，每个环节都是一个可视化的节点。优势是高度可定制、支持复杂工作流、资源占用比WebUI低30%左右、工作流可保存和分享。劣势是学习曲线陡峭，节点连线逻辑需要时间适应。适合进阶用户和自动化生产场景。

GitHub：https://github.com/comfyanonymous/ComfyUI

QClaw生图 是QClaw内置的AI生图技能，支持文生图和图生图，集成在本地Agent中。优势是一键调用、无需配置环境、鉴权自动处理、支持中文提示词。调用方式简单：只需要提供提示词和分辨率参数，系统自动完成任务提交、轮询等待、图片下载的全流程。适合QClaw用户快速生图，无需安装任何额外软件。

选择工具时可以参考以下决策路径。

如果你的需求是"快速出高质量艺术图，不在乎付费"，选Midjourney。它出图的艺术感是所有工具中最强的，特别适合插画、概念艺术、海报设计等场景。

如果你需要"本地部署、深度控制、免费开源"，选Stable Diffusion配合ComfyUI。虽然上手难度高，但一旦掌握，你能实现任何想要的生图效果，而且完全免费。

如果你想要"对话式生图、自然语言交互"，选DALL·E 3。它集成在ChatGPT中，使用门槛最低，特别适合不想学习复杂参数的普通用户。

如果你是"进阶玩家、追求最新架构"，选FLUX.2。DiT架构在文字渲染和高分辨率方面有明显优势，是未来发展的方向。

如果你是"QClaw用户、需要快速集成生图能力"，选QClaw生图技能。一行命令就能出图，不需要配置任何环境。

实际工作中，很多专业创作者会同时使用多个工具。比如用Midjourney出概念草图，用Stable Diffusion配合ControlNet精确控制构图，用DALL·E 3生成需要文字的图片。工具之间不是互斥的，组合使用往往能发挥最大价值。

对于预算有限的个人创作者，怕浪猫推荐这个组合：Stable Diffusion（免费本地部署）+ DALL·E 3（ChatGPT Plus包含）+ QClaw生图（Agent内置）。三者覆盖了从专业到日常的全部需求，月费仅需ChatGPT Plus的20美元。

工具没有绝对的好坏，只有是否匹配你的场景。怕浪猫的建议是：先选一个上手，掌握后再扩展。

1.3 AI图片生成的应用场景​

AI图片生成已经不是"玩具"了，它正在真实地改变各行各业的工作方式。下面是几个已经成熟落地的应用场景。

电商海报与产品图。 传统电商产品拍摄需要场地、模特、摄影师、后期修图，一套流程下来成本不菲。AI生图可以直接生成产品场景图：输入产品白底图，用图生图配合提示词，几秒内输出各种场景的产品图。

某电商平台商家反馈，使用AI生图后，产品图制作成本降低了80%，上新速度提升了3倍。原来需要一周完成的拍摄任务，现在半天就能出全套图。

具体操作流程通常是：先用手机拍一张产品白底图作为输入。然后写提示词描述想要的场景，比如"产品放在木质桌面上，背景是温馨的厨房，柔和的晨光从窗户射入"。设置适当的去噪强度（0.5到0.7之间），生成后挑选满意的结果。如果细节不理想，可以用局部重绘单独修改某些区域。

社交媒体配图与表情包。 公众号、小红书、微博等内容创作者可以用AI快速生成配图，不再需要翻找版权图库或自己拍摄。版权图库的图片往往需要付费授权且选择有限，AI生图则可以按需定制，每次生成的图都是原创的。

表情包生成更是AI的强项。通过文字描述加角色设定，批量生成表情包系列。一个典型的表情包生成流程：先确定角色形象（比如"一只圆滚滚的橘猫，白色腹部，橙色背部"），然后为不同情绪编写提示词（"开心的橘猫举着牌子写OK"、"生气的橘猫炸毛弓背"、"困惑的橘猫歪头"），统一使用相同Seed值保持角色一致性。

Logo与品牌设计。 AI生图在Logo设计领域的应用越来越成熟。设计师可以用Midjourney快速探索多种Logo方向，输入"minimalist logo for a coffee brand, geometric shape, warm tones"这类提示词，几分钟内获得数十个方向。选出有潜力的方案再用矢量软件精修，把AI生成的位图转换为可缩放的矢量图形。

需要注意的是，AI生成的Logo通常需要人工后期处理：矢量化、调整比例、适配不同尺寸、检查可注册性。AI目前还无法直接输出可用的矢量Logo文件，也无法保证生成的Logo不与已有商标冲突。

插画与概念艺术。 游戏公司和影视工作室已经在用AI生图做概念设计。美术指导用AI快速生成场景概念图，在团队内部对齐视觉方向后，再由画师细化。这个流程能把前期概念探索阶段从几周缩短到几天。

例如一个奇幻RPG游戏需要设计"精灵森林"场景，美术指导可以用Midjourney输入"ethereal elven forest, bioluminescent plants, ancient tree cathedral, moonlight filtering through canopy, fantasy concept art, highly detailed"获得多个视觉方向，从中选择最匹配游戏世界观的方向，然后交给概念画师细化。

游戏与影视美术素材。 游戏开发中的贴图、背景、UI元素等都可以用AI辅助生成。特别是独立游戏开发者，用AI生图能把美术成本压到极低。一些RPG游戏的NPC立绘、场景背景图已经大量采用AI生成。

游戏行业使用AI生图的典型场景包括：NPC角色立绘批量生成、场景背景图快速出稿、武器道具概念设计、UI图标和装饰元素制作。通过训练特定风格的LoRA模型，可以确保整个游戏的视觉风格统一。

一个实际案例：某独立游戏工作室开发一款像素风RPG游戏，美术团队只有两个人。他们用Stable Diffusion配合自定义像素风LoRA，一天能产出20张场景背景图和10个NPC立绘。如果纯靠手绘，同样的工作量至少需要两周。通过AI辅助，这个两人团队在三个月内完成了一个传统十人团队半年的美术工作量。

在影视行业，AI生图主要用于前期概念设计和后期 matte painting（遮罩绘画）。特效公司用AI快速生成场景概念图，导演确认视觉方向后再由画师精修。这种方式在 Netflix 和 Disney 的一些项目中已经投入使用。

个人创意创作。 普通用户用AI生图实现自己的创意：给朋友画生日贺卡、为小说配插图、做家庭相册的创意封面。AI让没有绘画基础的人也能把脑海中的画面呈现出来。

比如你写了一篇科幻短篇小说，需要一张封面图：一颗蓝绿色行星悬在双月天空下，前景是一座银色穹顶基地。用DALL·E 3直接描述这个场景就能得到不错的封面，整个过程不超过30秒。

再比如你想为父母的结婚纪念日做一张创意贺卡：把他们年轻时的老照片用AI上色修复，然后用图生图转换成油画风格，加上复古相框装饰。这样的个性化礼物在以前需要专业设计师帮忙，现在自己在家就能完成。

教育领域也开始使用AI生图。教师用AI生成教学插图，比如生物课上的细胞结构图、历史课上的古代建筑复原图、地理课上的地形地貌示意图。这些定制化的教学素材比教科书上的通用图片更有针对性，也更能吸引学生的注意力。

AI图片生成不是在取代创作者，而是在放大创作者的生产力。会用AI的设计师，产出效率是不用AI的5到10倍。

本章总结​

本章我们从三个维度了解了AI图片生成：技术原理、工具生态、应用场景。

技术层面，扩散模型是当前AI生图的绝对主流，核心原理是"加噪-去噪"的两阶段过程。从GAN到Diffusion、从像素空间到潜空间、从UNet到Transformer，技术不断演进。

工具层面，六大工具各有定位：Midjourney重艺术、SD重开源、DALL·E 3重易用、FLUX.2重前沿、ComfyUI重定制、QClaw重集成。选择工具的关键是匹配自己的场景和技术水平。

应用层面，电商、社交媒体、品牌设计、概念艺术、游戏开发、个人创作六大场景已经成熟落地，成本节约60%到95%不等。

如果你是刚接触AI生图的新手，怕浪猫建议你从这个路径开始：先用DALL·E 3或QClaw生图体验文生图的基本流程，感受提示词和生成结果之间的关系。然后尝试Midjourney，学习更系统的提示词语法，体验更高质量的出图效果。最后过渡到Stable Diffusion + ComfyUI，掌握本地部署和精细控制能力。这个学习路径大约需要两到三周时间，完成后你就具备了独立使用AI生图完成商业项目的能力。
