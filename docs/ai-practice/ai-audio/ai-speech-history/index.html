第 2 章：AI 语音技术发展简史

系列文章：《语音与音乐的机器之魂》 从 1950 年代的 Audrey 到 2024 年的 GPT-4o，AI 语音技术走过了 70 年的曲折道路。本章梳理这段历程中的关键里程碑。

1. 前深度学习时代（1950s–2010）​

1.1 早期探索（1950s–1970s）​

AI 语音技术的历史几乎和计算机本身一样长。

  • 1952 年：Bell Labs 开发 Audrey——第一个语音识别系统，能识别 10 个英文数字，准确率 97-99%（但仅限单人、需调参）
  • 1961 年：IBM Shoebox——识别 16 个英文单词，在 1962 年西雅图世博会展出
  • 1960s：伦敦大学学院的 Josef von Kempelen 的说话机器（机械式语音合成，实际为 18 世纪发明，此处为早期原理探索）
  • 1970s：隐马尔可夫模型（HMM） 引入语音识别，成为之后 30 年的基石

1.2 统计模型时代（1980s–2000s）​

这一时代的主流是 GMM-HMM（高斯混合模型 + 隐马尔可夫模型）：

音频 → 特征提取(MFCC) → GMM(声学模型) → HMM(时序模型) → 语言模型 → 文本

关键进展：

年份事件
1980sHMM 成为主流，CMU Sphinx、HTK 工具发布
1985DARPA 语音识别项目推动大词汇识别
1990s大词汇连续语音识别（LVCSR）成熟
1997Dragon NaturallySpeaking 发布（首个消费级连续语音识别）

TTS 方面：

  • 拼接式 TTS：从预录语音库中选取基本单元（音素/半音素），拼接后做频域平滑

    • 代表系统：Festival, ATR ∑, AT&T Natural Voices
    • 优点：自然度高（用真实录音）
    • 缺点：需要大量录音、边界可能不平滑

  • 参数式 TTS（HMM-based）：

    • 用 HMM 建模频谱、基频、时长的统计参数
    • 代表系统：HTS（HMM-based Speech Synthesis System）
    • 优点：模型小、可调节
    • 缺点：有"机器味"，自然度低于拼接式

1.3 这一时代的局限​

  • 需要大量手工特征工程
  • 需要专家构建发音词典、声学模型、语言模型
  • GMM 难以建模复杂的高维声学特征分布
  • TTS 自然度有天花板

2. 深度学习革命（2010–2018）​

2.1 语音识别的突破​

2011：DNN 替换 GMM​

Microsoft 的邓力团队在 ICASSP 2011 上发表论文，用 深度神经网络（DNN）替换 GMM 作为声学模型，词错率降低 30%——这在当时是革命性的提升。

DNN 的优势：

  • 能建模更复杂的高维分布
  • 不需要强假设（GMM 假设高斯分布）
  • 更好的泛化能力

2014：DeepSpeech​

百度发布的 DeepSpeech 是端到端语音识别的先驱：

音频频谱 → RNN(LSTM) → CTC 损失 → 文本
  • 完全端到端，无需 HMM、GMM
  • CTC 损失函数解决了输入输出对齐问题
  • 噪声环境下表现优异

2.2 神经 TTS 的诞生​

2016：WaveNet——划时代的工作​

DeepMind 的 WaveNet 是神经 TTS 的里程碑：

条件(Mel频谱) → 因果膨胀卷积堆叠 → softmax → 逐采样点生成

核心创新：

  • 膨胀因果卷积：感受野指数增长（每层翻倍），用 10 层可达 1024 个采样点的感受野
  • μ-law 量化：16-bit → 8-bit（256 类），减少预测类别数
  • 直接建模原始波形：不依赖中间表示

问题：自回归生成极慢——1 秒音频需要数分钟在 GPU 上生成。

2017-2018：Tacotron 2 + WaveNet​

Google 的 Tacotron 2 将 TTS 分为两个阶段：

文本 → Tacotron 2(编码器-解码器+注意力) → Mel频谱 → WaveNet(声码器) → 波形

Tacotron 2 的架构：

  • 编码器：音素 → Embedding → Conv1D → BiLSTM
  • 注意力：Location-sensitive attention
  • 解码器：自回归生成 Mel 帧 + Stop token
  • Post-Net：卷积残差精修 Mel 频谱

这套系统达到了接近人类水平的自然度，成为后续多年 TTS 研究的基线。

2.3 声码器演进​

时间声码器类型特点
—Griffin-Lim无训练零成本，质量一般
2016WaveNet自回归极高质量，极慢
2017Parallel WaveNet蒸馏+流并行生成，需要蒸馏
2018WaveGlow流模型可逆变换，显存大
2019MelGANGAN轻量快速，质量中等
2020HiFi-GANGAN速度质量最佳平衡
2022BigVGANGAN更大更好

2.4 这一时代的意义​

深度学习彻底改变了语音技术：

  1. 端到端：从多阶段 pipeline 走向统一模型
  2. 质量飞跃：TTS 从"机器味"到"接近人类"
  3. 数据驱动：减少手工规则，更多依赖数据
  4. GPU 生态：深度学习框架（TensorFlow/PyTorch）成熟

3. 大模型时代（2019–至今）​

3.1 语音 TTS 的大模型化​

VITS（2021）：端到端统一​

VITS 将声学模型和声码器统一到一个 VAE 框架：

文本 → 后验编码器 → 隐变量 z → 流模型解码器 → 波形
       ↑
  先验编码器(文本) + 标准化流

不再分两阶段，直接从文本到波形。

零样本 TTS 的崛起​

时间模型突破
2022YourTTS少量数据多说话人
2023VALL-E (Microsoft)3 秒声音克隆，zero-shot 新标杆
2023Voicebox (Meta)流匹配，多功能语音生成
2023NaturalSpeech 2/3扩散模型 + 矢量量化
2024CosyVoice (阿里)多语言零样本，开源
2024F5-TTS纯流匹配，高质量零样本

VALL-E 的意义：将语音生成建模为"语言建模"问题——用音频 token 作为"语言"，利用 LLM 的上下文学习能力实现零样本克隆。这改变了 TTS 的范式。

GPT-4o（2024）：原生语音交互​

GPT-4o 实现了原生多模态语音交互——不需要 ASR → LLM → TTS 的级联，而是直接在语音模态上推理和生成：

  • 全双工对话（可打断）
  • 情感感知（听出你的情绪）
  • 情感表达（带语气、笑声）
  • 延迟 < 300ms

3.2 音乐生成大模型​

音乐生成的发展稍晚于语音，但在 2023 年迎来了爆发：

时间模型意义
2016WaveNet 用于音乐证明直接音频生成可行
2020Jukebox (OpenAI)第一个生成完整歌曲的模型
2023MusicLM (Google)文本到音乐，两阶段架构
2023MusicGen (Meta)开源，单阶段，社区基石
2023Suno V3消费级 AI 歌曲创作，现象级产品
2024Udio专业音乐人友好的 AI 创作
2024Stable Audio高质量可控音乐生成
2024YuE (腾讯)开源歌曲生成

Suno 的意义：让没有任何音乐基础的普通人也能创作完整歌曲（歌词+旋律+人声+伴奏），AI 音乐从实验室走向大众。

3.3 自监督预训练​

wav2vec 2.0（2020）开启了语音的自监督学习：

原始波形 → 卷积特征提取 → Transformer
  → 掩码预测（对比学习）→ 预训练表示
  → 微调 → 下游任务（ASR/分类等）

自监督预训练 + 少量标注微调成为新范式，减少了对标注数据的依赖。

3.4 语音大模型（Speech LLM）​

2024 年后的趋势——将语音理解与生成统一到 LLM 框架：

语音输入 → 音频 Token → LLM → 音频 Token → 语音输出
                            ↑
                       文本 Token 混合
模型能力
Qwen-Audio语音理解 + 问答
GPT-4o实时语音对话
LLaMA-Omni开源语音交互
SpeechX统一语音处理
Spirit-LM语音-文本交织

4. 技术范式变迁总结​

规则/拼接 → 统计模型 → 深度学习 → 端到端 → 大模型/基础模型
  1950s      1990s       2012       2016        2022+

五大核心趋势​

  1. 端到端化：从多阶段 pipeline（GMM→HMM→LM）到单一模型
  2. 零样本化：从数小时录音到 3 秒参考音频
  3. 规模化：从百万参数到数十亿参数
  4. 多模态化：从纯语音到语音+文本+图像+视频
  5. 实时化：从离线合成到流式全双工交互

6. 本章小结​

70 年的技术演进，从规则到统计到深度学习再到大模型，AI 语音技术的发展呈现明显的加速趋势——前 50 年走完的路径，深度学习用 10 年超越，大模型用 3 年再次颠覆。

理解这段历史，能帮助我们把握技术发展的脉络，预判未来的方向。
