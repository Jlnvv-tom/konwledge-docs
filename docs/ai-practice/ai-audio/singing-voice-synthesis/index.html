第 11 章：歌声合成（SVS）与歌声转换（SVC）

系列文章：《语音与音乐的机器之魂》 歌声是语音与音乐的交汇点。本章介绍歌声合成与转换的技术路线，从 VOCALOID 到 DiffSinger 再到 RVC。

1. 歌声与语音的区别​

维度语音歌声
音高自然变化精确乐谱控制（半音/音分级）
时长语义驱动节拍驱动（每个音符可控）
颤音少见艺术性颤音（5-7 Hz 振荡）
气声偶尔常用表现手法
动态范围~20 dB~40 dB 或更大
元音变化少多（音高越高元音越开）

歌声合成的核心挑战：在精确音高控制的同时保持自然的表现力。

2. 歌声合成（SVS）​

2.1 传统方法​

VOCALOID（雅马哈）​

2004 年发布，最著名的歌声合成引擎：

乐谱 + 歌词 → 音素拼接 → 频域处理（音高/时长调整）→ 合成

工作方式：

  • 录制歌手的各个音素/音节样本
  • 根据乐谱选择和拼接样本
  • 频域调整音高和时长
  • 添加颤音和呼吸

VOCALOID 的局限：

  • 需要大量录制（每个歌手数天）
  • 拼接边界可能有瑕疵
  • 音高极高/极低时质量下降
  • 表现力有限（"电子感"）

UTAU​

社区驱动的开源歌声合成：

  • 支持用户自制音源
  • 质量取决于录音频
  • 重尾治（初音未来）即基于 VOCALOID

CeVIO​

AI 辅助歌声合成，部分使用神经网络：

  • 更自然的过渡
  • 支持情感参数
  • 日语市场为主

2.2 神经歌声合成​

DiffSinger（2021）​

当前最重要的开源歌声合成框架。

输入:
  - 乐谱（音高、时值、歌词）
  - 音素序列
  
架构:
  文本编码器 → 扩散模型 → Mel频谱 → 声码器 → 歌声

扩散过程:
  训练: Mel → 逐步加噪
  生成: 噪声 → 逐步去噪 → Mel

DiffSinger 的优势：

  • 扩散模型生成更自然的音素过渡
  • 可控的颤音和气声
  • 开源，社区活跃（OpenVPI）

DiffSinger 的组件：

模型组件:
  - 文本编码器: 音素 → 隐表示
  - F0预测器: 乐谱 → 基频轨迹
  - 时长预测器: 音素 → 帧数
  - 声学模型: 扩散模型，生成Mel频谱
  - 声码器: HiFi-GAN (nsf-hifigan)

OpenSVS​

基于 VITS 的端到端歌声合成：

  • 更简单的训练流程
  • 质量接近 DiffSinger
  • 推理更快

2.3 歌声合成的特殊模块​

颤音生成​

def vibrato_f0(base_f0, time, vibrato_rate=5.5, vibrato_depth=0.15):
    """生成颤音 F0 轨迹"""
    # 5-7 Hz 振荡是自然颤音的典型频率
    vibrato = 1 + vibrato_depth * np.sin(2 * np.pi * vibrato_rate * time)
    return base_f0 * vibrato

颤音需要：

  • 正确的频率（5-7 Hz）
  • 正确的深度（±10-30 半音分）
  • 渐入渐出（不是从头到尾都有）
  • 与歌词和情感配合

音高对齐​

乐谱: C4(0.5s) D4(0.5s) E4(1.0s)
     → 精确的 F0 轨迹: [261.6Hz × 0.5s] [293.7Hz × 0.5s] [329.6Hz × 1.0s]
     → 加上颤音和过渡

元音变化​

高音区元音会自然"打开"：

中音区 /a/ → 高音区更开的 /a/
中音区 /i/ → 高音区接近 /ɪ/

好的歌声合成模型需要学习这一规律。

3. 歌声转换（SVC）​

歌声转换保留原歌曲的旋律和节奏，仅改变歌手音色：

原歌声（歌手A）→ 提取内容(F0, 语言特征) → 音色转换 → 目标歌手(B)音色歌声

3.1 so-vits-svc​

基于 VITS 的歌声转换框架，社区影响极大：

训练:
  歌手A音频 → 内容编码 → VITS编码器 → 隐表示
  隐表示 → VITS解码器(歌手A音色) → 重建
  
转换:
  歌手A音频 → 内容编码 → 隐表示
  隐表示 → VITS解码器(歌手B音色) → 歌手B音色音频

特点：

  • 支持少量数据训练（30分钟~1小时）
  • 实时转换
  • 完全开源
  • 社区生态丰富（模型分享、调参工具）

3.2 RVC（Retrieval-based Voice Conversion）​

社区最流行的声音转换工具。

输入音频 → 内容编码( Speech Content Encoder) → 内容特征
                                              ↓
目标音色 → 特征索引 → 检索最相似的音色特征 → 合成 → 转换后音频

RVC 的创新：

  • 检索增强：用目标音色的预计算特征库
  • Top-k 检索：找到最相似的目标特征
  • 跨语言支持
  • 实时转换（GPU 上 < 100ms 延迟）

RVC 的工作流程：

步骤1（准备）: 收集目标歌手音频 → 提取特征 → 建立索引
步骤2（训练）: 训练特征映射模型（数小时）
步骤3（推理）: 输入任意歌声 → 检索+映射 → 目标音色歌声

3.3 SVC 的评估​

歌声转换比 TTS 更难评估，因为涉及音乐审美：

客观指标：

  • SIM：说话人/歌手相似度
  • F0 RMSE：音高保持度（转换不应改变旋律）
  • MCD：Mel 频谱距离

主观指标：

  • 音色自然度：听起来像真人唱歌吗？
  • 音色相似度：听起来像目标歌手吗？
  • 可懂度：歌词能否听清？
  • 音乐性：情感和表现力如何？

4. 歌声合成的技术挑战​

4.1 精确音高控制​

要求: 在 C4 (261.63 Hz) 上保持 0.5 秒
实际: F0 需要在 261.63 ± 1 Hz 内稳定

模型挑战:
  - 自回归模型可能漂移
  - 扩散模型需要足够步数保证精度
  - F0 预测器需要高精度

4.2 长时稳定性​

一首歌 3-5 分钟，模型需要在整首歌内保持：

  • 音色一致（不"跑音色"）
  • 音质稳定
  • 情感连贯

解决方案：

  • 长上下文窗口
  • 全局音色嵌入
  • 分段合成 + 交叉淡入淡出

4.3 表现力建模​

同一首歌的不同演绎:
  - 深情版：更多气声、更慢颤音
  - 力量版：更强力度、更明亮音色
  - 即兴版：加花、转音

当前模型主要解决"能唱对"，"唱得好"仍是挑战。

5. 歌声 AI 生态​

5.1 工具链​

工具用途特点
DiffSinger歌声合成开源，可训练自定义音源
so-vits-svc歌声转换社区驱动
RVC实时声音转换最流行
Synthesizer V商业歌声合成专业级质量
ACE Studio商业歌声合成中文生态
UTAU歌声合成老牌开源
OpenUtauUTAU 现代版支持 AI 引擎

5.2 创作流程​

1. 制作伴奏（DAW + 虚拟乐器）
2. 编写乐谱（旋律 + 歌词）
3. 歌声合成（DiffSinger/SynthV）
4. 后期处理（EQ/混响/压缩）
5. 混音（人声与伴奏融合）
6. 母带处理

6. 本章小结​

歌声技术发展：

VOCALOID（拼接）→ DiffSinger（扩散）→ RVC（检索+神经）
   2004            2021               2023

歌声合成是语音技术中最具艺术性的方向——不仅需要"说对"，还需要"唱好"。评估的主观性使其比 TTS 更具挑战。

开源社区（OpenVPI、RVC 项目）在这一领域的贡献甚至超过了商业公司，推动了技术的快速普及。
