## 5.1 经济增长理论：索洛模型、拉姆齐模型、内生增长

经济增长理论是宏观经济学的起点。它回答一个最基本的问题：为什么有些国家富裕，有些国家贫穷？

**索洛模型（Solow Model, 1956）**

索洛模型是经济增长理论的基石。它的核心假设极其简洁：储蓄率外生，技术进步外生，资本边际产出递减。

| 要素 | 假设 | 数学表达 |
|------|------|---------|
| 生产函数 | 规模报酬不变 | Y = F(K, AL) |
| 资本积累 | 固定储蓄率 | K̇ = sY - δK |
| 技术进步 | 外生，增长率g | Ȧ/A = g |
| 人口增长 | 外生，增长率n | L̇/L = n |

索洛模型的核心结论是：长期经济增长完全由技术进步率g决定。资本积累只能带来水平效应（level effect），不能带来增长效应（growth effect）。储蓄率提高，人均产出会上升到新的稳态水平，但增长率不变。

> 索洛模型最深刻的结论是：没有技术进步，增长终将停止。这解释了为什么发达国家不可能仅靠积累资本维持增长——资本边际产出递减是铁律。

索洛模型的稳态条件（Modified Golden Rule）：

```
sf(k*) = (n + g + δ)k*
```

其中k*是稳态人均有效资本，s是储蓄率，n是人口增长率，g是技术进步率，δ是折旧率。

**拉姆齐模型（Ramsey Model, 1928 / Cass 1965 / Koopmans 1965）**

拉姆齐模型把索洛模型中的外生储蓄率内生化。消费者最优化跨期消费决策，储蓄率由模型内生决定。

拉姆齐模型的核心是消费者的跨期效用最大化问题：

```
max ∫ e^(-ρt) u(c(t)) dt
 s.t. k̇ = f(k) - c - (n+g+δ)k
```

其中ρ是时间贴现率，c是人均消费，k是人均资本。

| 概念 | 索洛模型 | 拉姆齐模型 |
|------|---------|----------|
| 储蓄率 | 外生固定 | 内生最优 |
| 消费者 | 无（被动储蓄） | 最优化跨期效用 |
| 稳态条件 | sf(k*)=(n+g+δ)k* | f'(k*)=ρ+δ+θg（Modified Golden Rule） |
| 动态路径 | 立即跳到稳态 | 渐进趋近稳态 |

拉姆齐模型的稳态条件（Modified Golden Rule）比索洛模型更深刻：f'(k\*) = ρ + δ + θg，其中θ是跨期替代弹性（Elasticity of Intertemporal Substitution, EIS）的倒数。这意味着稳态资本存量不仅取决于技术和人口，还取决于消费者的时间偏好和跨期替代弹性。

**内生增长（Endogenous Growth）**

索洛模型最大的局限是技术进步外生。内生增长理论试图解释技术进步本身是如何被经济系统决定的。

| 模型 | 核心机制 | 关键贡献者 | 结论 |
|------|---------|----------|------|
| AK模型 | 资本边际产出不递减 | Harrod, Rebelo | 储蓄率影响增长率 |
| 外部性模型 | 知识有溢出效应 | Romer (1986), Lucas (1988) | 社会回报>私人回报 |
| 产品种类模型 | 中间品种类扩大 | Romer (1990) | R&D投入驱动增长 |
| 质量阶梯模型 | 产品质量提升 | Aghion-Howitt (1992) | 创造性破坏 |
| 内生技术采纳 | 技术扩散有滞后 | Parente-Prescott (1994) | 技术壁垒解释收入差距 |

> Romer 1990年的论文是内生增长理论的里程碑。他首次把R&D投入和技术创新放进一般均衡框架，解释了为什么市场竞争不能完全激励创新——因为创新的回报有部分外溢。这个工作后来获得了2018年诺贝尔经济学奖。

## 5.2 消费与投资：持久收入假说、q理论

消费和投资是宏观经济学中两个最核心的需求组成部分。理解消费和投资行为，是理解经济波动和政策传导的基础。

**持久收入假说（Permanent Income Hypothesis, PIH）**

Friedman的持久收入假说认为：消费不是由当期收入决定，而是由"持久收入"（Permanent Income）——即一生收入的期望现值——决定。

| 模型 | 消费决定因素 | 预测 |
|------|----------|------|
| Keynesian | 当期收入 | 边际消费倾向固定 |
| PIH | 持久收入 | 暂时性收入冲击几乎不影响消费 |
| 生命周期假说（LCH） | 一生收入和财富 | 消费随生命周期平滑 |
| 缓冲存货模型 | 预防性储蓄动机 | 流动性约束下消费对当期收入敏感 |

PIH的核心数学表达：

```
c_t = r/(1+r) * [a_t + Σ E_t[y_{t+j}]/(1+r)^j]
```

其中a_t是期初财富，y是劳动收入，r是利率。消费等于总财富（金融财富+人力财富）的年金价值。

PIH的经验含义：暂时性收入冲击（如一次性减税）对消费影响很小，持久性收入冲击影响很大。但实证研究发现，消费对暂时性收入的反应大于PIH预测——这被称为"过度敏感"（Excess Sensitivity）问题。

> PIH和LCH的共同核心思想是"消费平滑"（Consumption Smoothing）：理性消费者会通过储蓄和借贷把消费在时间上平滑分配。但现实中，流动性约束和预防性储蓄使消费比理论预测更波动。

**q理论（q Theory）**

Tobin的q理论是投资理论的核心框架。q定义为：企业的市场价值与资本重置成本之比。

| q的类型 | 定义 | 含义 |
|--------|------|------|
| 平均q | 企业市值/资本重置成本 | 整体企业的投资价值 |
| 边际q | 一单位额外资本的市场价值/重置成本 | 新增投资的价值 |

q > 1时，企业应该投资（市场价值高于重置成本）；q < 1时，企业不应该投资。

Hayashi定理：在一定条件下（规模报酬不变、完全竞争、凸调整成本），平均q等于边际q。这意味着你可以从股票市场数据（企业市值）直接推断投资意愿。

投资调整成本模型的核心方程：

```
I/K = (1/φ) * (q - 1)
```

其中φ是调整成本参数。q越大，投资率越高。调整成本越大，投资对q的反应越弱。

## 5.3 实际经济周期理论：RBC模型

实际经济周期（Real Business Cycle, RBC）理论由Kydland和Prescott在1982年提出。它的核心主张是：经济波动可以由技术冲击（Technology Shock）在完全竞争市场中的传导来解释，不需要引入货币摩擦或名义刚性。

RBC模型的结构：

| 要素 | 设定 | 来源 |
|------|------|------|
| 消费者 | 最大化终身效用，效用函数含消费和休闲 | 拉姆齐模型 |
| 生产者 | 最大化利润，生产函数含技术冲击 | 索洛模型 |
| 市场出清 | 所有市场完全竞争 | 瓦尔拉斯均衡 |
| 技术冲击 | AR(1)过程 | 对数正态分布 |
| 冲击传导 | 资本积累+跨期替代 | 内生传播机制 |

RBC模型的核心传导机制：

1. 正向技术冲击 → 当期产出增加 → 资本边际产出提高 → 投资增加
2. 资本积累增加 → 下一期产出也增加 → 持久效应
3. 工资上升 → 休闲的机会成本增加 → 劳动供给增加
4. 消费平滑动机 → 消费增加但幅度小于产出

> RBC模型的革命性在于：它用同一个框架解释了增长和波动。增长是技术进步的长期趋势，波动是技术冲击的短期效应。不需要"市场失灵"来解释经济衰退——衰退就是技术进步暂时放慢的结果。

RBC模型也受到了批评：

| 批评 | 内容 | RBC的回应 |
|------|------|----------|
| 技术冲击不可观测 | 什么是"负向技术冲击"？ | 用Solow残差作为代理 |
| 劳动供给反应过大 | 模型中劳动供给对工资的反应很小 | 加入不可分劳动假设 |
| 货币无关 | 货币政策对实体经济无影响 | 需要引入名义刚性 |
| 缺乏放大机制 | 技术冲击太小，无法解释波动幅度 | 引入资本利用率、中间品 |

## 5.4 新凯恩斯模型与DSGE：新凯恩斯菲利普斯曲线

RBC模型的"货币无关"结论与现实明显不符。新凯恩斯模型在RBC框架中引入了名义刚性（Nominal Rigidities）——价格和工资不能立即调整——使货币政策有了实际效应。

**新凯恩斯菲利普斯曲线（New Keynesian Phillips Curve, NKPC）**

NKPC是新凯恩斯模型的核心方程之一：

```
π_t = β·E_t[π_{t+1}] + κ·(y_t - y_t^n)
```

其中π是通胀率，β是贴现因子，κ是产出缺口对通胀的敏感度，y-y^n是产出缺口（Output Gap）。

| 方程 | 名称 | 含义 |
|------|------|------|
| NKPC | 新凯恩斯菲利普斯曲线 | 通胀取决于预期通胀和产出缺口 |
| IS曲线 | 动态IS方程 | 产出缺口取决于预期产出缺口和实际利率 |
| Taylor Rule | 货币政策规则 | 央行根据通胀和产出缺口调整利率 |

这三个方程构成了"三方程新凯恩斯模型"，是最简洁的DSGE模型。

**DSGE模型求解步骤**

DSGE（Dynamic Stochastic General Equilibrium，动态随机一般均衡）模型的求解是一个标准化的流程：

| 步骤 | 操作 | 工具 |
|------|------|------|
| 1. 定义模型 | 写出消费者、厂商、政府的最优化问题 | 数学推导 |
| 2. 求一阶条件 | 对每个最优问题求FOC | Lagrangian方法 |
| 3. 求稳态 | 令所有变量不随时间变化 | 手工求解或数值求解 |
| 4. 对数线性化 | 在稳态附近做对数线性近似 | Uhlig方法或自动微分 |
| 5. 求解理性预期 | 将模型转为状态空间形式 | Blanchard-Kahn条件 |
| 6. 脉冲响应 | 计算冲击的动态效应 | 脉冲响应函数（IRF） |
| 7. 方差分解 | 分解各冲击对波动的贡献 | 理论方差分解 |

Dynare是求解DSGE模型最常用的工具。一个典型的Dynare模型文件结构：

```matlab
% RBC model in Dynare
var y c k z;
varexo e;
parameters alpha beta delta rho sigma;
model;
c + k - (1-delta)*k(-1) = exp(z)*k(-1)^alpha;
c^(-sigma) = beta*c(+1)^(-sigma)*(alpha*exp(z(+1))*k^...
    (alpha-1) + 1 - delta);
log(z) = rho*log(z(-1)) + e;
end;
steady; stoch_simul(irf=40);
```

> Dynare是宏观经济学家的"Stata"。你不需要自己写200行MATLAB代码做对数线性化和求解——Dynare帮你自动完成。但你需要理解每一步在做什么，否则当Dynare报错时你完全不知道怎么修。

## 5.5 异质性主体宏观模型：HANK模型

传统的RBC和DSGE模型使用"代表性主体"（Representative Agent）假设——所有消费者相同，所有企业相同。这个假设大大简化了计算，但也丢失了重要的信息：异质性（Heterogeneity）。

HANK模型（Heterogeneous Agent New Keynesian Model）是宏观经济学的前沿。它在标准新凯恩斯框架中引入了消费者异质性——不同的财富水平、不同的收入冲击、不同的流动性约束。

HANK与标准NK模型的关键区别：

| 维度 | 标准NK模型 | HANK模型 |
|------|----------|---------|
| 消费者 | 单一代表性主体 | 异质性主体（Aiyagari型） |
| 收入冲击 | 无 | idiosyncratic劳动收入冲击 |
| 资产市场 | 完全 | 不完全（只有一种无风险资产） |
| 货币政策传导 | 跨期替代渠道 | 跨期替代 + 一般均衡收入效应 + 间接效应 |
| 计算 | 对数线性化 | 全局方法或二阶近似 |

HANK模型的核心创新是改变了货币政策传导机制。在标准NK模型中，利率变化通过跨期替代影响消费——利率下降，消费者减少储蓄增加消费。在HANK模型中，这个渠道很弱（因为富裕消费者的跨期替代弹性通常很小），但利率变化通过更间接的渠道影响消费——利率下降→产出增加→劳动收入增加→手到口消费者（Hand-to-Mouth Consumers）消费增加。

> HANK模型告诉你：货币政策之所以有效，不是因为富裕的人多消费了，而是因为低收入者的收入增加了。这个洞察改变了对货币政策传导机制的理解。

## 5.6 货币与财政政策分析：泰勒规则、财政乘数

宏观经济学最终要回答的问题之一是：政策有效吗？怎么有效？

**泰勒规则（Taylor Rule, 1993）**

泰勒规则是货币政策最著名的经验规则。它描述央行如何根据通胀和产出缺口调整名义利率：

```
i_t = r* + π_t + φ_π*(π_t - π*) + φ_y*(y_t - y_t*)
```

其中i是名义利率，r*是均衡实际利率，π是通胀率，π*是目标通胀率，y-y*是产出缺口，φ_π和φ_y是反应系数。

| 参数 | 经验值 | 含义 |
|------|-------|------|
| φ_π | 1.5 | 通胀上升1个百分点，利率上升1.5个百分点 |
| φ_y | 0.5 | 产出缺口1个百分点，利率上升0.5个百分点 |
| π* | 2% | 目标通胀率 |

Taylor原则：φ_π > 1是保证均衡确定性的关键条件。如果φ_π < 1，通胀上升时实际利率下降，进一步刺激通胀，导致"自我实现的预期"（Self-fulfilling Expectations）和"太阳黑子均衡"（Sunspot Equilibria）。

**财政乘数（Fiscal Multiplier）**

财政乘数衡量政府支出增加对总产出的影响。它是财政政策分析的核心概念。

| 模型 | 乘数大小 | 原因 |
|------|---------|------|
| Keynesian乘数 | 1/(1-MPC) > 1 | 消费-收入正反馈 |
| 拉姆齐模型 | <1 | 挤出效应（利率上升，投资下降） |
| 零利率下限（ZLB） | >1 | 货币政策不挤兑财政政策 |
| HANK模型 | 视分布而定 | 手到口消费者放大乘数 |

## 总结

高级宏观经济学从索洛模型出发，经过拉姆齐模型、RBC模型、新凯恩斯DSGE模型，一直到HANK模型，构建了一套理解经济波动和增长的完整理论框架。这个框架的核心特征是：基于微观最优化，用动态规划求解，用数值方法分析。

数学上，宏观经济学是三高课程中最密集的——动态规划、数值方法、马尔可夫链、状态空间表示，每一项都需要扎实的数学基础。但宏观经济学也是最"接地气"的——每一个模型都直接对应一个现实问题：为什么有经济衰退？货币政策有效吗？财政刺激的乘数有多大？
