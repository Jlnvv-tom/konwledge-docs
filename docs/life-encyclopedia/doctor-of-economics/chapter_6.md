# 第6章：计量经济学课程精解——从OLS到因果推断

你以为计量就是跑回归？现代计量经济学的核心是因果识别，不是统计显著。

我是怕浪猫，一个在计量经济学课上被矩条件折磨过、在实证研究中被内生性问题困扰过的人。高级计量经济学是经济学博士方法论训练的核心——它不只是教你跑回归，而是教你如何从观测数据中识别因果关系。

这一章，怕浪猫把高级计量经济学的六大模块讲透：经典线性回归、MLE与GMM、工具变量与2SLS、面板数据、因果推断前沿、机器学习与计量经济学的交叉。

## 6.1 经典线性回归：矩阵形式OLS、高斯-马尔可夫定理

OLS（Ordinary Least Squares，普通最小二乘法）是计量经济学的起点。博士级别的OLS与本科的区别在于：本科用求和符号，博士用矩阵；本科背假设，博士推导假设的数学含义。

**矩阵形式OLS**

给定y = Xβ + ε，OLS估计量为：

```
β̂ = (X'X)⁻¹X'y
```

这个表达式的推导只需要一个假设：X'X可逆（即X列满秩）。其他假设（外生性、同方差、无自相关）不影响估计量的计算，只影响估计量的性质。

| 假设 | 数学表达 | 影响 |
|------|---------|------|
| 线性性 | y = Xβ + ε | 模型设定 |
| 满秩 | rank(X) = k | 估计量存在 |
| 外生性 | E[ε|X] = 0 | 一致性 |
| 同方差 | Var(ε|X) = σ²I | 标准误有效 |
| 无自相关 | E[εε'|X] = 0 | 标准误有效 |
| 正态性 | ε|X ~ N(0, σ²I) | 精确推断 |

**高斯-马尔可夫定理（Gauss-Markov Theorem）**

高斯-马尔可夫定理：在外生性、同方差、无自相关假设下，OLS估计量是最佳线性无偏估计量（BLUE, Best Linear Unbiased Estimator）。

| 性质 | 条件 | 含义 |
|------|------|------|
| 无偏性 | E[ε\|X]=0 | E[β̂]=β |
| 一致性 | E[ε\|X]=0 | β̂ → β (plim) |
| 有效性 | 同方差+无自相关 | Var(β̂)最小 |
| 渐近正态性 | 独立同分布+方差有限 | √n(β̂-β) →d N(0, V) |

> 高斯-马尔可夫定理不是告诉你OLS"最好"，而是告诉你：在一组特定假设下，OLS是最佳线性无偏估计。如果假设不满足——比如有异方差或内生性——OLS虽然无偏但不再有效，甚至可能不一致。

当同方差假设不满足时，需要使用异方差稳健标准误（Heteroskedasticity-Robust Standard Errors），即White标准误：

```
V̂_robust = (X'X)⁻¹ X' diag(ε̂²) X (X'X)⁻¹
```

Stata中只需一个选项即可实现：

```stata
reg y x1 x2 x3, robust
```

## 6.2 极大似然估计与广义矩估计：MLE、GMM

OLS只是线性回归的估计方法。当模型非线性或分布已知时，需要更一般的估计框架。

**MLE（Maximum Likelihood Estimation，极大似然估计）**

MLE的核心思想：选择使观测数据出现概率最大的参数。

| 模型 | 似然函数 | 应用场景 |
|------|---------|---------|
| 线性回归（正态误差） | L = Π (2πσ²)^(-1/2) exp(-ε²/2σ²) | 连续因变量 |
| Logit | L = Π p_i^y_i (1-p_i)^(1-y_i) | 二元选择 |
| Probit | L = Π Φ(x_i'β)^y_i [1-Φ(x_i'β)]^(1-y_i) | 二元选择 |
| Tobit | 混合密度 | 截断/删失数据 |
| Poisson | L = Π e^(-λ_i) λ_i^y_i / y_i! | 计数数据 |

MLE的性质：

| 性质 | 条件 | 含义 |
|------|------|------|
| 一致性 | 模型正确设定 | β̂_MLE → β |
| 渐近正态性 | 正则条件 | √n(β̂-β) →d N(0, I⁻¹) |
| 渐近有效性 | 模型正确设定 | 方差达到Cramer-Rao下界 |
| 不变性 | 参数变换 | β̂的函数 = 函数的MLE |

> MLE的最大优势是渐近有效——如果模型设定正确，没有其他估计量比MLE的渐近方差更小。但它的最大风险是：如果分布假设错误，MLE可能不一致。这就是为什么经济学家也喜欢GMM——它不需要指定完整分布。

**GMM（Generalized Method of Moments，广义矩估计）**

GMM由Hansen在1982年提出，是计量经济学最通用的估计框架。

GMM的核心思想：如果模型正确，存在一组矩条件E[g(z,β₀)]=0。GMM通过最小化矩条件的样本对应物来估计β。

| 步骤 | 操作 | 数学表达 |
|------|------|---------|
| 1. 设定矩条件 | 从模型推导矩条件 | E[g(z,β₀)]=0 |
| 2. 选择加权矩阵 | 决定矩条件的权重 | W |
| 3. 最小化目标函数 | J = ḡ(β)' W ḡ(β) | β̂_GMM = argmin J |
| 4. 检验过度识别 | J统计量 | χ²检验 |

GMM的统一性：OLS、IV、2SLS都是GMM的特例。

| 估计方法 | 矩条件 | 加权矩阵 |
|---------|-------|---------|
| OLS | E[X'(y-Xβ)]=0 | (X'X)⁻¹ |
| IV | E[Z'(y-Xβ)]=0 | (Z'Z)⁻¹ |
| 2SLS | E[Z'(y-Xβ)]=0 | 最优加权矩阵 |
| MLE | 得分函数E[s(β)]=0 | 信息矩阵的逆 |

两步GMM的操作步骤：

```stata
* 第一步：用单位矩阵作为加权矩阵
gmm (y - {xb:x1 x2 _cons}), instruments(z1 z2) wmatrix(identity)
* 第二步：用第一步的矩条件协方差作为加权矩阵
gmm (y - {xb:x1 x2 _cons}), instruments(z1 z2) wmatrix(robust) twostep
```

> GMM的美在于它把所有计量方法统一在一个框架下。理解了GMM，你就理解了计量经济学的"通用语言"。Hansen因为这个贡献获得了2024年诺贝尔经济学奖。

## 6.3 工具变量与两阶段最小二乘：IV、2SLS、LATE

内生性（Endogeneity）是实证研究面临的最大挑战。当E[ε|X]≠0时，OLS不一致，需要用工具变量来解决。

**内生性的来源**

| 来源 | 例子 | 后果 |
|------|------|------|
| 遗漏变量 | 能力影响工资但不可观测 | OLS有偏 |
| 联立性 | 供需同时决定价格和数量 | OLS有偏 |
| 测量误差 | 自报收入有误差 | OLS向零衰减 |
| 样本选择 | 只观测到就业者的工资 | 选择偏差 |

**IV（Instrumental Variables，工具变量）**

一个好的工具变量需要满足两个条件：

| 条件 | 含义 | 检验方法 |
|------|------|---------|
| 相关性 | IV与内生解释变量相关 | 第一阶段F统计量>10 |
| 外生性 | IV与误差项不相关 | 过度识别检验（需过度识别） |

> 找工具变量是实证经济学家最有"创造力"的工作。Angrist用出生季度作为教育的工具变量——因为义务教育法规定孩子满6岁入学，但出生季度不同导致不同季节出生的人受教育时间不同。这个工具变量巧妙且合理，是经济学工具变量的经典案例。

**2SLS（Two-Stage Least Squares，两阶段最小二乘）**

2SLS是IV估计最常用的实现方式：

第一阶段：用工具变量Z解释内生变量X

```
X = Zπ + v  →  X̂ = Zπ̂
```

第二阶段：用X̂代替X回归

```
y = X̂β + ε  →  β̂_2SLS
```

Stata实现：

```stata
* 2SLS
ivregress 2sls y (x1 = z1 z2) x2 x3, robust
* 或使用ivreg2获得更多诊断
ivreg2 y (x1 = z1 z2) x2 x3, robust first
```

**LATE（Local Average Treatment Effect，局部平均处理效应）**

Imbens和Angrist在1994年证明：IV估计量识别的不是平均处理效应（ATE），而是"局部平均处理效应"——只对工具变量影响其行为的人群（compliers）有效的处理效应。

| 类型 | 定义 | 特征 |
|------|------|------|
| 总是接受者 | 无论IV如何都接受处理 | IV不影响其行为 |
| 从不接受者 | 无论IV如何都不接受处理 | IV不影响其行为 |
| 顺从者 | IV影响其是否接受处理 | IV的作用对象 |
| 叛逆者 | IV使其做相反行为 | 违反单调性假设，不允许存在 |

> LATE的深刻含义是：IV估计的因果效应不能简单推广到全人群。如果你的工具变量只影响一部分人的行为，你估计的因果效应也只适用于这部分人。这个认知改变了经济学家对IV结果的理解方式。

## 6.4 面板数据方法：固定效应、随机效应

面板数据（Panel Data）同时具有截面维度和时间维度，能控制不可观测的个体异质性。

| 数据类型 | 维度 | 优势 | 局限 |
|---------|------|------|------|
| 截面数据 | N×1 | 简单 | 无法控制个体异质性 |
| 时间序列 | 1×T | 动态分析 | 无法控制个体差异 |
| 面板数据 | N×T | 控制个体异质性 | 数据获取困难 |

**固定效应（Fixed Effects, FE）模型**

固定效应模型通过加入个体虚拟变量（或组内去均值）来控制不可观测的不随时间变化的个体特征：

```
y_it = α_i + x_it'β + ε_it
```

其中α_i是个体固定效应，吸收所有不随时间变化的个体特征（如能力、性格、地理位置）。

| 模型 | 假设 | 估计方法 | 适用场景 |
|------|------|---------|---------|
| 固定效应 | α_i与x相关 | 组内变换或LSDV | 不可观测异质性与x相关 |
| 随机效应 | α_i与x不相关 | GLS | 不可观测异质性与x不相关 |
| 随机效应 Mundlak | α_i = x̄'γ + u | Correlated RE | 兼容FE和RE |

Hausman检验：如果H₀（α_i与x不相关）成立，FE和RE都一致但RE更有效。如果H₀不成立，只有FE一致。因此实际中大多直接用FE。

> 面板数据的核心价值是"控制不可观测的异质性"。你不需要观测到所有混淆变量——只要它们不随时间变化，固定效应就能控制它们。这是面板数据比截面数据强大的根本原因。

固定效应在Stata中的实现：

```stata
* 固定效应
reghdfe y x1 x2, absorb(id year) cluster(id)
* absorb同时控制个体和年份固定效应
* cluster(id)聚类标准误到个体层面
```

## 6.5 因果推断前沿：DID、RDD、合成控制法

现代计量经济学的核心已从"估计参数"转向"识别因果效应"。以下是三种最重要的因果推断方法。

**双重差分（Difference-in-Differences, DID）**

DID通过比较处理组和对照组在政策变化前后的差异来识别因果效应。

```
δ̂ = (Ȳ_T,post - Ȳ_T,pre) - (Ȳ_C,post - Ȳ_C,pre)
```

| 假设 | 内容 | 检验方法 |
|------|------|---------|
| 平行趋势 | 无政策时两组变化趋势相同 | 事前趋势检验 |
| 无预期效应 | 政策实施前行为不变 | 安慰剂检验 |
| 稳定单位处理值 | 无溢出效应 | 理论论证 |
| 无同期冲击 | 政策期内无其他混淆冲击 | 安慰剂检验 |

Card和Krueger在1994年用DID研究最低工资对就业的影响，是因果推断的经典案例。他们比较了新泽西州（提高最低工资）和宾夕法尼亚州（未提高）的快餐店就业变化，发现最低工资提高并未减少就业——这颠覆了传统经济学对最低工资的认知。

**断点回归（Regression Discontinuity Design, RDD）**

RDD利用某个running variable的阈值来识别因果效应。阈值以上的个体接受处理，以下的不接受。

| 类型 | 设计 | 识别 | 例子 |
|------|------|------|------|
| 锐断点 | 阈值处处理概率从0跳到1 | 阈值处的局部ATE | 助学金门槛 |
| 模糊断点 | 阈值处处理概率跳变但不为0/1 | LATE | 选举获胜阈值 |

RDD的图形分析：

```r
# R中的RDD实现
library(rdrobust)
rdrobust(y, x, c=0, p=1, kernel="triangular", bwselect="mserd")
# y=结果变量, x=running variable, c=断点位置
# p=多项式阶数, kernel=核函数, bwselect=带宽选择方法
```

> RDD被称为"准实验中最接近随机对照试验"的方法。因为在断点附近，个体几乎等同于随机分配到处理组或对照组。Lee利用选举中"以微弱优势获胜"的断点，研究了政党连任对政策的影响——这个设计极其巧妙。

**合成控制法（Synthetic Control Method, SCM）**

SCM由Abadie等人在2010年提出，适用于单一处理单元的政策评估。它通过加权组合多个控制单元来"合成"一个与处理单元相似的对照组。

| 步骤 | 操作 | 要点 |
|------|------|------|
| 1. 选择预测变量 | 确定匹配维度 | 选政策前相关变量 |
| 2. 计算权重 | 最小化处理前差异 | 非负权重和为1 |
| 3. 构建合成对照 | 加权平均控制单元 | 模拟"反事实" |
| 4. 计算效应 | 处理 - 合成对照 | 政策因果效应 |
| 5. 安慰剂检验 | 对每个控制单元做同样操作 | 排列检验 |

## 6.6 机器学习与计量经济学的交叉：Lasso、双重机器学习

机器学习与计量经济学的交叉是近年来的前沿领域。两者的核心区别在于目标不同：计量经济学关注因果识别和推断，机器学习关注预测。

| 维度 | 计量经济学 | 机器学习 |
|------|----------|---------|
| 目标 | 因果效应 | 预测精度 |
| 关键假设 | 外生性、识别策略 | 交叉验证 |
| 标准误 | 核心输出 | 通常不关注 |
| 模型选择 | 理论驱动 | 数据驱动 |
| 过拟合 | 通过设定避免 | 通过正则化避免 |

**Lasso回归**

Lasso（Least Absolute Shrinkage and Selection Operator）通过L1正则化实现变量选择和参数估计同时进行：

```
min Σ(y_i - x_i'β)² + λΣ|β_j|
```

在计量经济学中，Lasso主要用于高维控制变量的选择——当控制变量很多时，用Lasso选择最相关的控制变量，再做因果估计。

**双重机器学习（Double Machine Learning, DML）**

DML由Chernozhukov等人在2018年提出，用机器学习方法处理高维混淆变量，同时保持因果推断的有效性。

DML的三步流程：

| 步骤 | 操作 | 作用 |
|------|------|------|
| 1. 用ML估计混淆函数 | 分别用X预测Y和D | 残差化 |
| 2. 用残差做回归 | Y_res on D_res | 消除混淆偏差 |
| 3. 交叉拟合 | 样本分半交替估计 | 避免过拟合 |

```python
# Python中DML的实现
from econml.dml import LinearDML
est = LinearDML(model_y=RandomForestRegressor(),
                model_t=RandomForestRegressor())
est.fit(Y, T, X=X)  # Y=结果, T=处理, X=控制变量
ate = est.ate(X)
```

> DML的革命性在于：它让你可以用机器学习处理高维控制变量，同时保持因果推断的统计性质。这在过去是不可能的——传统计量要么选择少量控制变量（可能遗漏），要么放入所有变量（过拟合）。DML通过交叉拟合和双重残差化解决了这个困境。

## 6种因果推断方法对比表

| 方法 | 识别假设 | 适用场景 | 优势 | 劣势 |
|------|---------|---------|------|------|
| RCT | 随机分配 | 可实验的场景 | 金标准 | 伦理/成本限制 |
| IV | 相关性+外生性 | 有好工具变量 | 解决内生性 | 好IV难找，识别LATE |
| DID | 平行趋势 | 政策时间差异 | 直观，易理解 | 平行趋势难验证 |
| RDD | 阈值附近随机 | 有明确阈值 | 最接近RCT | 效应局部，外部效度有限 |
| SCM | 合成对照匹配 | 单一处理单元 | 透明直观 | 需要好的控制池 |
| DML | 双重稳健 | 高维混淆变量 | 灵活，数据驱动 | 需要大样本 |

## 总结

计量经济学的核心不是"跑回归"，而是"做推断"。从OLS到GMM，从IV到因果推断前沿，每一步都是方法论工具的升级。理解这些方法的假设条件、适用场景和局限性，比会写代码重要得多。

因果推断革命改变了经济学研究的方式。二十年前，经济学家还在争论"这个回归系数显著不显著"。今天，经济学家讨论的是"这个识别策略可信不可信"。这个转变的核心是：统计显著不等于因果显著，相关不等于因果。
