# 第9章：核心实验室与数据训练——从Stata到Dynare

一个经济学博士的数据分析能力，决定了她能不能独立做研究。

我是怕浪猫，一个在数据室里泡了几年、从Stata菜鸟到能独立构建DSGE模型的人。经济学博士的训练不只是上课读论文，更重要的是动手做——处理数据、估计模型、跑模拟、做图表。这些"动手"能力需要在实验室和项目中训练。

这一章，怕浪猫把经济学博士的核心工具、实验室类型和5个必做训练项目讲透。

## 9.1 软件工具矩阵：Stata、R、Python、MATLAB、Dynare

经济学博士需要掌握多种软件工具。不同工具有不同的定位和适用场景，选错工具会事倍功半。

| 工具 | 定位 | 优势 | 劣势 | 适用场景 |
|------|------|------|------|---------|
| Stata | 应用计量标配 | 简单易用、命令统一 | 付费、数据处理弱 | 微观实证、面板数据 |
| R | 统计计算 | 免费、包丰富、灵活 | 学习曲线陡 | 统计分析、数据可视化 |
| Python | 通用编程 | 免费、生态强大、ML集成 | 计量包不如Stata成熟 | 数据抓取、机器学习 |
| MATLAB | 数值计算 | 矩阵运算强、速度快 | 付费、语法旧 | 宏观模型、动态规划 |
| Dynare | DSGE求解 | 专为DSGE设计 | 需要MATLAB/Octave | 宏观模型求解 |
| Julia | 高性能计算 | 速度快、语法现代 | 生态小、用户少 | 大规模数值计算 |

**Stata：应用计量的标配**

Stata是经济学界使用最广泛的计量软件。大多数微观实证论文的回归分析都是用Stata做的。

| 功能 | 命令 | 用途 |
|------|------|------|
| OLS | reg y x, robust | 基本回归 |
| 面板FE | reghdfe y x, absorb(id year) | 固定效应 |
| 2SLS | ivregress 2sls y (x=z) | 工具变量 |
| DID | did_multiplegt | 双重差分 |
| RDD | rdrobust y x, c(0) | 断点回归 |
| GMM | gmm | 广义矩估计 |
| Logit/Probit | logit/probit y x | 二元选择 |

> Stata的核心优势是"统一性"——所有命令遵循相似的语法结构，学会一个命令就很容易举一反三。加上reghdfe、ivreg2、estout等用户贡献的ado包，Stata几乎能处理所有应用计量需求。

Stata数据处理的核心命令速查：

```stata
* 数据合并
merge 1:1 id year using "data2.dta"
* 分组统计
egen mean_y = mean(y), by(id)
* 生成滞后项
tsset id year
gen lag_y = L.y
* 生成差分
gen d_y = D.y
* 崩塌到更高层级
collapse (mean) y x1 x2, by(state year)
```

**R：统计计算与可视化**

R在经济学界的地位越来越重要，特别是在统计分析和数据可视化方面。

| R包 | 用途 | Stata对应 |
|------|------|----------|
| lm_robust (estimatr) | 稳健标准误OLS | reg, robust |
| felm (lfe) | 高维固定效应 | reghdfe |
| plm | 面板数据 | xtreg |
| rdrobust | 断点回归 | rdrobust |
| ggplot2 | 数据可视化 | 无（Stata图形功能弱） |
| fixest | 快速固定效应 | reghdfe |
| modelsummary | 回归表格 | estout/esttab |

> R的最大优势是ggplot2——经济学论文中最好看的图几乎都是R画的。Stata的图形功能虽然够用，但美观度和灵活性远不如ggplot2。

**Python：数据抓取与机器学习**

Python在经济学中的应用场景：

| 场景 | Python库 | 用途 |
|------|---------|------|
| 数据抓取 | requests, BeautifulSoup | 网页数据采集 |
| 数据处理 | pandas | 类似Stata的数据操作 |
| 机器学习 | scikit-learn | 预测、分类 |
| 深度学习 | PyTorch, TensorFlow | 复杂ML模型 |
| 文本分析 | NLTK, spaCy | NLP处理 |
| 因果ML | econml | DML等因果机器学习 |

**MATLAB + Dynare：宏观模型标配**

MATLAB和Dynare是宏观经济学家的标准工具组合。

| 功能 | MATLAB | Dynare |
|------|--------|--------|
| 值函数迭代 | 手写代码 | 不需要 |
| DSGE求解 | 手写或用工具箱 | 自动求解 |
| 脉冲响应 | 手写 | 自动生成 |
| 贝叶斯估计 | 手写 | 自动完成 |
| 参数校准 | 手写 | 手动设定 |

Dynare的基本工作流：

```matlab
% 1. 定义变量
var y c k z;
varexo e;
parameters alpha beta delta rho;

% 2. 写模型方程
model;
c + k - (1-delta)*k(-1) = exp(z)*k(-1)^alpha;
c^(-1) = beta*c(+1)^(-1)*(alpha*exp(z(+1))*k^(alpha-1)+1-delta);
log(z) = rho*log(z(-1)) + e;
end;

% 3. 校准参数
alpha = 0.33; beta = 0.96; delta = 0.08; rho = 0.95;

% 4. 求稳态
steady;

% 5. 求解和模拟
stoch_simul(order=1, irf=40);
```

## 9.2 五大实验室类型：实验、田野、计算、调查、微观模拟

经济学博士的"实验室"不只是有电脑的房间。它是一个完整的研究基础设施，包括数据、方法、工具和网络。

**实验室类型1：实验经济学实验室**

实验经济学实验室用于在受控环境下测试经济理论。

| 要素 | 内容 |
|------|------|
| 设施 | 计算机网络、隔离座位、实验软件（如z-Tree, oTree） |
| 研究方法 | 受控实验、博弈实验、市场实验 |
| 优势 | 因果识别最强（真正的随机实验） |
| 局限 | 外部效度问题（实验室≠现实） |
| 代表学者 | Vernon Smith, Ernst Fehr |

**实验室类型2：田野研究**

田野研究在真实环境中进行，结合了实验的控制性和观测数据的现实性。

| 类型 | 特征 | 例子 |
|------|------|------|
| 纯田野实验 | 随机分配+真实环境 | 随机发放小额信贷 |
| 框架田野实验 | 真实环境但受试者知道在实验 | 课堂实验 |
| 自然田野实验 | 受试者不知道在实验 | 税收提醒信随机化 |

**实验室类型3：计算实验室**

计算实验室用数值模拟方法研究复杂经济系统。

| 方法 | 用途 | 工具 |
|------|------|------|
| Agent-Based Modeling | 模拟异质性主体互动 | NetLogo, Mesa |
| DSGE模拟 | 模拟宏观政策效应 | Dynare |
| 校准与反事实模拟 | 量化模型的政策实验 | MATLAB |

**实验室类型4：调查数据实验室**

调查数据是微观实证研究的重要数据来源。

| 数据类型 | 代表数据 | 覆盖内容 | 获取方式 |
|---------|---------|---------|---------|
| 家庭面板 | PSID, CFPS, CHFS | 收入、消费、财富 | 申请或公开下载 |
| 劳动力调查 | CPS, LFS | 就业、工资、工时 | 公开下载 |
| 企业面板 | Compustat, LBD | 企业财务、就业 | 付费或申请 |
| 行政数据 | 税收记录、社保记录 | 精确的收入和就业 | 需政府合作 |

**实验室类型5：微观模拟实验室**

微观模拟（Microsimulation）用个体层面数据模拟政策变化的影响。

| 方法 | 原理 | 应用 |
|------|------|------|
| 静态微观模拟 | 政策变化后直接重新计算 | 税收改革影响 |
| 动态微观模拟 | 模拟个体行为响应 | 退休决策、劳动力供给 |
| 行为微观模拟 | 估计行为弹性后模拟 | 福利改革影响 |

## 9.3 5个必做训练项目

以下是5个覆盖不同技能的必做训练项目。每个项目都对应一种核心研究能力。

**项目1：复现一篇经典论文**

| 要素 | 内容 |
|------|------|
| 目标 | 从原始数据开始，复现论文的核心结果 |
| 推荐论文 | Card-Krueger (1994) 或 Angrist-Krueger (1991) |
| 技能训练 | 数据处理、回归分析、稳健性检验 |
| 工具 | Stata或R |
| 时间 | 2-3周 |
| 验收标准 | 复现表格与原文一致 |

> 复现是学习实证研究的最佳方式。通过复现，你不仅学会了方法，还体会到了研究过程中的所有细节——数据清洗、变量构造、样本选择、稳健性检验。这些细节在论文里看不到，但决定了研究的质量。

**项目2：构建并求解一个RBC模型**

| 要素 | 内容 |
|------|------|
| 目标 | 从模型设定到脉冲响应函数 |
| 技能训练 | 动态规划、对数线性化、Dynare操作 |
| 工具 | MATLAB + Dynare |
| 时间 | 2-3周 |
| 验收标准 | IRF图形合理，Blanchard-Kahn条件满足 |

关键步骤：

```
1. 写出消费者和厂商的最优化问题
2. 求一阶条件和市场出清条件
3. 手工求稳态
4. 写Dynare模型文件
5. 运行stoch_simul，获得IRF
6. 检查IRF是否符合经济学直觉
7. 做敏感性分析（改变参数）
```

**项目3：用DID做一个政策评估**

| 要素 | 内容 |
|------|------|
| 目标 | 用DID方法评估一个真实政策 |
| 推荐政策 | 限购政策、教育改革、最低工资 |
| 技能训练 | 面板数据处理、DID估计、平行趋势检验 |
| 工具 | Stata |
| 时间 | 3-4周 |
| 验收标准 | 回归结果+平行趋势图+安慰剂检验 |

**项目4：用IV估计一个因果效应**

| 要素 | 内容 |
|------|------|
| 目标 | 用IV方法解决一个内生性问题 |
| 推荐题目 | 教育回报、邻居效应、移民影响 |
| 技能训练 | IV估计、第一阶段诊断、过度识别检验 |
| 工具 | Stata或R |
| 时间 | 3-4周 |
| 验收标准 | 第一阶段F>10+合理的外生性论证 |

**项目5：用机器学习做预测**

| 要素 | 内容 |
|------|------|
| 目标 | 用ML方法预测一个经济变量 |
| 推荐题目 | 房价预测、违约预测、收入预测 |
| 技能训练 | 数据分割、交叉验证、模型比较 |
| 工具 | Python (scikit-learn) |
| 时间 | 2-3周 |
| 验收标准 | 交叉验证误差合理+特征重要性分析 |

> 这5个项目覆盖了经济学博士需要的主要技能：实证分析（项目1、3、4）、理论建模（项目2）、机器学习（项目5）。做完这5个项目，你的研究技能就达到了"可以独立做研究"的门槛。

## 9.5 数据处理核心原则

| 原则 | 内容 | 原因 |
|------|------|------|
| 可复现性 | 所有数据处理步骤用代码记录 | 他人（和未来的你）能复现 |
| 版本控制 | 用Git管理代码和数据版本 | 追踪修改历史 |
| 文档化 | 每步数据处理都有注释 | 半年后你还看得懂 |
| 原始数据不动 | 永远不对原始数据做修改 | 保留数据源头 |
| 脚本化 | 从原始数据到最终表格全用脚本 | 避免手动操作出错 |

> 数据处理的核心原则是"可复现"。你的研究从原始数据到最终回归表格的每一步都应该用代码记录，任何人拿到你的代码和数据应该能复现你的结果。这不仅是学术规范，也是好习惯——半年后你回来修改论文时，如果没有代码记录，你完全不记得当时怎么处理的。

## 工具选择决策树

```
研究需求
├── 微观实证（截面/面板）
│   ├── 简单回归 → Stata
│   ├── 复杂图表 → R (ggplot2)
│   └── 大数据/ML → Python
├── 宏观建模
│   ├── DSGE → MATLAB + Dynare
│   ├── 值函数迭代 → MATLAB
│   └── Agent-Based → Python/NetLogo
├── 理论建模
│   └── 解析推导 → 纸笔 + LaTeX
└── 数据获取
    ├── 公开数据 → Python (requests/pandas)
    ├── API数据 → Python/R
    └── 文本数据 → Python (NLTK/spaCy)
```

## 总结

工具是研究的"手脚"。Stata帮你快速做回归分析，R帮你画出漂亮的图表，Python帮你处理大数据和机器学习，MATLAB+Dynare帮你求解宏观模型。每个工具有自己的定位，掌握多个工具让你在面对不同研究问题时游刃有余。

但记住：工具是手段，不是目的。一个用Stata做DID做得好的研究，远比一个用Python做DML但研究设计有缺陷的研究有价值。选对工具很重要，但更重要的是研究问题本身和识别策略。
