# 第025章：赵铁匠走了

## 细纲
- 核心事件：赵铁匠在河边安详离世，林远在他坟前放了锤子的铁屑
- 字数目标：2500字
- 目标情绪：感伤→释然
- 章尾钩子：林远在碑前发现树根已经包了碑面的三分之一

### 情节安排
1. 回来后第十二年。赵铁匠五十二。在河边走的时候摔了【铺垫·密200】
2. 林远照顾他三天。赵铁匠说了最后一句话【情绪·密300】
3. 赵铁匠走了。林远在他坟前放了铁屑【情绪·密250】
4. 林远把赵铁匠的锤子收回茅屋——和铜刻刀放在一起【铺垫·密200】
5. 去碑前看。树根已包碑面三分之一【钩子·密200】

预算合计：2500字
