# 全书大纲

## 全书体量与阶段总览
- 全书总章节数：约45章
- 目标字数：10万字
- 全书情绪曲线：惊奇→沉浸→痛苦→绝望→震撼→意难平

### 阶段划分
1. 开篇期（第1-10章，约25%）：穿越降临、接触现代、安置适应；情绪基调 惊奇/困惑
2. 发展期（第11-25章，约35%）：十年学习、群像分化、羁绊建立、预兆显现；情绪基调 沉浸/不安
3. 高潮期（第26-35章，约25%）：归乡、知识错位、绝望尝试；情绪基调 痛苦/绝望
4. 收尾期（第36-45章，约15%）：闭环揭示、刻碑、余韵；情绪基调 震撼/意难平

## 卷级大纲

### 第一卷：天外来客（约2.5万字，10章）
- 功能：穿越降临、建立世界、埋主线钩子
- 核心事件：槐安村1200人穿越到2026年上海郊区，与现代社会接触，被政府安置
- 起始→结束：林远从古代书生→刚接触现代世界的惊恐少年
- 关键节点：第1章穿越、第3章接触现代人、第5章政府介入、第8章开始学编程

### 第二卷：十年饮冰（约3.5万字，15章）
- 功能：学习深化、群像展开、羁绊建立、埋闭环伏笔
- 核心事件：林远在方老师门下学AI；赵铁匠学冶金；村民分化；发现考古异常
- 起始→结束：林远从初学者→AI实验室研究员；村民从惊恐→半融入
- 关键节点：第12章三年后时间跳跃、第15章AI生成古汉语、第18章六年节点、第22章考古发现、第24章方老师说出传说

### 第三卷：不如归去（约2.5万字，10章）
- 功能：裂缝再现、归乡、知识错位
- 核心事件：十年期满裂缝重开，全村被迫归乡；回到古代后发现知识无法应用
- 起始→结束：林远从现代研究员→古代绝望的知识囚徒
- 关键节点：第26章预兆、第28章离别、第30章回到古代、第33章赵铁匠崩溃

### 第四卷：咬尾蛇（约1.5万字，10章）
- 功能：闭环揭示、刻碑、余韵
- 核心事件：林远发现"异常文物"就是他自己，接受闭环，刻碑埋下
- 起始→结束：林远从绝望→释然
- 关键节点：第36章挖出石碑、第38章对照笔记本、第40章理解闭环、第43章刻碑、第45章结尾余韵
