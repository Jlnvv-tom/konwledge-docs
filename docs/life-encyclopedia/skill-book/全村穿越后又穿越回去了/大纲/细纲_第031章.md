# 第031章：传播

## 细纲
- 核心事件：阿拉伯数字从槐安村传到镇上，再传到更远
- 字数目标：2500字
- 目标情绪：平静→微妙的自豪
- 章尾钩子：一个商人把数字带到了杭州

### 情节安排
1. 回来后第十五年。王小毛去镇上卖粮，带着账本【铺垫·密250】
2. 镇上的粮商看到阿拉伯数字记账，困惑但觉得方便【信息揭示·密300】
3. 粮商学了数字用法，开始用在自己的账本上【铺垫·密200】
4. 一年后数字从镇上传到县城。两个商人因为用数字对账省了时间【情绪·密250】
5. 三年后一个杭州商人来镇上采购，看到了数字，带回了杭州【钩子·密200】

预算合计：2500字
