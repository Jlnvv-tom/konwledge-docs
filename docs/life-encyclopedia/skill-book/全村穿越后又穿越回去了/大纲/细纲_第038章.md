# 第038章：数字走了

## 细纲
- 核心事件：阿拉伯数字从槐安村传到松江镇后又传到县城，林远听说了这件事
- 字数目标：2500字
- 目标情绪：平静→微妙的感慨
- 章尾钩子：林远在本子上写了一行字——"数字在走，不需要我"

### 情节安排
1. 回来后第十八年。王小毛从镇上回来说数字传到县城了【铺垫·密250】
2. 林远在本子上记了这个消息。然后想了很久【信息揭示·密300】
3. 他回忆上海——数字从1到9到10到100到1000——在屏幕上滚【情绪·密250】
4. 现在数字从泥地走到纸——从纸走到镇——从镇走到县【铺垫·密250】
5. 林远在本子上写"数字在走。不需要我"【钩子·密200】
