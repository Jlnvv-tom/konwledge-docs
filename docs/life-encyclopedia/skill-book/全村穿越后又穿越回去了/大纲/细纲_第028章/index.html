第028章：王家的媳妇

细纲​

  • 核心事件：穿越前第三年，王家的媳妇周兰在上海学做裁缝，差点不回去
  • 字数目标：2500字
  • 目标情绪：代入→意难平
  • 章尾钩子：周兰在裂缝前最后一刻跑回来了

情节安排​

  1. 周兰是王家媳妇。穿越前二十三。在上海学了缝纫【铺垫·密250】
  2. 她手巧，在上海找到了一家裁缝铺打工，学机器缝纫【信息揭示·密300】
  3. 铺子老板的儿子对她好——不是爱情，是善意【情绪·密250】
  4. 裂缝要开的时候她犹豫了——她有工作了有朋友了【冲突·密250】
  5. 最后时刻她抱着缝纫机踩出来的第一件衣服跑回裂缝【钩子·密200】
