第015章：竹简

竹子是林远自己去买的。

闵行花鸟市场。一家卖竹编制品的摊位。老板娘四十多岁，上海口音。林远问她有没有毛竹——竹简要用毛竹。竹肉厚，纤维致密，适合刻字。老板娘说"有"，从后面拖出来一根。已经处理过了——去皮，煮过，晾干。米黄色。表面光滑，有一股竹子的清香。

林远买了三根。老板娘帮他锯成竹片——每片长约25厘米，宽约2.5厘米。锯的时候林远在旁边看着。锯齿切入竹面的时候发出一种清脆的声音——"嚓嚓嚓"——和他在实验室里刻石头的"嚓"不一样。竹子有弹性，锯的时候竹片会跟着锯齿微微弯曲，像活的。

他把一捆竹片扛回了实验室。方远舟看了他一眼，没说话。方远舟这两天话变少了。不是不想说——是能说的话都说完了。碑文定好了。闭环确认了。裂缝在开。剩下的就是做。

刻刀的问题在第三片竹简的时候暴露了。

钨钢刀——方远舟从考古所借的——太硬了。刻石碑刚好。刻竹简的时候刀尖在竹面上滑——竹纤维有方向，顺着纤维方向刻的时候刀会跑偏。林远刻了五个字有三个歪了。

他停下来。看着竹简上歪掉的刻痕。这些歪痕一千年后会被碳化变黑。考古照片里那些字——他看过的——刻痕不歪。笔直。均匀。说明刻那些字的刀不一样。刀和竹面的咬合更好。

他给赵铁匠打了电话。不是微信——打电话。赵铁匠学手机的时候第一个学的是打电话。他打字慢，但说话快。

"赵叔。我要一把刀。刻竹子的。钨钢的太滑。"

赵铁匠在电话那头沉默了三秒。"竹子滑。得用铜的。铜软，咬得住。"

"你会打铜刀？"

"你给我铜料。我打。"

林远找到了铜料——实验室有一批铜片做对比实验用的。他拿了两片。一片黄铜，一片青铜。带去赵铁匠的工厂。

赵铁匠下班后在工厂的后院生了一炉。不是电炉——他不碰电炉了——是一个小炭炉。他找了工厂的铸造车间借的。炭炉点起来的时候火光映在他脸上。

他打铜刀的样子和十年前在槐安村打铁的样子一样。

赤着上身。锤子——他又把锤子从床头柜里拿出来了——在手里转了半圈，握住。铜片烧到暗红。放到砧子上。锤子落下去。"叮"。第一锤。铜片变薄了一点。翻面。第二锤。又薄了一点。

林远站在旁边看。

赵铁匠打了二十年铁。这是他在现代第一次打铁。不是电钻。不是电线。是铁锤打铜片。他打的是一把刀。

他打了半个小时。铜片被打成了一条长条——宽一指，厚两分。然后他在砂轮上磨——砂轮是工厂的，他借的。铜的磨削和铁不一样，火星少，铜屑是金色的，像碎金子。

刀磨好了。赵铁匠在刀背上刻了一个"赵"字。用他自己打的那把钨钢刀——方远舟借的那把——刻的。刻痕歪歪扭扭。赵铁匠打了一辈子铁，没学过写字。但他会刻自己的姓。

他把刀递给林远。"试试。"

林远接过来。铜刀比钨钢刀轻。握手处赵铁匠打了一个弧形——正好贴合掌心。刀尖窄，刀刃薄。

他在竹片上试了一刀。

不滑了。

铜的软硬度刚好——刀尖咬住竹纤维，不跑偏。刻痕干净。线条流畅。

"好刀。"林远说。

赵铁匠没说话。他在炉子旁边蹲下来，锤子放在脚边。火光暗了。他看着林远手里的铜刀。

林远开始刻第一片竹简。

1, 4, 9, 16, 25, 36, 49, 64, 81。

阿拉伯数字。他在竹面上一个一个刻。铜刀切入竹纤维的声音是"嚓"——比钨钢刀更沉。每刻一个数字他停一下，看一眼——有没有歪。没歪。继续。

十个数字。半个小时。

他看着竹简上的数字。一行横排。从左到右。这和古代竹简的书写习惯相反——古人从上到下竖排。但考古照片里的竹简就是横排的。他刻的内容来自未来。未来的习惯是从左到右。

第二片竹简：print("Hello World")

他刻得更慢。每个字母都要稳。p-r-i-n-t-(-"-H-e-l-l-o- -W-o-r-l-d-"-)。

铜刀在竹面上的声音变成了有节奏的"嚓嚓嚓"。每一个字母两到三刀。括号和引号各一刀。

刻完了。

他看着那行字。在竹简上。在古代的载体上。未来的语言。

你好，世界。

第三片竹简：数学公式。

勾股定理：a² + b² = c²。刻在竹简上半部分。

圆周率前二十位：3.14159265358979323846。刻在竹简中间。这行很长，字小。他刻了一个小时。

一元二次方程求根公式：x = (-b ± √(b²-4ac)) / 2a。刻在竹简下半部分。

三个公式。一片竹简。

他放下刀。手酸。手指上有铜的绿色痕迹——铜氧化了。竹粉粘在指缝里。

三片竹简。一行平方数列。一行代码。一行公式。

他拿手机拍了照片。然后把手机里的照片和考古报告的照片并排放在一起看。

竹简上的刻字——位置、大小、排列方向——对得上。不是完美对上——考古照片里的刻痕风化了一千年，模糊了。但能辨认的位置是对的。

他放下手机。

方远舟不知道什么时候进来的。站在他身后。也在看那三片竹简。

两个人站着。没说话。

竹简放在桌上。米黄色。刻痕是深色的——竹纤维被切断后氧化变深。一行平方数。一行代码。一行公式。

三片竹简。一段一千年的时间。

方远舟把手放在桌上。没碰竹简。碰了竹简旁边的桌面。

"和我照片里的一样。"他说。

林远点头。

"你还没回去。"方远舟说。"但这些东西已经——"

"已经在了。"林远说。"我已经刻了。在过去。"

方远舟看着竹简。然后他看着林远。

"你现在什么感觉？"

林远想了一会儿。

"和刻碑的时候不一样。刻碑的时候手在抖。刻竹简的时候不抖了。"

"为什么？"

"碑上是古训。是我写的。我写的字——'莫贪天外物，归时尽成空'——这句话陈婆婆念了八十八年。那句话有重量。刻的时候手在抖。"

"竹简呢？"

"竹简上是数字和代码。数字和代码没有感情。print("Hello World")就是一行代码。1到9的平方就是数列。它们不在意谁刻的。"

他顿了一下。

"但刻的时候——"

方远舟等着。

"刻的时候我想起第一天在教室里写第一行代码。按了F5。屏幕上出现Hello World。你好，世界。我在跟这个世界打招呼。"

他看着竹简上那行字。

"现在我把它刻在这里。等我回去——一千年后——有人挖到这行字。那时候'世界'已经不是2026年的世界了。是公元965年的世界。"

"你在跟965年的世界打招呼。"

"不是。"林远说。"我在跟一千年后的世界打招呼。世界收到我的招呼之后把我送回去了。然后我在竹简上把招呼刻下来。等一千年。世界再收到。"

他抬头看方远舟。

"这是一个循环的招呼。"

方远舟没有说话。

两个人在实验室的灯下站着。桌上三片竹简。一块石碑。刻刀。铜屑。竹粉。

窗外天黑了。

方远舟的手机响了。天文台的自动推送。他看了一眼。

"裂缝扩张速度增加了。上个月0.3%，这个月0.7%。"

林远看着方远舟。

"按这个速度，"方远舟说，"大概还有一年。"

一年。

他还有一年来准备。一年之后裂缝重新打开。全村一千二百人——不到一千二了，走了一些——要被送回去。

他还有一年。

竹简刻完了。碑文刻完了。他准备好了。

但他还有一件事没做。

他还没有跟方远舟告别。
