第029章：孩子

村里的孩子在上海上了三年学。

不是所有孩子——是十二个。帐篷区管理处和闵行区教育局协调的。槐安村的适龄儿童——七到十二岁——进了附近的一所小学。借读。没有学籍。但可以上课。

十二个孩子。穿 donated 的校服。坐在教室最后一排。一开始听不懂——上海话和普通话不一样，老师的语速太快。三个月后听懂了。半年后开始举手回答问题。一年后成绩中上。两年后有几个冲到了班里前十。

李冬是其中之一。

她到上海的时候八岁。穿越前在村里画画的那个——画房子和太阳。在上海她发现了画画。不是课本上的画画——是美术课上的画画。水彩。蜡笔。彩色铅笔。老师在黑板上画一个苹果。她跟着画。画得比同班任何人好。

美术老师说"她有天赋"。给她一盒彩色铅笔。十二色。她拿在手里的时候手在抖——不是怕。是兴奋。十二种颜色。她在村里只见过五种颜色：黑、白、红、蓝、黄。现在多了七种。绿。紫。橙。粉。棕。灰。

她用十二色铅笔画了槐安村。从记忆里画。土房。麦田。河。山。老槐树。她不知道画得像不像——她走的时候才八岁。但她记得。颜色不对——她没有足够浅的黄色画土房的颜色。但她画了。

美术老师把她的画贴在了教室的墙上。

后来那幅画和其他小朋友的画一起被收进了学校的"学生作品展"。再后来展完了。画被收下来。李冬去要了回来。她把画折好揣在怀里。

回古代的那天——白光降临的时候——李冬揣着那幅画。画折成巴掌大。在怀里。贴着心口。

白光把人还原了。衣服还原了。但画——纸——白光不认。

画在白光里化了。

李冬到了古代。从白光里醒来。脚下是泥土。手空了。画没了。

她哭了。

不是穿越回来的哭。不是因为害怕。是因为画没了。她在上海画的唯一一张画。十二色铅笔。槐安村。土房。麦田。河。山。老槐树。没了。

她蹲在麦田边哭。哭了很久。

后来她擦了眼睛。走到泥地上。蹲下来。用树枝在泥地上画。

画房子。画树。画太阳。

没有颜色。只有线条。

但她画了。从八岁画到十岁。两年。在上海的两年。在上海之后回到古代的每一天。

画没了。手还在。眼睛还在。记忆还在。

林远在村塾教李冬的时候发现了她的笔法不一样。

她用毛笔写字。横竖撇捺。但她落笔的方式不像古代写字的人。古代写字的人落笔——毛笔尖先触纸，然后笔管微微倾斜，笔毫铺开。李冬的落笔是——笔尖直接按下去。重。然后拖。像用铅笔写字的力道。

铅笔。硬笔。尖端接触纸面。用力。移动。留下痕迹。

她在上海用铅笔写了两年。她的手记住了铅笔的力道。回到古代用毛笔——力道改不回来。

林远看着她写字。看了很久。

然后他做了一件事。他从茅屋里找了一块木炭。木炭——烧火的余烬。黑。硬但不光滑。他试了一下——木炭在粗纸上能留痕。不洇。比毛笔精确。比铅笔差远了。但比毛笔好。

他把木炭递给李冬。

"用这个写。"

李冬接过来。试了一下。木炭在纸上留下一道黑线。不粗不细。不会洇。她写了一个字——"天"。字形比用毛笔写的好。

"先生，这是什么？"

"炭。烧火的炭。可以写字。"

"像——"她停了一下。"像铅笔。"

"不像。但比毛笔像。"

李冬笑了。她用木炭继续写。写了一行字。然后她翻过纸——在背面画。画了一个圆。圆旁边画了一个方的东西。

方的东西。房子。圆的东西。

太阳。

和以前一样。

林远看着她画。李冬十岁了。在上海长大了两岁。回来之后什么都没有了——没有彩色铅笔。没有美术课。没有画纸。没有画。但她还在画。用木炭。在粗纸上。

工具变了。手没变。画没变。

有一天。下课了。孩子们跑了。李冬没走。蹲在泥地上画。

"先生。"

"嗯。"

"你说天外面有房子。有树。有太阳。和这里一样。"

"嗯。"

"那我在这里——是不是也在天里面？"

林远看着她。

十岁。穿粗布。脸上有泥。手指上有木炭的黑。眼睛——黑的。亮的。

"对。"林远说。"你在天里面。我在天里面。所有人都在天里面。"

"那天外面呢？"

"天外面也是天里面。只是另一个天。"

李冬想了一会儿。然后她低头继续画。在泥地上画了一个圆。圆里面画了一棵树。圆外面又画了一个圆。圆里面也画了一棵树。

两个圆。两棵树。

"这个是这里的天。"她指了小圆。"这个是天外面的天。"她指了大圆。

"它们都是圆的。"

"嗯。"

"都有树。"

"嗯。"

李冬继续画。在两个圆之间画了一条线。连起来。

"这是你走过的路。"她说。"你从这里走到了那里。又走回来了。"

林远蹲下来。看着泥地上的两个圆。一条线。一棵树。两棵树。

一条线连着两个圆。

像一个8。像一条咬住尾巴的蛇。像时间。

"先生。"

"嗯。"

"我能去天外面吗？"

林远看着她。

"你已经在里面了。"

李冬点了点头。好像觉得这很合理。

她低头继续画。在两个圆旁边又画了一个方的东西。房子。

天里面。天外面。都有房子。都有树。都有太阳。

她画完了。站起来。拍了拍屁股上的土。跑走了。

林远蹲在泥地上。看着那幅画。两个圆。一条线。一棵树。两棵树。一个房子。

风从麦田吹过来。泥地上的画被风带了沙子。沙子盖住了一部分线条。再过几天，风会把整个画盖住。沙子会把画抹平。

但画在过。

他在泥地上蹲了一会儿。然后站起来。

走了。
