# 第020章：埋

林远选了一个月圆夜。

八月十五。中秋。槐安村的人过中秋——吃月饼，拜月娘。村里没有月饼的模具，月饼是自家做的，豆沙馅，皮厚，硬。拜月娘在院子里摆一张矮桌，放三块月饼、一碗水、一枝桂花。月亮升起来的时候全家跪下磕三个头。

林远在院子里拜了月娘。吃了半块月饼。豆沙是甜的——比上海的甜。上海的月饼他吃过，蛋黄莲蓉，油，甜得发腻。村里的月饼朴，面粉和豆沙，但甜得干净。

月亮升到头顶的时候他出了门。

村里安静。月光照在土路上。土路在月光下发白。远处有狗叫。风吹麦穗的声音——沙沙的，像下雨。

他走到村口。老槐树。

槐树在月光下。树冠大，像一个伞。叶子在月光下是墨绿的。树干粗——两个人合抱不过来。树皮上有沟壑。树根处有空坑——碑以前所在的位置。

他带了铲子。铁铲。赵铁匠打的。

他在空坑旁边挖。不是在坑里挖——在坑旁边。老槐树的根延伸出来，他在根和根之间找了一个缝隙。往深处挖。一尺。两尺。三尺。

三尺深。坑底是湿土。蚯蚓在土里动。树根在坑壁上盘着。活的根——白色的细根。老槐树还活着。

他从怀里掏出三片竹简。

第一片：1, 4, 9, 16, 25, 36, 49, 64, 81。
第二片：print("Hello World")
第三片：勾股定理、圆周率、求根公式。

竹简在月光下发黄。刻痕发暗。铜刻刀刻的。赵铁匠打的刀。在上海刻的。带到古代来的。

他要把它们埋在这里。

一千年后——公元2025年——方远舟的考古队会在这个位置、这个深度、这棵老槐树下面挖到它们。碳14测定：公元920年±30年。碳化痕迹和刻痕风化与千年埋藏一致。

他拿出油布。油布是从厨房偷的——猪油涂在麻布上。防水。他把竹简包好。三层。每一层都用麻绳扎紧。

然后他把竹简放进坑里。

放在树根之间。根会在一千年里包裹这些竹简。根和土会保护它们。竹简会碳化——纤维在地下慢慢脱水、氧化、变黑。但刻痕会保留。碳化后的竹简变脆了，但字还在。

他对着坑看了一会儿。

三片竹简。在月光下。在湿土里。在树根之间。

他想说一句话。但他不知道该跟谁说。

跟一千年后的方远舟说？

跟一千年后挖到这些竹简的考古队员说？

跟一千年后看到考古报告的自己说？

不。他在跟时间说。

"一千年后再见。"

他说出来的时候声音很小。风吹了一下，声音散了。月亮在天上。月亮不知道他在说什么。月亮也不在乎。

他开始填土。一铲一铲。湿土盖在油布上。盖住了。再填。再压。填到一半的时候他用脚踩实了。再填。再踩。填满了。他把多余的土撒到周围的草丛里。看不出挖过的痕迹。

他站起来。

老槐树在月光下。树冠大。叶子沙沙响。树根处——他埋了竹简的地方——什么也看不出来。只有土和草。

他拍了拍手上的土。土在月光下是白的。指甲缝里有泥。

他转身。

碑在旁边。青石碑。一米高。半米宽。他把碑从茅屋里搬出来放在树边——他要在明天开始刻。碑面上已经有第一行字——"莫貪天外物，歸時盡成空"——在上海刻的。但后面还有内容要刻。不明符号。数学公式。代码片段。

他要在这里——在老槐树下——把碑刻完。然后把碑立起来。立在坑旁边——碑以后也会被埋。等老槐树被雷劈了，树倒了，碑碎了，残碑留在坑里。一千年后被挖到。

他看着碑面。月光照在碑上。灰青色。第一行字——"莫貪天外物，歸時盡成空"——在月光下是阴影。

他蹲下来。拿起铜刻刀。赵铁匠新打的那把——刀背上有歪歪扭扭的"趙"字。

他开始刻第二行。

不是字。是符号。数字。

1, 4, 9, 16, 25, 36, 49, 64, 81。

铜刀在石面上的声音——"嚓"。和在上海实验室里刻的声音一样。但环境不一样。没有灯。没有空调。只有月光。只有风。只有远处赵铁匠铺子里偶尔传来的一两声"叮"——赵铁匠没睡。他也在打铁。

他刻了一个"1"。阿拉伯数字。一笔。竖。刻痕浅。

他刻了一个"4"。两笔。竖折。

他刻了一个"9"。两笔。弯钩。

阿拉伯数字。在公元965年的青石上。在月光下。用赵铁匠打的铜刀。由一个从2026年回来的人刻上去。

一千年后这些数字会被风化。模糊。但能辨认。方远舟会在考古照片里看到它们。然后他会拿着照片来找林远——在2026年——然后林远会看到。然后林远会回来。然后林远会刻。

刀在石面上走。声音传出去。在安静的夜里传得很远。

沙沙。嚓嚓。

像有人在跟石头说话。
