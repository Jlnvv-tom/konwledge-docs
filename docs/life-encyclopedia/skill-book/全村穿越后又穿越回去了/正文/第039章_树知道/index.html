第039章：树知道

2026年。秋。十月。

方远舟回到了遗址。

半年前——三月——他在这里种了一棵槐树苗。膝盖高。叶子嫩绿。浇水。走人。

现在他回来了。

树活了。

不只活了。长了一截。从膝盖高长到了齐腰高。半年长了半尺。叶子比半年前多了——密了一层。深绿色——秋天了但还没黄。松江的秋天来得晚。叶子要到十一月才黄。

根。方远舟蹲下来看。根从土里露出来——树苗根部的土面上有几条细根。白色的。活的。根在往地里扎。

他用手摸了摸树苗的茎。茎比半年前粗了。从筷子粗变成了小指粗。树皮——开始有了纹路。不光滑了。有细纹。像——

像老槐树。

方远舟的手停在树皮上。他记得老槐树。在考古报告的照片里——老槐树被雷劈了之后倒了。树桩的截面。年轮。他数过年轮——三百多圈。三百年的树。

三百年的树被雷劈了。倒了。碑碎了。根化了。

现在新的树苗在这里。半年。小指粗。

也许三百年后——这棵树也会变成老槐树。也会有三百年。也会有人——不知道是谁——看到这棵树。不知道是谁种的。

但树知道。树不知道。树只管长。

方远舟在树旁边站了很久。

他从口袋里掏出笔记本。林远的。旧了。封面有汗渍。边角卷了。

他翻到最后一页。第137页。

"方先生。我回去之后会刻一块碑。碑上有一句话。那句话是我写的。也是陈婆婆念的。也是你找到的。如果你看到这块碑——说明我已经回去了。说明我已经刻了。说明一千年的时间没有让我们失散。"

"你好。一千年后的世界。"

旁边是方远舟用铅笔写的："收到了。"

他看着那两行字。一行是林远的。一行是他的。

半年前他在这里站过。念了那句"下辈子再见"。树苗在风里晃了三下。

现在他回来了。树活了。长了。

他不知道树会不会活三百年。也许会。也许不会。也许下一场台风就折了。也许明年的虫害就死了。也许活下来。

但半年了。活了半年。长了半年。

他看着树苗。

"林远。"他说。声音不大。

风从远处吹来。上海的风。带着城市的声音——高架上的车声。远处的建筑工地的打桩声。一架飞机从天上飞过。发动机的声音。

"看到了吗？"方远舟说。"树活了。你种的。"

他顿了一下。"不是你种的。是陈婆婆种的。陈婆婆在古代种了。然后你回来刻了碑。然后碑被埋了。然后一千年后我挖到了。然后我种了一棵新的。"

"这棵树——第四代了。老槐树。陈婆婆的苗。你的老槐树。我的苗。"

树在风里。叶子动。茎不动。

方远舟看着树。

他蹲下来。在树根部——根从土里露出来的地方——他伸手摸了摸土。

土是湿的。秋天了。前几天下了雨。土松软。根在土里。

他不知道根扎了多深。也许一尺。也许两尺。也许更深——碰到了更深处的东西。

碰到了——

千年前的根痕。

老槐树的根——三百年——在地下化了几百年。化成了碳。碳在土里。根痕在土里。新的根——新的槐树的根——往下扎。碰到碳化的根痕。

根碰到根。新的碰到旧的。

方远舟不知道地下发生了什么。他看不到。没有人能看到。

但他知道——根在地下。根在走。根在找水。找养分。找——

根在找根。

新的根碰到旧的根痕。旧的根痕是碳。碳是植物。是纤维。是结构。新的根绕过碳化的旧根。或者在碳化的旧根旁边——长过去。

根连着根。

不是物理上的连——是空间上的重合。新的根走了旧的根走过的路。在同一个位置。同一个深度。同一个方向。

也许三百年后——新的槐树也会被雷劈。也会倒。也会留下根痕。根痕和根痕——新的和旧的——在同一个位置。

一千年前的根痕。现在的根。三百年后的新的根痕。

根连着根。时间连着时间。

方远舟站起来。

他把笔记本放在口袋里。

他看着树苗。齐腰高。叶子绿。茎比半年前粗了。根在土里。

他伸出手。摸了摸树苗最上面的一片叶子。

叶子软。嫩的。绿的。叶脉在阳光下看得到——细的。密的。像网。

他松开了叶子。叶子弹回去。在风里晃。

他转身。

走了。

走了几步。停。回头。

树在平地上。齐腰高。比半年前高了。比半年前壮了。

远处是上海的天际线。灰色的楼。一架飞机在天上飞。

树在中间。

绿。

方远舟看了三秒。转过头。走了。

风从东边吹来。树苗的叶子在风里。

晃了一下。两下。三下。

像在点头。

根在地下。看不见。但树知道根在哪里。

（全书完）
