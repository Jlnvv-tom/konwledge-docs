第021章：碑文

刻碑用了一个月。

每天从天亮刻到天黑。天亮到中午是上午刻，光好，眼睛不累。中午吃饭。下午刻到日头偏西。日头偏西后光不好，刻痕看不清，就停。

赵铁匠每天送饭。不是自己做的——他不会做饭。是村里王家的媳妇做的。一碗米饭，一碟咸菜，有时有一条鱼——河里的鱼，比上海的食堂好吃。赵铁匠端着碗走过来，放在碑旁边的石头上。然后蹲下来看林远刻字。

他不说话。看。偶尔递水。

林远刻碑的姿势是蹲着的。有时候跪着。碑平放在地上，他俯身刻。铜刀在石面上的声音——"嚓嚓"——成了这个月的背景音。村里人路过会看一眼。有人问"刻什么呢"，林远说"碑"。

第一周刻完了正面的古训和数字。古训在上海就刻好了——"莫貪天外物，歸時盡成空"。数字是新刻的——平方数列，一行。

第二周刻了数学公式。勾股定理——a² + b² = c²。圆周率前二十位——3.14159265358979323846。求根公式——x = (-b ± √(b²-4ac)) / 2a。这些符号在石头上比在纸上清楚——刻刀不会洇。但精度要控制。每一个符号的深度要均匀。深了石面会崩，浅了一千年后风化掉。

第三周刻了代码片段。不是完整的代码——完整的代码太长，碑面不够。他刻了几行短的：

print("Hello World")

while True: learn()

x = 0 while x < 10000: x += 1

每一行都用拉丁字母和符号。在青石上刻拉丁字母——每一个字母两到三刀。括号一刀。等号一刀。冒号一刀。

他刻的时候想起在上海用键盘打这些字符的场景。手指在键盘上跳——一秒钟打十几个字母。现在铜刀在石面上——一分钟刻三四个字母。

速度差了千倍。

但字会留下。

键盘上的字——屏幕上的字——关了就没了。石碑上的字——一千年后还在。

第三周末尾他开始刻"不明符号"。考古报告说碑上有"若干不明符号，疑为后世伪刻或自然风化痕迹"。他要刻一些看起来像风化痕迹的东西——不完整的符号、断笔、半截数字。这些会混淆未来的辨识。但他需要刻——因为考古报告里已经有了这些"不明符号"。如果不刻，就和考古报告不符。闭环不成立。

他用了两天刻这些"不明符号"。随便刻的。一些短线条，一些半圆，一些不规则的点。看起来像风化。但其实是刻的。

第四周。

碑文快刻完了。正面：古训、数字、公式、代码、不明符号。背面：空的。

他在碑的背面刻了几个字。

不是公式。不是代码。不是古训。是六个字。

"林远到此一游。"

楷书。繁体。竖排。小字。在碑的背面右下角。

考古报告里没有提到这六个字。因为碑的背面在发掘时已经严重风化——没有辨认出来。或者考古队没有清理背面。或者清理了但没辨认出来。无论如何——这六个字不在考古记录里。

所以这不是闭环的一部分。这是他给自己刻的。

"林远到此一游。"

来过。刻过。留下了。

他把铜刀放下。站起来。腰酸得直不起来。他用手撑着膝盖，慢慢站直。一个月。每天蹲着刻字八个小时。膝盖疼。手指上有铜的绿色痕迹和石粉的白色痕迹。指甲磨短了——铜刀握久了指甲磨在石面上。

碑立在老槐树下。

正面朝外。字迹清晰——刻痕深，线条稳。一个月的练习让他的手法比在上海时好了。不均匀的地方还有——但少了。一千年后风化会把这些不均匀抹掉。风化是时间的砂纸。

他站在碑前。看着碑面上的字。

古训。数字。公式。代码。不明符号。

一个人的十年。在青石上。在月光下。

赵铁匠在旁边。他把锤子放在脚边。蹲着。他看着碑面。他不认识碑上的大部分符号——数字他认识一些。字母不认识。公式不认识。代码不认识。古训认识。

"莫貪天外物，歸時盡成空。"赵铁匠念了一遍。声音不大。

"赵叔。你知道这话是谁说的吗？"

"陈婆婆。"

"陈婆婆从哪里听来的？"

赵铁匠想了一下。"她娘教她的。她娘从她娘那里听来的。代代相传。"

"源头是我。"林远说。"这句话是我写的。我刻在这块碑上。陈婆婆的祖上看到了碑。念给了下一代。一代一代念下来。念了八十八年。念到我穿越前。陈婆婆念给我听。"

赵铁匠看着碑面。沉默了很久。

"所以你刻这句话的时候——"

"我刻的是我以后会听到的。我听到的是我已经刻过的。"

赵铁匠站起来。

他走到碑前。伸手摸了摸碑面。手指沿着刻痕滑过去。和他摸铁的花纹一样——在金相显微镜下面。他看不到的东西在决定他看得到的东西。

"远儿。"

"嗯。"

"铁里面有花纹。碑上也有花纹。"

"嗯。"

"你是碳。"

林远看着赵铁匠。

赵铁匠没有解释。他拿起锤子。走了。

林远一个人在碑前站着。

月亮升起来了。月光照在碑面上。刻痕在月光下是阴影。碑的影子落在地上——长长的一条。和老槐树的影子叠在一起。

树影和碑影交叠。

树根在地下。碑在树旁。竹简在根间。

他坐下来。在碑前。背靠碑面。石碑被太阳晒了一天，还有余温。温的。不是空调的温度——是日头的温度。

他闭上眼睛。

碑刻完了。竹简埋了。

闭环完成了他这一侧的部分。

剩下的——交给时间。

一千年。

他在碑前坐了一夜。

月亮从东走到西。星在天上转。露水下来了。草叶上有水珠。他的衣服湿了。但碑是干的——碑面有刻痕，水珠顺着刻痕流下去了。

天亮了。鸡叫了。

他站起来。拍了拍衣服上的露水。

碑在老槐树下。正面朝外。字迹在晨光里清晰。

他看了一眼碑面。

"莫貪天外物，歸時盡成空。"

他转身。走回茅屋。

要开始过日子了。

在公元965年的日子里过日子。

没有电。没有代码。没有AI。没有方远舟。没有方远舟的手冲咖啡。

有麦田。有河。有鸡。有赵铁匠的锤声。有陈婆婆在老槐树下坐着。

有刻好的碑。

有埋好的竹简。

有时间。一千年的时间。

他要活在这段时间里。
