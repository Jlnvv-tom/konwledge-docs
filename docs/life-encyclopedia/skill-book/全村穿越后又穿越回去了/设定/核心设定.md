# 核心设定

## 基本信息
- 书名：全村穿越后又穿越回去了
- 题材/类型：历史科幻 + 时间循环 + 群像
- 目标平台：通用
- 预计字数：10万字（约40-45章，每章2000-2500字）
- 目标读者：喜欢历史穿越、时间悖论、群像故事的读者
- 读者契约：用"古人学AI"的反差制造惊奇与共鸣，最终以时间闭环收束——他们不是改变历史，而是在完成历史
- 主角高光/代理权：林远不可替代的判断——他是唯一能理解时间闭环含义的人，最终刻碑的选择只能由他做出
- 核心期待债：古人看到2026年AI爆发的震撼 + 归乡后知识无法应用的绝望 + 闭环揭示的震撼

## 一句话梗概
唐宋年间千人村庄整体穿越到2026年，少年学者林远用十年学会AI与编程，又随全村穿越回古代，发现那些"不该存在的文物"就是他亲手埋下的——时间咬住了自己的尾巴。

## 主角设定
- 姓名：林远
- 年龄：19岁（穿越时）→ 29岁（回古代时）
- 核心特质：好奇心重、善于观察、固执
- 核心能力：古代读书人的学习能力 + 十年现代教育（编程、AI、数学）
- 弱点/缺陷：执念太重——总想复刻现代科技，不愿接受"回不去"的现实；对方老师的感情让他迟迟无法放下
- 核心动机：想弄清楚"为什么是我们"——穿越不是随机的，闭环有因果

## 世界观骨架
- 时代/背景：架空唐宋之间（约公元900年），一个偏远山村"槐安村"，约1200人
- 核心设定：时间裂缝——非随机事件，是闭环的因果产物。裂缝把整村人连人带地皮送到2026年上海郊区，10年后又送回原时点。被送走的时间段在古代"消失"了约72小时，但对村民来说过了10年
- 社会结构：村长-族老-匠人-农户的宗族结构。穿越后宗族结构被现代冲击，回古代后重新固化但已不同
- 力量体系：无超自然力量。唯一的"超能力"是知识和信息差

## 核心冲突
- 主线矛盾：拥有未来知识却无法在古代复刻——"有脑子没工具"的绝望
- 终极阻碍：时间闭环——他越想改变历史，越发现历史已写好

## 反转设计
- 类型：时间线反转 / 认知反转
- 内容：林远在2026年读过的"槐安村遗址异常文物考古报告"——精密齿轮、刻着数学公式的竹简、一句不像古人写的古训——回到古代后他发现这些全是他自己即将创造的东西
- 铺垫线索：
  1. 裂缝在2026年的出现位置恰好在槐安村遗址上方
  2. AI模型曾"意外"生成古汉语族谱序言
  3. 陈婆婆念的古训"莫贪天外物，归时尽成空"来源不明
  4. 村口老槐树下有一块刻着看不懂符号的石碑

## 贯穿道具
**老槐树**——
1. 穿越前：村口百年老槐，村人信仰象征
2. 现代十年：陈婆婆坚持在安置点种下从村里带来的老槐树苗
3. 归乡后：树苗被带回古代，在原位置种下——成为新的"村口老槐树"
4. 结尾：林远把刻碑埋在老槐树下，千年后考古队在此发掘

## 卷次结构
- 第一卷《天外来客》（第1-10章，约25000字）：穿越、接触现代、安置适应
- 第二卷《十年饮冰》（第11-25章，约35000字）：学习、分化、羁绊、预兆
- 第三卷《不如归去》（第26-35章，约25000字）：归乡、错位、绝望、尝试
- 第四卷《咬尾蛇》（第36-45章，约15000字）：闭环揭示、刻碑、余韵
