# 第034章：传说

发掘结束之后，方远舟写了三个月论文。

论文题目是《上海松江槐安村遗址2025年度发掘报告——兼论唐宋地层的异常文字符号》。

报告体例标准。发掘方法。地层描述。遗物分类。碳14数据。微痕分析。和所有考古报告一样。

但"异常文字符号"那一节——他写了八千字。

他描述了三件文物。

第一件：青铜齿轮。直径4.2厘米。21齿。渐开线齿廓。碳14测定地层年代公元900年±40年。

第二件：竹简残片三枚。碳化。碳14测定竹简材质年代公元920年±30年。刻痕内容：阿拉伯数字平方数列、"print"和"Hello"的拉丁字母残片、数学公式符号。

第三件：青石碑。残高62厘米。出土于老槐树原位置下方。碑面有植物根系覆盖。剥离根痕后辨认出楷书"莫贪天外物，归时尽成空"十字及若干符号。背面风化严重，辨认出"林远"等字迹。

另有：刻有阿拉伯数字的陶片五枚。出自生活区灰坑。刻有拉丁字母的木简残片两枚。

随葬品：赵姓墓葬出土铜刻刀一把，刀背刻"赵"字。铁锤一个。

他在论文里描述了这些文物的出土坐标、地层关系、碳14数据、微痕分析结果。所有数据都指向一个结论：这些文物是唐宋时期的，不是后人埋入的。

但他没有写"时空穿越"四个字。他写的是"异常文字符号的来源待考"。

论文投到了《考古》杂志。

审稿意见回来了。

第一审稿人："考古数据完整。碳14和微痕分析严谨。但异常文字符号的解释不足。作者应排除现代人埋入的可能性。"

第二审稿人："阿拉伯数字和拉丁字母在唐宋地层出现——这要么是地层扰动导致的混入，要么是后人伪造。作者排除了这两种可能（碳14和微痕数据支持），但未提出合理的替代解释。建议补充。"

第三审稿人："如果数据确实可靠，这是一个重大发现。但'时空穿越'不是学术解释。建议作者谨慎措辞。"

方远舟看完了审稿意见。他在修改稿里补了一段：

"异常文字符号的来源目前无法给出学术解释。碳14测定和微痕分析排除了地层混入和后人伪造的可能。作者注意到，当地县志《录异记》记载了一个传说：'槐安村，宋时村人千余忽不知所往，三日复归，自言历十年，尽通天书。'传说中的'天书'或可解释为某种非当世文字。但传说不能作为学术证据。本报告仅做记录，解释留待后续研究。"

修改稿提交了。等了两个月。

通过了。

论文发表在《考古》2026年第一期。

标题：《上海松江槐安村遗址2025年度发掘报告》。

方远舟。通讯作者。

---

论文发表后。

学术圈的反应——分两派。

一派：数据扎实。方法对。碳14可靠。值得关注。但无法解释。列为"待解之谜"。

另一派：不可能。唐宋地层不可能有阿拉伯数字和拉丁字母。碳14可能误差。微痕分析可能有误。地层可能有未识别的扰动。建议重新发掘验证。

方远舟没有回应。他知道争议会一直存在。在没有时空穿越的直接证据之前——碳14和微痕分析再扎实，也不会有人相信"一千年前有人刻了拉丁字母"这件事。

除了他。

他知道是谁刻的。他知道为什么。他知道这些字怎么来的。但他不能说。说了也没人信。他只能在论文里写"来源待考"。

---

有一天。方远舟在办公室。复旦。江湾校区。

他在改一篇新的论文——关于槐安村遗址墓地区的研究。赵姓墓葬的铜刻刀和铁锤。他想写一篇关于那个刻刀的微痕分析。

他桌上放着那本笔记本。林远的。

他翻到最后一页。第137页。

"你好。一千年后的世界。"

他看着那行字。然后他在论文的致谢里加了一行字。

致谢通常写感谢资助方、感谢合作者、感谢田野工人。他写了那些。然后在最后加了一行：

"献给槐安村的林远先生。"

他的学生看到了。问他："方老师，林远先生是谁？"

方远舟想了一下。

"一个——老师。"

"哪个学校的？"

"很远的地方。"

学生没再问。

方远舟把论文打印了一份。放在桌上。旁边是笔记本。论文的致谢里有"林远先生"。笔记本第137页有"你好。一千年后的世界。"

论文在桌上。笔记本在桌上。

窗外是复旦的校园。梧桐树。学生骑车经过。远处有图书馆。

方远舟坐在椅子上。他四十七了。头发白了一半。穿长袖衬衫。扣子扣到手腕。眼镜是圆框的。

他看着窗外。

梧桐树叶子绿了。春天。

他低头。在笔记本第137页的空白处——"你好。一千年后的世界。"旁边——用铅笔写了一行小字：

"收到了。"

两个字。铅笔。在林远写的字旁边。

他合上笔记本。放在桌上。

然后他站起来。拿上咖啡杯。去磨豆子。手冲壶。水从壶嘴倒出来。细细的。弯弯的。落在咖啡粉上。粉鼓起来。冒泡。

咖啡味弥漫在办公室里。

和二十年前一样。
