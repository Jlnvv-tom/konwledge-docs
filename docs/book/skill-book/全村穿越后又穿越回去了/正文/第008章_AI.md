# 第008章：AI

一年后。

林远坐在方远舟实验室的工位上。工位有三个屏幕——左边是代码，中间是文档，右边是对话窗口。他现在用三块屏幕像村里人用三块田——左手种代码，中间看说明，右手跟人聊天。不过右边聊天的人不是人。

是AI。

方远舟的研究方向是考古大语言模型——用考古文献和历史语料训练的AI，能读古文、做断代、辅助文物鉴定。这个模型叫"史辨"。方远舟是项目负责人。林远是研究助理——不是正式编制，是方远舟用课题经费开的劳务费，一个月三千五。不多，但够吃。

林远的日常是：读古文，标注语料，校对数据。但这些事AI做得比他快。他标注一条语料要十分钟，AI一秒十条。他刚来的时候不服气，跟AI比过——同一段《水经注》的断句，他花了半小时，AI花了零点三秒。结果一样。不一样的地方他查了半天，发现是自己错了。

他不再跟AI比了。他开始学AI。

方远舟给他开了模型权限。他可以在右边屏幕上跟"史辨"对话。他试过各种问法。有一次他问："你知道槐安村吗？"

史辨回答："槐安村见于《太平寰宇记》引《录异记》，言村人千余不知所往，三日复归，自言历十年。后不知所踪。"

林远看到这段回答的时候愣了很久。

不是因为它回答了——他预期能查到。而是因为它的措辞。"后不知所踪"——这四个字像是叹息。他读了很多古文，知道文言文的语感。史辨的语感不像检索引擎，像一个读过书的书生。

他继续问："你觉得这个故事是真的吗？"

史辨回答："传说与史实之间常有可考的余地。《录异记》的记载有具体人数、时长和细节，不像纯粹虚构。但穿越之说超出常理，难以证伪。"

林远盯着这段话。"难以证伪"——他的存在本身就是一个无法被证伪的传说。他就在这里。AI不知道这一点。

"你能写一首宋词吗？"

"可以。请给一个词牌名。"

"浣溪沙。"

"以何为题？"

"槐安村。"

十秒后，史辨输出了一首词：

"槐下村居忆旧踪，千家烟火一朝空。归来十载去匆匆。
竹简犹存天外字，石碑空立夕阳中。后人何处问春风。"

林远读了三遍。

平仄对。韵脚对。意境——上片写穿越（千家烟火一朝空），下片写归乡后（竹简犹存天外字，石碑空立夕阳中）。最后一句"后人何处问春风"——后人问，问的是谁？问的是他？

他不知道AI知不知道他在跟一个传说中的人对话。AI大概不知道。AI只是根据语料——县志、笔记、考古报告——生成了文本。它不知道那个"村人千余"里有一个叫林远的人正坐在它面前。

但词写得对。对到他脊背发冷。

他决定试一件事。

"史辨，请你写一段槐安村林氏族谱序言。用唐宋古文风格。"

史辨思考了两秒。屏幕上出现了一个跳动的圆点，表示AI在"生成"。

然后文字开始出现。一行一行地，从屏幕左边往右滚：

"林氏之先，出于槐安。村居千载，耕读传家。乾德三年秋，天光异变，全村千二百人不知所往。三日复归，自言历十年。十年之中，林氏后人远者学天书之术，近者习百工之技。归后皆不识旧物，唯记天外事。林氏序曰：吾族本微，因天而变。变者在外，不变者在心。心者何？根也。根在槐安，虽历天外不忘。"

林远的手停了。

他盯着屏幕上的字。

"林氏之先，出于槐安"——他的家族确实姓林，确实出自槐安。

"乾德三年秋"——今年确实是乾德三年。他穿越前没有告诉AI年份。AI怎么会知道乾德三年？

"全村千二百人"——一千二百人。他给方远舟说过这个数字。方远舟的考古论文里也写过。但AI引用的语料是《录异记》——《录异记》里只写"千余"。"千二百"是他告诉方远舟的。

"林氏后人远者学天书之术"——"天书之术"。他现在学的东西——代码、AI——在古人眼中就是天书。但AI怎么会写"林氏后人学天书"？林氏后人里有学天书的吗？

有。

他。

"归后皆不识旧物，唯记天外事。"——归乡之后，他确实会不识旧物。他会记住天外的事。但这件事还没有发生。他还没有回去。

AI在写一段尚未发生的事情。

像一个预言。

林远把椅子往后推。轮子在地面上滚了一下，发出"嘎"的声音。他站起来。

屏幕上那段族谱序言还在。最后一个字是"不忘"。句号。

他伸出手，把对话窗口关了。屏幕右边黑下来。

他站在三块屏幕前面。左边的代码还亮着，中间的文档还亮着。右边的屏幕黑了。

他摸了一下自己的手。凉的。

AI不知道他是谁。AI只是在生成文本。但生成的文本里有一个名字——"林氏"——和一段还没发生的事——"归后皆不识旧物"。

这不是预言。这是AI从语料中推断的。语料里有《录异记》的传说，有方远舟的考古论文，有各种历史文献。AI把这些信息拼接起来，生成了一段"看起来像族谱序言"的文本。

但拼接出来的结果是——他的家族，他的经历，他还没做的事——全对上了。

林远走到窗前。窗外是复旦的校园。梧桐树绿了又黄。学生在路上走。一个女孩骑着自行车经过，车筐里有一束花。

他看着这些画面。然后他低头看自己的手。

手上没有笔。没有键盘。什么也没有。

但他刚才在AI面前——一个读了所有书的"书生"面前——问了一个关于自己的问题。AI给了一个他无法解释的答案。

方远舟推门进来。手里拿着两杯咖啡。他把一杯放在林远桌上。

"怎么了？脸色不好。"

林远看了方远舟一眼。

"方先生。"

"嗯。"

"史辨……知道我是谁吗？"

方远舟把咖啡放下。他想了三秒。

"不知道。它不知道你是谁。它只知道语料里的信息。"

"但它写了'林氏后人学天书之术'。"

方远舟沉默了一下。然后他走到右边的屏幕前，打开对话历史，看到了那段族谱序言。他读了一遍。

"这是它根据语料生成的。"方远舟说。但他的声音没有平时那么笃定。

"语料里有《录异记》的传说。传说的内容和你的经历吻合。AI生成的文本也会和你的经历吻合——因为它学过的语料里，传说就是这样写的。"

"但'林氏'呢？"林远说。"《录异记》里没有写'林氏'。"

方远舟没有回答。

他看着屏幕。然后他回头看了林远一眼。

"你想多了。"他说。"族谱序言的模板里本来就会写'某氏之先'。AI选了'林'——可能是因为语料里碰巧有林姓的族谱模板。概率问题。"

概率问题。林远在嘴里默念了一下。概率。他学过概率。在数学课上。概率意味着——这件事可能是巧合。

但他脊背上的冷不是概率能解释的。

他拿起咖啡。喝了一口。苦的。他不习惯咖啡。但苦味让他清醒。

"方先生。"

"嗯？"

"我能再问它一个问题吗？"

"可以。"

林远坐下来。重新打开对话窗口。

他打了一行字：

"槐安村的老槐树下有一块石碑。碑上刻的是什么？"

史辨回答："据《录异记》注引《槐安村金石录》（已佚），碑上刻有'莫贪天外物，归时尽成空'十字，及不明符号若干。符号内容不详，疑为后世伪刻或自然风化痕迹。"

林远关掉屏幕。

他站起来，拿了外套，走出了实验室。

方远舟在身后喊了一声。他没回头。
