# 第031章：传播

回来后第十五年。王小毛二十三岁了。

他去镇上卖粮。

镇叫松江镇。离槐安村二十里。走路半天。王小毛挑了两担麦子——一担八十斤——用扁担挑着走。到镇上的时候日头刚过午。

松江镇不大。一条主街。两排铺面。粮铺、布铺、铁器铺、杂货铺、茶馆。街尾是码头——河上有个小码头，船从下游上来，把盐、铁、布运进来，把粮、麻、药材运出去。

王小毛到粮铺。粮铺老板姓张。张老板五十多了。做了三十年粮食买卖。

"张叔。两担麦。"

张老板看了一眼麦子。"今年你家的麦子好。"

"堆肥。"

"什么肥？"

"鸡粪沤的。沤两个月。"

张老板不太懂。但麦子确实好。颗粒饱满。颜色正。他给了个好价钱。

王小毛从怀里掏出一本账本。麻纸封面。里面是粗纸。他翻开。用铅笔——不是，用木炭——在账本上记。

"张叔。两担麦。每担八十斤。每斤三十二文。共——"

他算了一下。80×2×32=5120。

"五千一百二十文。"

张老板看着账本。他看到了数字。

"你这是什么字？"

"数字。"

"什么字？"

王小毛指了指账本上的"80"。"这是八十。这是2。这是32。这是5120。"

张老板皱眉。他记账用"正"字。一笔一划。五十斤画十个"正"。一百斤画二十个。每次对账要数半天"正"字。

"这个……怎么用的？"

"1是一竖。2是一弯。3是三弯。1到9。9后面是10。10是1和0放在一起。"

王小毛在泥地上写了一遍。1到9。10。20。50。80。100。

张老板看了。他蹲下来。用手指在数字旁边比划。

"100——一百。1和0。"

"对。"

"那两百呢？"

"2和0和0。200。"

"三百？"

"300。"

张老板站起来。他想了一下。他在自己的账本上——纸的——用毛笔写了一个"200"。旁边用汉字写"二百"。

他看了一会儿。然后他把"二百"划掉了。只留"200"。

"省了两个字。"他说。

王小毛笑了。

张老板又问："加法怎么算？"

"加就是加号。+。1+1=2。2+3=5。50+30=80。"

张老板在账本上试了一下。50+30=80。

"乘法呢？"

"乘号。×。80×32=2560。两担各八十斤，每斤三十二文，一共五千一百二十文。"

张老板算了一下。他用算盘。打了一遍。5120。对了。

"你这比算盘快。"

"不是比算盘快。是记账快。算还是一样的算。但记——数字比'正'字清楚。不用数。看一眼就知道多少。"

张老板看了王小毛一会儿。

"你从哪里学的？"

"村里的林先生教的。"

"林先生？"

"村里的教书先生。"

张老板没再问了。他给了钱。5120文。用麻绳串好。五串一千的，一串一百二十的。王小毛把钱放进布袋。走了。

---

一年后。张老板的账本全换了。

不是换了纸。是换了记法。他用毛笔在账本上写阿拉伯数字。歪歪扭扭——毛笔写数字不好写。但能认。

他的伙计也学会了。伙计是个十六岁的男孩。学得比张老板快——年轻人脑子活。伙计开始用数字记每天的进出货。每天晚上结账的时候，伙计念数字，张老板拨算盘。两人配合得越来越快。

两年后。镇上另一个粮铺——李记——看到了张老板的账本。李老板来张老板的铺子串门，看到账本上的数字。

"张哥，你这记的什么？"

"数字。"

"什么数字？"

张老板教了他一遍。和李老板蹲在地上用树枝写。

李老板学了三天。三天之后李记粮铺的账本也换了。

三年后。镇上不只粮铺在用数字了。布铺、杂货铺、码头上的运货单——开始出现阿拉伯数字。不是所有人都用。但用的人多了。

张老板后来去问了王小毛："你那个林先生还收学生吗？"

"收。村里有村塾。"

"我让我家老二去学。"

张老板的小儿子——十二岁——被送到槐安村。在林远的村塾学了半年。学了数字、算术、还有——林远教了他一点堆肥法。张老板家也有地。

半年后小孩回来了。带了一本手抄的数字册。1到100。加减乘除口诀。张老板把册子供起来。

---

三年后。一个杭州商人来松江镇采购药材。

商人姓沈。做药材生意的。在松江镇待了三天。第三天晚上他在茶馆喝茶，旁边一桌是张老板和几个镇上的商户。他们在算账——用阿拉伯数字。

沈商人看到了。他凑过去看了一会儿。

"这是什么东西？"

"数字。"

"哪国的字？"

"不知道。松江镇这边都这么用。"

沈商人蹲下来看了一会儿。他是个聪明人——做生意的都聪明。他三天就学会了。

回杭州的时候他带了一本数字册。在杭州的铺子里用了起来。

一年后。杭州的药材行里开始有人用阿拉伯数字。不是所有人都用。但有些人用了。

数字在传播。从槐安村。到松江镇。到县城。到杭州。

林远不知道这些。他在槐安村的村塾里教书。他只知道镇上有人在用数字。他不知道数字传到了杭州。

但数字在走。像水滴在纸上洇。从一个点开始。往外。往外。

一千年后——如果考古队在杭州的宋代地层里发现了刻着阿拉伯数字的木简——他们会困惑。但他们不会知道来源。来源是一个从2026年回来的教书先生。在泥地上写了1到9。一个八岁的孩子学会了。一个二十三岁的年轻人带到了镇上。一个粮商学了。一个药材商带回了杭州。

数字在走。

人不知道自己在传。但数字在走。

够了。
