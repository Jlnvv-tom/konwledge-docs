# 第011章：六年

六年了。

林远在复旦读研。方向是计算考古——用AI辅助古文断代和文物分析。导师是方远舟。方远舟三年前还是社科院挂职的研究员，现在全职转到了复旦，带了一个实验室，二十多个人。史辨模型从1.0跑到了3.0，参数量翻了两百倍，语料从十万条扩到了三百万条。去年发了一篇Nature子刊——AI辅助唐代墓志铭自动断代——方远舟是通讯作者，林远是二作。论文致谢里写了一行字："感谢槐安村社区的支持。"没有说那是什么意思。外人以为是田野调查的某个村庄。

实验室在江湾校区新建的楼里。五楼，朝南。林远的工位从后排搬到了中排——二作的待遇。三块屏幕。左边代码，中间文档，右边AI对话。跟三年前一样的布局，但屏幕大了，椅子好了，咖啡从速溶变成了手冲。方远舟买了手冲壶放在办公室，每天下午磨豆子的时候整个走廊都是咖啡味。

林远现在说普通话比很多南方人都标准。他穿T恤和牛仔裤——donated的衣服早穿完了，他自己买的。他有一张银行卡，里面有十个月的劳务费存款。他没有支付宝——方远舟帮他注册的时候需要人脸验证，他的人脸在系统里没有记录，过不了。他用现金和银行卡。

他每个月还是去看一次陈婆婆。陈婆婆在安置点——现在叫"槐安村社区"了——种树。槐树苗从腰高长到了比她还高。她不浇水了——树根扎够了，不用她浇了。她每天坐在树下面。不说话。有人来看她，她就看一眼。没人来，她就看树。

林远去的时候她照例说了一句话。这次说的是：

"还剩四年。"

林远不知道她怎么算的。但她说"还剩四年"的时候语气和三年前说"天要收了"的时候一样。稳。不慌。像说天气。

林远现在知道裂缝的收窄速度了——天文台的观测报告方远舟帮他拿到了。裂缝的角直径在以每年约15%的速度缩小。按指数衰减算，还有四年左右会完全关闭。

陈婆婆不知道天文台的数据。但她说的和天文台算的一样。

林远不再问她怎么知道的。他接受了一件事：陈婆婆知道一些他不知道的东西。不是迷信——是某种他说不出名字的感知。也许是因为她在老槐树下活了八十年，跟那棵树之间有某种他理解不了的连接。也许是因为"莫贪天外物，归时尽成空"这句古训——从她嘴里念出来的——是某种真实的信息。

他不再追问了。

村民的分化在第六年进入了稳定期。稳定不是和解——是固定。两拨人不吵了，但也不来往。

融入派里有十几个人做得不错。有人开了个小饭馆——做村里的菜式，用现代的食材和厨具。有人去了工厂。有人学了开车。有个年轻人考了成人大专。有两个小孩考上了高中——上海的高中，不是夜校。

回去派人少了。不是走了——是老了。三年前还有三百多人的"回去派"主要是不肯学现代东西的老人。这三年里走了十一个。不是穿越回去——是病死的。现代的医院没救过来。有些是到了现代之前就有的病，拖太久了。有些是心里的事——老人不肯吃东西，不肯看病，就那么耗着。

周老实每次去参加葬礼。他现在每周去两次街道办。不是去开会了。是去要墓地。

墓地——在上海，在2026年——很贵。政府给了政策减免，但还是需要钱。钱从哪来？村民的收入——打工的、做小生意的——凑在一起，勉强够。但不够买二十个墓位。

方远舟帮了忙。他联系了松江的一座公墓，以"历史特殊群体"的名义争取到了一块集体墓区。三十个墓位，免费。名字按村里习惯竖刻。墓碑上的生卒年——有的只写了"生年不详，卒于2026"。

林远去参加了一次葬礼。死者是村里的老王头，六十八岁，一辈子种地。到现代后什么都不学，天天坐在板房门口看天。死的那天早上还在看天。下午就没气了。走得很安静。

葬礼上周老实念了一段话。不是佛经。不是道经。是村里祖传的丧词——"生于土，归于土。来处来，去处去。"

来处来。去处去。林远听了这句话心里动了一下。来处——槐安村。去处——如果死了，去处是上海的墓地。如果没死，去处是——回去。还是留下。

他不知道。

那天晚上回到实验室，他打开了史辨3.0的数据库。他要查一个东西——方远舟的考古课题"槐安村遗址异常文物"的完整报告。

他之前看过照片。第三章——方远舟给他看的那次。三张照片：精密齿轮、刻公式竹简、石碑拓片。但那次方远舟只给他看了照片。完整报告——包括出土坐标、碳14数据、材质分析、微痕检测——他没看过。

现在他有权限了。史辨3.0的考古数据库里收录了全国考古所的公开报告。他搜了"槐安村"。

报告标题："上海松江槐安村遗址2025年度发掘简报"。

方远舟是通讯作者。林远知道这个——方远舟一直在做这个遗址。但他不知道完整报告长什么样。

报告不长，八页。林远翻到第四页的时候看到了"异常文物"章节。

三件文物。

第一件：青铜齿轮。直径4.2厘米，齿数21齿。齿距误差小于0.1毫米。材质为青铜，含锡量18%。出土于第三层——唐宋文化层——深度1.2米。碳14测定：地层年代公元900年±40年。

微痕分析：齿轮表面有打磨痕迹，工具不明。齿形为渐开线齿廓——这种齿形在欧洲直到17世纪才出现。

报告附注："该齿轮的加工精度和齿形设计远超唐宋时期的已知技术水平，来源待考。"

第二件：竹简。残长23厘米，宽2厘米。表面有碳化痕迹。出土于同一地层。碳14测定：竹简材质年代公元920年±30年。

竹简上刻字。刻法——不是毛笔书写，是利器刻划。刻痕深度0.3毫米。

刻字内容分为两部分：

上部：阿拉伯数字1至9的平方数列——1, 4, 9, 16, 25, 36, 49, 64, 81。

下部：一串拉丁字母和数字组合——"print("Hello World")"。

报告附注："竹简材质年代与地层年代吻合，非后人埋入。刻字内容包含阿拉伯数字和拉丁字母，这些字符在唐宋时期的中国文献中从未出现。初步排除近代伪造——碳化痕迹和刻痕风化程度与千年埋藏一致。来源完全不明。"

第三件：石碑。残高62厘米，宽40厘米。青石。出土于同一地层，位于遗址中心——村口老槐树原位置下方0.5米。

碑面刻字：楷书，竖排。"莫贪天外物，归时尽成空。"十字。以及若干不明符号——部分符号与第二件竹简上的拉丁字母相似。

林远看着屏幕。

他没有动。

屏幕上那行字在发光——不是屏幕的光。是他的记忆在发光。

"print("Hello World")"——这是他来到现代后写的第一行代码。第七章——不，第七天。他坐在教室最后一排，在那个翻开的笔记本电脑上，用粗大的手指按下了这行字。

但竹简上的字不是他刻的。他在古代没有刻过这行字。他还没回去。

他怎么会在回去之前——在古代的竹简上——刻下这行代码？

除非他回去之后刻的。

除非他回去之后——回到槐安村之后——把他在现代学的东西刻在竹简上，埋在老槐树下。一千年后被人挖出来。再过一千零六十年——他在现代的实验室里看到这张照片。

闭环。

他盯着那行"print("Hello World")"。

你好，世界。

他给世界打了一声招呼。世界听到了。一千年前就听到了。

他把照片存下来。存在了自己的私人文件夹里。文件名叫"证据1.png"。

他没有告诉方远舟。

他关掉数据库页面，回到代码界面。屏幕上的代码还亮着。他看着代码——那些英文字母和符号。他写的每一行代码，在一千年前都已经被刻在竹简上了。

他还没有回去。但他在古代留下的痕迹已经在那里了。

时间不是一条河。时间是一个咬住自己尾巴的蛇。
