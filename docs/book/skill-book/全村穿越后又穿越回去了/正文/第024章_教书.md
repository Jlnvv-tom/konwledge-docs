# 第024章：教书

二十年后。林远三十九了。

他站在村塾的讲台——其实是一张矮桌——前面。二十三个孩子坐在地上。矮桌上有书本——是他手抄的，用毛笔在粗纸上抄的《千字文》和《三字经》。穿越前村塾只有七八个孩子。现在二十三个。不是村里孩子多了——是附近村子的人听说槐安村有个"林先生"教得好，把孩子送来了。

他教三门课。

第一门：古文。《千字文》开蒙。《三字经》讲道理。然后《论语》《孟子》。和穿越前的村塾一样。但他的教法不一样了。他不像老先生那样让学生死背。他会讲故事。讲孔子的故事。讲孟子见梁惠王的故事。讲着讲着孩子们就记住了。

第二门：算术。阿拉伯数字。加减乘除。分数。小数。他教了二十年。村里现在有三代人会用阿拉伯数字。老一辈是当年林远第一批教的孩子——现在三十多岁了。他们教了自己的孩子。孩子们又教了更小的孩子。数字在槐安村扎了根。

他不确定这会不会改变历史。也许会。也许一千年后的考古队在槐安村遗址发现了刻着阿拉伯数字的陶片和木简，会困惑。但他不在乎了。他教孩子数字不是为了改变历史。是为了让他们好过一点。

会算数的孩子，将来帮父亲记账不用画"正"字了。会算数的孩子，将来去镇上买东西不会被多要钱。会算数的孩子，将来——如果天再漏了——能更快地学会那边的数。

第三门：常识。这是他自己加的。穿越前没有。他教的东西很杂：怎么堆肥。怎么轮作。怎么选种。怎么洗手——用皂角洗手。怎么处理伤口——用煮过的布包扎。怎么分辨毒蘑菇。

这些不是他在上海学的。是他在上海"读书的时候顺便看到的"。他看了很多杂书。农业、医学、建筑。他在上海的时候不觉得这些有用——上海什么都有。但回来之后他发现，只有这些"不先进但有用的"知识能在古代用。

他不能发电。但他能堆肥。他不能造显微镜。但他能教孩子洗手。他不能写代码。但他能教数字。

小改变。一点一点。二十年。槐安村的麦子比周围村子高两成。槐安村的孩子比周围村子少生病。槐安村的人比周围村子会算账。

这些不会进历史书。但他知道。

王小毛二十三了。

他是林远教的第一批学生。第一批只有一个——就是他。八岁学数字的那个孩子。现在二十三。穿长衫。在村里当记账先生——不是给一家记账。是给全村记账。谁家收了多少粮。谁家欠了多少税。谁家借了谁家的牛。全用阿拉伯数字记。

他记的账本——林远看过——比穿越前村里任何账本都清楚。一笔一笔。日期。数量。经手人。清清楚楚。

王小毛有时候在账本上写注释。不写汉字。写数字。比如"借牛一天"旁边写"1D"。D是天——day。他用拼音的第一个字母当缩写。

林远看到"D"的时候愣了一下。他没教过这个。王小毛自己发明的。拼音缩写。

一个公元965年的孩子。自己发明了拼音缩写。

林远没有纠正他。也没有表扬他。他只是看了一眼。然后走开了。

走开之后他在路上笑了。一个人笑。不是大笑。是嘴角弯了一下。

那个孩子不知道D是什么。他只是用了一个自己方便的符号。但他不知道他做的——在某种意义上——和他在上海实验室里写代码的人做的一样。用符号代表意思。用缩写提高效率。

一个八百多年后的人——不，一千多年后的人——会做同样的事。但那个人会用键盘。王小毛用树枝。

工具不同。人一样。

一个新来的孩子——六岁。隔壁村送来的。叫李冬。坐在第一排。小脸脏脏的。眼睛圆。

下课之后其他孩子跑了。李冬不走。蹲在泥地上。用树枝在泥地上画画。

林远走过去看。李冬画了一个方的东西。方的东西上面有一个圆的东西。

"你画的什么？"

"房子。"

"房子上面是什么？"

"太阳。"

"太阳是圆的？"

"嗯。"

林远蹲下来。他在李冬旁边画了一个方的东西。方的东西旁边画了一个小方的东西。

"这是什么？"

"房子。小的房子。"

"小房子旁边呢？"

李冬想了想。在旁边画了一个不规则的形状。"树。"

林远点头。"好。"

然后他在树上画了一个小圆。

"这是什么？"

"果子。"

"对。"

李冬笑了。他继续画。在旁边又画了一棵树。树上又画了一个圆。

林远看着这个六岁的孩子。穿粗布。脸脏。手指头粗。用树枝在泥地上画。画房子。画树。画果子。

他不知道这个孩子的未来。也许他会种地。也许他会记账。也许他会去镇上当学徒。也许他会一辈子在村里。

但他在画。在泥地上。用树枝。

画是画。和写字不一样。但——

"李冬。"

"嗯？"

"你有没有想过——天外面有什么？"

李冬抬头看着他。眼睛圆圆的。

"天外面？"

"对。天的外面。"

李冬想了一会儿。摇头。

"天外面有什么？"

林远笑了。

"有树。有果子。有房子。和这里一样。"

李冬点了点头。好像觉得这很合理。天外面和这里一样。有什么奇怪的。

他低头继续画。

林远站起来。走出村塾。

远处赵铁匠在河边。搬了一把竹椅。坐在河边。看水。

他每天下午去河边。不带锤子。不带刀。空着手。坐着。看水。

水从上游流到下游。流走了。新的水又流过来。流走了。又流过来。

赵铁匠看水。不知道他在想什么。也许什么都不想。也许在想铁里面的花纹。也许在想电。也许在想上海的工厂。

林远不知道。他没去问。

有些事不问比问了好。

他站在村塾门口。看着赵铁匠在河边。看着陈婆婆坟地方向的山坡。看着老槐树下的碑。看着麦田。

二十年了。日子过着。一天接一天。

够了。
