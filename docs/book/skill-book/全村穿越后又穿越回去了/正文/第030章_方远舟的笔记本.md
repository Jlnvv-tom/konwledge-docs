# 第030章：方远舟的笔记本

2025年。六月。松江。

考古营地是三间板房。铁皮顶。有空调但不凉——空调老了。板房里白天四十度。晚上三十度。

方远舟在第三间板房里。他把它当办公室。一张折叠桌。一把折叠椅。桌上有一台笔记本电脑——联想的，旧了。旁边有一盏台灯——LED的，电池的，因为板房没有通电。他在用电池。

天黑了。他开了台灯。白光照在桌面上。

他从口袋里掏出笔记本。林远留给他的那本。不是"無憾"——那本没送出去。是林远自己写的那本。铅笔字。横线本。A4大小。封面旧了。边角卷了。

他没有翻到第137页。第137页他背下来了。他翻到了第1页。

第1页。

"方先生。这是我写的第一页。我不知道写多少页。但我想从头开始写。"

"今天是穿越后的第100天。我在帐篷里。外面在下雨。陈婆婆不吃饭。赵铁匠在抠灰地面。我在学简体字。"

"简体字和繁体字之间有规律。'開'变成'开'。'學'变成'学'。像一个人脱了外套。"

方远舟看着第一页。他记得这段话。他在实验室里第一次看到这页的时候笑了——"像一个人脱了外套"。

翻到第5页。

"今天方先生给了我一本小学课本。一年级。我三天读完了。简体字不难。难的是拼音。26个字母。我背了两天。在帐篷壁上用手指划。划到帆布起毛。"

"方先生说'你学得快'。我不知道快不快。我只知道——如果不快，我就看不到明天。时间不够。裂缝在关。我必须在裂缝关上之前学会所有能学的东西。"

翻到第12页。

"今天我第一次用手机。方先生给的旧手机。我按了1+1=2。屏幕上出现了2。数学是对的。在这里也对。在槐安村也对。1+1永远等于2。天变了地变了，2不变。"

翻到第20页。

"我学会了打字。键盘。26个字母。比拼音难——要找位置。但比毛笔快。方先生说'打字比写字快十倍'。但我写字写了二十年。打字才学了三个月。手还记着笔的力道。有时候打字的时候手指在找毛笔的角度。但笔不在了。键盘在。"

翻到第35页。

"今天赵铁匠问我'电能不能打铁'。我说能。赵铁匠沉默了。然后他说'那个力来了我就不用打铁了'。我说'你还是要打铁。电来了只是多了个工具。锤子还在'。赵铁匠说'可我不会别的。我就会打铁'。"

"我写了二十年书。赵铁匠打了二十年铁。我们都会一样东西。到了这里，一样东西不够了。要学新的。但旧的不是白学的。二十年打铁的手比别人的手稳。二十年写字的眼睛比别人的眼睛准。旧的东西在新世界里不是废物。是基础。"

翻到第48页。

"今天我第一次写代码。print('Hello World')。屏幕上出现了Hello World。你好，世界。我在跟这个世界打招呼。世界不知道我在打招呼。但屏幕知道。机器知道。"

"机器和人不一样。人不一定回应你。机器一定回应你——只要你写对了代码。写错了它报错。写对了它执行。因果明确。没有含糊。"

"写代码和写文章一样——先想清楚要说什么，再说。区别是文章可以含糊，代码不能。含糊就报错。"

翻到第60页。这页有一幅画。铅笔画的。

方远舟凑近看。是一棵树。老槐树。树干粗。树冠大。树下有一个人。很小。蹲着。是陈婆婆。

林远画的。铅笔。线条不熟——他学画画只学了几个月。但画得有感觉。树是黑的——铅笔画了很多层。陈婆婆是白的——留白。在黑树下的白人。

方远舟看了很久。

翻到第75页。又有一幅画。这次是三块屏幕。左中右。屏幕上画着线和字——很抽象。但能看出是三块屏幕。在屏幕旁边画了一个咖啡杯。

方远舟笑了。那个咖啡杯。他的手冲壶。他每天下午磨豆子。整个走廊都是咖啡味。

翻到第90页。

"今天赵铁匠在金相显微镜下看到了铁的花纹。他说像麦穗。像河。他打了一辈子的铁。第一次看到铁里面长什么样。他站在显微镜前看了一个小时。"

"我在想——我学了十年。我也在看我自己的'花纹'。我的花纹是什么？是代码？是数字？是AI？不是。我的花纹是——我看到的东西。我看到铁里面有麦穗。我看到代码可以跟机器说话。我看到数字可以在泥地上写。我看到——时间是一个圈。"

"赵铁匠说'你是碳'。碳在铁里。碳决定花纹。"

"也许。也许我是碳。也许不是。但碳不知道自己在铁里。我也不知道自己在时间里。"

翻到第100页。

"今天方先生跟我说了槐安村传说。他说'你就是那个传说里的人'。我说不出话来。"

"我知道了。闭环。时间。蛇咬住了尾巴。"

"但我不知道我是碳还是铁。我不知道是我决定了碑上的字，还是碑上的字决定了我。也许都不是。也许我们都只是——在时间里走了一遭。"

翻到第120页。

"碑文准备好了。方先生帮了我很多。他帮我买了青石碑。他帮我找到了考古所的刻刀。他帮我对照了考古照片。他帮我确认了闭环。"

"我想跟他说谢谢。但谢谢太轻了。十年。他用十年帮了我。不是帮我一个人——帮了全村。帮赵铁匠找培训班。帮陈婆婆守树苗。帮周兰找裁缝铺。帮周老实和街道办沟通。帮孩子们上了学。"

"他不是我们村里的人。但他做了村里人做的事。"

翻到第136页。倒数第二页。

"明天要走。今天最后一页。"

"方先生。"

"我不知道回去之后会怎样。我会刻碑。我会埋竹简。我会过日子。我会教孩子。这些我都知道。"

"但我不知道——一千年后——你会不会看到这块碑。我不知道——你看到的时候——还会不会记得我。"

"也许会。也许不会。也许你已经忘了。十年对你来说也许不长。你研究了槐安村十五年。你从十五年前就在等我。等我回来。等碑出现。"

"你在等我。我在回去刻碑。一千年后你等我。现在我在等你。"

"谢谢你。方先生。下辈子再见。"

翻到最后一页。第137页。

"方先生。我回去之后会刻一块碑。碑上有一句话。那句话是我写的。也是陈婆婆念的。也是你找到的。如果你看到这块碑——说明我已经回去了。说明我已经刻了。说明一千年的时间没有让我们失散。"

"你好。一千年后的世界。"

---

方远舟合上笔记本。

他把笔记本放在桌上。台灯的光照着封面。封面有汗渍。有灰。有泥。十年的痕迹。

 他站起来。走出板房。

外面是夜。上海的夜空看不到星星。但能看到云——灰色的。路灯把云底照白了。

远处有高楼的灯。有车在高架上的声音。世界是亮的。2025年的世界是亮的。

 他抬头。

 遗址上方——松江上空——天空有一小块地方闪了一下。

 白色的。一瞬即逝。

 像是什么东西在天上开了一下又关了。

 方远舟看着那块天空。什么也没有了。只有灰色的云和远处的城市灯光。

 也许是飞机。也许是闪电。也许是什么都不是。

 他站了很久。

 然后他笑了。嘴角弯了一下。和二十年前一样。和十五年前一样。

 "你好。"他说。声音很小。风带走了。

 "一千年前的世界。"

 他转身。走回板房。关了台灯。坐在黑暗里。

 笔记本在桌上。碑在地下。竹简在土里。树根在碑上。人在时间里。

 他闭上眼睛。

 什么也没有了。只有风。
