# 第006章：电

三个月后，林远第一次走进大学。

不是正式入学。方远舟用他的关系——他在社科院挂职，认识复旦的人——拿到了一张"访学旁听"的临时卡。卡上贴着林远的照片，照片是帐篷区登记时拍的。照片里的林远穿着一件 donated 的灰色卫衣，头发剪短了，脸洗干净了，但眼神还是那种——方远舟后来跟同事说——"像第一次进城但忍着不问"的眼神。

大学的教学楼和帐篷区不一样。帐篷区是平的、白的、方的。教学楼是高的、灰的、弯的。走廊里有窗户，窗外有树——不是槐树，是法国梧桐。林远不知道那叫法国梧桐，但他知道那是树。活的树。这个灰世界里也有树。

方远舟带他进了一间屋子。屋子里面有桌子，桌上有板子——不是手机那种小板子，是大板子，合起来的，翻开以后两边都亮。方远舟说那叫"笔记本电脑"。林远在本子上记了——他已经养成了记笔记的习惯，方远舟给了他一本横线本，他每天写满十几页。

方远舟指着天花板上一个圆球。球是白的，不亮。

"看好了。"

他按了墙上的一个东西。"咔"。

球亮了。

林远看到过灯。帐篷区有灯管，路上有路灯。但他一直没把灯和"那个墙上的东西"联系起来。他以为灯是自己在亮的，像萤火虫。

现在他看到了：方远舟按了一个东西，灯就亮了。再按一下，灯就灭了。

"怎么做到的？"他问。三个月的学习已经让他能用现代汉语做基本对话。声调还是怪的，方远舟说他"像浙江人学普通话"，但能交流。

"电。"方远舟在纸上写了一个字。"电。"

林远认识这个字。古代也有"电"字，指雷电。但方远舟说的不是雷电。

"雷是天上的电。这是人造的电。"方远舟指了指墙上。顺着他的手指，林远看到了一根线。线从灯座延伸出去，沿着墙壁走到角落，然后钻进地面的一个洞里。

"力从线里来。"林远说。

方远舟想了一下，点了点头。"差不多。电是一种能量。它在线里面流动，就像水在水管里流。开关就像阀门。打开阀门，水流过去，灯就亮了。关上，水停了，灯就灭了。"

林远看着那根线。

水渠。力在水渠里流。水渠是人挖的，力是——

"力从哪里来？"

方远舟说了一个词："发电厂。"

林远不理解。方远舟想了想，在纸上画了一个简图：一条河，一个轮子，轮子连着线，线连着灯。

"水推轮子转，轮子带动发电机，发电机把力变成电，电在线里跑，跑到这里，灯就亮了。"

林远看了三秒。

"水力。"

"对。也有烧煤的、烧气的、核能的。原理都一样——把别的力变成电，电在线里跑。"

林远在本子上记了三行字：

一、力可转化。水力可变电力。
二、电力在线中流动。
三、开关控制通断。

然后他站起来，走到墙边，看着那个开关。他伸手按了一下。灯灭了。再按一下。灯亮了。再按。灭。再按。亮。

他按了十五下。

方远舟在旁边看着他。他没有阻止。他知道这个行为是什么——是一个一千年前的人第一次碰到电灯开关时的反应。每按一下，灯亮一次灭一次，重复，可验证，因果明确。

这就是科学。同样的动作产生同样的结果。

林远停下来了。他把手从开关上拿开，看着灯——亮着。

"方先生。"

"嗯。"

"这个力……能打铁吗？"

方远舟愣了一下。然后他笑了。

回到帐篷区是傍晚。林远找到了赵铁匠。赵铁匠三个月来变化不大——他还是蹲在帐篷门口，锤子放脚边，但已经开始吃食堂的饭了。他吃得多，但话少。帐篷区的人都知道他手艺好，有人找他修东西——修拉链，修桌腿，修铁架子。他修得又快又好，但修完就回去蹲着，不说话。

林远蹲在他旁边。

"赵叔，你知道灯为什么会亮吗？"

赵铁匠抬头看了一眼帐篷顶上的灯管。三个月了他每天都看那个灯管，天黑了就亮，天亮了就灭。他没问过为什么。

"不知道。"

"有一种力叫电。它在线里面流。就像水渠里的水——水从高处往低处流，冲过水轮，轮子就转了。这个力也一样，从远处过来，在线里流，流到灯这里，灯就亮了。开关就是渠上的闸——闸开了水过，灯亮；闸关了水停，灯灭。"

赵铁匠听完了。

他没有看灯。他在看自己手边的锤子。

"能打铁吗？"

林远愣了一下。方远舟给他讲电的时候，他没想到这个问题。但赵铁匠问的不是"电是什么"——他不在乎电是什么。他只问一件事：电能不能帮他打铁。

"能。"林远说。"方先生说有一种东西叫'电锤'，比人手快十倍。还有一种叫'电炉'，比你的炭火温度高三倍。"

赵铁匠没有说话。他低头看着锤子。锤柄被他握了二十年，木头发黑发亮，有了包浆。锤头是他自己打的铁，百炼钢。

他把锤子拿起来，又放下。

"打出来的是一样的铁？"

"比你的铁好。"林远说。他不懂冶金，但他看到过帐篷区工人用的电钻。"那个电钻的钻头，比你打的任何铁都硬。"

赵铁匠站起来。

他走到帐篷顶上灯管下面，仰头看。灯管发白光，嗡嗡响，不闪。赵铁匠看了很久。

"不用炭，不用风箱，不用人手。"他说。"这力就是比水还方便。"

"对。"

赵铁匠伸手碰了一下灯管。

"烫。"他缩回手。然后又伸出去碰了一下。还是烫。但这次他没缩手。他把手贴在灯管上，灯管的热传到他掌心。那个温度他认识——是铁在炉子里烧到一定程度时的温度。不是明火。是暗热。

"赵叔。"

赵铁匠没有回头。

当夜帐篷区停了一次电。凌晨两点，灯管灭了，空调停了。黑暗中有人骂了一句。有人翻身继续睡。

林远被热醒的。他摸黑走出帐篷，想透口气。

他看到赵铁匠站在帐篷门口，仰头看着那个灭了的灯管。

黑暗中灯管什么也不是。灰白的管子，上面有蚊虫的尸体。不亮。不烫。不响。

赵铁匠站在那里，一动不动。

林远走到他旁边。两个人在黑暗里站着。远处有一辆车的灯光扫过来又过去。

"林远。"

"嗯。"

"这力来了，我就不用打铁了。"

林远没说话。

"可我不会别的。"赵铁匠说。"我就会打铁。"

灯管在头顶上不响。黑暗里只有两个人的呼吸声。

远处天空西边，那个白色光点已经看不到了。也许白天看不到。也许它已经关了。

赵铁匠在灯管下面站了一整夜。

天亮的时候来电了。灯管又亮了，嗡嗡响。赵铁匠闭了一下眼睛——不是嫌亮，是让眼睛适应。然后他低头，从地上捡起锤子。

"林远，你去学你的字。"他说。"我去找那个电钻。"

林远看着他。

赵铁匠把锤子别在腰上，往帐篷区管理处走。他背对林远，赤着上身，肩胛骨在晨光里微微不对称——左手常年握锤，左边肩比右边厚一指。

走了几步他停下来回头。

"那个力——电——你们学堂里能学吗？"

"能。"

"替我也问问。"

他转身走了。

林远站在帐篷门口，看着赵铁匠的背影。锤子在赵铁匠腰后面晃，一左一右，像钟摆。

林远怀里揣着那部旧手机。他摸了摸——手机外壳被体温捂热了。

他抬头看了一眼天。东边有光，是日头要出来了。西边什么也没有。白天的天空不会出现那个光点。

但他知道那个光点还在某个地方。也许在白天看不到的角度。

它在等他们。
