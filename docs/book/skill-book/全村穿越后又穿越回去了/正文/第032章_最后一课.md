# 第032章：最后一课

回来后第四十年。林远五十九。身弱了。

不是病。是老了。五十九岁在古代不算年轻。村里人平均活五十。他已经多活了九年。但身体——走路要拄杖了。咳嗽了。冬天冷的时候手指发僵。不能握刀了。不能写字了——毛笔也抖。

村塾他已经不每天去了。王小毛接了大半的课。林远每周去一次。去的时候坐在讲台——矮桌后面——看王小毛教。偶尔补充一两句。像一个退了的老先生。偶尔来。

但今天他来了。不是来听王小毛讲。是他要讲。

"今天我来讲。"他对王小毛说。

王小毛愣了一下。然后他把位置让出来。站到旁边。

林远坐在矮桌后面。面前是二十三个孩子。最小的六岁。最大的十二。坐了一地。穿粗布。脸上有泥。眼睛黑亮。

他看着这些孩子。这些孩子的父亲——有一半——是他教过的。他们的祖父——有几个——也是他教过的。三代人。

他今天不讲古文。不讲算术。不讲堆肥。

他讲故事。

"很久以前——"他开口。声音沙哑。但稳。"有一个村子。村子不大。一千多人。村口有一棵老槐树。"

孩子们安静了。他们喜欢听故事。

"有一天。天亮了。但不是太阳的光。是另一种光。白的。从天上落下来。把整个村子罩住了。"

他停了一下。喝了口水。水是温的。碗是粗陶的。

"村里的人——一千多——被光带走了。带到了另一个地方。"

"什么地方？"一个孩子问。

"一个——天外面的地方。"

孩子们的眼睛睁大了。有几个张了嘴。

"那个地方有铁鸟。在天上飞。比鹰大。比鹰快。没有翅膀。"

"有灯。不用点火。自己亮。力从线里来。"

"有板子。会发光。人用手指在板子上画。板子说话。"

"有人——一个男人——戴着圆框眼镜。手里抱着一摞纸。纸上画着一棵槐树。槐树下面有一块石碑。"

他停了。

孩子们等着。

"那个男人说——'你就是那个传说里的人。'"

"什么传说？"另一个孩子问。

"传说里说——有一个村子的人——一千多——去了天外面。又回来了。回来的时候人人懂天书。天书就是——一种人写给机器看的字。机器看了就照做。"

孩子们听不太懂。机器是什么。天书是什么。但他们听着。

"那个人在天外面待了十年。学了天书。然后又回来了。回来之后——他在老槐树下刻了一块碑。碑上刻了天书和一句话。"

"什么话？"一个最小的女孩问。六岁。圆脸。扎两条辫子。

"莫贪天外物。归时尽成空。"

孩子们没听懂。但有几个跟着念了。嘴里嘟囔着。

"先生——"最大的男孩问。十二岁。"这个故事是真的吗？"

林远看着那个男孩。男孩的眼睛——黑的。亮的。和他八十年前教的第一批孩子一样。

"真的。"他说。

"你怎么知道？"

"因为那个人是我。"

教室里安静了。

二十三个孩子。最小的六岁。最大的十二。他们看着面前的老先生。白头发。弯腰。拄着竹杖。手指有铜的绿色痕迹和石粉的白色痕迹——四十年没褪干净。

"先生去过天外面？"

"去过。"

"天外面有什么？"

"有灯。有铁鸟。有板子。有人戴着圆框眼镜。"

"先生——你为什么回来了？"

林远看着那个男孩。

"天要收的。"

他喝了一口水。放下碗。

"我在天外面学了十年。学了很多东西。回来之后——什么都用不了。没有电。没有线。没有灯。没有板子。"

"那你学了有什么用？"

"有用。"他说。"我学了一种数字。1到9。加号。减号。等号。我教给了你们。你们会用数字记账。不用数'正'字了。"

"我学了堆肥。鸡粪沤两个月。比生粪好。你们家的麦子比隔壁村高两成。"

"我学了洗手。用皂角洗手。你们少生病了。"

"这些东西不大。不能发电。不能让灯亮。但能让日子好过一点点。"

他停了。

孩子们看着他。

"先生。你后悔吗？"

"后悔什么？"

"后悔回去了。你可以留在天外面的。"

林远看着那个男孩。十二岁。眼睛亮得像两颗黑石。

他想了一会儿。

"不后悔。"他说。"我回来刻了碑。埋了竹简。教了你们。日子过着。够了。"

他站起来。竹杖在手里。慢慢站起来。膝盖响了。

"好了。今天到这里。下课。"

孩子们一个一个站起来。有的跑出去了。有的在门口回头看了一眼。

王小三没走。他蹲在泥地上。用树枝画着什么。

林远走过去看。

王小三画了两个圆。圆里面各有一棵树。两个圆之间有一条线连着。旁边画了一个方的东西。

房子。

和四十年前李冬画的一样。两个圆。一条线。两棵树。

林远看着那幅画。

"这是什么？"

"先生的故事。"王小三说。"这个圆是这里。这个圆是天外面。这条线是你走的路。这个是房子。这里也有房子。天外面也有房子。"

林远蹲下来。看着那幅画。和四十年前一模一样。

他伸手摸了一下泥地上的画。画是湿的。泥是软的。树枝划出来的线里有一点水。

"好。"他说。"画得好。"

王小三笑了。站起来。跑走了。

林远一个人在村塾里。看着泥地上的画。

两个圆。一条线。两棵树。一个房子。

他拄着竹杖。慢慢走出村塾。走到老槐树下。碑在根下。看不到。但他知道字在。

他靠着树坐下来。竹杖放在脚边。

太阳偏西了。风从麦田吹过来。麦穗黄了。秋天了。

远处有赵铁匠的锤声——不，赵铁匠走了二十八年了。没有锤声。只有风声。

他闭上眼睛。

风在吹。叶子在落。远处有孩子背书的声音。"人之初，性本善。性相近，习相远。"

习相远。

习——学。远——他。

他在风里笑了。嘴角弯了一下。

然后他没有再睁开眼睛。
