# 第035章：尾声

2026年。春天。三月。

方远舟回到了遗址。

发掘结束了。探方回填了。黄土盖回去了。地面平整了。考古队的板房拆了。工人走了。研究生走了。

遗址上什么也没有了。只有一块平地。黄土。几根残留的探方线——白色的绳子——在风里晃。

老槐树的原位置。方远舟用GPS定了的。东经121.2度。北纬31.0度。在这里——一千年前——有一棵老槐树。树下有一块碑。碑旁有竹简。树被雷劈了。碑碎了。竹简化了。千年后被方远舟挖到了。

现在什么也没有了。平地。

方远舟带了一样东西。

一棵树苗。

槐树苗。膝盖高。绿叶。细茎。根上包着泥土。装在一个塑料花盆里。

他从花鸟市场买的。老板问他种哪里。他说"种在松江"。老板没多问。

他蹲下来。在老槐树的原位置——GPS定位的那个点——挖了一个坑。用折叠铲。铲子是考古队的。坑不大。一尺深。

他把树苗从花盆里取出来。根上的土没散——他用手托着。把根放进坑里。填土。压实。浇了半瓶水——矿泉水。

树苗立在坑里。膝盖高。叶子在风里微微动。

他站起来。看着那棵树苗。

槐树。新的。小的。在老槐树曾经站立的位置。

老槐树在公元965年之前就在了。不知道活了多久。几百年。也许上千年。它被雷劈了。倒了。碑碎了。陈婆婆把碎块扔到了河边。老槐树的根在地下烂了。化了。变成了土。土被风刮走了。被雨冲走了。什么都不剩了。

但陈婆婆在穿越前育了一棵苗。苗穿越了。又回来了。苗在古代长大了——四十年——也变成了老槐树。被雷劈了。倒了。

现在方远舟种了一棵新的。在同样的位置。

这棵新的会不会长大？会不会活几百年？会不会被雷劈？

他不知道。

但他种了。

---

他站在树苗旁边。从口袋里掏出笔记本。林远的。

他翻到最后一页。第137页。

"方先生。我回去之后会刻一块碑。碑上有一句话。那句话是我写的。也是陈婆婆念的。也是你找到的。如果你看到这块碑——说明我已经回去了。说明我已经刻了。说明一千年的时间没有让我们失散。"

"你好。一千年后的世界。"

旁边是方远舟用铅笔写的两个字："收到了。"

他看着那两行字。一行是林远的铅笔字。一行是他的铅笔字。两种笔迹。在同一页纸上。

他合上笔记本。

他看着树苗。树苗在风里。叶子动。茎不动。

他想到了一个人。

林远。

十九岁。穿粗布短衫。蹲在灰地面上。用树枝在泥地上写"天""地""人"。抬头看天。眼睛里是"第一次进城但忍着不问"的眼神。

二十九岁。穿白衬衫。坐在实验室最后一排。手指在键盘上跳。print("Hello World")。你好，世界。

三十九岁。穿长衫。站在村塾里。用树枝在泥地上写阿拉伯数字。教孩子。声音稳。

四十九岁。头发白了。腰弯了。拄着竹杖。靠在老槐树上。看碑。看树。看风。

五十九岁。坐在老槐树下。闭上了眼睛。风从麦田吹过来。叶子落在膝盖上。远处孩子背书。"习相远。"

方远舟看着树苗。

"林远。"

他念了一声。声音不大。风吹了。声音散了。

"你在下面——听得到吗？"

没有人回答。树苗在风里。叶子动。

方远舟从口袋里掏出另一样东西。一本笔记本。新的。不是林远的。是他自己的。

他翻开第一页。用铅笔写了几个字：

"林远。"

"收到了。"

"碑我看到了。竹简我看到了。铜刀我看到了。锤子我看到了。数字我看到了。"

"你的学生——王小毛的孙子——他们还在用阿拉伯数字记账。松江镇的商人也在用。传到杭州了。你不知道吧。"

"陈婆婆的坟我找到了。在村西山坡。没有碑。只有一个土包。我在上面放了一块石头。"

"赵铁匠的坟我也找到了。旁边的。铜刀和锤子是他的随葬品。我没动。留在原地了。回填了。"

"你——你的坟——"

他停了一下。

"你的坟我没找到。也许在老槐树旁边。也许在别的地方。也许什么都没有——你走的时候什么都没带。"

他合上笔记本。放在口袋里。

他看着树苗。树苗在风里。

他对着空气说了一句话。声音不大。但清楚：

"下辈子再见。"

风吹了。树苗的叶子动了。三下。一下。两下。三下。

像在点头。

方远舟看了树苗一会儿。然后他转身。

走了。

走了几步他停下来。回头。

树苗在平地上。很小。膝盖高。旁边是黄土。远处是上海的天际线——灰色的楼。灰色的天。城市在远处。

树苗在中间。绿。

他看了三秒。然后转过头。继续走。

---

树苗留在原地。

没有人来看它。方远舟走了。考古队走了。工地上的工人不看它。

风吹它。雨淋它。太阳照它。

三月。四月。五月。

夏天来了。上海的三十七度。树苗的叶子卷了。下午的时候蔫了。晚上浇水——没有人浇水。

但树苗活了。

它的根往下扎。碰到黄土。碰到碎石。碰到——

更深处。

碰到老槐树的根。

老槐树的根——化了。变成了土。但土里还有根的痕迹——碳化的纤维。千年前的根在土里留下了碳。

新的根碰到碳。绕过去。继续往下。

水。养分。光。

树苗活了。

秋天。叶子黄了。落了。冬天。光秃了。春天。又发了。

一年。两年。十年。二十年。

树苗长高了。比人高了。比房子高了。

树干粗了。树皮有了沟壑。叶子密了。

没有人知道这棵树是谁种的。方远舟种的。方远舟给林远种的。林远给陈婆婆种的。陈婆婆给老槐树种的。

一代一代。

树不知道。树只管长。

---

一千年后。

也许还会有一棵老槐树。在松江。在某个平地上。树很大。三个人合抱不过来。

也许没有人知道这棵树的故事。

但树知道。

根在地下。看不见。但树知道根在哪里。

（全文完）
