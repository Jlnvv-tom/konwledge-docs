# 第017章：归

白光退去的时候，林远闻到了泥土的味道。

不是沥青。不是水泥。是泥土。湿的。黑的。活的。泥土里有草的根，有虫的壳，有腐叶的味道。他的鼻子一下子就被这种味道填满了——十年了。他在上海十年，闻到的是空调的干燥味、食堂的油烟味、实验室的咖啡味、地铁的金属味。他忘了泥土是什么味道。

他忘了。

但他鼻子记得。

他睁开眼。

麦田。

绿油油的麦穗在风里摆。天是蓝的——不是上海那种发灰的蓝，是深的、透的蓝。远处有山。山上有树。树是绿的。不是梧桐——是松和杉。山脚下有一条河。河不大，水不深，河面上有光在闪。

槐安村。

他站起来。脚下的地是软的——不是柏油路。是踩了千年的泥土路，硬但不光滑，有车辙的印子。他穿了十年运动鞋的脚踩在布鞋里——走之前他换了衣服。白光吞没他的时候他穿的是T恤和牛仔裤，但白光把他换回来了。他身上穿的是粗麻布的短衫。脚上穿的是草鞋。衣服是旧的——穿越前穿的那件。白光把他还原了。

还原了。人回来了。衣服回来了。但人不一样了。

他怀里揣着东西。三片竹简。一把铜刻刀——赵铁匠打的那把，刀背上有歪歪扭扭的"赵"字。这些东西是他从2026年带回来的。白光允许人带东西回来——只要是人手拿着的。不是机器。不是电。不是代码。是人手能碰到的东西。

竹简在怀里。刻刀在袖子里。他摸了一下——还在。

方远舟给的那本"無憾"没带进来。它在纸袋里。纸袋在白光中化掉了。纸是现代的产物——白光不认。

他转头。

村民在各处醒来。有人从麦田里站起来。有人从村口爬起来。有人从自家院子里拍着身上的土。陈婆婆坐在老槐树下——老的那棵，百年的那棵，没有穿越过的那棵。

陈婆婆看起来——年轻了？

不。不是年轻了。是回来了。穿越前她八十八岁。回来后她还是八十八岁。但她穿越前在上海的时候脸是灰的——板房里的灯管照的，加上八年没怎么晒太阳。现在她的脸在古代的日头下，被风一吹，红了一点。像活过来了。

她坐在老槐树下。手摸着树皮。树还在。老槐树没有走。穿越的时候整村的人和地皮走了，但老槐树留了。树太大了。根太深了。白光带不动。

树还在。树下的石碑——

林远走过去。

老槐树下有一个浅坑。坑里有一些碎石。碑没了。陈婆婆说过——"老槐树被雷劈了。树倒了。碑碎了。我爹把碎块搬到河边扔了。"

但那是未来的事。他还没有刻碑。现在碑还没有。坑是空的。石碑还没有存在。

他要刻。然后碑会在坑里。然后——很多年后——树被雷劈了。碑碎了。碎块被扔到河边。残碑留在坑里。一千年后方远舟挖到62厘米的残碑。

他看着那个空坑。

陈婆婆看到他看坑。她笑了一下。

"空的。"她说。"以后会有。"

林远蹲下来。"婆婆。"

"嗯。"

"你一直知道。"

"知道什么？"

"知道我会刻碑。知道碑会在这里。知道古训是我写的。"

陈婆婆没有回答。她摸着老槐树皮。树皮粗，沟壑深。她的手指在上面滑过去，像在读什么。

"我知道树有根。"她说。"根在地下。看不见。但树知道根在哪里。"

她抬头看了林远一眼。

"你也知道。"

林远没有再问。他站起来。看着村子。

槐安村。麦田在东。河在南。山在西。村口朝北——老槐树在村口。土房一间一间，茅草顶，木门。有人从门里走出来，站在门口看天。有人在院子里拍土。有人在井边打水。

一切如旧。七十二小时。对他们来说三天。对林远来说十年。但村子没有变。麦穗还在。井里有水。土房还立着。

变了的是人。

九百八十七个人站在各自的院子里、田埂上、井边。穿着麻布和草鞋。但有些人——林远看到了——站姿不一样了。有个年轻人站在院子里，手在身前握着——什么都没有。他在找手机。有人蹲在井边，眼睛盯着水面发呆——在发呆还是想看屏幕？有人在看天——不是看天气。是在看有没有裂缝。

赵铁匠走向铁匠铺。

林远跟过去。

铁匠铺在村子东头。土墙。茅草顶。里面有炉子、砧子、风箱、锤子——穿越前的锤子，赵铁匠的那把，没有带走的那把。锤子放在砧子旁边，二十年握出来的包浆还在。铁匠铺里还有一筐铁料，没有穿越走——整村的铁器留了下来。

赵铁匠走进铁匠铺。他扫了一眼。炉子灭了。风箱干裂了。铁料生了锈。锤子还好。

他拿起锤子。

锤子在手里。比他记忆中重——不。是一样重。十年了。他在工厂用了七年检修锤，比这把轻。这把锤子二十年的老锤，锤头沉，柄粗。他握住。

他站在砧子前。砧子上什么也没有。他举起锤子。

"叮——"

一锤。空打。锤子打在空砧子上。声音传出来。清脆。在安静的村子里传得很远。

赵铁匠放下锤子。

他皱了一下眉。

声音不对。

他打了二十年铁。空打的声音他知道——"叮"。干脆。短。锤子和砧子碰一下，声音出来，马上消散。

这次的声音是"叮——嗯——"。后面有一段嗡嗡的尾音。不是砧子的共振。是——

不是砧子变了。是他的耳朵变了。

在上海的工厂里待了七年。工厂有机器声、电流声、空调声。他的耳朵听了七年现代世界的声音。现在回到古代——太安静了。安静得他能听到以前听不到的东西。锤子打在砧子上的共振尾音。铁砧内部金属结构的振动声。以前这些东西被风箱的呼呼声、炉子的燃烧声盖住了。现在炉子没点。风箱没拉。世界安静得像一个真空。

他的耳朵变了。他的手没变。他的锤子没变。但他听不惯了。

十年。他的耳朵习惯了电灯的嗡嗡声。习惯了空调的呼呼声。习惯了机器运转的底噪。回到古代——那些声音都没有了。

赵铁匠把锤子放在砧子上。站在铁匠铺中间。看着炉子。看着风箱。看着铁料。看着墙角堆的炭。

他蹲下来。

"林远。"

林远站在门口。

"嗯。"

"铁还在。炭还在。锤子还在。"他用手扫了一下铁料筐。铁料上有锈。他的手指碰到铁锈的时候——棕色的粉末沾在指头上——他想起了一件事。

他在工厂看过金相显微镜。铁里面的花纹。碳排的。像麦穗。像河。

他现在看着筐里的铁料。铁料里也有碳。也有花纹。但他看不见了。显微镜在上海。在2026年。在这里他只有锤子和火。

"赵叔。"

"嗯。"

"你想打什么？"

赵铁匠看着铁料筐。沉默了很久。

"不知道。"

他不知道打什么了。打锄头？打镰刀？打锅？打门环？这些东西他打了二十年。但他现在看到的不是锄头、镰刀、锅、门环。他看到的是铁里面的花纹。是他看过的东西。是他再也看不到的东西。

他能打铁。但他打不出那种花纹了。花纹不是打出来的——花纹是碳在铁里自然形成的。他能控制碳的渗入——用火候。但他看不到碳在铁里排列的样子了。

他失去了显微镜。

"打一把刀。"林远说。

赵铁匠抬头。"什么刀？"

"刻字的刀。再打一把。这把——"他从袖子里抽出铜刻刀，"——只有一把。回头要刻碑的。万一钝了要换。"

赵铁匠看着那把铜刻刀。刀背上有他刻的"赵"字。歪歪扭扭的。但刀是他的手打出来的。铜是他的手选的。火候是他的手控制的。

他接过去。翻过来看了看刀刃。还没钝。

"行。"他说。"再打一把。"

他站起来。开始生炉子。炭放进炉膛。火点着。风箱拉开——"呼——"。风进去了。炭红了。

他拿起锤子。这次不打空。打铁。

"叮——"

一锤。铁料在炉子里烧。他在等。

铁铺里的声音和十年前一样。风箱、炉子、锤子。但打铁的人不一样了。他听过电的声音。他看过铁的里面。他知道电比风方便。他知道铁里有花纹。他再也回不去了。但他还在这里。在铁匠铺里。在火前面。

他还在打铁。
