# 第022章：日子

日子过起来了。

不是"过起来"——是"过"。日子不是过起来的。日子是一天接一天。天亮。天黑。天亮。天黑。中间种地。吃饭。睡觉。

林远不会种地。

穿越前他读过十年书。在村里他是书生——不种地的人。穿越后他在上海读了十年书，也不是种地的人。回来之后他发现——种地是活命的基本技能。

他分到了穿越前的家里的地。三亩。他爹在他穿越前就去世了。娘也走了。地是隔壁王家帮忙种的。回来之后王家把地还给他。

他站在地头看。三亩麦田。麦穗绿油油的。他不认识麦子的品种——只知道是冬麦。他不知道什么时候浇水，什么时候施肥，什么时候锄草。

但他学过。

在上海的最后两年，他读过一本书——《中国农业史》。从古代到现代的农业技术演变。他读那本书是因为方远舟的项目需要标注一些古代农业文献的语料。但他在书里看到了很多东西：堆肥法、轮作制、选种法、灌溉技术。

堆肥法。他把村里的厨余垃圾、鸡粪、牛粪、落叶收集起来，堆在院子角落。浇上水。盖上土。让它们发酵。两个月之后变成黑色的腐殖土——和现代的有机肥差不多。他把腐殖土撒到麦田里。麦苗比隔壁王家的田绿了一截。

周老实来看过。蹲在田埂上看了一会儿。问："你弄的什么？"

"堆肥。"

"什么肥？"

"把鸡粪和烂叶子沤了。沤两个月就成了肥。比生粪好。生粪烧根。沤过的肥不烧根。"

周老实想了一下。他种了一辈子地。知道生粪烧根。但他不知道沤两个月就不烧了。他回去之后跟村里人说了。有些人试了。有些人没试。试了的人——秋天的麦子比没试的人高了一拳。

轮作。他不能在一块地上年年种麦子。他知道轮作——今年种麦，明年种豆。豆子的根瘤菌固氮，能养地。后年再种麦，产量高。

他跟周老实说。周老实说"可以试试"。第二年他在自己的一亩地上种了豆。豆长得不好——他不太会种豆。但地确实松了。第三年种回麦子。麦子比第一年好。

这些不是大改变。不是把2026年的技术搬到公元965年。是小小的、可以做到的、用古代材料能实现的改变。堆肥。轮作。选种——他把麦穗最大的留做种子，明年种。年复一年。麦穗会越来越大。

村塾。

林远在穿越前就在村塾读书。回来之后村塾空了——原来的老先生在穿越的时候受惊，回来后病了，半年后走了。村塾没有人教。

周老实找林远。"你来教。"

林远教。

他教的课和穿越前不一样。穿越前村塾教的是《三字经》《百家姓》《千字文》。他回来加了一门课：算术。

不是《九章算术》那种算术。是阿拉伯数字的算术。加减乘除。他用树枝在泥地上写数字。1到9。加号。减号。乘号。除号。等号。

村里的孩子学得很快。孩子们没有包袱——他们没有学过筹算，不知道什么是"算筹"。他们看到的就是几个符号。1是一竖。2是一弯。3是三弯。简单。比汉字简单。

他教了一个月之后，村里有几个孩子会用阿拉伯数字记账了。王家的孩子——十岁——帮父亲记账，不再用"正"字数了。写"15""23""47"。清楚。

赵铁匠也学了。他不怕数字。他怕字母。数字他在工厂见过——量尺寸用的。他学会了用阿拉伯数字量铁料的长度和重量。

这些是小改变。不会改变历史。不会让公元965年变成2026年。

但日子好过了一点点。

堆肥让麦子多收了一成。轮作让地不歇了。数字让记账快了。这些小改变——一千年后的考古报告里不会写。因为太大了。一千年太长了。一个人做的小改变在历史里连灰尘都不算。

但对他来说够了。

他不是来改变历史的。他是来完成历史的。

碑刻了。竹简埋了。日子过着。

秋天的一个下午。他在村塾教完课。孩子们跑了。剩下一个。

男孩。八岁。王家的孩子。叫王小毛。聪明。学数字最快的那个。

王小毛蹲在泥地上。用树枝在数字旁边画了一个圆。圆里面画了一个小小的东西。

"先生。"

"嗯。"

"天外面有什么？"

林远看着他。

"你问这个做什么？"

"我爹说你是从天外面回来的。"

林远蹲下来。他看着王小毛。八岁的孩子。穿粗布短衫。草鞋。脸上有泥。眼睛黑亮的。

"你爹说的？"

"嗯。我爹说你和陈婆婆和赵铁匠从天外面回来的。天外面有铁鸟。有会发光的板子。有力从线里来的灯。"

林远沉默了一会儿。

"你爹还说了什么？"

"我爹说天外面的人不用种地。不用打铁。不用挑水。力从线里来。灯自己亮。饭自己熟。"

林远笑了一下。"你爹说的对一半。"

"哪一半？"

"力从线里来是对的。但人还是要种地。还是要打铁。还是要挑水。力从线里来——但线是人拉的。灯自己亮——但灯是人点的。饭自己熟——但米是人种的。"

王小毛想了一会儿。

"那先生你在天外面学了什么？"

林远看着泥地上的数字。1到9。加号。减号。等号。一个孩子画的圆。圆里面不知道是什么。

"学了数数。"他说。"1到9。加号。减号。等号。"

"这些天外面也有？"

"天外面的人人都会。"

王小毛低头看地上的数字。然后他拿起树枝在数字旁边写了一个"10"。

"先生，这个对不对？"

"对。1和0放在一起就是10。"

王小毛笑了。他站起来。拍了拍屁股上的土。跑了。

林远蹲在泥地上。看着那行数字。1到9。10。加号。减号。等号。一个圆。

公元965年。一个八岁的孩子学会了阿拉伯数字。这个孩子将来会把数字教给他的孩子。他的孩子再教给下一代。一代一代传。

一千年后——2025年——考古队在槐安村遗址里挖到了一些刻着阿拉伯数字的陶片和木简。他们困惑：唐宋地层的陶片上为什么有阿拉伯数字？

但林远知道了。那不是阿拉伯人传来的。是他教的。他教了一个叫王小毛的孩子。王小毛教了下一代。下一代又教了下一代。数字在槐安村传了一千年。

他站起来。拍了拍手上的土。

太阳偏西了。赵铁匠的铺子传来"叮"的一声。陈婆婆在老槐树下坐着。树影里有碑。

日子过着。

一天接一天。

没有电。没有代码。没有AI。

有数字。有堆肥。有麦子。有孩子。

够了。
