# 第014章：碑成

石碑是从青浦运来的。

方远舟找了三天。上海的石材市场大部分卖花岗岩和大理石——他不要那些。考古照片里的碑是青石——石灰岩，青灰色，质地细密，适合刻字。最后他在青浦一家老石材厂找到了一块。一米高，半米宽，厚十厘米。老板说这块青石是浙江长兴出的，和松江本地的石灰岩成分接近。

运到复旦江湾校区的时候是下午。方远舟租了一辆面包车。他和林远两个人把碑从车上搬下来。碑比林远想象的沉。他蹲下去抱底，方远舟在上面扶着，两个人抬着走了二十米进实验室。放在地上的时候"咚"的一声。

碑的表面是毛面——没有磨光。灰青色，有细小的化石碎片嵌在里面——贝壳、海百合茎。亿万年前的海生物变成了石头。林远摸了一下碑面——粗，但不扎手。刻刀能在上面留痕。

刻刀是方远舟从考古所借的。钨钢刀头。方远舟说这种刀比古代的刻碑工具硬十倍。林远不关心硬多少——他关心的是怎么刻。

他在碑前蹲下来。刻刀在手里的重量比毛笔重，比铅笔重。握法不一样——不是三指握笔，是整个拳头攥住刀柄，刀尖朝下，用力压。

他在碑的背面——不是正面——试了一刀。刀尖碰到石面的时候传来一种震动。不是铁碰铁的那种"叮"，是一种闷的"嚓"。石面上出现了一个白点——石灰岩被刀尖切开了表层。白点很小，不到一毫米。

他试了第二刀。在白点旁边刻了一条短线。三毫米。用力比第一刀大。线比第一根深。

他试了第三刀。这次他试着刻一个字——"一"。一笔横。他刻了三刀——起笔、行笔、收笔。刻痕深浅不一。起笔处太深了，收笔处飘了。

不像字。像小孩用树枝在泥地上画的。

他把刀放下。看着碑面。三个痕迹。一个点，一条线，一个不像"一"的"一"。

一千年前的那个人——就是他——在竹简上刻的"print("Hello World")"——刻痕深浅均匀，线条流畅。那个人刻了很多次。熟练了。

他还不熟。

"不急。"方远舟在旁边说。"你还有两年。"

林远点头。他拿起刻刀。在碑面边缘又试了几刀。每一刀的深度在变化——他在找手感。打铁的人叫"火候"，写字的人叫"笔意"。刻石的人叫什么？他不知道。但他知道那个感觉存在——刀和石头接触的瞬间，有一个力度的值。大于那个值，石面崩裂；小于那个值，刻不进去。刚好在那个值上——刀切进石面，石粉翻起来，线条干净。

他找了半个小时找到了那个值。

然后他在碑面正面——方远舟帮他磨了两天磨平的那面——刻了第一行字。

莫貪天外物，歸時盡成空。

十个字。竖排。从右到左。

第一个"莫"字刻了二十分钟。中间横折撇捺十二笔。每一笔至少两刀。刀刀要稳。手不能抖。

手在抖。

不是怕。是一种他从没经历过的紧张——他在写历史。不是比喻。他真的在写历史。这十个字会被埋在地下。一千年后被人发现。一千年后他会看到照片。一千年后他会回到这里刻下这十个字。

他的手在抖。因为他刻的每一笔都是他自己看过的。照片里的碑文——风化严重，但能辨认。他刻的字会被风化一千年。风化后的样子——就是他看过的照片。

他在制造照片。

他在制造他看过的那个东西。

他刻完了"莫"字。停下来看。刻痕深浅不够均匀。"莫"下面的四点——两撇两捺——有点歪。但大体上是对的。一千年后风化会抹掉那些不均匀。照片里看到的就是一个模糊的、风化的"莫"字。

他继续刻。

"貪"。二十分钟。
"天"。十五分钟——比"莫"快了，手不抖了。
"外"。十五分钟。
"物"。二十分钟。
"，"。五分钟——一个顿号，不是古代的句读，但他要刻。照片里有。
"歸"。二十五分钟——笔画多。
"時"。二十分钟。
"盡"。二十五分钟。
"成"。十五分钟。
"空"。二十分钟。

三个半小时。十个字。

他放下刻刀。站起来。腰酸——蹲了三个半小时。膝盖嘎嘎响。

碑面上十个字。楷书。繁体。竖排。刻痕不深，但清晰。他蹲下来看——字形对。笔画对。和他在本子上写的一样。

方远舟进来了。他看到碑面的时候停了一步。然后走过来蹲下来看。

他没有说"好"或者"不好"。他拿出手机拍了一张照片。然后把手机翻过来给林远看——手机屏幕上是他拍的碑面照片和考古报告里的拓片照片，并排放在一起。

两块碑面。一块刚刻好，字迹清晰。一块风化了一千年，模糊发暗。

但字形对得上。

方远舟把手机收起来。他看着林远。两个人蹲在碑的两侧。

"够了。"方远舟说。"先刻这些。公式和代码的留到后面。"

林远点头。他知道后面还有什么——平方数列、Hello World、数学公式。那些刻在竹简上，不刻在碑上。碑上只有古训和"不明符号"。

他站起来去洗手。水龙头的水冲着刻刀上的石粉。石粉是白的——石灰岩的粉末。水流进水池，白色的粉在水里散开，像墨在水里化。

第二天陈婆婆来了。

林远去接她。坐地铁。陈婆婆不坐地铁——八十八了，走不动了。林远叫了出租车。陈婆婆坐出租车的时候不说话——她已经坐过几次了，不害怕了，但不说话。

到了实验室。陈婆婆坐着轮椅——方远舟借的——被推到碑前。

她看着碑面。

那十个字刻在青石上。新的。灰白的碑面，深灰的刻痕。字迹清晰。

陈婆婆伸出手。枯干的手指摸了碑面。手指沿着刻痕滑过去——从"莫"到"空"。十个字。她的手指在每一个字上停了一下。

然后她的手指停在"空"字上。

"空。"她念了一声。

她抬头看林远。

"这就是那块。"她说。

林远蹲下来。"婆婆，哪块？"

"那块。"她指了指碑。"我在老槐树下见过。小时候。"

林远看着她。"你见过石碑？"

"不是这块。"陈婆婆说。"那块是旧的。风化的。上面的字看不清了。但我知道上面有字。我小时候去摸过。"

林远的心跳了一拍。

"那块碑后来呢？"

"没了。"陈婆婆说。"有一天老槐树被雷劈了。树倒了。碑碎了。我爹把碎块搬到河边扔了。"

林远闭了一下眼。

碑碎了。碎块被扔在河边。一千年后——如果那些碎块还在——考古队能不能找到？

考古报告里说"残高62厘米"——碑是碎的。残存的部分。其余部分——碎块——被陈婆婆的父亲扔在河边了。

但考古报告里有完整的碑文拓片——"莫贪天外物，归时尽成空"。拓片是从残碑上拓的吗？还是从碎块上拓的？

如果是残碑——62厘米——足够刻下十个字。碑的原高是一米。残存62厘米。十个字在62厘米内刻得下。

碎块在河边。也许千年后碎块被泥沙埋了。也许被河水冲走了。也许被人捡走了。

但残碑——62厘米那块——一直在老槐树下。在土里。直到方远舟的考古队挖到它。

"婆婆。"林远说。"那块碑是我刻的。"

陈婆婆看着他。

"我知道。"她说。"你不是刻过了吗。"

林远愣住了。

"你刻过了。"陈婆婆又说了一遍。"在小时候之前。你早就刻过了。你回来之后刻的。然后那块碑就在那里了。我小时候见过它。"

她笑了。八十八岁了。牙齿掉了一半。但笑的时候嘴角往上弯。

"远儿。你以为你还没刻。你已经刻了。我小时候就见过。"

林远蹲在碑前。他看着碑面上的十个字。

他已经刻了。在过去。在他还没回去的时候。他已经刻了。陈婆婆小时候见过。陈婆婆在穿越前念的那句古训——是她从碑上看来的。碑是他刻的。古训是他写的。陈婆婆念了八十八年。

他回去之后刻碑。碑被埋了。陈婆婆小时候看到了。念了八十八年。穿越前念给他听。他穿越到现代。看到了考古报告。知道了闭环。准备了碑文。回去刻碑。

蛇咬住了自己的尾巴。

他站起来的时候手机响了。方远舟的消息。

"天文台刚发报告。裂缝停止收窄了。"

林远看着手机。

方远舟又发了一条："不止停止收窄。它在重新增大。角直径比上个月大了0.3%。"

裂缝在开。

它在重新打开。
