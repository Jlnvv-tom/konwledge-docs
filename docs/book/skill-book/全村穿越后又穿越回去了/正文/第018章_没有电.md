# 第018章：没有电

林远回到茅屋。

茅屋是他穿越前住的。在村口往西数第三间。土墙。茅草顶。木门。门后面是他的书房——一张矮桌、一块砚台、两支毛笔、一摞竹简和粗纸。

他在矮桌前坐下。

桌上还有他穿越前抄的《九章算术》。树枝——他用来在泥地上写字的那根——不在了。穿越的时候丢了。但桌上的竹简和纸还在。

他拿起毛笔。在砚台上蘸墨。墨是穿越前磨的，干了。他往砚台里倒了一点水——水壶在角落里，还有半壶水。水倒进去，墨化开了一点。不浓。淡。

他在纸上写了一个字。

字洇了。

纸太粗。纸纤维不均匀。墨一上去就往四周洇。写出来不是字，是一团黑晕。他写了十年铅笔和钢笔——在光滑的纸上。笔尖划过去，墨水留痕。现在回到毛笔和粗纸——他控制不了了。

他写了五个字。只有两个能辨认。其余三个洇成了墨团。

他把笔放下。

他想写代码。print("Hello World")。但代码需要精确。每一个符号不能错。冒号、括号、引号——毛笔写不出来这些符号。就算写得出来，纸洇了，看不清。看不清就等于没写。

他换了竹简。竹简不洇——竹面光滑。但他只有刻刀，没有——

他有刻刀。铜刻刀。赵铁匠打的。

他在竹简上刻了一行字。不是代码——是一行古文："乾德三年秋，村人归。"

刻痕歪歪扭扭。他刻碑的时候练了三个月，但那是刻石头。刻竹子不一样——竹纤维有方向。他记得在实验室刻竹简的时候，赵铁匠打的那把铜刀咬得住竹纤维。现在刀在手里。但他的手——

他的手十年没刻过竹简了。他在实验室刻了三个月碑，加上几片竹简。但那是十年里最后三个月的事。前面九年半他没有碰过刻刀。他碰的是键盘。

他的手会打字。不会刻字。

他把竹简放下。站起来。走出茅屋。

他走到井边。井在村子中央。他用绳子提了一桶水上来。水是清的。他在水桶里看了一眼自己的倒影——脸是黑了。穿越前他在实验室里白。现在日头晒了三天——不，回来才几个小时。但古代的日头比上海烈。

他把水桶放下。

他走到村口老槐树下。陈婆婆不在了。她回屋了。槐树还在。空坑还在。

他在坑边蹲下来。从怀里掏出竹简。三片。一片是平方数列。一片是Hello World。一片是数学公式。

这三片竹简是从2026年带回来的。它们和考古报告里的照片一模一样。他回去之后要再刻一套——不，不是再刻一套。考古报告里的竹简就是他带回来的这些。等等——

不对。

考古报告里的竹简是公元920年左右碳化的。他在现代刻的竹简是2026年刻的。他从2026年带回来竹简——这些竹简在他回到公元965年后，要埋在地下。一千年后被人挖到。碳化。变成考古发现。

所以竹简不归他刻。竹简已经刻好了。他在2026年刻的。他带回来了。他要做的就是——埋。

但碑不一样。碑是在古代刻的——用古代的材料，古代的工具。他要回到古代之后亲手刻碑。考古报告里的碑——风化痕迹和碳化痕迹与千年埋藏一致——说明碑是回到古代后刻的。

竹简是2026年的产物。碑是公元965年的产物。

他明白了。

竹简不需要再刻。带回来埋就行。碑需要刻。

他从坑里站起来。他要做的事很清楚：

一、刻碑。
二、埋竹简。
三、埋碑。

但刻碑需要时间。他需要练习刻字。他需要在碑上刻古训、刻不明符号。不明符号——他选了一些数学公式和代码片段。在碑上刻这些——用毛笔写不了，用刻刀可以。但碑面和竹简不一样。碑面是石头。

他已经练了三个月了。手在碑上刻字的稳定性比竹简上好——石头不像竹子那样滑。但精度不够。考古照片里的刻痕——他看了很多遍——线条是均匀的。他的线条还做不到均匀。

他需要继续练。

但现在他想试另一件事。

他想发电。

不是真的发电。他知道在公元965年发电是不可能的。但他想试——用最简单的材料——看能不能让一盏灯亮起来。

材料需要：铜线。磁铁。转子。

铜线——赵铁匠可以打铜丝。村里有铜——从穿越前留下来的铜器。
磁铁——没有。村里没有天然磁石。松江地区不出磁石。
转子——可以用木头削。

没有磁铁。发电的基本原理是电磁感应——导体在磁场中运动产生电流。没有磁场就没有电。

他可以做一个最原始的电池——伏打电池。铜片、锌片、盐水。铜有。锌——没有。锌在唐宋时期不作为单独金属存在。 brass（黄铜）里有锌，但提取不出来。

他能做什么？

什么也做不了。

他有知识。他知道电是什么。他知道电磁感应。他知道半导体。他知道AI。他知道代码。他知道这些东西的原理。但原理不能发电。原理不能点亮灯。原理不能让机器运转。

他需要材料。他需要铜线——不是赵铁匠能打的那种粗铜条——是细的、长的、绝缘的铜线。他需要磁铁。他需要锌。他需要硫酸。他需要——太多了。

一个人。在公元965年的一个村庄里。想复刻2026年的技术。

不可能。

他回到茅屋。坐在矮桌前。砚台里的墨干了。竹简和粗纸在桌上。毛笔在笔架上。

他拿起毛笔。蘸了水。在纸上试写。

"print("Hello World")"

墨洇了。但这次他写得很轻——几乎不沾纸。他控制了力度。字很小。勉强能辨认。

p-r-i-n-t-(-"-H-e-l-l-o- -W-o-r-l-d-"-)

他看着那行字。歪歪扭扭。像虫爬。在粗纸上。用毛笔写的代码。

他拿起纸。举到窗户的光下看。字迹淡。纸粗糙。有些字母糊在一起——"r"和"i"看不出区别。"l"和"l"粘在了一起。

这写不了代码。

代码需要精确。一个字母错了程序就报错。一个括号漏了就跑不起来。纸和毛笔的精度不够。

他需要铅笔。铅笔的石墨芯可以在纸上留痕，不洇。精准。可擦。

但铅笔是18世纪发明的。公元965年没有铅笔。

他需要纸。光滑的纸。不是这种粗纤维的竹纸——是打了浆、加了胶、砑光过的纸。

他需要——他需要一整个工业体系。

他一个人。一双手。十年学的知识。

不够。

他把纸放下。把毛笔放下。坐在矮桌前。茅屋外面有鸡叫。有风。有远处赵铁匠铺传来的"叮"声。

他低下头。

十年的知识。2026年的世界。电、代码、AI、显微镜、手机、互联网——所有这些都在他脑子里。但出不来。他没法把脑子里的东西变成手里的东西。中间隔着——

一千年。

一千年的工业差距。一个人填不上。

他不是方远舟。方远舟在一个有电的世界里研究古代。他在一个没有电的世界里想念现代。

他翻开笔记本——不是方远舟那本"無憾"，是他自己记的——在古代粗纸上用毛笔写的——

写不了。纸太粗。字洇。代码写不了。

他把纸合上。

在公元965年写代码，和在2026年用毛笔打铁一样荒谬。
