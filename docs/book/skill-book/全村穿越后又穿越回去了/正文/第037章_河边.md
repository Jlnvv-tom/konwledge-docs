# 第037章：河边

回来后第十年。赵铁匠四十五。不打铁了。

手抖。眼花。打不了。

他每天去河边坐。竹椅。从家里搬的。椅子是穿越前的——穿越的时候带过去了。带回来了。椅子还结实。竹子是活的。十年穿越——在上海的板房里放着——没有散。回来后又在铁匠铺前面放了十年。还是没散。

竹椅子。竹靠背。竹扶手。竹坐面。穿榫结构。不用钉子。不用胶。竹和竹咬在一起。

赵铁匠在椅子上坐着。河边。水在流。

他每天下午去。日头偏西的时候。坐到天黑。有时候坐到月亮出来。

---

镇上来收税的差役路过。

差役姓刘。三十出头。穿皂衣。腰间别一把刀——没鞘，用布包着。不拔。收税的不拔刀。带刀是为了唬人。

刘差役每月来一次。走二十里路从镇上到槐安村。收夏税和秋税。粮。布。麻。村里交了。他记在册子上。回镇上交差。

他路过河边的时候看到了赵铁匠。一个光膀子的中年男人坐在竹椅上看水。

"嘿。干什么的？"

赵铁匠没回头。"看水的。"

"看水？不用干活？"

"不干了。"

刘差役走到他旁边。看了看赵铁匠。赤着上身。肩膀宽——左手肩比右手厚一指。胸膛上有疤——不是刀疤。是烫伤。铁花溅的。

"你以前干什么的？"

"打铁的。"

"铁匠？"刘差役看了看他身边。没有锤子。没有砧子。没有炉子。

"在哪里打？"

"家里有铺子。村东。"

"为什么不打了？"

"手抖。"

赵铁匠伸出右手。手在微抖。

刘差役看了一眼。他不太懂。打铁的手他见过——镇上的铁匠。手粗。黑。有茧。但赵铁匠的手——

"你的手不像打铁的。"

赵铁匠低头看自己的手。

白的。

比他穿越前白了。不是没晒太阳——回来后他打了三年铁。赤着上身。日头晒。但手——手掌还是白的。手指还是白的。

在上海的七年他干了什么？接电线。装电灯。修配电箱。都是手上的活。但不是打铁。不是炉子前面。不是火星溅到手上的活。

他的手在工厂里白了。不是工厂不晒——工厂有顶。顶下面干活。手不见日头。七年。手白了。

回来后打了三年铁。手又黑了一些。但没有穿越前黑。穿越前他打了二十年铁。手是黑的。碳灰。铁屑。火星。二十年的痕迹嵌在皮肤纹路里。洗不掉。

但现在——十年的工厂白加上三年的铁匠黑——混合起来。不像铁匠。不像工人。像一个——他不知道像什么。

"不像打铁的。"刘差役说。"倒像个——读书的。"

赵铁匠笑了一下。读书的。他在上海上过夜校。学过电工。学过——

他读过什么？他读过小学课本。认了简体字。学了阿拉伯数字。学了一点电工基础。

他是读书人吗？

他不是。他是铁匠。但铁匠的手不像铁匠了。读书人的手不像读书人。像什么？

像——两种东西混在一起。铁和书。锤子和笔。黑和白。

赵铁匠看着自己的手。

"我打了二十年铁。"他说。"在上海打了七年电。回来又打了三年铁。手变了。"

刘差役不懂"上海"是什么。"上海"这个词他在镇上听过——有人说松江府北边有个地方叫上海。但不知道为什么赵铁匠说"在上海打电"。

"打电？什么东西？"

"电线。把线接好。灯就亮了。"

刘差役看着他的眼睛。"灯——亮了？不用油？不用蜡？"

"不用。力从线里来。"

刘差役沉默了一会儿。他看着赵铁匠。这个光膀子的中年男人。手在抖。手是白的。胸膛上有烫疤。坐在竹椅上看水。

"你——"刘差役犹豫了一下。"你从哪里来的？"

赵铁匠没回答。他看着河水。水在流。阳光在水面上闪。有一片叶子在水上漂。叶子转了一圈。转走了。

"从这里来的。"他说。

刘差役没再问。他收了税。走了。

---

走之前刘差役回头看了赵铁匠一眼。

赵铁匠还在竹椅上。看水。背对着他。

赤着上身。肩膀宽。左手肩比右手厚一指。

刘差役走了。

赵铁匠没动。他看着水。水在流。叶子漂走了。又一片叶子漂过来。

他在河边坐到天黑。

月亮出来了。水面上有月光。月光碎了。又合了。又碎了。

他想起在上海的时候。工厂宿舍。上铺。下铺的河南小伙子打游戏。手机屏幕的蓝光映在天花板上。窗外有路灯。路灯不灭。

这里没有路灯。月亮是唯一的灯。月亮不是力从线里来的灯。月亮是天上的灯。不用人点。不用人接电线。不用人开关。

月亮自己亮。自己灭。

他在竹椅上坐着。月亮在走。水在流。风在吹。

他不知道他在等什么。也许什么都没在等。也许在等水把什么东西冲过来。也许在等月亮走完。也许在等天亮。

天亮了他回铁匠铺。看看炉子。看看砧子。看看锤子——在矮桌上。和铜刻刀并排。

不看也行。

看也行。

他在河边坐着。坐着就坐着了。
