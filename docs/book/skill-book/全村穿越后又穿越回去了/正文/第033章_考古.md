# 第033章：考古

2025年。七月。松江。槐安村遗址。

方远舟的团队在遗址上挖了四个月了。六个人。三个研究生。两个技工。一个方远舟。加上偶尔来的当地工人。

遗址面积不大——约三千平方米。一个村子的规模。他们按五米见方的探方网格挖。已经挖了十二个探方。

遗址的分层很清楚。

第一层：表土层。现代。二十厘米。沥青碎块、塑料碎片、钢筋水泥——这是2026年"时空异常事件"之后在这块地上建的临时建筑残留。

第二层：明清文化层。三十厘米。碎瓷片、铜钱、铁钉。

第三层：唐宋文化层。四十到六十厘米。这才是重点。

第三层里有生活区的痕迹。灶坑。灰坑。柱洞——房子立柱子的坑。还有一条浅沟——排水沟。

在生活区的灰坑里——垃圾坑——他们发现了陶片。不是普通陶片。碎陶碗的底部。上面有刻痕。

"方老师！这个陶片上有字！"

研究生小刘拿着陶片跑过来。方远舟接了。翻到底部。

刻痕。不深。但能辨认。

阿拉伯数字。

"12"和"3"。刻在一个陶碗的底部。像是编号——也许是这个碗是第12号的第3个？也许别的。

方远舟看着陶片上的数字。碳化的痕迹——不是书写，是刻划。和碑上的刻痕风格一致。

"拍照片。编号。记坐标。"他说。

小刘跑了。

接下来的三天。生活区灰坑里又出土了七片有刻痕的陶片。五个有阿拉伯数字。两个有——

"方老师你看这个。"小刘拿了一片木简残片。

木简。碳化严重。黑的。脆。但表面有刻痕。

方远舟拿在手里看了很久。他拿放大镜看。

刻痕。字母。

p-r-i-n-t

"print"。

他的手停了。

"还有这个。"小刘拿了一片更小的残片。

-H-e-l-l-o

"Hello"。

方远舟把两片木简放在桌上。他坐在折叠椅上。看着那两片碳化的竹简。

print。Hello。

他二十年前在实验室里——在那间有空调有手冲咖啡有咖啡味的实验室里——第一次看到林远在电脑上打出的那行字。print("Hello World")。

现在他在松江的考古探方里。三十七度的天。板房里四十度。没有空调。没有手冲咖啡。只有一台电池台灯和两片碳化的竹简。

竹简上的字——碳化了一千年。模糊了。但能辨认。

"print"和"Hello"在竹简上。在一千年前被刻上去。在地下埋了一千年。现在被挖出来了。

他二十年前在实验室里看到考古报告照片里的那行字——"print("Hello World")"。他当时震惊。但没有现在这样。

因为现在是实物。竹简。碳化的纤维。刻痕。手指能摸到的凹凸。一千年的土味和碳味。

他摸着竹简上的刻痕。刻痕不深。但一千年后还在。

"方老师……这些字母怎么解释？"小刘问。

方远舟没有回答。他把竹简放在桌上。站起来。走出板房。

他站在遗址边缘。看着探方。探方里有灰坑——生活区垃圾坑——里面有刻着阿拉伯数字的陶片和刻着拉丁字母的木简残片。

唐宋文化层。公元900年前后。

这些数字和字母不应该出现在这个地层里。但它们在了。碳化痕迹和刻痕风化与千年埋藏一致。不是后人埋的。是那个年代的。

方远舟站在探方边。他想到了林远。二十年前——林远蹲在这片灰坑的位置（那时候是柏油路）——在帐篷区——在帐篷壁上用手指划字母。二十年后——他站在灰坑边——看到竹简上的字母。

他回到板房。翻开林远的笔记本。翻到第48页。

"今天我第一次写代码。print('Hello World')。屏幕上出现了Hello World。你好，世界。我在跟这个世界打招呼。"

他把笔记本合上。

---

墓地区在遗址西侧。小山坡上。团队上周开始挖墓地。

宋代的民间墓地很简单。土坑。少数有棺钉——铁钉。大多数什么都没有。骨头都化成土了。只剩土色深浅不同——深色的地方是尸体曾经躺的地方。

大部分墓没有随葬品。只有少数有——铜钱、陶碗、铁刀。

有一座墓不一样。

墓在墓地区最东边。靠近老槐树的位置。棺钉是铁的——四枚。棺木化完了。但棺底有一样东西。

"方老师。这个墓里有一把刀。"

方远舟跳进墓坑。半米深。黄土。棺底的位置有一把铜刀。

铜的。发绿。锈了。但形状完整——长条形。一端有刃。另一端有握手弧形。握手处有——

他翻过来。刀背上有字。

歪歪扭扭。一个字。

"趙"。

方远舟的手停了。

他蹲在墓坑里。拿着铜刀。看着那个"赵"字。

赵铁匠。赵铁匠打的铜刻刀。刀背上的"赵"字。赵铁匠自己刻的。歪歪扭扭。

他不知道刻了几个字。二十年打铁加上七年工厂。他打了很多东西。但铜刻刀——他只打了一把。给林远刻碑用的。

这把刀在赵铁匠的墓里。赵铁匠的随葬品。

方远舟把刀放在手心。铜刀重不到二两。长五寸。刃钝了——用过。刀背上有锈。但"趙"字还在。

旁边还有一样东西。在棺底另一侧。

一把铁锤。锤头生锈了。锤柄——木头的——化完了。只留下锤头。锤头上有包浆的痕迹——二十年的手汗。

赵铁匠的锤子。穿越前的那把。在上海放在床头柜上。回来后重新别在腰上。赵铁匠走后——锤子和铜刻刀一起放在矮桌上。后来——

后来谁把它们放进了赵铁匠的棺材？林远。林远把锤子和刻刀放在赵铁匠的棺材里。作为随葬品。

赵铁匠在地下。一把锤子。一把刀。打铁和刻字。力和痕。

方远舟坐在墓坑里。半米深。黄土。三十七度。

他拿着铜刻刀。看着"趙"字。

"赵铁匠。"他说。声音在墓坑里闷闷的。"你说你是碳。"

没有人回答。

他把铜刀放在桌上。拍了照。记了坐标。

然后他站起来。爬出墓坑。

他抬头看天。

天空——

松江上空——遗址正上方——

闪了一下。

白色的。一瞬。

也许是飞机。也许是鸟。也许是什么都不是。

方远舟看着那块天空。什么也没有了。只有蓝。

他笑了。

"你好。"他说。声音很小。

"一千年前的世界。"
