# 第019章：赵铁匠的发电机

赵铁匠花了三天打铜丝。

不是三天三夜。是白天打。晚上睡觉。三餐吃粮。三天。

铜是村里的——穿越前留下来的铜盆。穿越的时候铜盆没带走。回来后还在墙角，生了一层绿锈。赵铁匠把铜盆拆了。砸平。放到炉子里烧。烧到暗红。拿出来放到砧子上。锤。

"叮。叮。叮。"

一锤一锤打。铜在高温下变软。他从中间往外打——打薄。铜面变宽。变薄。然后用凿子切成条。条不均匀——宽窄不一，有的地方厚有的地方薄。

林远在旁边看。他看到铜条的时候就知道不行了。铜条太粗。不是铜丝。是铜条。直径至少有三毫米。他在实验室见过的铜线——漆包线——直径零点几毫米。差距是一个数量级。

赵铁匠把铜条再烧。再打。打了一遍又一遍。三天下来，他把铜盆打成了——

一根两尺长的铜条。最细的地方有筷子粗。最粗的地方有手指粗。表面凹凸不平。有锤痕。有烧痕。

赵铁匠把铜条放在林远面前。

"行不行？"

林远拿起来。铜条在手里沉。弯了一下——能弯。但不均匀。弯的时候粗的地方不弯，细的地方弯了。

"不行。"他说。

赵铁匠的脸暗了一下。他拿起锤子。"我再打。"

"打不了。"林远说。"铜太软。你的锤子打不出细丝。需要一种——拉丝的模具。铁板上有孔。铜从孔里穿过去就变细。"

赵铁匠想了想。"铁板打孔。能打。"

"孔要多小？"

"多小？"

"头发丝那么细。"

赵铁匠沉默了。

头发丝。他的锤子和凿子在铁板上能打出筷子粗的孔。头发丝——他做不到。他打了一辈子铁。没有打过那么小的孔。

"算了。"林远说。"用这根吧。绕线圈。"

他在村里找了一块木头。圆柱形。一握粗。他把铜条绕在木头上——绕了六圈。铜条太硬，绕不动。赵铁匠帮他烧了铜条。烧软了再绕。绕了六圈，铜条就用完了。

六圈。他在实验室里见过的线圈——几千圈。几万圈。

六圈不够。但他只有两尺铜条。

"磁石呢？"赵铁匠问。

磁石。林远在来之前想了。天然磁石——磁铁矿——在某些地方的河砂中存在。村里的河——松江上游的小河——如果上游有铁矿脉，河砂里可能有磁铁矿砂。

"去河边。"他对赵铁匠说。"淘砂。黑色的、重的砂子。"

赵铁匠去了。带了两个竹筐。去了三天。

第一天什么也没淘到。河砂是黄的，细的。没有黑色的。

第二天他往上游走了半里路。河窄了。水急了。他在石头缝里掏。掏到了一把黑色的砂——重。不均匀。有细有粗。

第三天他淘了半筐黑砂。带回来。

林远拿了一片薄铁——村里的旧铁片——放到黑砂里。黑砂不吸附。磁铁矿有磁性——但磁铁矿砂的磁性非常弱。他需要用铁片去试——如果黑砂能吸住铁片，说明有磁性。

铁片放上去。黑砂不动。

不行。这些黑砂不是磁铁矿。是普通的铁砂。

赵铁匠站在旁边。看着黑砂和铁片。

"没有磁力。"林远说。

赵铁匠没说话。他蹲下来。拿起一把黑砂。用手捻。砂子从他指缝里漏下去。黑砂在阳光下闪了一下——不是金属的光。是矿物的光。

"我再去。"他说。

"去哪里？"

"上游。再往上游走。山里。"

林远摇头。"就算找到磁石——磁性也不会强。我们的铜条太粗太短。六圈线圈在微弱的磁场里转——产生的电流连一根毫毛的触感都不够。"

赵铁匠站起来。

"灯点不亮？"

"点不亮。"

"那力呢？电的力呢？比手大的力——有没有？"

"没有。"

赵铁匠看着铁匠铺。炉子。风箱。砧子。锤子。铜条。黑砂。

他在工厂待了七年。接过电线。装过电灯。修过配电箱。他摸过电——有一次接错线被电了一下，手麻了半天。那种力——从线里来的力——他记得。

现在铜条在他手里。木头上有六圈铜条。没有磁石。没有电流。没有力。

他把铜条从木头上拆下来。铜条弹了一下——烧软了但还有弹性。

他走到炉子前。炉子灭了。他把铜条扔进炉膛里。铜条落在炭灰上。发出一声轻响——"叮"。铜和铁碰撞的声音。然后安静了。

赵铁匠站在炉子前。

他拿起锤子。放在砧子上。

"赵叔。"

林远站在门口。

"我打不了电。"赵铁匠说。他没有回头。"我能打铁。打铜。打锡。但我打不了电。"

林远没说话。

"力从线里来。"赵铁匠说。"线太粗。力过不来。磁石找不到。力没有源头。线没有路。灯没有光。"

他转过身。脸上没有泪。但他的眼睛——林远在上海见过那种眼睛。在赵铁匠站在灯管下面看了一整夜的那天晚上——那种眼睛。

不是绝望。是明白。

赵铁匠明白了。他在工厂学到的东西——电、线、磁、力——和林远学的代码一样。回不来。在公元965年的槐安村，他只有锤子、风箱、炉子、炭、铁、铜。他能打铁。但他打不出电。

"我打铁。"赵铁匠说。他把锤子从砧子上拿起来。握在手里。二十年的锤子。包浆还在。

"你打你的铁。"林远说。

赵铁匠开始生炉子。炭。火。风箱。炉膛里的铜条在炭火上慢慢变红。

他在炉子前蹲下来。火焰照着他的脸。赤着上身。锤子在手里。砧子在面前。

他打铁。

"叮。"

一锤。

和穿越前一样。和十年前一样。和二十年一样。

但人不一样了。
