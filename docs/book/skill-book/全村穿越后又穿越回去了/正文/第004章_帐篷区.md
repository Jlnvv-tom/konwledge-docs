# 第004章：帐篷区

他们被塞进了一辆比房子还大的铁肚子里。

林远是最后一个上的。他站在车门口看了半天——不是门，是一块折叠起来的铁板，放下来之后变成三级台阶。台阶上有防滑纹，和刀鞘上的鱼鳞纹不一样，是一种更规整的方格子。他踩上去的时候脚底传来一种橡胶的触感，软的，像踩在猪皮上。

方远舟在车上。他一直跟着林远，用纸笔和偶尔蹦出来的几个字官话交流。车里有空调，林远不知道那叫空调，但他能感觉到——外面是六月上海的三十七度，车里突然凉了下来。凉得他起了一层鸡皮疙瘩。

车开了。林远抓住了头顶的扶手。不是因为他知道要抓扶手，是因为车一开他整个人往后仰，差点摔倒。他看到窗外——灰地面在往后退，灰色柱子在往后退，天上的铁鸟也在往后退。但车里的他没有动。他在一个移动的盒子里，外面的世界在动，他不动。

赵铁匠坐在后排。他没用扶手，两只手攥着锤子，两脚踩实了地板，纹丝不动。但他的脸色发白。

一千多人挤在十几辆大车里，开了大约两刻钟。林远没有计时工具，但他的身体有感觉。他的胃告诉他过了多久——从穿越到现在没吃过东西。

车停了。门打开。热浪涌进来。

林远下车的时候看到了一片白色的东西——千顶白色帐篷。整整齐齐，一排一排，像麦田一样方方正正。帐篷之间拉着绳子，挂着牌子。牌子上写着字——简体字，他不全认识。但有些字他能猜："男""女""水""食"。最后一个是画了一个杯子，冒着热气。

帐篷区外面停着更多的车。穿白衣服的人在帐篷之间穿梭，手里拿着板子或纸。穿军装的人站成一排，腰间挂着东西。远处有一面巨大的旗——红的，上面有星星。林远不认识那面旗，但他知道那是旗帜。旗帜代表这个地方是谁的。

方远舟领着他走到一顶帐篷前面。帐篷里有桌子，桌上有纸，纸旁边有人。一个穿白衣服的年轻女人拿了一碗东西过来，递给林远。

碗里是汤面。但不是他见过的汤面。面条是卷的，黄的，比他吃过的面细。汤是红的，上面漂着油花和菜叶。一个塑料碗——他不知道塑料是什么——很轻，轻得不像碗。

林远接过碗的时候闻到了味道。

他的手停了一秒。

那碗面的味道是他没有闻过的。不是麦子的味道，不是菜的味道，不是油的味道。是所有这些味道加上一种他说不出来的东西——后来他知道那叫"味精"。但此刻他不知道，他只知道那股味道击中了他胃里的饥饿，像一拳打在空肚子上。

他低头吃了一口。

面条是软的。比他吃过的任何面都软。牙齿咬下去几乎不用力，面就散了。汤是咸的，但咸得不冲，咸里有一种回甘。他第二口就喝了汤，第三口把面塞进嘴里，第四口碗就空了。

他端着空碗站在那里。

方远舟看着他。

"还有。"方远舟说。指了指帐篷外面。

林远摇了摇头。不是不饿——是太快了。他在村里吃一碗面要嚼很多口，每一口都有麦壳的粗糙感。这碗面太顺了，滑进喉咙就没了，像喝水。

赵铁匠不吃。

林远端着第二碗面走出去的时候，看到赵铁匠蹲在帐篷外面的地上。锤子放在脚边，两只手在地上抠——灰地面有一块松了的地方，他在抠灰。抠下来的灰碎堆在膝盖旁边。他不吃。

"赵叔。"

赵铁匠没抬头。

"不食。"

两个字。林远知道赵铁匠的脾气。他不吃的意思不是不饿，是不认。他不认这碗面。他不认这个灰地面的世界。他不认天上飞的铁鸟。他攥着锤子，脚边是抠下来的灰碎，像在说：这地是我的，我能挖开它。

林远把面放在赵铁匠旁边。没说话。进帐篷了。

帐篷里有一块板子——不是方远舟那种小板子，是一块大的，挂在帐篷柱子上。板子在发光，上面有人。

不是画。是真人。

林远看到板子上有一个灰地面，灰地面上有一群人。那些人穿的衣服他认得——麻布，草鞋，梳髻。是村民。是两小时前的他们。

板子上有一个人在说话——穿着整齐，坐在一张桌子后面，面前有纸。那人嘴里说的词里有"槐安村"三个字，但其余的听不懂。画面切换，出现了一张地图，地图上有一个红点。然后画面又切换，出现了一个白头发的老人，脸上有皱纹，穿着白大褂，在黑板上画了一个圈。圈里写着"时空异常"四个字——繁体字，林远认得。

时空。异常。

林远看着板子。画面里的人说了一句话，方远舟在旁边轻声翻译："他说，这不是 cosplay。"

画面切换成英文。林远看不懂。但画面切换回来之后，一个新画面出现了——一个穿制服的人站在讲台后面，讲台上有一个标牌。方远舟说那个标牌上写的是"国务院新闻办公室"。

国务院。林远在书上见过"国务院"这个词。宋以前的唐，有"尚书省"，类似的意思。管天下大事的。

这件事已经惊动了管天下大事的人。

帐篷外面传来一阵声音。几个穿白衣服的人拿着纸和板子走过来，挨个帐篷敲门。进来的那个人对林远说了一串话，方远舟翻译："他们要登记你们带来的物品。武器、贵重物品、私人物品都要登记。"

林远身上什么也没有。穿越前他在看书，身上只有一根树枝和一块砚台。树枝不知道掉哪里了，砚台在怀里——他摸了摸，还在。

他跟着工作人员出去登记。帐篷区中间有一张长桌，村民们排队。林远看到了村长周老实在前面，手里抱着一摞族谱。赵铁匠把锤子放在桌上又拿走了。王家的媳妇在登记孩子的出生年份。

排到陈婆婆的时候，问题来了。

陈婆婆坐在帐篷门口的地上，怀里抱着那棵老槐树苗。泥土包着根，用一块麻布裹着。她不排队。工作人员蹲到她面前说话，她不理。方远舟过去蹲下来，用纸笔写："婆婆，需要登记物品。"

陈婆婆抬头看了他一眼。

"这是槐安村的根。"她说。声音不大。但说得很清楚。

方远舟在纸上写："我知道。登记不是没收。只是记录。"

陈婆婆低头看怀里的树苗。苗小，只有膝盖高，叶子嫩绿，茎上有细绒毛。在灰地面和白色帐篷之间，那一丛绿色刺眼得像滴在墨上的血。

"它跟老槐树不一样。"陈婆婆说。

方远舟写："哪里不一样？"

陈婆婆摸着树苗的叶子，没有回答那个问题。她说了一句别的话：

"老槐树走的时候留了根。它没走成。这棵是它留的。"

工作人员在旁边等着。方远舟看了他们一眼，站起来，对他们说了一句话。那句话林远听不懂，但工作人员点点头走了。

方远舟在纸上写："这棵树不登记了。你保管。"

陈婆婆没有表示。她把树苗往怀里紧了紧，闭上眼睛。

林远站在旁边。他看着陈婆婆怀里的那棵树苗——穿越前，老槐树没有过来。但陈婆婆花盆里的这棵苗过来了。

带泥土。带根。

他不知道这意味着什么。但他隐约觉得，陈婆婆知道。她从穿越前就在念那句古训。她从一开始就知道些什么。

帐篷区远处，天空的西边，那个淡淡的白色光点还在闪。

没有关。
