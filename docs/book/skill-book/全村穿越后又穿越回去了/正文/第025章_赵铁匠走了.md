# 第025章：赵铁匠走了

回来后第十二年。赵铁匠五十二了。

他在河边走的时候摔了。

不是走路摔的。是腿软。他的右腿——站在铁匠铺里打铁的那条腿——膝盖的软骨磨没了。在上海的时候他不知道。回来之后打了两三年铁，膝盖开始疼。然后肿。然后走路一瘸一拐。

周老实让他去看郎中。镇上的郎中看了，说是筋骨病，贴膏药。贴了半年没用。赵铁匠不贴了。

他每天去河边坐。坐着的时候腿不疼。站起来的时候疼。走几步就好了。但那天——

他从竹椅上站起来的时候右腿一软。膝盖弯了。整个人往右倒。头磕在河边的石头上。

是王小毛看到的。王小毛现在二十三了，每天去河边挑水。他看到赵铁匠倒在地上，头上有血。跑过去扶。赵铁匠没晕。眼睛睁着。但嘴歪了。说话含糊。

"远儿……叫远儿……"

王小毛跑去找林远。

林远到的时候赵铁匠还坐在河边。头上血流了一脸。王小毛用袖子按着他的头。赵铁匠的眼睛半开。嘴歪着。

"赵叔。"

"嗯。"赵铁匠看到他了。眼睛动了一下。

林远把他背回茅屋。让他躺下。叫了郎中。郎中来了。看了。说是中风——脑里有瘀血。古代叫"卒中"。郎中开了药。活血化瘀的。

林远知道——在现代这叫脑卒中。需要送医院。需要做CT。需要溶栓或者手术。但这里没有医院。没有CT。没有溶栓药。

他有郎中和草药。

他给赵铁匠喂了药。三天。

三天里赵铁匠躺在茅屋里。不能动。右半边身子瘫了。右手——打铁的手——握不了拳。嘴歪。说话含糊。

林远守了三天。

第三天傍晚。赵铁匠清醒了一点。眼睛能转了。嘴不那么歪了。说话——含糊但能听懂。

"远儿。"

"嗯。赵叔。"

"锤子呢。"

"在铁匠铺。"

"……拿过来。"

林远去铁匠铺拿锤子。锤子在砧子上。和铜刻刀并排。他拿了锤子。回来。

赵铁匠看着锤子。他不能转头——脖子僵。林远把锤子放在他左手里。左手还有劲。他握住了锤子。锤子在他的手里——二十年的锤子。穿越前的那把。

"远儿。"

"嗯。"

"我打了二十年铁。"

"嗯。"

"在上海打了七年电。"

"嗯。"

"回来又打了三年铁。然后手抖了。打不了了。"

"嗯。"

"……我打了一辈子铁。"

他握着锤子。手在抖。锤子在手里晃。但没掉。

"远儿。"

"嗯。"

"铁里面有花纹。"

"嗯。"

"你看到了吗？"

林远看着他的眼睛。赵铁匠的眼睛——浑了。不如在上海的时候亮。但他在问。他想知道。

"看到了。"林远说。"像麦穗。像河。"

赵铁匠笑了。嘴歪着。但笑了。

"好。"

他闭上了眼睛。

锤子从手里滑下来。掉在床上。没出声。被褥接住了。

赵铁匠走了。

---

林远在赵铁匠坟前站了很久。

坟在村西山坡。陈婆婆旁边。土包。木板。烧了"赵"字。

林远从兜里掏出一小包东西。铁屑。从赵铁匠的铁匠铺地上扫的。二十多年的铁屑。黑的。像粉。

他把铁屑撒在坟前的土上。

铁屑落在土上。看不到。混进了泥里。

铁里面有碳。碳决定了花纹。赵铁匠是碳——在上海说的那句话。他是碳。他在铁里。他决定了花纹。

现在铁屑在土里。混在泥里。一千年后——如果考古队挖到这个山坡——他们会不会在土里发现铁屑？也许。也许不会。铁屑太少了。会氧化。会散。

但林远知道在那里。

他把锤子和铜刻刀收回了茅屋。放在矮桌上。并排。锤子在左。刀在右。

他看着这两样东西。赵铁匠一辈子——就是锤子和刀。打铁和帮人刻字。粗和细。力和痕。

他从茅屋出来。走到老槐树下。

碑在。树根在碑面上爬了——十二年。从碑脚开始。现在爬到了碑面的三分之一。白色的根贴着刻痕延伸。有些根已经嵌进了刻痕里——根顺着"莫"字的笔画在走。

树根在读碑。

林远蹲下来。看着根。根在"貪"字上分了一条岔。一条顺着横笔走，一条顺着竖笔走。在"天"字上面又合到了一起。

根不知道自己在读什么。它只是往有缝的地方长。刻痕就是缝。

但林远看到了。根在碑上画出了一条新的线。

他不知道一千年后根会把碑变成什么样。也许根会把碑面挤裂。也许根会把碑推倒。也许根会保护碑——根和土和碑混在一起，形成一块坚硬的土石混合物。

他不知道。但根在走。时间在走。

他站起来。

太阳偏西了。远处有人在麦田里收麦。镰刀割麦子的声音——"嚓嚓嚓"——和铜刻刀在石面上的声音一样。

一样的声音。

一样的手。

不一样的人。
