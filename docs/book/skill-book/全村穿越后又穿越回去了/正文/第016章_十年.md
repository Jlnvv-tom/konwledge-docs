# 第016章：十年

第十年。夏天。

裂缝在六月十五日重新打开。和穿越那天一样的日期。天文台的报告说角直径达到了和十年前相同的值。白光在天空中重新可见——白天看不到，但晚上看得到。比月亮大，比星星近。

陈婆婆站在槐树下。

槐树已经长到了三米高。十年了。从膝盖高的树苗长到了三米。枝干有林远手腕那么粗。叶子密密匝匝，在夏天的风里沙沙响。

"时候到了。"她说。

她没有看天。她在看树。

她说完这句话之后，消息传开了。不是广播——是口口相传。融入派的人打电话给回去派。在工厂里上班的人收到家里人的消息。在大学里旁听的小孩被家长接走了。一千二百人——十年前穿越来的一千二百人——现在不到一千了。走了二十多个。不是死了——是有些人已经不愿意回去了。

有十二个人明确表示不走。他们在上海有了工作、有了对象、有了生活。他们说"我们留在这里。如果裂缝能再开一次让我们回去，那也能让我们留在这里。"

周老实去劝了三次。没劝动。最后他说："不走也是你们的命。走了也是我们的命。"

六月十五日下午。闵行区"槐安村社区"。

所有要回去的人——九百八十七人——站在社区广场上。穿着现代的衣服——T恤、牛仔裤、运动鞋。有人手里攥着手机——说要把手机带走。赵铁匠腰上别着锤子——不是打铁的那把了，是他在工厂用的一把检修锤。陈婆婆抱着——不是槐树苗了——一棵槐树的种子。种子是她从树梢上摘的。树太高了，她够不到。是林远帮她摘的。

林远站在人群中间。他穿着白衬衫和黑裤子。手里抱着一个布包。包里是三片竹简、一把铜刻刀、一本笔记本。竹简和刻刀要带回古代。笔记本要留给方远舟。

方远舟站在人群外面。

他今天请了假。穿了一件旧的长袖衬衫——还是八年前那件。扣子扣到手腕。眼镜擦干净了。头发比八年前白了很多。他站在人群外面，手里抱着一个纸袋。袋子里是他给林远的东西——他没说是什么。

天在变。

和十年前一样。天光从蓝色变成白色。不是云。是光。白光从天上落下来。先是一柱，然后扩展。光柱的直径比十年前小一点——穿越来的时候全村连地皮一起过来了，回去的时候只带人。

裂缝的角直径已经达到了临界值。天文台说："维持时间预计72小时。72小时后裂缝会完全关闭。72小时是窗口期。"

72小时。三天。三天之内不进去的人——永远留在这里。

陈婆婆抬头看了天。白光照在她脸上。她八十八了。皱纹比十年前深。但她的眼睛在白光里是亮的。

"走吧。"她说。

她第一个走进了光柱。

白光裹住她的身体。她的身影变淡了。然后消失了。像一滴墨在水里化开。连她抱着的种子也一起消失了。

她走了。回了。

后面的人开始跟上。一个一个。有人跑着进去。有人走着进去。有人抱着孩子进去。有人闭着眼进去。有人回头看了一眼现代的世界——灰色的建筑、路灯、汽车——然后转过头走进去。

赵铁匠走到光柱前停了一下。他回头看了一眼。不是看建筑。是看工厂的方向。他在那里工作了七年。他的锤子在工厂里打了七年。

他低头看腰间的锤子。然后他解下锤子，放在了地上。

没有带走。

他走进光柱。白光吞没了他的赤裸上身和宽厚的肩膀。

林远最后。

他站在光柱前面。白光照在他脸上。热的——光柱是热的。不是太阳的热。是一种从里到外的热。

他回头看方远舟。

方远舟站在人群外面。纸袋抱在胸前。他的眼镜在白光里反光。

林远走过去。

他把布包里的笔记本抽出来。递给方远舟。

"方先生。"

方远舟接了笔记本。

"这里面有我写的所有东西。"林远说。"十年学的。代码、数学、AI的东西。还有一些我写给你的话。在第137页。"

方远舟把笔记本攥紧了。

"你不带走？"

"带不走。"林远说。"竹简和碑文要带——那些是闭环的一部分。笔记本不是。笔记本是给你的。"

方远舟的手指在笔记本封面上按了一下。

他把手里的纸袋递过来。

"给你的。"

林远接了。打开。

里面是一本新的笔记本。封面上写着两个字。方远舟的字——钢笔，繁体。

"無憾。"

林远看着那两个字。

無憾。没有遗憾。

他把纸袋揣进怀里。贴着胸口。

"方先生。"

"嗯。"

"十年了。"

"十年了。"

"谢谢你。"

方远舟张了张嘴。没说出话来。他伸手摘了眼镜，用衬衫袖子擦了一下镜片。镜片上没有雾。但他的眼睛有。

"你回去之后——"他说。声音哑了。"——不要后悔。"

"不会。"

"你是村里最聪明的人。你读了最多的天书。但你不知道天什么时候收。"他引用了陈婆婆的话。然后他笑了一下。笑得很难看。"现在你知道了。"

林远点头。

他转身走向光柱。

白光越来越近。热。从脸到胸口。脚下的柏油路面在白光里发白。他走了一步。两步。三步。

身后传来方远舟的声音。不是喊。是说话。但实验室里那个声量——那种在课堂上讲课的声量——在空旷的广场上传得很远。

"林远！"

林远停下。没回头。

"你回去之后——告诉一千年后的我——你刻的碑——我看到了。"

林远闭了一下眼睛。

他点头。一下。

然后他走进了光柱。

白光从四面八方涌来。脚下的地面消失了。声音消失了。方远舟的声音消失了。

在消失的最后一瞬间——也许是零点几秒——他听到了方远舟喊的最后一句话。不是喊。是说出来。在白光吞没一切之前，最后一口气穿过了白光：

"你好，世界。"

Hello World。

然后白光关闭。

广场上空了。九百八十七个人不见了。

方远舟站在广场上。手里攥着一本旧笔记本。笔记本封面有汗。

他低头。看了一眼笔记本。

然后他翻到第137页。

上面写着一行字。林远的字——铅笔，简体，横排：

"方先生。我回去之后会刻一块碑。碑上有一句话。那句话是我写的。也是陈婆婆念的。也是你找到的。如果你看到这块碑——说明我已经回去了。说明我已经刻了。说明一千年的时间没有让我们失散。"

"你好。一千年后的世界。"

方远舟合上笔记本。

他抬头。天上的白光已经消失了。天空恢复了蓝色。上海的六月。三十七度。远处有车在高架上驶过的声音。路灯还没亮。

他站在空了的广场上。

手里攥着两本笔记本。一本是林远留给他的。一本是他给林远的——没给出去。

"無憾。"

他把那本没送出去的笔记本放在胸口。贴着心跳的位置。

然后他坐下来。在空了的广场上。坐在柏油路面上。三十七度。屁股底下发烫。

他坐了很久。

直到路灯亮了。

直到天完全黑了。

直到天文台的通知来了："裂缝已完全关闭。"

他站起来。

把两本笔记本都揣进怀里。

走出了广场。
