# 第038章：数字走了

回来后第十八年。王小毛三十一了。

他从镇上回来。跑了二十里路。到村口的时候日头偏西了。喘。

"先生！先生！"

林远在村塾。下课了。正在擦墙上的木炭字——写了一个月了。字迹淡了。该重新写了。

"怎么了？"

"数字——传到县城了！"

林远停了。手里的木炭停在墙上。

"什么意思？"

"县城的粮行——用了。我这次去镇上卖粮。张老板跟我说——县城的李记米行也开始用阿拉伯数字记账了。不是我们教的。是镇上的人教他们的。"

林远把手里的木炭放下。走到矮桌前。坐下来。

"县城……"他念了一下。

县城。松江府。从槐安村到松江镇是二十里。从松江镇到县城——松江府城——是四十里。一共六十里。走路一天半。

数字走了六十里。

"什么时候开始的？"

"张老板说——大概半年前。县城有一个商人去镇上进货。看到了张老板的账本。学了。回去教给了别人。"

半年。

"张老板还说什么了？"

"他说县城有三家铺子在用了。粮行。布庄。杂货。还有一家——当铺。当铺也在用。"

当铺。当铺用数字记——当票上的数字。典当金额。利息。日期。

林远在本子上记了。

粗纸。木炭。

"数字传到县城。第十八年。半年前开始。三家铺子。粮行、布庄、当铺。镇上张老板说的。"

他写完了。看着那行字。

十八年。从他在泥地上写1到9开始。到现在。数字走了六十里。从槐安村到松江镇到松江府城。

十八年。

他在上海——用了多久学会数字？三天。三天学会1到9。一个月学会加减乘除。

在古代——数字走了十八年才走了六十里。

慢吗？

慢。非常慢。在上海——数字在互联网上——一秒钟走十万八千里。一个邮件一秒钟到美国。一个网站一秒钟被全世界看到。

但在公元965年。数字靠人走。一个人走二十里。教一个人。那个人再走二十里。再教一个人。

慢。但——

在走。

不需要电。不需要互联网。不需要手机。不需要任何现代的东西。

数字只要两个人就够了。一个会的人教。一个学的人学。教完了学的人就成了会的人。会的人再教。一个变两个。两个变四个。四个变八个。

十八年。六十里。三家铺子。

慢。但没停。

---

林远在矮桌前坐了一会儿。

他回忆上海。复旦。实验室。三块屏幕。他在右边屏幕上跟史辨3.0对话。AI回答他的问题。一秒钟。一个答案从数据库里出来。横跨了千年的语料。一秒钟。

在上海——信息一秒钟走一万里。在古代——信息十八年走六十里。

但上海的信息——走了又怎样？方远舟的考古报告——在网上发布了。一秒钟全世界都看到了。但有人信吗？有人信唐宋地层里有阿拉伯数字吗？

信不信是一回事。能不能看到是另一回事。

在古代——数字走了六十里。六十里之外的人不知道。但六十里之内的人——三家铺子——他们在用。用着。记着。算着。

数字在六十里内活着。不需要互联网。不需要全世界。六十里就够了。

也许有一天——也许一百年后——也许两百年后——数字会传到杭州。传到苏州。传到更远的地方。

也许不会。也许有一天官府禁止了。也许有一天人们忘了数字是什么。也许有一天数字只在槐安村和松江镇——在六十里内——活着。

够了。

六十里。三家铺子。够了。

---

林远在本子上写了一行字。

木炭。粗纸。

"数字在走。不需要我。"

他看着那行字。

不需要我。他写了。他教了。数字开始了。然后数字自己走了。从泥地走到纸。从纸走到镇。从镇走到县城。

他不知道数字会走多远。他不知道数字会不会走到杭州。走到苏州。走到更远的地方。他不知道数字会不会被官府禁掉。他不知道数字会不会在两百年后消失。

但数字在走。

它不需要他。

他只做了一件事——在泥地上写1到9。教了一个八岁的孩子。那个孩子长大了去了镇上。镇上的人学了。县城的人学了。

他不需要推。数字自己会走。因为数字好学。比"正"字好学。比筹算好学。比任何古代的记数方法都好学。

好学的东西会自己走。不需要人推。

他在本子上又写了一行。

"好学的东西会自己走。"

他合上本子。站起来。

走出村塾。远处的天。太阳偏西了。麦田在风里摆。绿色。

他不知道这会不会改变历史。一千年后的考古报告里会不会有"宋代松江地区民间使用阿拉伯数字"的记录。他不知道。

但他知道——数字在走。在六十里内。在三家铺子里。在王小毛的账本上。在张老板的账本上。在县城某个当铺的当票上。

在走。

够了。

他走回茅屋。矮桌上放着赵铁匠的锤子和铜刻刀。旁边是本子。

他看着锤子和刀。

锤子不能走。锤子重。一个人拿起锤子才能打铁。放下锤子就不能了。

铜刻刀不能走。刀在手才能刻。放下刀就不能了。

但数字能走。数字轻。比锤子轻。比刀轻。比任何东西都轻。

轻的东西走得远。

重的东西走得近。

锤子在矮桌上。刀在矮桌上。数字在六十里外。也许在更远的地方。

赵铁匠在矮桌下面——在地下——在土里。

数字在纸上了。在账本上了。在当票上了。

走远了。

不需要锤子。不需要刀。不需要人。

只需要一个符号。1。2。3。

符号自己会走。

他看着矮桌上的本子。本子上写着"数字在走。不需要我。"

他闭上眼睛。笑了一下。

嘴角弯了。

够了。
