# 第005章：发光的板子

方远舟给林远的第一件东西是一本小学课本。

"语文。"他说，把书放在桌上。"一年级。"

林远翻开第一页。纸上印着四个字：开、学、了。下面是一张画，画里有一个小孩背着一个书包。小孩的衣服有颜色——红的，蓝的，黄的。林远没见过那种书包。书页很白，比他写过的任何纸都白。纸面光滑，摸上去像方远舟那个板子的背面。

他用了三天读完那本书。

不是因为他聪明——虽然方远舟后来一直说他聪明——而是因为简体字和繁体字之间有规律。他读了前二十页之后就摸到了："開"变成"开"，"學"变成"学"，"體"变成"体"。笔画减少了，但骨架没变。像一个人脱了外套，里面还是那个人。

简体字的问题解决了，剩下的是拼音。方远舟给他写了一张表：二十六个字母对应二十几个声母韵母。林远背了两个晚上。他的记忆方法是在帐篷的帆布壁上用手指划，每个字母划三遍，划到帆布上起毛为止。

到第四天他开始读二年级的课本。第五天三年级。方远舟每天来看他一次，带新书和一碗食堂的饭。食堂的饭比方便面好——有米饭，有菜，有肉。肉是鸡肉。林远第一次吃鸡肉的时候愣了一下：他吃过鸡，但村里杀鸡是过年的事，一只鸡要分五家人吃。这里一个人一碗里就有半只鸡腿。

赵铁匠到第四天才开始吃东西。不是因为饿了——是因为他看到帐篷外面的工人用一种他没见过的工具修帐篷支架。那工具是电钻。赵铁匠盯着电钻看了半天，然后走过去，在工人旁边蹲下来。工人吓了一跳，但赵铁匠只是伸手摸了摸电钻的金属外壳。

他回到帐篷里，端起那碗已经凉了的饭，吃了。

吃完了他把碗放下，对林远说了一句话："那铁器里有风。"

林远不知道他说的是什么。后来方远舟告诉他那是"电钻"，用电驱动的。赵铁匠没见过电，但他看懂了——那工具没有风箱，没有人力，但转得比他打铁的任何工具都快。他说"有风"，是因为他找不到更准确的词。力从哪里来？他的认知里只有风、水、畜力和人力。他选了"风"。

到第七天，方远舟给林远带来了那个板子。

"手机。"方远舟说。"旧的。不联网了。但能看里面的东西。"

那块板子比林远在车上看到司机举着的那块小。黑色的，比他的手掌略大。一面是亮的，另一面是黑的。侧面有一个小凸起，按下去之后亮的那面亮了。

林远按了一下。

屏幕亮了。上面出现了密密麻麻的小方块，每个方块里有一个符号。他认出了一些——是简体字。还有一些他不认识的符号——字母。方块排列得很整齐，像一张棋盘。

他用手指碰了一个方块。

方块变了。屏幕上出现了一张新的画面。画面上有一个圆形的东西，圆形下面有数字。

林远研究了十分钟。他发现那个圆形的东西可以按。按了之后屏幕上的数字变了。他按了一下"1"，又按了一下"+"，再按了一下"1"。然后他看到了"="。

他按了"="。

屏幕上出现了一个"2"。

林远把手机放在桌上。他看着那个"2"。然后他拿起手机，又按了一遍：1+1=2。

还是2。

他又按：2×3=6。

6。

他按：99×99=9801。

9801。

《九章算术》里有一道题：今有田广十五步，从十六步，问为田几何。答曰：一亩。他用九章的方法要列筹算，摆在桌上慢慢推。手机——这个板子——按一下就有了。

林远把手机举到眼前。黑色，薄，轻。没有算筹，没有纸笔，没有墨。力从哪里来？他不知道。但它算对了。数学是对的。一加一等于二。九十九乘九十九等于九八零一。在槐安村是这样，在这个灰地面的世界也是这样。

他放下手机。

然后他做了一件事：他打开了手机里另一个方块。那个方块里有很多小画面，每个画面上有一个图和一行字。他随机点了一个。画面展开了——是一个会动的画。画里有人在跑。人在一条灰色的地面上跑，旁边有轮子在地上滚。

不是真人。是画里的人。但画里的人在动。

林远看了很久。

那个会动的画放了大约两分钟就停了。屏幕暗下来。他又按了一下，亮了，但画面不动了。他不知道那叫"视频"。他不知道"信号"。他不知道"流量"。他不知道那个画里跑着的人和轮子是真实拍下来的，不是画出来的。

但他知道一件事：这块板子能算数，能显示画。它能做事情。方远舟说过——它是工具。

工具不需要被理解。工具需要被使用。

他拿着手机走出帐篷。天已经黑了。帐篷区里亮起了灯——不是灯笼，是灯管。白光照得帐篷区亮如白昼。

他抬头。

西边的天上，那个白色光点还在。但比昨天又暗了一些。方远舟说过那是"裂缝"。裂缝在收窄。它什么时候关上，他们什么时候——

什么时候什么？回去？

林远看着那个光点。他不确定自己想回去。他不确定自己想留下。他只确定一件事：手里的这块板子，他要搞清楚它怎么用。

他低头，在手机上按下了那个"1"。

"1"出现在屏幕上。

他看着那个"1"。然后在旁边写了一个"9"，在旁边写了一个"6"，在旁边写了一个"5"。

965。

他的年。

他又按了"2""0""2""6"。

2026。

两个数字。一千零六十一年的距离。但在这块板子上，它们只是四个符号的差别。

林远把手机揣进怀里。回帐篷。

明天他要问方远舟：这个板子里面装的是什么。
