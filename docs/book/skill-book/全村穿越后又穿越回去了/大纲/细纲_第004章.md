# 第004章：帐篷区

## 细纲
- 核心事件：政府安置村民到临时帐篷区，林远第一次看到现代生活的细节
- 字数目标：2500字
- 目标情绪：适应→微妙的不安
- 章尾钩子：陈婆婆不肯交出老槐树苗

### 情节安排
1. 大巴车送村民去安置点，林远第一次坐车【人物塑造·密250】
2. 帐篷区——千顶白帐篷，物资堆成山【信息揭示·密200】
3. 林远第一次吃现代食物——方便面，被味道击中【情绪·密200】
4. 赵铁匠拒绝吃，蹲在帐篷外打石头【人物塑造·密200】
5. 林远看到帐篷里的电视新闻——自己在画面上【信息揭示·密250】
6. 新闻里说"时空异常事件"，用了一个林远听不懂但方远舟翻译的词："穿越"【铺垫·密200】
7. 工作人员要求登记物品，陈婆婆抱着老槐树苗不肯交【钩子·密200】

预算合计：2500字
