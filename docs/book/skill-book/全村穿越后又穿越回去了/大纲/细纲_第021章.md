# 第021章：碑文

## 细纲
- 核心事件：林远用一个月刻完碑文，包括古训、数字、公式和不明符号
- 字数目标：2500字
- 目标情绪：庄重→释然
- 章尾钩子：碑刻完了，林远在碑前坐了一夜

### 情节安排
1. 刻碑持续一个月。每天从早到晚【铺垫·密200】
2. 赵铁匠每天送饭，在旁边看林远刻字【人物塑造·密250】
3. 林远刻到最后一行——古训的落款【情绪·密250】
4. 他在碑的背面刻了几个字——不是给考古队的，是给自己的【铺垫·密200】
5. 刻完了。碑立在老槐树下。他坐在碑前【情绪·密200】
6. 月亮升起来。碑影落在地上。和树影叠在一起【钩子·密200】

预算合计：2500字
