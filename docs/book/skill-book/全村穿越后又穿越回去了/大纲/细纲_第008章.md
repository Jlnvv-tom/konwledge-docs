# 第008章：AI

## 细纲
- 核心事件：林远第一次接触AI大模型，被AI的能力震撼
- 字数目标：2500字
- 目标情绪：震撼→不安
- 章尾钩子：AI生成了一段古汉语族谱序言，林远浑身发冷

### 情节安排
1. 一年后。林远在方远舟的AI实验室打工，开始接触大语言模型【铺垫·密200】
2. 方远舟演示AI——给它一个问题，它回答得像一个博学的人【信息揭示·密300】
3. 林远用古汉语跟AI对话，AI流利回应——像遇到一个读过所有书的书生【情绪·密250】
4. 林远问AI"你能写一首宋词吗"，AI十秒内写出，工整有致【情绪·密200】
5. 林远让AI"写一段槐安村族谱序言"，AI生成了——但内容和他的家族对得上【铺垫·密250】
6. 林远浑身发冷，关掉对话窗口【钩子·密200】
