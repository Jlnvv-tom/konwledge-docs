# 第006章：电

## 细纲
- 核心事件：林远弄懂了"电"是什么，赵铁匠也弄懂了
- 字数目标：2500字
- 目标情绪：兴奋→震撼
- 章尾钩子：赵铁匠在灯泡前哭了一夜

### 情节安排
1. 三个月后。林远已经能用现代汉语交流，方远舟带他去大学实验室【铺垫·密200】
2. 林远第一次看到电线和灯泡的关系——"力从线里来"【情绪·密300】
3. 林远理解了"电"：不是风，不是水，是一种看不见的力，在线里流【信息揭示·密300】
4. 他第一次触摸开关，灯亮了又灭，他反复按了十几次【情绪·密200】
5. 回到帐篷区，他跟赵铁匠解释"电"——用"水渠"做比喻【人物塑造·密250】
6. 赵铁匠沉默良久，问了一个问题："能打铁吗？"【情绪·密200】
7. 当夜帐篷区停电，赵铁匠在黑暗中摸到灯泡前，坐着不动【钩子·密200】
