# 第八章：国家监察委员会

## 8.1 设立背景与宪法地位

### 体制改革背景

国家监察委员会的设立是中国政治体制和国家监督体系的重大制度创新。在监察委员会体制建立之前，中国的反腐败力量分散在多个机构：党内有纪委的党纪监督，政府内有监察部的行政监察，检察机关有反贪污贿赂局和反渎职侵权局的法律监督。这种"多头反腐"格局存在以下突出问题：

1. **力量分散**：反腐力量分散于不同机关，难以形成合力，影响了反腐效能。
2. **覆盖不全**：行政监察只能监督行政机关工作人员，对非党员公职人员、国企管理人员、公办教科文卫单位管理人员等缺乏有效监督。
3. **手段不足**：行政监察手段有限，缺乏强制调查权，难以应对复杂的腐败犯罪。
4. **程序衔接不畅**：党纪处分、行政处分与刑事处罚之间的衔接程序不够顺畅，存在"两规"等措施的法律依据不足等问题。

为解决这些问题，党的十八大以来，中央决定推进国家监察体制改革，整合反腐力量，建立集中统一、权威高效的国家监察体系。

### 试点与推广

2016年11月，中共中央决定在北京市、山西省、浙江省开展国家监察体制改革试点。三地试点积累了宝贵经验后，2017年10月，党的十九大决定将改革在全国推开。2018年3月，第十三届全国人民代表大会第一次会议通过了《中华人民共和国宪法修正案》和《中华人民共和国监察法》，国家监察委员会正式成立。

### 宪法地位

国家监察委员会是最高监察机关，其宪法地位体现在以下层面：

- **国家机关属性**：监察委员会与国务院、最高人民法院、最高人民检察院并列，同属国家机关体系，由全国人民代表大会产生，对其负责并报告工作。
- **独立于行政、审判、检察机关**：监察委员会不是行政机关，不受国务院领导；不是司法机关，不受法院和检察院的制约——它是一个独立的国家机关序列。
- **垂直领导关系**：国家监察委员会对地方各级监察委员会实行业务领导，上级监察委员会对下级监察委员会的管辖有指导权。

这一制度设计使中国形成了"一府一委两院"（人民政府、监察委员会、人民法院、人民检察院）的新格局，体现了监察权在国家权力结构中的独立地位。

## 8.2 监察对象范围

### 法定监察对象

《监察法》第十五条规定，监察委员会对下列公职人员和有关人员进行监察：

**（一）中国共产党机关、人大机关、行政机关、政协机关、监察机关、审判机关、检察机关、民主党派机关和工商联机关的公务员，以及参照《公务员法》管理的人员。**

这一项涵盖了所有在国家机关中从事公务的人员，无论是党员还是非党员，都纳入了监察范围。

**（二）法律授权或者受委托管理公共事务的组织中从事公务的人员。**

包括各类事业单位、社会团体中依法行使公共职权的人员。

**（三）国有企业管理人员。**

包括国有企业中的董事、监事、高级管理人员以及关键岗位管理人员。

**（四）公办的教育、科研、文化、医疗卫生、体育等单位中从事管理的人员。**

这一项将公立学校、科研院所、医院、文化机构、体育机构的管理人员纳入监察范围，弥补了此前监督的盲区。

**（五）基层群众性自治组织中从事管理的人员。**

包括村民委员会、居民委员会的组成人员，以及村民小组长等。

**（六）其他依法履行公职的人员。**

这是一项兜底条款，确保所有行使公权力的人员都不会脱离监督。

### "全覆盖"的意义

监察对象的这一范围实现了对"所有行使公权力的公职人员"的监察全覆盖，解决了过去监察范围过窄、部分公职人员"不在监督视野内"的问题。改革前，行政监察对象约为800万人；改革后，监察对象扩展至约3000万人，覆盖面大幅提升。

## 8.3 合署办公体制

### 纪委与监委合署

国家监察委员会与中共中央纪律检查委员会（中央纪委）合署办公，实行"一套工作机构、两个名称"的体制。这一安排的实质是党的纪检职能与国家监察职能由同一套机构统一行使，但在法律上分别以党内机构和国家机关的名义开展工作。

合署办公的具体运作方式：

1. **统一领导**：中央纪委书记同时担任国家监察委员会主任，统一领导纪检和监察工作。
2. **统一机构**：内设职能部门同时承担纪检和监察职责，不设两套班子。
3. **区分程序**：对党员适用党纪程序（依据党章和《纪律处分条例》等党内法规），对非党员公职人员适用监察程序（依据《监察法》）。对同一对象涉及党纪和政务双重处分的，并行办理。
4. **统一文书**：党内审查和监察调查可以同时开展，分别出具党纪处分建议书和监察建议书。

### 合署办公的合理性

合署办公体制的设计有其深层考虑：

- **反腐合力**：党的纪检机关在长期反腐败斗争中积累了丰富经验和专业力量，监察委员会依托纪检系统的工作基础，可以快速形成战斗力。
- **避免重复**：如果纪委和监委分设两套机构，势必造成机构重叠、资源浪费、职责交叉，降低反腐效率。
- **党对反腐的领导**：反腐败是党的自我革命的重要组成部分，合署办公有利于党对反腐败工作的集中统一领导。

同时，合署办公也面临"权力集中如何监督监督者"的挑战。为此，《监察法》设置了多项制约机制，包括监察委员会向人大常委会报告专项工作、接受人大监督等。

## 8.4 三大职责：监督、调查、处置

### 监督职责

监督是监察委员会的首要职责。《监察法》第十一条规定，监察委员会"对公职人员开展廉政教育，对其依法履职、秉公用权、廉洁从政从业以及道德操守情况进行监督检查"。

监督的主要方式包括：

1. **日常监督**：通过信访举报、日常检查、谈话提醒等方式，对监察对象的廉洁情况进行常态化监督。
2. **专项监督**：围绕特定领域（如扶贫、环保、招投标等）开展专项监督检查。
3. **派驻监督**：上级监察委员会向本级党和国家机关派驻或派出监察机构、监察专员，实现对驻在部门的"贴身监督"。
4. **巡视巡察联动**：与党的巡视巡察工作相配合，形成"巡视巡察+监察"的监督合力。

### 调查职责

调查是监察委员会的核心职能。监察委员会对涉嫌贪污贿赂、失职渎职等职务违法和职务犯罪进行调查。

调查手段包括：

1. **一般调查措施**：谈话、询问、查询、调取、勘验检查、鉴定等。
2. **特殊调查措施**：留置、搜查、技术调查、限制出境、通缉等。

其中，**留置**是监察体制改革最具标志性的制度创新。留置取代了此前纪委使用的"两规"（"双规"）措施，实现了以下突破：

- **法律依据明确**：留置由《监察法》设定，具有明确的法律依据，解决了"两规"长期存在的法律依据不足问题。
- **期限限制严格**：留置时间不得超过三个月，特殊情况可延长一次，每次不超过三个月。
- **程序规范**：留置须报上一级监察机关批准；省级以下监察机关采取留置措施须报省级监察机关批准。
- **权利保障**：留置期间应当保障被留置人员的饮食、休息和安全，提供医疗保障；讯问时应全程录音录像。

### 处置职责

处置是监察委员会对调查结果做出处理的环节。根据调查结果，监察委员会可以做出以下处置：

1. **政务处分**：对违法的公职人员依法作出警告、记过、记大过、降级、撤职、开除等政务处分决定。
2. **问责决定**：对不履行或者不正确履行职责的领导人员，按照管理权限作出问责决定，或者向有权作出问责决定的机关提出问责建议。
3. **移送起诉**：对涉嫌职务犯罪的，移送人民检察院依法审查起诉。
4. **提出监察建议**：对监察对象所在单位廉政建设和履行职责存在的问题等提出监察建议。
5. **撤销案件**：对没有证据证明被调查人存在违法犯罪行为的，应当撤销案件，并通知被调查人所在单位。

## 8.5 反腐败衔接机制

### 监察与刑事诉讼的衔接

监察委员会调查的职务犯罪案件需要移送检察机关审查起诉，因此监察程序与刑事诉讼程序之间存在重要的衔接机制：

**（一）证据衔接**

监察机关在调查中收集的证据材料，可以在刑事诉讼中作为证据使用。监察机关收集物证、书证、证人证言、被调查人供述和辩解、鉴定意见、勘验检查笔录、视听资料、电子数据等证据，应当依法收集、固定和审查，确保符合刑事诉讼的证据标准。

**（二）强制措施衔接**

监察机关将案件移送检察机关后，检察机关应当依法对被调查人采取刑事强制措施（拘留、逮捕等）。对于监察机关已经采取留置措施的案件，检察机关应当在留置期限届满前作出是否逮捕的决定。

**（三）审查起诉**

检察机关对监察机关移送的案件进行审查，根据情况作出起诉或不起诉决定。检察机关经审查认为需要补充核实的，应当退回监察机关补充调查，也可以自行补充侦查。

**（四）审判程序**

人民法院对检察机关提起公诉的职务犯罪案件依法进行审判。审判中适用《刑事诉讼法》的规定，保障被告人的辩护权和其他诉讼权利。

### 与其他机关的协作配合

监察委员会在反腐败工作中还需要与以下机关协作：

1. **公安机关**：监察机关在调查中需要公安机关协助采取技术调查、限制出境、通缉等措施；公安机关查办的案件涉及公职人员职务犯罪的，应当移送监察机关。
2. **审计机关**：审计机关在审计中发现的涉嫌职务违法犯罪的线索，应当移送监察机关。审计结果是监察机关的重要信息来源。
3. **人民法院**：人民法院在审理案件中发现的职务违法犯罪线索，应当移送监察机关。
4. **检察机关**：检察机关在诉讼监督中发现的线索移送监察机关；同时，检察机关依法对监察机关移送的案件进行审查起诉，形成"监检制约"关系。

### 国际追逃追赃

国家监察委员会统筹协调反腐败国际追逃追赃工作，是《监察法》赋予的重要职责。监察委会同有关部门开展"天网行动"等国际追逃追赃专项行动，通过引渡、遣返、异地追诉、劝返等方式将在逃境外的职务犯罪嫌疑人引渡或遣返回国。

中国已与数十个国家签署了引渡条约和刑事司法协助条约，为国际追逃追赃提供了法律基础。监察委员会还积极参与反腐败国际治理，推动构建国际反腐败新秩序。

> **本章小结**：国家监察委员会的设立是中国政治体制改革的里程碑事件，它将分散的反腐败力量整合为集中统一、权威高效的国家监察体系，实现了对所有行使公权力的公职人员监察全覆盖。通过与中央纪委合署办公，监察委员会在保持党对反腐败工作领导的同时，将反腐工作纳入法治化轨道——以留置取代"两规"，以监察程序衔接刑事诉讼程序，体现了"用法治思维和法治方式反腐败"的治理理念。监察委员会的设立使中国形成了"一府一委两院"的新权力格局，监察权作为独立于行政权、审判权、检察权之外的第四种国家权力，在国家治理体系中发挥着不可替代的监督作用。
