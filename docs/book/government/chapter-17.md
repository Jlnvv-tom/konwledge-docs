# 第十七章：社会管理部门

社会管理部门是政府公共服务职能的主要承担者，覆盖公共安全、社会救助、就业社保、医疗卫生、教育、住房等与人民生活最直接相关的领域。这些部门的治理能力直接决定了人民群众的获得感、幸福感和安全感。随着中国社会主要矛盾的转化——从"人民日益增长的物质文化需要同落后的社会生产之间的矛盾"转变为"人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾"——社会管理部门的职能重心正从"保基本、兜底线"向"促均衡、提品质"升级。

---

## 17.1 公安部：治安、刑侦、出入境、交通管理

### 核心职责

公安部是国务院组成部门，是全国公安工作的领导指挥机关。根据《中华人民共和国人民警察法》（2012年修正），公安部承担以下核心职责：

1. **治安管理**：预防、制止和惩治违法犯罪活动，维护社会治安秩序，管理户籍、居民身份证、特种行业、危险物品等。
2. **刑事侦查**：侦办刑事犯罪案件，组织重特大案件的侦破和跨区域犯罪活动的协调指挥。
3. **出入境管理**：管理中国公民出入境和外国人在华停留居留，签发护照和签证。
4. **交通管理**：管理道路交通，处理交通事故，管理机动车和驾驶人。
5. **网络安全**：监督管理计算机信息系统的安全保护工作，打击网络犯罪。
6. **禁毒工作**：组织指导禁毒工作，打击毒品违法犯罪活动。

### 组织架构

公安部内设机构包括：办公厅、情报指挥中心、研究室、督察审计局、人事训练局、宣传局、新闻宣传局、经济犯罪侦查局、治安管理局、刑事侦查局、反恐怖工作局、食品药品犯罪侦查局、网络安全保卫局、技术侦察局、预审局、监所管理局、禁毒局、出入境管理局、交通管理局、法制局、国际合作局、装备财务局、科技信息化局等。

公安部管理国家移民管理局（加挂出入境管理局牌子），后者为副部级机构。

### 关键政策领域

**平安中国建设**：公安部是平安中国建设的核心力量，推动立体化信息化社会治安防控体系建设，深入开展扫黑除恶专项斗争（2018-2020年）和常态化扫黑除恶斗争。

**户籍制度改革**：推动农业转移人口市民化，全面放开城区常住人口300万以下城市落户限制，完善居住证制度。这项改革深刻影响着亿万人口的迁徙权利和发展机会。

**交通治理**：实施"减量控大"（减少事故死亡总量、控制较大以上事故），推进"醉驾入刑"执法常态化，建设"智慧交管"系统。

**打击电信网络诈骗**：针对近年来高发的电信网络诈骗犯罪，公安部组建反诈中心，开展"断卡行动""断流行动"等专项打击，建设国家反诈中心APP。

**出入境便利化**：实施144小时过境免签政策，扩大免签国家范围，简化签证手续，服务高水平对外开放。

## 17.2 民政部：社会救助、基层自治、社会组织管理

### 核心职责

民政部是国务院组成部门，承担基本民生保障、基层社会治理、基本社会服务等职责。根据《中华人民共和国社会救助法》（2023年通过）及相关部门法律法规，民政部核心职责包括：

1. **社会救助**：拟定社会救助政策、标准并监督实施，管理城乡居民最低生活保障、特困人员救助供养、临时救助、低保边缘家庭救助等。
2. **基层政权建设和社区治理**：指导城乡社区治理体系和治理能力建设，推动基层民主政治建设。
3. **社会组织管理**：负责社会团体、基金会、社会服务机构等社会组织的登记管理和执法监督。
4. **养老服务**：拟定养老服务体系建设规划、政策和标准，推进养老服务发展。
5. **儿童福利**：拟定儿童福利、未成年人保护政策，管理孤残儿童保障、农村留守儿童关爱保护。
6. **慈善事业促进**：管理慈善组织认定和公开募捐资格，促进慈善事业发展。
7. **殡葬管理**：推进殡葬改革，管理殡葬服务。
8. **区划地名管理**：负责行政区划设立、调整、撤销的审核，管理地名工作。

### 组织架构

民政部内设机构包括：办公厅、政策法规司、规划财务司、社会组织管理局（社会组织执法监督局）、社会救助司、基层政权建设和社区治理司、区划地名司、养老服务司、儿童福利司、慈善事业促进司、社会事务司、老龄工作司等。

### 关键政策领域

**社会救助兜底保障**：全面建成以基本生活救助、专项社会救助、急难社会救助为主体，社会力量参与为补充的社会救助体系。截至2024年，全国低保对象约3300万人，特困人员约470万人。

**养老服务体系建设**：面对快速老龄化（60岁以上人口已超过2.9亿），民政部推动居家社区机构相协调、医养康养相结合的养老服务体系建设。2024年起实施的"积极应对人口老龄化"战略将养老服务提升到国家安全高度。

**基层治理现代化**：推动社区减负增效，完善社区工作者队伍体系，发展"五社联动"（社区、社会组织、社会工作者、社区志愿者、社会慈善资源）治理机制。

**社会组织改革发展**：深化社会组织登记制度改革，完善社会组织党建，培育发展社区社会组织和慈善组织，加大对非法社会组织的打击力度。

## 17.3 人力资源和社会保障部：就业、社保、劳动关系

### 核心职责

人力资源和社会保障部（简称"人社部"）是国务院组成部门，统筹就业创业、社会保障和劳动关系三大领域。其核心职责包括：

1. **就业促进**：拟定就业创业政策，管理人力资源市场，统筹高校毕业生、农民工、退役军人等重点群体就业。
2. **社会保障管理**：管理基本养老保险、失业保险、工伤保险等社会保险基金和经办服务。
3. **职业能力建设**：管理职业培训、职业技能等级认定、技工院校等。
4. **劳动关系协调**：拟定劳动关系政策，实施劳动监察，处理劳动争议仲裁。
5. **事业单位人事管理**：管理事业单位人事制度和工资收入分配。
6. **人才评价**：管理专业技术人员职业资格和职称制度改革。

### 组织架构

人社部内设机构包括：办公厅、政策研究司、法规司、规划财务司、就业促进司、人力资源流动管理司、职业能力建设司、专业技术人员管理司、事业单位人事管理司、农民工工作司、劳动关系司、工资福利司、养老保险司、失业保险司、工伤保险司、农村社会保险司、社会保险基金监管局、调解仲裁司、劳动保障监察局、国际合作司等。

### 关键政策领域

**就业优先战略**：将就业置于宏观政策层面，实施就业优先导向的财政、货币、产业政策。城镇新增就业年均保持在1200万人以上。

**社保全国统筹**：企业职工基本养老保险全国统筹于2022年1月正式实施，解决了地区间基金负担不平衡问题。在此基础上推动基本养老保险全国统筹，完善个人养老金制度（2022年启动试点）。

**灵活就业人员保障**：面对2亿灵活就业人员（包括网约车司机、外卖骑手、直播主播等），探索新就业形态劳动者权益保障制度，开展职业伤害保障试点。

**技能中国行动**：大规模开展职业技能培训，推行"新八级工"职业技能等级制度，建设技能型社会。

**劳动争议多元化解**：推动劳动争议调解仲裁与诉讼衔接，加强新就业形态劳动争议处理机制建设。

## 17.4 国家卫生健康委员会：医疗改革与公共卫生

### 核心职责

国家卫生健康委员会（简称"国家卫健委"）是国务院组成部门，2018年机构改革中在新组建的国家卫生和计划生育委员会基础上设立。根据《中华人民共和国基本医疗卫生与健康促进法》（2019年通过），国家卫健委核心职责包括：

1. **公共卫生管理**：拟定重大疾病防治规划、国家免疫规划并组织实施，管理传染病防治和卫生应急工作。
2. **医疗卫生服务管理**：拟定医疗机构、医疗服务行业管理办法并监督实施，建立医疗服务评价和监督管理体系。
3. **基层卫生**：拟定基层卫生、妇幼健康发展规划和管理办法并组织实施。
4. **药物政策**：组织制定国家药物政策和基本药物制度，开展药品使用监测和临床综合评价。
5. **老龄化应对**：协调落实应对人口老龄化政策措施，推进医养结合发展（与民政部协同）。
6. **职业健康**：拟定职业卫生、放射卫生相关政策标准并组织实施。
7. **综合监督**：负责公共卫生、医疗卫生等综合监督执法。

### 组织架构

国家卫健委内设机构包括：办公厅、规划发展与信息化司、财务司、法规司、体制改革司、医政司、基层卫生健康司、妇幼健康司、医疗应急司、公共卫生司（疾病预防控制局）、综合监督局、药物政策与基本药物制度司、食品安全标准与监测评估司、老龄健康司、职业健康司、人口监测与家庭发展司、宣传司、国际合作司等。

国家卫健委管理国家疾病预防控制局（国家CDC），后者为副部级机构。2023年机构改革后，国家疾控局的职能进一步强化。

### 关键政策领域

**"健康中国2030"战略**：作为健康中国行动的核心实施部门，推进15个专项行动，涵盖健康干预、慢病管理、重大疾病防控等领域。

**深化医改**：持续深化"三医联动"（医疗、医保、医药）改革。国家卫健委主导公立医院改革（药品零加成、现代医院管理制度、分级诊疗制度建设），与国家医保局协同推进药品集中带量采购。

**分级诊疗制度**：推进医联体、医共体建设，促进优质医疗资源下沉，县域医共体建设覆盖90%以上县（市）。

**疾控体系改革**：新冠疫情后，国家疾控局职能强化，构建"以疾控机构为骨干、医疗机构为依托、基层卫生机构为底网"的疾控体系。

**人口生育政策**：实施三孩生育政策及配套支持措施，发展普惠托育服务体系，降低生育、养育、教育成本。

**中医药发展**：管理国家中医药管理局，推动中医药传承创新发展，实施中医药振兴发展重大工程。

## 17.5 教育部：教育体系与教育公平

### 核心职责

教育部是国务院组成部门，主管全国教育事业。根据《中华人民共和国教育法》（2021年修正）和《中华人民共和国义务教育法》（2018年修正），教育部核心职责包括：

1. **教育规划**：拟定教育改革与发展战略和规划，制定教育事业发展政策。
2. **各级各类教育管理**：管理学前教育、义务教育、普通高中教育、职业教育、高等教育、继续教育和特殊教育。
3. **教育公平**：推进义务教育均衡发展，保障特殊群体受教育权利，管理学生资助政策。
4. **教师管理**：管理教师队伍建设，实施教师资格制度，负责教师职称评审。
5. **教育考试**：管理全国统一招生考试（高考、研究生考试等），拟定招生计划。
6. **学位管理**：实施《中华人民共和国学位法》（2024年通过），管理学位授权体系。
7. **语言文字**：管理国家通用语言文字工作。

### 组织架构

教育部内设机构包括：办公厅、政策法规司、发展规划司、综合改革司、人事司、财务司、教材局、基础教育司、校外教育培训监管司、职业教育与成人教育司、高等教育司、教育督导局（国务院教育督导委员会办公室）、民族教育司、教师工作司、体育卫生与艺术教育司、思想政治工作司、社会科学司、科学技术与信息化司、高校学生司、学位管理与研究生教育司（国务院学位委员会办公室）、语言文字信息管理司、语言文字应用管理司、国际合作与交流司等。

### 关键政策领域

**"双减"政策**：2021年7月出台的《关于进一步减轻义务教育阶段学生作业负担和校外培训负担的意见》是近年来最具影响力的教育政策之一，严格规范校外培训机构，推动教育回归学校主阵地。教育部专门设立校外教育培训监管司负责此项工作。

**义务教育优质均衡**：在基本实现县域义务教育基本均衡发展的基础上，推进"优质均衡"创建，缩小城乡、校际差距。

**职业教育改革**：推动《职业教育法》（2022年修订）实施，确立职业教育与普通教育同等重要地位，推进"产教融合、校企合作"，建设一批高水平职业院校和专业群。

**"双一流"建设**：统筹推进世界一流大学和一流学科建设，2022年公布第二轮"双一流"建设高校及学科名单（147所高校）。

**教育数字化**：建设国家智慧教育公共服务平台，推进教育数字化转型，以数字化促进教育公平和质量提升。

## 17.6 住房和城乡建设部：住房保障与城市建设

### 核心职责

住房和城乡建设部（简称"住建部"）是国务院组成部门，主管城市建设、住房保障和房地产行业。其核心职责包括：

1. **住房保障**：拟定住房保障政策，组织编制住房保障发展规划和年度计划，管理保障性住房建设（公租房、保障性租赁住房、共有产权住房等）。
2. **房地产市场调控**：监督管理房地产市场，拟定房地产开发、交易、租赁政策。
3. **城市建设管理**：指导城市市政基础设施建设（道路、供水、排水、燃气、供热等），管理城市更新和老旧小区改造。
4. **村镇建设**：指导农村危房改造、小城镇建设。
5. **建筑业监管**：监督管理建筑市场，管理建设工程质量安全和工程造价。
6. **住房公积金监管**：监督管理住房公积金的归集、使用和管理。

### 组织架构

住建部内设机构包括：办公厅、法规司、计划财务与外事司、建筑市场监管司、工程质量安全监管司、标准定额司、房地产市场监管司、住房保障司、住房改革与发展司、城市建设司、村镇建设司、建筑节能与科技司、人事司等。

### 关键政策领域

**房地产长效机制**：坚持"房住不炒"定位，实施"因城施策"的房地产调控，建立房地产长效机制。2024年以来推进"保交房"工作，切实保障购房人合法权益。

**保障性住房建设**：构建"保障+市场"的住房供应体系，加大保障性租赁住房供给，解决新市民、青年人住房困难。2021-2025年规划筹集建设保障性租赁住房870万套（间）。

**城市更新行动**：推进以老旧小区改造为重点的城市更新，2020年以来全国新开工改造城镇老旧小区超20万个。实施城市体检制度，推动"城市病"治理。

**建筑业转型升级**：推动智能建造与建筑工业化协同发展，发展装配式建筑，推广绿色建筑标准。

**城市管理执法体制改革**：推进城市管理执法体制改革，理顺城市管理执法体制，提升城市治理精细化水平。
