# 第二十三章：公务员考试与录用

## 本章导读

"逢进必考"是中国公务员录用的基本原则。自1994年首届中央国家机关公务员考试举行以来，公务员考试已成为中国最具影响力的公共部门选拔制度之一。本章系统介绍国考与省考的区别、报考条件、笔试与面试流程、体检政审与录用审批的全链条，并解析选调生制度这一特殊的后备干部选拔通道。

---

## 23.1 国考与省考：中央与地方公务员考试

### 23.1.1 国考：国家公务员考试

国家公务员考试（简称"国考"）由中共中央组织部、人力资源和社会保障部、国家公务员局统一组织，面向中央机关及其直属机构招录公务员。

**招录机关范围：**
- 中央党群机关：中央办公厅、中央组织部、中央宣传部等；
- 中央国家行政机关：国务院各部委（外交部、国家发改委、财政部、公安部等）；
- 中央国家行政机关直属机构：各地海关、国家税务总局各省税务局、各地铁路公安、海事局等；
- 国务院参照公务员法管理事业单位：如国家统计局各调查队、中国气象局等。

**考试时间：** 通常每年10月报名，11月底或12月初笔试，次年1-3月面试。

**招录规模：** 近年国考每年招录人数在2.5万至4万人之间，报名人数在130万至300万之间，竞争比通常在50:1至80:1。

### 23.1.2 省考：各省公务员考试

省级公务员考试（简称"省考"）由各省级党委组织部会同省级人社厅、公务员局组织，面向本省各级党政机关招录公务员。

**招录机关范围：**
- 省级党群机关：省委各部门、省人大、省政协等；
- 省级行政机关：省政府各厅局；
- 市级机关：地级市市委、市政府各部门；
- 县级机关：县（市、区）委、县政府各部门；
- 乡镇机关：乡镇党委、政府。

**考试时间：** 各省自行确定。多数省份参加"联考"（同一时间考试），通常在每年3-4月报名，4月笔试。部分省份单独组织，如北京、上海、广东、山东、浙江、江苏等，时间各不相同。

**省考联考：** 自2009年起，多个省份选择在同一天进行笔试，使用统一题库或部分统一试题。联考规模通常在20个省份以上，招录总人数远超国考。

### 23.1.3 国考与省考的比较

| 维度 | 国考 | 省考 |
|------|------|------|
| **组织单位** | 中央组织部、国家公务员局 | 各省级党委组织部 |
| **招录机关** | 中央机关及直属机构 | 地方各级党政机关 |
| **编制归属** | 中央行政编制 | 地方行政编制 |
| **考试时间** | 每年11-12月 | 每年3-4月（联考）或自行安排 |
| **笔试科目** | 行测+申论（部分加专业课） | 行测+申论（各省略有差异） |
| **户籍限制** | 一般无户籍限制 | 部分省份限制本省户籍 |
| **职业发展** | 中央机关起点高，晋升空间大 | 地方机关贴近基层，锻炼全面 |
| **工作地点** | 全国分配（含基层税务所等） | 本省内分配 |

需要说明的是，国考和省考录用后均依法取得公务员身份，编制性质同属行政编制，差异主要在于隶属关系和工作层级。

## 23.2 报考条件与限制

### 23.2.1 基本报考条件

根据《公务员法》第十三条和《公务员录用规定》，报考公务员应当具备以下基本条件：

1. 具有中华人民共和国国籍；
2. 年龄为十八周岁以上，三十五周岁以下（部分职位可放宽）；
3. 拥护中华人民共和国宪法，拥护中国共产党领导和社会主义制度；
4. 具有良好的政治素质和道德品行；
5. 具有正常履行职责的身体条件和心理素质；
6. 具有符合职位要求的工作能力；
7. 具有大学专科以上文化程度；
8. 法律规定的其他条件。

### 23.2.2 职位附加条件

除基本条件外，各招录职位还可设置以下附加条件：

- **学历要求**：多数中央机关要求本科及以上学历，部分要求研究生学历；
- **专业要求**：根据职位需要限定专业大类（如法学类、经济学类、计算机类等），部分职位不限专业；
- **基层工作经历**：部分职位要求两年以上基层工作经历。中央机关省级以上职位通常要求基层工作经历；
- **政治面貌**：部分职位要求中共党员（含预备党员）；
- **证书要求**：部分职位要求法律职业资格证书、注册会计师证书等；
- **性别要求**：极少数职位因工作特殊性限定性别。

### 23.2.3 不得报考的情形

根据《公务员法》第二十六条，以下人员不得录用为公务员：

1. 因犯罪受过刑事处罚的；
2. 被开除中国共产党党籍的；
3. 被开除公职的；
4. 被依法列为失信联合惩戒对象的；
5. 有法律规定不得录用为公务员的其他情形的。

此外，在职公务员和参照公务员法管理的机关（单位）工作人员，不得再次报考公务员考试（须经批准辞去公职后方可报考）。这一规定的目的是防止在职公务员频繁流动，保障机关工作稳定。

### 23.2.4 年龄限制的特殊规定

一般职位的年龄上限为35周岁。但以下情形可适当放宽：

- 应届硕士研究生、博士研究生（非在职）年龄可放宽至40周岁；
- 公安机关人民警察职位年龄上限一般为30周岁（特警更严）；
- 部分专业技术职位经批准可适当放宽。

## 23.3 笔试（行测+申论）与面试流程

### 23.3.1 笔试：行政职业能力测验（行测）

**考试形式：** 全客观题，闭卷考试，考试时限120分钟，满分100分。

**题型构成：**

| 模块 | 题量（参考） | 主要考查能力 |
|------|-------------|-------------|
| 常识判断 | 20题 | 政治常识、法律常识、经济常识、历史人文、科技常识等 |
| 言语理解与表达 | 40题 | 选词填空、片段阅读、语句表达 |
| 数量关系 | 15题 | 数学运算（行程问题、工程问题、排列组合等） |
| 判断推理 | 40题 | 图形推理、定义判断、类比推理、逻辑判断 |
| 资料分析 | 20题 | 统计图表分析、文字材料分析 |

国考行测分为省级以上和市地以下两套试卷，省级以上通常题量更大（135题）、难度更高。省考行测在题型和难度上与国考类似，但各省有微调。

### 23.3.2 笔试：申论

**考试形式：** 主观题，闭卷考试，考试时限180分钟（省考多为150分钟），满分100分。

**考查能力：** 阅读理解能力、综合分析能力、提出和解决问题能力、文字表达能力、贯彻执行能力。

**题型构成：**

1. **归纳概括题**：要求从给定材料中归纳、概括特定信息；
2. **综合分析题**：要求对某一现象或观点进行分析、评价；
3. **提出对策题**：要求针对材料反映的问题提出解决对策；
4. **应用文写作题**：要求撰写通知、倡议书、讲话稿、调研报告等应用文体；
5. **大作文**：要求根据给定材料和话题，撰写1000-1200字的议论文。

国考申论同样分省级以上和市地以下两套试卷，主题和难度有所区别。省级以上更侧重宏观分析和政策建议，市地以下更侧重基层执行和具体问题解决。

### 23.3.3 笔试成绩计算

| 考试类别 | 成绩计算方式 |
|----------|-------------|
| 一般职位 | 行测×50% + 申论×50% |
| 外语类职位 | 行测×25% + 申论×25% + 外语水平测试×50% |
| 公安机关职位 | 行测×40% + 申论×30% + 公安专业科目×30% |
| 银保监/证监职位 | 行测×25% + 申论×25% + 专业科目×50% |

### 23.3.4 面试：结构化面试为主

**面试组织：** 笔试成绩公布后，各招录机关按笔试成绩从高到低，以1:3的比例确定面试人选（部分职位比例为1:5）。

**面试形式：**

1. **结构化面试**（最常见）：考生依次进入考场，回答相同的3-5道题目，时间约15-20分钟。考官按评分标准独立打分。
2. **无领导小组讨论**：6-9名考生为一组，围绕给定问题进行讨论，考官观察评分。部分中央机关和省直部门采用。
3. **半结构化面试**：在结构化题目基础上，考官可进行追问。

**面试题型：**
- 综合分析题（对某一社会现象或政策谈看法）；
- 计划组织题（设计一个活动或调研方案）；
- 人际沟通题（处理工作中的矛盾关系）；
- 应急应变题（处理突发情况）；
- 岗位匹配题（自我认知与岗位适应）。

### 23.3.5 综合成绩计算

最终录用依据综合成绩排名。综合成绩的一般计算方式：

> **综合成绩 = 笔试成绩×50% + 面试成绩×50%**

部分机关可能调整为笔试×60% + 面试×40%或其他比例，具体以招考公告为准。

## 23.4 体检、政审与录用审批

### 23.4.1 体检

面试结束后，根据综合成绩从高到低，按1:1的比例确定体检人选。

**体检标准：** 执行《公务员录用体检通用标准（试行）》及《公务员录用体检操作手册（试行）》。公安机关、国家安全机关等特殊职位执行更严格的专项标准。

**常见不合格情形：**
- 血压异常（收缩压>140mmHg或舒张压>90mmHg）；
- 转氨酶超标（超过正常值2倍以上）；
- 视力不达标（一般职位矫正视力不低于4.8，警察职位裸眼视力不低于4.8）；
- 色盲、色弱（部分职位受限）；
- 重大疾病或传染病。

对体检结果有异议的，可在7日内提出复检申请，复检仅限一次。

### 23.4.2 政审（政治审查）

体检合格后进入政审环节。政审由招录机关或委托考生所在单位（学校、社区）进行。

**审查内容：**
1. **政治思想表现**：是否拥护党的领导、社会主义制度，有无不当言论或行为；
2. **道德品质**：社会公德、职业道德、家庭美德表现；
3. **遵纪守法情况**：有无违法犯罪记录，有无违纪违规行为；
4. **个人社会关系**：直系亲属及主要社会关系的政治表现情况（特别是报考机要、国安等特殊职位）；
5. **个人诚信记录**：是否有严重失信行为。

**政审方式：**
- 查阅档案（学籍档案、人事档案）；
- 走访所在单位或学校；
- 函调（向相关单位发函核实）；
- 网络核查（信用记录、违法记录等）。

### 23.4.3 公示与录用审批

政审合格后，招录机关将拟录用人员名单进行公示，公示期不少于5个工作日。公示无异议的，按规定办理审批手续。

**审批权限：**
- 中央机关及其直属机构拟录用人员，由国家公务员局审批；
- 地方各级机关拟录用人员，由省级或市地级公务员主管部门审批。

**试用期：** 新录用公务员试用期为一年。试用期满考核合格的，予以任职定级；考核不合格的，取消录用。

### 23.4.4 任职定级

新录用公务员试用期满后，根据学历确定职务和级别：

| 学历 | 任职定级 | 级别 |
|------|---------|------|
| 高中、中专 | 办事员 | 二级科员（二十七级） |
| 大专 | 办事员 | 二级科员（二十六级） |
| 本科 | 科员 | 一级科员（二十五级） |
| 硕士研究生 | 副主任科员 | 四级主任科员（二十四级） |
| 博士研究生 | 主任科员 | 二级主任科员（二十二级） |

注：上表为2019年职级并行改革后的定级标准。

## 23.5 选调生制度：后备干部选拔

### 23.5.1 选调生的概念与定位

选调生是各省级党委组织部有计划地从高等院校选调品学兼优的应届大学毕业生到基层工作的特殊公务员群体。其核心定位是**党政领导干部队伍的后备力量**和**县级以上党政机关高素质工作人员的来源**。

选调生与普通公务员的关键区别在于：
- 选调生是"选拔培养"而非单纯"招录使用"；
- 选调生在基层锻炼后纳入后备干部管理，晋升通道更为明确；
- 选调生的管理由党委组织部直接负责，而非由用人单位管理。

### 23.5.2 选调生的分类

| 类别 | 选调对象 | 特点 |
|------|---------|------|
| **中央选调生** | 部分顶尖高校应届毕业生（含硕士、博士） | 由中央组织部直接选调，面向极少数高校（如清华、北大等），培养目标为中央机关干部 |
| **定向选调生** | 部分重点高校应届毕业生 | 省级党委组织部面向特定高校定向选调，通常需党员+学生干部+校级奖励 |
| **集中选调生** | 普通高校应届优秀毕业生 | 面向更广范围高校，门槛相对较低，但仍有较高政治素质和学业要求 |

### 23.5.3 选调条件

选调生通常要求同时满足以下条件：
1. 政治素质好，中共党员（含预备党员）；
2. 大学期间担任过学生干部（班长、团支书、学生会干部等）；
3. 获得过校级以上奖励（优秀学生干部、奖学金等）；
4. 学习成绩优良；
5. 有志于从事基层工作，志愿到基层锻炼；
6. 应届毕业生（部分省份放宽至毕业1-2年内）。

定向选调还要求毕业院校在指定名单内（通常为"双一流"建设高校或部分省属重点高校）。

### 23.5.4 选调生的培养路径

选调生的培养一般遵循以下路径：

1. **基层锻炼期（1-2年）**：录用后安排到村（社区）或乡镇（街道）锻炼。中央和定向选调生一般先到村任职1年，再在乡镇（街道）锻炼1年。

2. **返回定岗**：基层锻炼期满考核合格后，返回录用机关工作。部分选调生留在基层继续工作。

3. **跟踪培养**：党委组织部建立选调生信息库，定期考察、跟踪培养，优先安排参加培训、挂职锻炼等。

4. **提拔使用**：选调生在基层工作满一定年限后，符合条件的可优先提拔使用。许多优秀选调生在30岁前后即担任乡镇党政班子成员，走上领导岗位。

### 23.5.5 选调生考试流程

选调生招录一般包含以下环节：

1. **发布公告**：各省级党委组织部发布公告，明确选调范围、条件和计划；
2. **推荐报名**：高校党委组织部门推荐，学生自愿报名；
3. **资格审查**：党委组织部审核资格；
4. **笔试**：单独组织或参加省考笔试；
5. **面试**：结构化面试为主；
6. **体检、考察**：同公务员录用流程；
7. **审批录用**：省级党委组织部审批。

## 23.6 公务员录用与"逢进必考"原则

### 23.6.1 "逢进必考"的制度内涵

"逢进必考"是指进入公务员队伍必须经过公开考试录用的原则。这一原则的核心要义是：

1. **公开性**：招考职位、条件、程序、结果全部公开，接受社会监督；
2. **平等性**：符合条件的人员平等竞争，不因身份、背景、关系等因素受到歧视或优待；
3. **竞争性**：通过考试择优录用，确保录用人选的能力素质；
4. **规范性**：录用程序严格按照法律法规执行，杜绝随意性和暗箱操作。

### 23.6.2 法律依据

《公务员法》第二十二条规定："录用公务员，应当公开发布招考公告，按照公开、平等、竞争、择优的原则，经过考试和政治审查，择优录用。"

《公务员录用规定》进一步细化了考试录用的各项程序和要求。

### 23.6.3 例外情形

"逢进必考"是基本原则，但存在以下法定例外：

1. **调任**：国有企业事业单位、人民团体和群众团体中从事公务的人员，可以调入机关担任领导职务或者四级调研员以上及其他相当层次的职级。调任有严格的条件和审批程序，不是大规模进入通道。

2. **军转安置**：军队转业干部安置到机关工作的，可免于公开考试，但需符合相应条件并经过安置程序。

3. **选举产生**：通过法定选举担任领导职务的（如选举产生的乡镇长、县长等），按选举法规定确认身份。

4. **政策性安置**：如退役军人安置等特殊情形。

需要强调的是，上述例外情形均有严格的法律依据和审批程序，不得随意扩大适用范围。从制度运行实践看，90%以上的公务员通过公开考试方式录用。

### 23.6.4 "逢进必考"的制度意义

"逢进必考"制度的实施，具有深远的社会意义：

1. **促进社会公平**：打破了过去"接班""内招"等封闭式用人模式，为各阶层提供了平等进入公共部门的机会；
2. **提升队伍素质**：通过竞争性考试，确保录用人选具备基本的能力素质；
3. **遏制用人腐败**：公开透明的考试程序，有效防范了"萝卜招考""因人设岗"等不正之风；
4. **增强政府公信力**：公平公正的选人用人机制，增强了公众对政府的信任。

### 23.6.5 面临的挑战与改进

"逢进必考"制度在实施中也面临一些挑战：

- **"高分低能"问题**：部分考生应试能力强但实际工作能力不足，需要在面试环节和试用期内加强甄别；
- **基层留人难**：基层公务员待遇相对较低，考上后服务期满即流失的现象较为普遍，需要通过政策倾斜（如定向招录、服务年限要求等）加以解决；
- **考试公平性**：面试环节的主观性仍是公众关注的焦点，需不断完善评分标准和监督机制。

近年来，公务员考试制度持续优化，包括：推进分级分类考试、加强诚信体系建设、严打考试作弊、完善面试考官异地交流制度等，不断提升"逢进必考"制度的科学性和公平性。

---

## 本章小结

公务员考试录用制度是公务员队伍"入口"管理的核心制度。国考与省考并行，为中央和地方机关分别输送人才。考试流程涵盖笔试（行测+申论）、面试、体检、政审、公示和审批等环节，程序严密、公开透明。选调生制度作为后备干部选拔的特殊通道，强调基层锻炼和跟踪培养，是优秀年轻干部成长的重要路径。

"逢进必考"作为公务员录用的基本原则，体现了公开、平等、竞争、择优的价值取向，是促进社会公平、提升队伍素质、遏制用人腐败的重要制度保障。理解了考试录用制度后，下一章将进入公务员管理的核心内容——职务与职级并行制度。
