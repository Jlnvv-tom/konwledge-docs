#### 第八章 猫的常见疾病与家庭医学

8.1 猫瘟（猫泛白细胞减少症）：症状与预防
- 病原体：猫细小病毒（Feline Panleukopenia Virus, FPV）的极强环境存活力
- 临床症状：高热、呕吐、腹泻与白细胞骤降
- 传播途径：直接接触与环境间接传播
- 诊断方法：抗原检测与血常规
- 预防策略：核心疫苗的接种时间表与抗体滴度检测

8.2 猫鼻支与猫杯状病毒感染
- 猫疱疹病毒（Feline Herpesvirus-1, FHV-1）：反复发作的上呼吸道感染
- 猫杯状病毒（Feline Calicivirus, FCV）：口腔溃疡与跛行综合征
- 鉴别诊断：两种病毒的症状重叠与确诊方法
- 治疗方案：抗病毒药物、抗生素预防与支持疗法
- 预防与潜伏带毒：终身排毒风险与多猫管理

8.3 猫传染性腹膜炎（Feline Infectious Peritonitis, FIP）
- 冠状病毒（Feline Coronavirus, FCoV）突变机制：从肠道型到FIP型
- 湿性FIP：腹腔/胸腔积液的临床特征
- 干性FIP：肉芽肿病变的多器官表现
- 诊断难题：PCR、抗体滴度与李凡他试验的综合判读
- 治疗突破：GS-441524等核苷类似物的应用与疗效

8.4 泌尿系统疾病：自发性膀胱炎与尿路结石
- 猫下泌尿道疾病（Feline Lower Urinary Tract Disease, FLUTD）的分类与常见病因
- 猫自发性膀胱炎（Feline Idiopathic Cystitis, FIC）：应激相关的神经内分泌机制
- 尿路结石类型：鸟粪石与草酸钙结石的饮食因素
- 尿闭紧急处理：公猫尿道阻塞的黄金抢救时间
- 长期管理：饮食调控、环境丰容与饮水促进

8.5 慢性肾病：老年猫的头号杀手
- IRIS（International Renal Interest Society）分期：基于肌酐、SDMA与血压的分级体系
- 早期信号：多饮多尿、体重下降与食欲减退
- 诊断指标：血液生化、尿液分析与UPC（Urine Protein-to-Creatinine）比值
- 治疗策略：皮下输液、磷结合剂与促红素
- 家庭监测：体重曲线、饮水量记录与食欲评估

8.6 猫糖尿病与甲状腺功能亢进
- 猫糖尿病（Diabetes Mellitus, DM）：胰岛素抵抗与低胰岛素血症的双型分类
- 糖尿病管理：长效胰岛素、低碳水饮食与血糖监测
- 猫甲亢（Feline Hyperthyroidism）：甲状腺腺瘤增生与老年猫的高代谢状态
- 甲亢诊断：T4、fT4与TSH的综合判读
- 甲亢治疗：甲巯咪唑、碘-131放射治疗与手术

8.7 皮肤病：猫癣、耳螨与跳蚤防治
- 猫癣（皮肤癣菌病）：伍德灯检查与口服抗真菌药
- 耳螨（Otodectes cynotis）：耳道深褐色分泌物与显微镜确诊
- 跳蚤与蜱虫防治：每月驱虫药的选择与全环境消杀
- 过敏性皮炎：食物过敏与环境过敏的鉴别
- 猫粉刺（下巴黑头）：成因分析与局部清洁方案

8.8 口腔疾病：口炎与牙吸收
- 猫慢性口炎（Feline Chronic Gingivostomatitis, FCGS）：免疫介导的口腔黏膜炎症
- 牙体吸收（Tooth Resorption, TR）：病因不明的牙齿溶解病变
- 牙龈炎与牙周病：菌斑积累到牙齿松动的病程
- 全口拔牙：难治性口炎的最后手段与术后生活质量
- 口腔肿瘤：鳞状细胞癌与纤维肉瘤的早期识别

8.9 疫苗接种计划与驱虫方案
- 核心疫苗：猫三联（猫瘟+猫鼻支+猫杯状）的接种时间表
- 非核心疫苗：猫白血病（Feline Leukemia Virus, FeLV）与猫艾滋（Feline Immunodeficiency Virus, FIV）的适用场景
- 疫苗反应：轻度嗜睡到严重过敏的识别与处理
- 体内驱虫：蛔虫、钩虫、绦虫与心丝虫的用药方案
- 体外驱虫：跳蚤、蜱虫与耳螨的联合防控策略

8.10 急救常识：何时该立即就医
- 呼吸急促与张口呼吸：心肺急症的识别
- 反复呕吐与脱水：判断严重程度的临床指标
- 外伤与骨折：临时止血、包扎与搬运技巧
- 中毒应急：误食毒物后的催吐与活性炭使用
- 癫痫发作：保持气道通畅与记录发作时长
