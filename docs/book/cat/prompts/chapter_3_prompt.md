#### 第三章 全球猫品种图鉴

3.1 猫品种的分类体系与认定标准
- 国际主流猫协：CFA（Cat Fanciers' Association）、TICA（The International Cat Association）、FIFe（Fédération Internationale Féline）与GCCF（Governing Council of the Cat Fancy）的体系差异
- 品种认定标准：头型、体型、毛色与眼睛颜色的评分体系
- 血统证书与谱系注册的意义
- 自然品种vs人工培育品种的区分
- 品种标准的演变历史与争议

3.2 长毛猫品种谱：波斯猫、缅因猫、布偶猫等
- 波斯猫：扁脸结构的美学与呼吸道隐患
- 缅因猫：北美最大体型家猫的特征与性格
- 布偶猫：蓝色眼睛与"瘫软"性格的基因基础
- 挪威森林猫与西伯利亚猫：寒冷气候的适应进化
- 其他长毛品种：土耳其梵猫、伯曼猫与索马里猫

3.3 短毛猫品种谱：英短、美短、暹罗猫等
- 英国短毛猫：圆脸与厚实体型的标准特征
- 美国短毛猫：银虎斑的经典花色与活泼性格
- 暹罗猫：重点色基因与"话痨"性格的独特性
- 孟加拉豹猫：野性外表与家猫性格的杂交育种
- 其他短毛品种：阿比西尼亚猫、俄罗斯蓝猫与东方短毛猫

3.4 无毛猫与特殊品种：斯芬克斯、曼赤肯等
- 斯芬克斯猫：无毛基因突变与皮肤护理需求
- 曼赤肯（短腿猫）：软骨发育不全基因的争议
- 苏格兰折耳猫：折耳基因与骨骼畸形的伦理讨论
- 卷毛猫品种：德文卷毛、柯尼斯卷毛的毛质差异
- 多趾猫（海明威猫）：多指基因的遗传与影响

3.5 中华田园猫：狸花、橘猫、三花与玳瑁
- 中国狸花猫：唯一获CFA认证的中国自然品种
- 橘猫毛色遗传：橘色基因与性别的关联（80%为公猫）
- 三花猫与玳瑁猫：X染色体失活与花色形成的原理
- 玄猫（黑猫）与白猫：毛色基因与文化象征
- 狸花猫的国际地位与国内保护现状

3.6 品种与健康：遗传疾病的认知与预防
- 品种猫遗传病数据库：HCM（Hypertrophic Cardiomyopathy）、PKD（Polycystic Kidney Disease）与SMA（Spinal Muscular Atrophy）的基因筛查
- 波斯猫多囊肾病（PKD）的遗传模式与检测
- 缅因猫与布偶猫的肥厚型心肌病（HCM）筛查
- 折耳猫软骨发育异常的不可逆性
- 混血优势：田园猫的基因多样性与健康优势
