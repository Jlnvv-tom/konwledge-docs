## 一、通用型 AI Agent（自主执行型）

这类产品能够理解用户意图，自主规划任务步骤，调用工具完成端到端的工作流程，从"对话"走向"执行"。

### 1.1 Manus（Monica.im）

- **开发方**：Monica.im（中国创业团队，创始人肖弘）
- **核心功能**：
  - 全球首款通用型自主 AI Agent，能理解复杂指令并直接交付任务成果
  - 支持简历筛选、数据分析、旅行规划、合同审查、财务报告等多场景
  - 异步任务执行：用户可关闭电脑，Manus 在云端持续工作
  - 多智能体协作架构（规划器 + 执行器 + 验证器）
- **产品表现**：
  - GAIA 基准测试 SOTA 成绩，刷新所有难度级别纪录
  - 2025年3月发布后引爆科技圈，邀请码一度炒至5万元
  - 2025年12月被 Meta 以数十亿美元收购，成为 Meta 第三大收购案

### 1.2 OpenAI Operator

- **开发方**：OpenAI
- **核心功能**：
  - 自主执行浏览器操作：预订旅行、电商购物、填写表单
  - 编写代码并执行复杂多步骤操作
  - 结合 GPT 模型的推理能力与浏览器自动化
- **产品表现**：
  - 2025年1月发布，标志着 OpenAI 从对话型 AI 向行动型 AI 转型
  - OpenAI 同步推出三档付费 Agent 服务，最高定价 2 万美元/月
  - 被视为"博士级别"的自主操作能力

### 1.3 AutoGLM（智谱 AI）

- **开发方**：智谱 AI
- **核心功能**：
  - 手机端自主执行超过50步的长步骤操作
  - 跨 App 任务：导航、网购、点外卖、信息查询
  - 多模态理解与 GUI 交互
  - 深度思考功能：生成思维链拆解复杂任务
- **产品表现**：
  - 2024年表现出色，2025年持续升级
  - AgentGLM-PC 版本支持 Mac 和 Windows 桌面端
  - 展现强大的多模态能力和跨应用交互潜力

### 1.4 Lovart

- **开发方**：Lovart 团队
- **核心功能**：
  - 垂直领域 AI 设计 Agent，专注于创意设计工作流
  - 采用 MCoT（多链思维）技术，动态调整设计逻辑分支
  - 从需求理解到设计交付的完整闭环
- **产品表现**：
  - 2025年5月发布，在 X（Twitter）上爆火
  - 被称为"设计领域的 Manus"
  - 内测制运行，邀请码机制

### 1.5 OpenHands（原 OpenDevin）

- **开发方**：开源社区
- **核心功能**：
  - 开源通用 AI Agent，可自主完成软件开发任务
  - 支持代码编写、调试、测试全流程
  - 多语言、多框架支持
- **产品表现**：
  - GitHub 高星项目，活跃的开源社区
  - 被视为 Manus 的开源替代方案

## 二、AI 对话助手与大模型产品

基础大模型与消费级对话产品，是 AI Agent 的"大脑"基座。

### 2.1 ChatGPT（OpenAI）

- **开发方**：OpenAI
- **核心模型**：GPT-4o / GPT-5 系列
- **核心功能**：
  - 多模态交互：文本、语音、图像、代码
  - 插件生态最丰富，支持联网搜索、文件分析、代码执行
  - GPT Store 应用生态
  - Canvas 协作编辑模式
- **产品表现**：
  - 全球月访问量 57.5 亿（2026年5月），断层领跑
  - 每周 3 亿+活跃用户
  - App Store 下载量超 1 亿次

### 2.2 Claude（Anthropic）

- **开发方**：Anthropic
- **核心模型**：Claude 4 系列（Sonnet / Opus）
- **核心功能**：
  - 超长上下文理解（200K+ tokens）
  - 计算机使用能力（Computer Use）
  - Artifacts 实时预览与协作
  - MCP（Model Context Protocol）协议开创者
- **产品表现**：
  - 月访问量 9.72 亿（2026年5月），环比增长 15.67%
  - 长文本理解与写作逻辑自然，被广泛用于学术、科研
  - 安全性与合规性领先

### 2.3 Gemini（Google DeepMind）

- **开发方**：Google DeepMind
- **核心模型**：Gemini 3 Pro
- **核心功能**：
  - 与 Google 搜索、YouTube、Workspace、Google Finance 深度整合
  - 原生多模态：文本、图像、音频、视频理解
  - Deep Research 深度研究功能
  - 全局记忆功能
- **产品表现**：
  - 月访问量 29.9 亿（2026年5月），环比增长 5.13%
  - 三巨头中增长最快
  - 5分钟生成46页学术论文，性能超 OpenAI DR 40%

### 2.4 DeepSeek（深度求索）

- **开发方**：深度求索（中国）
- **核心模型**：DeepSeek-V3 / R1 系列
- **核心功能**：
  - MoE 架构，低成本实现顶尖性能
  - 开源生态，支持本地部署
  - 推理模型 R1 在 STEM 领域表现突出
  - 中文理解能力强
- **产品表现**：
  - 2025年1月爆火，月访问量 2.78 亿
  - 以 1/10 训练数据量在 STEM 领域超越通用模型
  - 引发全球开源 AI 浪潮

### 2.5 Kimi（月之暗面）

- **开发方**：月之暗面（Moonshot AI）
- **核心功能**：
  - 超长上下文窗口（200 万字）
  - Kimi+ 智能体平台
  - 长文档总结与知识密集型场景
  - 智能搜索与信息整理
- **产品表现**：
  - 国内超长上下文领域标杆
  - 用户规模持续增长
  - 在长文档分析、学术论文阅读场景表现优异

### 2.6 豆包（字节跳动）

- **开发方**：字节跳动
- **核心模型**：豆包大模型
- **核心功能**：
  - 对话交互、内容创作
  - 多模态理解（文本、图像）
  - 与抖音/今日头条生态联动
- **产品表现**：
  - 国内用户规模第一梯队的 AI 助手

### 2.7 通义千问（阿里云）

- **开发方**：阿里云

  - 企业级部署支持

- **产品表现**：
  - 中国企业级大模型调用量第一（32.1% 市场份额）

- **产品表现**：
  - 2025 AI 智能体平台 TOP30 排名第一

## 四、AI Agent 开发框架（代码级）

面向开发者的编程框架，提供任务规划、对话管理、工具调用、多 Agent 协作等模块。

### 4.1 LangChain / LangGraph

- **开发方**：LangChain（开源）
- **核心功能**：
  - 将 LLM 与外部数据源、工具、API 连接
  - 模块化可组合的 Chain 架构
  - LangGraph：支持有状态多 Agent 图工作流
  - LangSmith：调试与监控
- **产品表现**：
  - 生态最庞大的 AI Agent 框架
  - 开发者使用率最高
  - 文档与社区支持完善

### 4.2 AutoGen（微软）

- **开发方**：微软研究院（开源）
- **核心功能**：
  - 多 Agent 对话与协作框架
  - 支持人类在环（Human-in-the-loop）
  - 可编程 Agent 角色定义
  - 代码执行与调试
- **产品表现**：
  - 微软研究院出品，企业级可靠性
  - 多 Agent 协作场景标杆

### 4.3 CrewAI

- **开发方**：CrewAI（开源）
- **核心功能**：
  - 角色扮演式多 Agent 协作
  - 定义 Agent 角色、目标、工具
  - 任务分配与串行/并行执行
  - 简洁的 API 设计
- **产品表现**：
  - 多 Agent 协作场景热门选择

### 4.4 LlamaIndex

- **开发方**：LlamaIndex（开源）
- **核心功能**：
  - 数据连接 + RAG + Agent

  - Agent 工具调用
- **产品表现**：
  - RAG 领域权威框架

### 4.5 Semantic Kernel（微软）

- **开发方**：微软（开源）

  - 与 Azure AI 深度集成
- **产品表现**：
  - .NET 生态首选
  - 微软企业客户广泛采用

### 4.6 OpenClaw

- **开发方**：OpenClaw（开源）
- **核心功能**：
  - 多渠道 AI Agent 运行时
  - 支持消息平台（Signal、Telegram、Discord 等）
  - 工具调用、记忆系统、技能系统

- **产品表现**：
  - 多渠道支持能力突出
  - 适合构建个人 AI 助理

### 4.7 Google ADK（Agent Development Kit）

- **开发方**：Google
- **核心功能**：
  - Gemini 模型驱动的 Agent 开发
  - Agent Engine 部署与可观测性
  - A2A 协议原生支持
  - 与 Google Cloud 深度集成
- **产品表现**：
  - Google 2025年推出《Advent of Agents》教程
  - 从快速上手到多 Agent 复杂编排全流程覆盖

## 十八、AI Agent 协议与基础设施

推动智能体互操作性与标准化通信的协议和基础设施。

### 18.1 MCP（Model Context Protocol）

- **提出方**：Anthropic
- **核心功能**：
  - 开放标准协议
  - Agent 与外部工具"即插即用"
  - 上下文管理与工具调用标准化
- **产品表现**：
  - 行业广泛采纳
  - 多家厂商兼容支持

### 18.2 A2A（Agent2Agent）协议

- **提出方**：Google
- **核心功能**：
  - 跨供应商 Agent 间通信
  - 开放协议标准
  - Agent 互操作性
- **产品表现**：
  - 谷歌 2026 AI Agent 趋势报告核心
  - 推动从"孤立大模型"到"可互操作智能体生态"

### 18.3 NVIDIA Nemotron

- **开发方**：NVIDIA
- **核心功能**：
  - 基于 Meta Llama 的推理模型系列
  - Nano(4B)/Super(49B)/Ultra(253B) 三档
  - 针对不同计算资源优化
  - AI Agent 任务优化（指令遵循、函数调用、编码、数学）
- **产品表现**：

  - NVIDIA AI Enterprise 平台支持

### 18.4 OpenClaw

  - 工具/技能/记忆系统
  - 子 Agent 编排
  - 自我更新与配置管理
- **产品表现**：
