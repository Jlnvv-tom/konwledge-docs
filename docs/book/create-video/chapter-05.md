## 第五章 图生视频（Image-to-Video, I2V）

### 一、图生视频的基本原理与核心约束

图生视频（Image-to-Video, I2V）是视频生成领域中最核心的任务之一。与文本到视频（Text-to-Video, T2V）不同，图生视频的输入是一张静态图像，输出是一段以该图像为起始帧的动态视频。这一任务的本质是：给定第一帧的完整像素信息，模型需要预测后续每一帧的内容，使得生成的视频在视觉上连贯、在运动上自然。

图生视频的核心约束被称为首帧一致性（First-Frame Consistency）。这意味着生成视频的第一帧必须与输入图像在像素级别上高度一致——不仅是整体构图和色调，还包括细节纹理、物体边界、光照方向等所有视觉特征。如果首帧就与输入图像存在偏差，后续帧的生成将基于错误的起点，误差会迅速累积放大，最终导致整个视频与输入图像"脱节"。

首帧一致性的困难在于，视频生成模型通常在潜空间（Latent Space）中工作。输入图像首先需要通过变分自编码器（VAE, Variational Autoencoder）编码为潜空间表示，然后在潜空间中进行去噪生成，最后再通过VAE解码回像素空间。这个编码-解码过程本身就会引入信息损失。如果编码后再解码的图像与原始图像已经有差异，那么以此为起点的视频生成自然无法保证严格的一致性。

除了首帧一致性之外，图生视频还面临运动合理性的挑战。模型需要从一张静态图像中推断出可能的运动模式——哪些物体应该动、往哪个方向动、以多快的速度动。这是一个本质上欠约束的问题（Ill-posed Problem），因为同一张静态图像可以对应多种合理的运动解释。比如一张风景照片中，树叶可以微微摇曳，也可以被大风吹动，还可以完全静止。模型需要学习到自然的运动先验，才能生成令人信服的动态效果。

为了解决这些问题，研究者们设计了多种条件注入（Condition Injection）机制，将输入图像的信息以不同方式融入视频生成过程。这些机制是图生视频技术的核心，直接决定了生成质量和一致性表现。

### 二、四种条件注入方式的详细原理与对比

条件注入是图生视频的关键设计。它决定了输入图像的信息如何引导视频生成过程。目前主流的方法可以分为四种：拼接注入、参考帧注意力、控制网络和自适应归一化。每种方式都有其独特的优势和适用场景。

#### 拼接注入（Concatenation Injection）

拼接注入是最直接的条件注入方式。其核心思想是将输入图像的条件信息与噪声张量在通道维度上拼接，形成联合输入送入去噪网络。

具体流程如下：输入图像首先经过VAE编码器编码为潜空间表示，其形状为 $C \times H \times W$，其中 $C$ 是通道数，$H$ 和 $W$ 是空间维度。同时，视频的噪声张量形状为 $F \times C \times H \times W$，其中 $F$ 是帧数。将输入图像的潜空间表示沿帧维度广播到 $F$ 帧，然后在通道维度上与噪声张量拼接，得到形状为 $F \times 2C \times H \times W$ 的联合张量。

这个联合张量被送入U-Net或其他去噪网络。网络的第一层卷积需要修改为接受 $2C$ 通道的输入，其余结构保持不变。在训练过程中，网络学习如何利用拼接的图像条件来引导去噪过程，使得生成的视频以输入图像为起点。

拼接注入的优点是实现简单，不需要修改网络的核心架构，只需调整输入层。缺点是条件信息只在网络入口处注入一次，随着网络深度的增加，条件信号可能逐渐衰减。此外，通道维度的翻倍增加了计算量。

```
拼接注入数据流示意：

输入图像 ──→ VAE编码 ──→ 潜空间表示 [C×H×W]
                                │
                     广播到F帧 [F×C×H×W]
                                │
噪声张量 [F×C×H×W] ──────────→ 通道拼接 ──→ 联合张量 [F×2C×H×W]
                                              │
                                              ↓
                                         去噪网络 (U-Net)
                                              │
                                              ↓
                                        去噪潜空间表示 [F×C×H×W]
                                              │
                                              ↓
                                         VAE解码 ──→ 输出视频
```

#### 参考帧注意力（Reference Frame Attention）

参考帧注意力是一种更灵活的条件注入方式。它不修改输入通道，而是将输入图像的特征作为额外的Key-Value对注入到注意力层中。

在标准的自注意力（Self-Attention）机制中，每一帧的特征同时作为Query（Q）、Key（K）和Value（V）。参考帧注意力在此基础上，将输入图像通过特征提取网络（通常是共享的VAE编码器或单独的特征提取器）提取特征，然后将这些特征作为额外的Key和Value拼接到每帧的注意力计算中。

具体来说，假设视频帧的特征序列为 $F$ 帧，每帧特征长度为 $N$，通道维度为 $d$。输入图像提取的特征长度为 $M$。在注意力计算中，Key和Value的长度从 $N$ 扩展为 $N + M$，而Query仍然是 $N$。这样，每一帧在计算注意力时都可以"看到"输入图像的特征，从而在生成过程中保持与输入图像的一致性。

这种方式的优势在于条件信息可以在网络的多个层级、多个位置被注入，而且注意力机制天然具有全局感受野，条件信号不容易衰减。劣势是增加了注意力计算的复杂度，尤其是当特征序列较长时，计算和显存开销显著增加。

```
参考帧注意力机制示意：

输入图像 ──→ 特征提取 ──→ 参考特征 [M×d]
                                │
                    ┌───────────┤
                    ↓           ↓
               参考Key      参考Value
                    │           │
帧特征 [N×d] ──→ Q,K,V ──→ 拼接K,V ──→ 注意力计算 ──→ 输出特征 [N×d]
                 │              │
            原始K,V       扩展K,V [N+M × d]
                          (原始N + 参考M)

每帧均可访问参考图像特征 → 全局一致性保持
```

#### 控制网络（ControlNet）

控制网络（ControlNet）最初由Zhang等人提出用于文本到图像生成中的条件控制，后来被引入图生视频领域。其核心思想是创建一个主网络的副本（旁路网络），专门用于处理条件信息，然后将处理结果注入主网络。

在图生视频场景中，ControlNet的工作流程如下：主去噪网络保持冻结或缓慢更新，负责视频帧的生成。ControlNet接收输入图像（或从图像提取的结构信息，如边缘、深度图等），通过自身的编码器提取多尺度的条件特征。这些特征通过零卷积（Zero Convolution）层处理后，被加到主网络对应的解码器层中。

零卷积是该设计的关键创新。它是一个权重和偏置初始值为零的卷积层，这意味着在训练开始时，ControlNet的输出对主网络没有任何影响，主网络的行为与原始模型完全一致。随着训练的进行，零卷积的权重逐渐更新，条件信息开始被逐步引入。这种设计避免了随机初始化的旁路网络在训练初期对主网络造成破坏性干扰。

ControlNet的优点是条件控制能力强，可以注入多种类型的结构信息（边缘、深度、姿态等），而且主网络的知识得到保留。缺点是需要额外的网络副本，参数量和显存消耗近乎翻倍。同时，训练过程需要较长时间才能收敛。

```
ControlNet架构示意：

                        输入图像/结构信息
                              │
                     ┌────────┴────────┐
                     ↓                 ↓
              ControlNet编码器      (冻结的副本)
              (可训练, 含零卷积)      
                     │
              ┌──────┼──────┐
              ↓      ↓      ↓
           多尺度条件特征 (经零卷积处理)
              │      │      │
              ↓      ↓      ↓
         ┌────┴──────┴──────┴────┐
         │    主去噪网络 (U-Net)   │
         │  编码器 ←── 注入 ── 解码器 │
         │         (逐层相加)       │
         └─────────────────────────┘
                     │
                     ↓
                去噪输出
```

#### 自适应归一化（AdaLN, Adaptive Layer Normalization）

自适应归一化（AdaLN, Adaptive Layer Normalization）是一种将条件信息融入网络内部操作的注入方式。与直接拼接特征不同，AdaLN通过调整网络层的归一化参数来实现条件控制。

标准的层归一化（Layer Normalization）对特征进行如下操作：先计算特征在通道维度上的均值 $\mu$ 和方差 $\sigma^2$，然后进行归一化和缩放平移：

$$y = \gamma \cdot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta$$

其中 $\gamma$ 和 $\beta$ 是可学习的缩放和偏移参数。在AdaLN中，这两个参数不再是固定的可学习参数，而是由条件信息通过一个多层感知机（MLP, Multi-Layer Perceptron）动态生成的。具体而言，输入图像的特征经过MLP网络，输出维度为 $2C$（对应缩放和偏移各 $C$ 个通道），然后被用于该层的归一化操作。

这意味着同一网络层在不同输入图像的条件下会表现出不同的行为，实现了条件对特征分布的动态调控。在图生视频中，AdaLN通常与时间步嵌入（Timestep Embedding）和文本嵌入（Text Embedding）一起使用，图像条件与这些条件一起被送入MLP，共同生成归一化参数。

AdaLN的优势是参数效率高——不需要增加大量额外参数，只是用一个小的MLP来生成归一化参数。同时，AdaLN作用于每个网络层的内部操作，条件信号可以被深度注入。劣势是条件控制较为间接，不如拼接或注意力机制那样直观，对于需要精细空间控制的任务可能力不从心。

```
AdaLN条件注入示意：

输入图像 ──→ 特征提取 ──→ 条件向量
                                │
                    文本嵌入 ────┤
                    时间步嵌入 ──┤
                                ↓
                           MLP网络
                                │
                    ┌───────────┴───────────┐
                    ↓                       ↓
                 缩放参数 γ'             偏移参数 β'
                    │                       │
                    ↓                       ↓
         层归一化: y = γ' · (x - μ)/√(σ²+ε) + β'
                    │
                    ↓
              条件调控后的特征
```

#### 四种条件注入方式对比

| 对比维度 | 拼接注入 | 参考帧注意力 | 控制网络 | 自适应归一化 |
|---------|---------|------------|---------|------------|
| 注入位置 | 网络输入层 | 每个注意力层 | 主网络解码器层 | 每个归一化层 |
| 注入方式 | 通道维度拼接 | Key-Value扩展 | 零卷积特征相加 | 动态生成缩放偏移 |
| 条件信号强度 | 入口强，深层衰减 | 全程保持 | 全程保持，可分层控制 | 全程保持，但间接 |
| 参数量增加 | 较少（仅输入层） | 中等（注意力扩展） | 较大（网络副本） | 最少（仅MLP） |
| 计算开销 | 低 | 较高（注意力计算） | 高（前向传播两次） | 最低 |
| 空间控制精度 | 中等 | 高 | 最高 | 低 |
| 训练难度 | 简单 | 中等 | 较复杂（零卷积调参） | 简单 |
| 适用场景 | 通用图生视频 | 需要全局一致性 | 需要精细结构控制 | 多条件融合 |

从表格可以看出，四种方式各有优劣。实际应用中，很多模型会组合使用多种注入方式以达到最佳效果。例如，同时使用拼接注入和AdaLN，既在输入层直接提供图像条件，又在网络内部通过归一化参数进行动态调控。

### 三、Stable Video Diffusion（SVD）完整方案详解

Stable Video Diffusion（SVD）是Stability AI于2023年底发布的图生视频模型，是当时最成熟的开源图生视频方案之一。SVD基于Stable Diffusion 2.1构建，通过精心设计的架构修改和训练策略，实现了高质量的图生视频生成。

#### 架构细节

SVD的架构以Stable Diffusion 2.1为基础。Stable Diffusion 2.1使用一个U-Net结构作为噪声预测器，在潜空间中进行去噪。U-Net包含编码器、中间块和解码器三部分，每部分由多个残差块和注意力块组成。

为了适配视频生成，SVD对U-Net噪声预测器进行了关键修改——添加时间卷积（Temporal Convolution）和时间注意力（Temporal Attention）层。原始的U-Net只能处理二维空间信息，无法建模帧间的时间依赖关系。SVD在每个空间残差块之后插入一个时间残差块，在每个空间注意力块之后插入一个时间注意力块。

时间卷积的操作方式是将视频帧的维度从 $F \times C \times H \times W$ 重排为 $C \times F \times H \times W$（将帧维度提升为伪通道维度），然后进行一维时间卷积（kernel size为3）。卷积后再重排回原始形状。这样每个空间位置的特征都会沿时间维度进行混合，建模相邻帧之间的运动关系。

时间注意力则更加直接：将每一帧在某个空间位置的特征作为序列元素，进行帧间自注意力计算。这使得模型能够捕捉长距离的时间依赖关系，比如一个物体在第1帧出现，在第10帧消失，时间注意力可以建模这种跨帧的关联。

除了添加时间层之外，SVD还采用了拼接注入的方式来引入输入图像条件。输入图像经过VAE编码后的潜空间表示被广播到所有帧，然后与噪声张量在通道维度拼接，形成 $2C$ 通道的输入送入修改后的U-Net。第一层卷积的输入通道从 $C$ 改为 $2C$，其余参数从预训练的Stable Diffusion 2.1继承。

时间层的参数是随机初始化的，而空间层的参数从预训练模型继承。这种设计利用了Stable Diffusion 2.1在大规模图像数据上学到的丰富视觉先验，只需要训练时间层和微调空间层即可获得视频生成能力。

#### 三阶段训练

SVD的训练采用三阶段策略，每个阶段有明确的目标和数据配比。

第一阶段是图像预训练。这个阶段实际上就是Stable Diffusion 2.1的原始训练，在大规模图像-文本对数据集上进行。模型学习视觉表示能力和文本条件控制能力。SVD直接继承这一阶段的预训练权重作为初始化，不需要从头训练。

第二阶段是视频大规模预训练。这个阶段使用大规模视频数据集，将图像模型适配为视频生成模型。训练数据包括从互联网收集的大量视频，经过过滤和清洗后用于训练。关键点是：空间层的参数以较小的学习率微调，而新添加的时间层以较大的学习率从头训练。这种差异化学习率确保空间知识不被遗忘的同时，时间层能够快速收敛。

此阶段还引入了运动幅度的控制。SVD在训练时对视频数据的运动幅度进行标注（通过计算光流统计量），使得模型可以学习到不同运动幅度下的生成能力。这解释了为什么SVD在推理时可以通过调节参数控制生成视频的运动剧烈程度。

第三阶段是高质量数据微调。这个阶段使用经过人工筛选的高质量视频数据集，数据量远小于第二阶段但质量更高。微调的目的是提升生成视频的视觉质量和运动自然性。这一阶段采用了较低的学习率和较少的训练步数，避免过拟合。

```
SVD三阶段训练策略：

阶段一: 图像预训练 (继承)
├─ 数据: 大规模图像-文本对 (LAION等)
├─ 目标: 学习视觉表示
├─ 模型: Stable Diffusion 2.1
└─ 产出: 预训练权重

阶段二: 视频预训练
├─ 数据: 大规模网络视频 (经过过滤)
├─ 初始化: 阶段一权重 + 随机初始化时间层
├─ 学习率: 空间层(小) / 时间层(大)
├─ 目标: 学习时间建模能力
└─ 产出: 视频生成基础模型

阶段三: 高质量微调
├─ 数据: 人工筛选高质量视频 (小规模)
├─ 初始化: 阶段二权重
├─ 学习率: 整体较低
├─ 目标: 提升视觉质量和运动自然性
└─ 产出: 最终SVD模型
```

#### 推理流程

SVD的推理流程包含以下步骤。

首先是VAE编码。输入图像通过VAE编码器编码为潜空间表示。由于SVD使用Stable Diffusion 2.1的VAE，潜空间通道数为4，空间维度为原图的八分之一。例如，输入图像分辨率为1024×576，编码后的潜空间表示为4×72×128。

其次是噪声生成。根据目标帧数（默认14或25帧），生成与视频帧序列形状相同的随机噪声张量。噪声张量的形状为 $F \times 4 \times 72 \times 128$，其中 $F$ 是帧数。

然后是条件注入。输入图像的潜空间表示被广播到所有帧，与噪声张量在通道维度拼接，形成 $F \times 8 \times 72 \times 128$ 的联合输入。同时，运动幅度参数被编码为条件向量，通过AdaLN注入网络。

接下来是迭代去噪。联合输入被送入修改后的U-Net进行迭代去噪。默认使用25步DDIM（Denoising Diffusion Implicit Models）采样。每一步中，U-Net预测噪声残差，然后用预测的噪声更新潜空间表示。去噪过程中，时间注意力和时间卷积确保帧间的一致性和连贯性。

最后是VAE解码。去噪后的潜空间表示通过VAE解码器逐帧解码回像素空间，得到最终的视频帧序列。SVD支持生成14帧或25帧的视频，分辨率为1024×576（横屏）或576×1024（竖屏），帧率通常设置为6帧每秒。

```
SVD推理流程：

输入图像 (1024×576 RGB)
    │
    ├─→ VAE编码 ──→ 潜空间表示 [4×72×128]
    │                    │
    │               广播到F帧 [F×4×72×128]
    │                    │
    │              通道拼接 ──┐
    │                          │
噪声张量 [F×4×72×128] ─────────┤
    │                          │
    ↓                          ↓
    └───→ 联合输入 [F×8×72×128]
              │
              ↓
    ┌─────────────────────────┐
    │   迭代去噪 (25步 DDIM)   │
    │                         │
    │   每步:                 │
    │   1. U-Net预测噪声      │
    │   2. 空间层: 帧内处理    │
    │   3. 时间层: 帧间处理    │
    │   4. 更新潜空间表示      │
    └─────────────────────────┘
              │
              ↓
    去噪潜空间表示 [F×4×72×128]
              │
              ↓
    VAE逐帧解码 ──→ 视频帧序列
              │
              ↓
    输出: 14-25帧, 1024×576, ~6fps
```

#### 输出规格

SVD的标准输出规格为14帧或25帧的视频，分辨率为1024×576（16:9横屏）或576×1024（9:16竖屏）。帧率约为6帧每秒，对应视频时长约2.3秒（14帧）或4.2秒（25帧）。这个时长虽然短暂，但对于社交媒体内容、动态壁纸、产品展示等应用场景已经足够。

输出视频的帧数和分辨率受限于显存和计算能力。由于时间注意力层需要在所有帧之间计算注意力，帧数的增加会导致计算复杂度呈平方增长。25帧是单卡推理的实际上限，更长的视频需要通过分段生成和帧间过渡技术来实现。

### 四、阿里万相Wan2.1的图生视频方案

阿里万相Wan2.1是阿里巴巴通义万相团队推出的视频生成模型，在图生视频任务上展现了出色的性能。Wan2.1在架构设计上进行了多项创新，包括3D因果VAE、Flow Matching训练目标和I2V Mask机制。

#### 3D因果VAE（3D Causal VAE）

传统的视频VAE通常采用2D空间压缩加时间压缩的分离方案。先对每一帧进行空间压缩，再沿时间维度进行下采样。这种方案的问题在于时间压缩会损失帧间运动信息，而且非因果的设计（即当前帧的编码可能依赖未来帧）不适用于自回归生成。

Wan2.1设计了3D因果VAE来解决这些问题。所谓"因果"（Causal），是指当前帧的编码只依赖当前帧和之前的帧，不依赖未来帧。这一性质使得VAE可以用于自回归式生成——逐帧或逐段生成视频时，已生成的帧不会因为后续帧的生成而改变。

3D因果VAE通过3D因果卷积（3D Causal Convolution）实现因果性。在时间维度上，卷积核只覆盖当前时刻及之前的时刻，未来时刻被遮蔽。具体实现方式是在普通3D卷积的输出上应用因果掩码（Causal Mask），或者直接将卷积核在时间维度上进行不对称填充（只在时间维度的一侧填充）。

在压缩效率方面，3D因果VAE实现了256倍的总压缩比。空间维度压缩8倍（每边4倍），时间维度压缩4倍，通道维度扩展为16通道（从RGB的3通道到潜空间的16通道）。总压缩比为 $4 \times 4 \times 4 \times 3/16 = 256/16 \times 16 = 256$。这个高压缩比大幅减少了潜空间的数据量，使得模型可以在有限的显存下处理更长的视频。

与SVD使用的2D VAE（每帧独立编码，时间维度不压缩）相比，3D因果VAE在时间维度上也进行了压缩，这意味着潜空间的帧数也减少了，进一步降低了时间注意力的计算复杂度。同时，时间压缩迫使VAE学习帧间的运动表示，而非简单地对每帧独立编码。

```
3D因果VAE vs 传统2D VAE对比：

传统2D VAE (SVD使用):
空间: 8倍压缩 (每边4倍)
时间: 无压缩 (每帧独立编码)
通道: 4通道
总压缩: 4×4 = 16倍 (空间) × 1 (时间)
帧间运动信息: 不在VAE层面建模

视频帧序列 ──→ 逐帧VAE编码 ──→ 每帧独立潜空间表示
[F×3×H×W]                    [F×4×H/8×W/8]

3D因果VAE (Wan2.1使用):
空间: 8倍压缩 (每边4倍)  
时间: 4倍因果压缩
通道: 16通道
总压缩: 4×4×4 = 64倍 (时空) × 3/16 = 256倍
帧间运动信息: VAE层面建模

视频帧序列 ──→ 3D因果卷积编码 ──→ 时空联合潜空间表示
[F×3×H×W]                      [F/4×16×H/8×W/8]

因果性: 当前帧编码只依赖当前帧和之前的帧
```

#### Flow Matching替代DDPM

Wan2.1使用Flow Matching作为训练目标，替代了传统的去噪扩散概率模型（DDPM, Denoising Diffusion Probabilistic Models）。Flow Matching是近两年提出的一种生成模型训练框架，与扩散模型有相似之处但具有独特优势。

在扩散模型中，训练目标是学习从噪声到数据的逆向去噪过程。模型预测每一步的噪声，然后通过多步迭代去噪生成数据。这个过程需要较多的采样步骤（通常20-50步）才能得到高质量结果。

Flow Matching的核心思想是学习一个向量场（Vector Field），该向量场定义了从噪声分布到数据分布的连续路径（称为概率路径，Probability Path）。训练时，模型被要求匹配这个向量场在各个时间步的值。与扩散模型不同，Flow Matching的路径可以是直线的（最优传输路径，Optimal Transport Path），而扩散模型的路径通常是弯曲的。

直线路径的优势在于采样效率更高。因为路径是直的，可以用更少的步骤从噪声走到数据，甚至在极端情况下可以一步生成。此外，Flow Matching的训练梯度更稳定，损失景观更平滑，有助于模型收敛。

在Wan2.1中，Flow Matching的具体实现是：定义从标准高斯分布到视频数据分布的最优传输路径，模型预测该路径上每个时间步的速度向量（Velocity），训练目标是最小化预测速度与真实速度之间的均方误差。推理时，使用欧拉法（Euler Method）或更高阶的数值方法沿预测的向量场进行积分，从噪声生成视频。

```
Flow Matching vs DDPM 路径对比：

DDPM (弯曲路径):
噪声 ─────╲
           ╲     ╲
            ╲      ╲
             ╲       ╲
              ╲       ╲
               ╲       ╲
                ╲       ╲
                 ╲       ╲
                  ╲       ╲
                   ╲       ╲
                    ╲       ╲
                     ╲       ╲
                      ╲       ╲
                       ╲       ╲
                        ╲       ╲
                         ╲       ╲
数据 ──────────────────╲─────────╲──→ 数据

需要多次迭代去噪 (20-50步)
路径弯曲, 采样效率低

Flow Matching (直线/最优传输路径):
噪声 ───────────────────────────────→ 数据
    (直线 = 最优传输路径)

可以少量步骤完成采样 (5-15步)
路径直接, 采样效率高
训练梯度更稳定
```

#### I2V Mask机制保证一致性

Wan2.1设计了I2V Mask机制来严格保证首帧一致性。这一机制的思路简单而有效：在去噪过程中，对第一帧施加特殊处理，确保其内容与输入图像严格一致。

具体实现上，Wan2.1在潜空间中构造一个掩码（Mask）。第一帧的潜空间表示被标记为"已知"区域，其余帧被标记为"未知"区域。在每一步去噪迭代中，第一帧的潜空间表示被强制替换为输入图像的VAE编码结果（或保持不变），只有其余帧进行正常的去噪更新。

这种设计的好处是明确地将问题分解为两个部分：第一帧的一致性由Mask机制硬性保证，不需要模型去学习；模型的全部学习能力都用于生成后续帧的运动和内容。这减轻了模型的学习负担，也避免了首帧一致性与其他目标之间的优化冲突。

此外，Mask机制还为模型提供了关于"哪些帧需要生成、哪些帧已经确定"的显式信息。模型在训练过程中学习到，被Mask的区域是条件，未被Mask的区域是需要生成的目标。这种训练方式使得模型在推理时能够自然地以已知帧为条件生成未知帧，为后续的帧扩展（如视频续写）提供了基础。

```
I2V Mask机制示意：

潜空间帧序列 (F帧):
┌──────┬──────┬──────┬──────┬──────┐
│ 帧1  │ 帧2  │ 帧3  │ 帧4  │ ...  │
│ 已知 │ 未知 │ 未知 │ 未知 │ 未知 │
│(输入)│(生成)│(生成)│(生成)│(生成)│
└──────┴──────┴──────┴──────┴──────┘
  ↑
  │ 每步去噪: 强制替换为输入图像编码
  │ 其余帧: 正常去噪更新

训练阶段:
├─ 输入: 随机选帧设为"已知", 其余设为"未知"
├─ 模型学习: 以已知帧为条件生成未知帧
└─ 不限于第一帧, 可学习任意位置的条件生成

推理阶段:
├─ 第一帧设为"已知" (输入图像)
├─ 其余帧设为"未知"  
├─ 去噪时第一帧保持不变
└─ 模型以第一帧为条件生成后续帧
```

#### 特征缓存机制

Wan2.1还引入了特征缓存机制（Feature Cache Mechanism）来提升推理效率。在视频生成过程中，输入图像的条件特征在每一步去噪迭代中都需要被计算。如果每步都重新计算输入图像的特征，会造成大量重复计算。

特征缓存机制的解决方案是：在去噪开始前，预先计算输入图像通过VAE编码器和特征提取网络的全部中间特征，并将这些特征存储在缓存中。在后续的每一步去噪迭代中，直接从缓存中读取特征，避免重复计算。

这一机制可以显著减少推理时间，尤其是当网络层数较多、特征维度较大时。代价是需要额外的显存来存储缓存的特征。在实际实现中，通常只缓存计算量最大、重复度最高的特征（如VAE编码结果和参考帧注意力中的Key-Value对），在计算效率和显存占用之间取得平衡。

### 五、AnimateDiff技术路线

AnimateDiff是将预训练的文本到图像模型适配为动画生成框架的技术方案。与SVD从头训练时间层不同，AnimateDiff的设计目标更加通用——它希望任何基于Stable Diffusion的个性化模型（如LoRA微调模型、DreamBooth模型等）都能直接获得动画生成能力，而不需要额外训练。

AnimateDiff的核心是一个插入式运动模块（Motion Module）。这个模块被设计为即插即用的组件，可以插入到任何Stable Diffusion U-Net的架构中。运动模块由时间注意力层组成，插入在空间注意力层之后。与SVD的时间层类似，运动模块沿时间维度进行自注意力计算，建模帧间关系。

运动模块的训练策略是其关键创新。AnimateDiff在训练运动模块时，冻结整个Stable Diffusion基础模型的所有参数，只训练运动模块的参数。训练数据使用大规模通用视频数据集。由于基础模型被冻结，运动模块学到的是与具体模型无关的通用运动先验——它学习的是"物体通常如何运动"的通用知识，而不是某个特定风格下的运动模式。

训练完成后，运动模块可以插入到任何基于同一架构的Stable Diffusion模型中。例如，用户有一个用LoRA微调过的动漫风格模型，只需要将训练好的运动模块插入其中，就可以用这个模型生成动漫风格的动画。这种可插拔的设计使得AnimateDiff在个性化动画生成方面非常灵活。

AnimateDiff的输入条件包括文本提示词和输入图像（用于图生视频模式）。文本通过CLIP（Contrastive Language-Image Pretraining）文本编码器提取特征，通过交叉注意力注入网络。输入图像通过拼接注入的方式与噪声张量合并。运动模块在网络内部建模时间关系，将静态的图像生成过程转化为动态的视频生成过程。

不过，AnimateDiff的生成质量受限于基础模型的能力和运动模块的泛化性。由于运动模块是通用化的，它可能无法很好地处理特定场景的复杂运动。此外，AnimateDiff生成的视频通常帧数较少（16-32帧），分辨率也受限于基础模型（通常512×512）。

```
AnimateDiff框架示意：

任意Stable Diffusion模型 (冻结参数)
┌─────────────────────────────────┐
│  U-Net编码器                     │
│  ├─ 空间残差块 (冻结)            │
│  ├─ 空间注意力块 (冻结)          │
│  ├─ [插入] 运动模块 (可训练)     │ ← 时间注意力, 建模帧间关系
│  ├─ 下采样 (冻结)                │
│  ├─ 空间残差块 (冻结)            │
│  ├─ 空间注意力块 (冻结)          │
│  ├─ [插入] 运动模块 (可训练)     │
│  └─ ...                         │
│  U-Net解码器 (对称)              │
│  └─ 每层均插入运动模块           │
└─────────────────────────────────┘
         ↑
    运动模块 (预训练, 通用)
    可插入任意SD模型

使用方式:
1. 选择任意个性化SD模型 (如动漫风格LoRA)
2. 插入预训练运动模块
3. 输入: 文本提示词 + 输入图像
4. 输出: 个性化风格动画
```

### 六、Wan2.2-S2V：一张图+一段音频生成数字人视频

Wan2.2-S2V（Speech-to-Video）是Wan2.1的升级版本中专门针对数字人场景设计的生成方案。它的输入极其简洁——一张人物肖像照片和一段音频，输出是一个与音频同步的说话人视频。这一能力在数字人播报、虚拟主播、视频配音等场景有巨大的应用价值。

Wan2.2-S2V的核心挑战在于音视频同步（Lip Sync）。生成的视频不仅要与输入照片在视觉上一致，还需要与音频在时间上精确对齐——嘴唇的运动必须与语音内容匹配，面部表情需要与语调协调，头部运动需要自然且有节奏感。

为了实现这一目标，Wan2.2-S2V的架构在视频生成模型的基础上增加了音频条件分支。音频信号首先通过音频编码器提取特征。音频编码器通常基于wav2vec或类似的自监督语音模型，能够提取包含语音内容、语调、节奏等信息的深层音频特征。这些音频特征通过交叉注意力（Cross-Attention）机制注入到视频生成网络中——音频特征作为Key和Value，视频帧特征作为Query。

在条件注入方面，Wan2.2-S2V同时使用多种注入方式。输入图像通过拼接注入和参考帧注意力提供视觉条件，音频通过交叉注意力提供运动和时间同步条件。I2V Mask机制也被用于保证首帧一致性——输入照片作为第一帧被严格保留。

训练数据方面，Wan2.2-S2V需要大量的人脸说话视频数据进行训练。这些数据需要包含多样的说话人、多样的语言内容、多样的表情和头部运动。训练时，模型学习从音频特征到面部运动的映射关系——给定音频和首帧图像，生成与音频同步的面部运动序列。

Wan2.2-S2V的一个关键技术细节是音频特征的时间分辨率与视频帧率的对齐。音频特征通常具有较高的时间分辨率（如每秒50个特征向量），而视频帧率通常为25帧每秒。这种不匹配需要通过插值或下采样来解决。Wan2.2-S2V使用时间对齐网络（Temporal Alignment Network）将音频特征映射到与视频帧率匹配的时间分辨率，同时保留语音的时序细节。

```
Wan2.2-S2V架构示意：

输入1: 人物照片 ──→ VAE编码 ──→ 视觉条件
                                    │
                              (拼接注入 + 参考帧注意力)
                                    │
输入2: 音频波形 ──→ 音频编码器 ──→ 音频特征
                 (wav2vec等)        │
                              (交叉注意力注入)
                                    │
                                    ↓
                        ┌─────────────────────┐
                        │   视频生成网络       │
                        │                     │
                        │   视觉条件 ──→ 注入  │
                        │   音频条件 ──→ 注入  │
                        │   I2V Mask ──→ 首帧 │
                        │   Flow Matching去噪 │
                        └─────────────────────┘
                                    │
                                    ↓
                        输出: 数字人说话视频
                        (嘴唇与音频同步, 表情自然)
```

Wan2.2-S2V的输出质量在多项指标上达到了领先水平。生成的视频在视觉质量上与输入照片高度一致，在音视频同步上达到了毫秒级的精度，在运动自然性上能够生成包括眨眼、微表情、头部轻微摆动等细节动作。这些能力的实现得益于大规模训练数据、精心设计的架构和Flow Matching训练目标的稳定性。

### 七、图生视频六大应用场景详解

图生视频技术在多个领域找到了落地应用。以下详细分析六大核心应用场景。

#### 场景一：照片活化

照片活化（Photo Animation）是图生视频最直觉的应用场景。用户上传一张静态照片，AI将其转化为短动画。这种应用在社交媒体上有极高的传播价值。

具体应用包括：将老照片中的人物活化，让已故亲人的影像重新"动"起来；将风景照片转化为动态壁纸，让静止的山水变得有云卷云舒、水波荡漾的效果；将宠物照片活化，让照片中的猫狗做出可爱的动作。

技术实现上，照片活化对运动幅度的控制有较高要求。过大的运动会导致画面失真，过小的运动则缺乏趣味性。SVD等模型提供的运动幅度参数在这里非常有用。此外，照片活化场景通常需要处理各种分辨率和宽高比的输入图像，模型的适应性也是一个考量因素。

#### 场景二：AI数字人

AI数字人（AI Digital Human）是图生视频技术最具商业价值的应用之一。通过一张人物照片和文本或音频驱动，生成数字人说话、表演的视频。这在虚拟主播、新闻播报、在线教育、企业宣传等领域有广泛应用。

图生视频技术在数字人场景中的核心价值是降低了内容制作的门槛。传统数字人方案需要3D建模、动作捕捉、渲染等专业流程，制作周期长、成本高。基于图生视频的方案只需要一张照片和一段文本或音频，就可以在几分钟内生成数字人视频。

Wan2.2-S2V就是为这一场景设计的典型方案。它的音频驱动能力使数字人能够自然地说话和表达情感。随着技术的进步，数字人视频的质量已经接近真人拍摄水平，在某些受控场景下甚至难以区分。

#### 场景三：插画动化

插画动化（Illustration Animation）是将静态插画转化为动画的过程。这一应用在广告创意、儿童教育、社交媒体内容创作等领域有大量需求。

图生视频模型可以将插画中的元素赋予生命——让插画中的人物开始走动，让背景中的云朵飘动，让画面中的水流起来。模型的运动推断能力使得这一过程完全自动化，不需要动画师手动设置关键帧。

插画动化的技术挑战在于插画的风格多样性。不同插画师的风格差异很大，从扁平化设计到水彩画，从线稿到厚涂。模型需要在各种风格上都能生成合理的运动。Stable Diffusion系列的模型由于在大规模多样化数据上训练，具有较强的风格适应性，在这一场景中表现良好。

#### 场景四：产品展示

产品展示（Product Showcase）是电商和营销领域的重要应用。传统的产品视频拍摄需要搭建场景、调试灯光、拍摄剪辑，成本和时间投入较大。图生视频技术可以将一张产品照片转化为多角度、多场景的展示视频。

例如，一张珠宝产品的静物照片可以转化为珠宝旋转展示的视频；一张服装产品照片可以转化为模特穿着走动的视频；一张家具照片可以转化为在不同家居场景中摆放展示的视频。

这一场景对结构保持（Structure Preservation）有较高要求。产品的外观细节必须精确保持，不能因为视频生成而失真或变形。ControlNet等精细条件控制技术在这一场景中特别有用，可以通过边缘、深度等结构信息约束生成过程，确保产品外观的一致性。

#### 场景五：场景延伸

场景延伸（Scene Extension）是将有限的视觉内容扩展为更完整的动态场景。这包括空间延伸（将照片的视野扩展到画框之外）和时间延伸（将短视频延长为更长的视频）。

空间延伸在电影和游戏场景设计中非常有用。一张概念设计图可以通过图生视频技术扩展为完整的全景动态场景，设计师可以快速预览场景的动态效果。时间延伸则解决视频生成模型输出帧数有限的问题，通过将上一段视频的末尾帧作为下一段的输入图像，逐步生成更长的视频。

场景延伸的技术挑战在于延伸部分与原始内容的一致性。空间延伸需要保持光照、色调、风格的连贯；时间延伸需要保持运动的连续性，避免在接缝处出现跳变。参考帧注意力和I2V Mask机制在这些场景中可以发挥重要作用。

#### 场景六：影视前期

影视前期（Film Pre-production）是图生视频在专业影视制作中的应用。在电影、电视剧、动画片的制作过程中，前期可视化（Previsualization）是一个重要环节。导演和摄影师需要将剧本中的场景转化为视觉化的预览，以便规划镜头、构图和运动。

传统的前期可视化需要使用3D软件搭建粗略的场景和角色模型，工作量不小。图生视频技术可以将分镜插画或概念设计图直接转化为动态预览，大幅提升前期制作的效率。

此外，图生视频还可以用于特效预览。将特效场景的设计图转化为动态视频，让特效团队提前了解最终效果的动态呈现，有助于在制作前发现问题并进行调整。

影视前期场景对生成质量的要求很高。画面需要达到影视级的分辨率和动态范围，运动需要符合物理规律和摄影语言。当前的开源模型还难以完全满足这些要求，但随着技术的进步，这一应用场景的潜力巨大。

### 八、三大核心挑战深入分析

图生视频技术虽然取得了显著进展，但仍面临三大核心挑战：首帧一致性、运动自然性和结构保持。这些挑战的根源在于视频生成问题本身的复杂性和欠约束性。

#### 挑战一：首帧一致性

首帧一致性要求生成视频的第一帧与输入图像在像素级别上严格一致。这一要求看似简单，实际上涉及多个环节的精度问题。

首先是VAE编码-解码的精度损失。输入图像通过VAE编码为潜空间表示，再从潜空间解码回像素空间。这个过程中存在信息损失，解码后的图像与原始图像之间会有细微差异。如果模型以编码后的潜空间表示作为起点进行生成，最终输出的第一帧实际上是解码后的图像，而非原始输入图像。

不同的解决方案采取了不同策略来应对这一问题。SVD的方案是在训练过程中让模型学习纠正VAE的解码偏差，使生成结果在视觉上接近输入图像。Wan2.1的I2V Mask机制则更直接——在去噪过程中强制保持第一帧的潜空间表示不变，确保解码后的第一帧尽可能接近输入图像。

其次是条件注入的信息损失。无论采用哪种注入方式，输入图像的信息都需要经过网络层的处理才能影响生成结果。拼接注入中，条件信号可能随网络深度衰减；注意力注入中，条件信息需要与帧特征竞争注意力权重；AdaLN注入中，条件控制是间接的。这些因素都可能导致生成结果与输入图像之间存在偏差。

最后是数值精度问题。在混合精度训练和推理中，浮点数的精度限制可能导致微小但累积的偏差。对于一般应用场景，这些偏差可以忽略，但对于要求像素级一致性的专业应用（如产品展示、影视制作），则需要特别注意。

```
首帧一致性的精度链条：

输入图像 (像素空间)
    │
    ↓ VAE编码 (损失1: 量化误差)
潜空间表示 (第一帧)
    │
    ↓ 去噪过程 (损失2: 条件衰减)
    │  拼接注入: 信号随深度衰减
    │  注意力注入: 注意力权重分配
    │  AdaLN: 间接控制
    │
    ↓ VAE解码 (损失3: 重建误差)
输出第一帧 (像素空间)
    │
    ↓ 对比
与输入图像的差异 = 损失1 + 损失2 + 损失3

解决策略:
├─ SVD: 训练学习纠正偏差
├─ Wan2.1: Mask强制保持 + 因果VAE减少损失
└─ 通用: 高精度推理 + 后处理对齐
```

#### 挑战二：运动自然性（病态问题）

运动自然性是图生视频面临的最深层挑战。从一张静态图像推断合理的运动是一个本质上欠约束的问题（Ill-posed Problem）——同一张图像可以对应无穷多种合理的运动模式。

考虑一张包含旗帜的照片。旗帜可能正在微风中轻轻飘动，也可能在大风中剧烈翻飞，还可能完全静止。仅从一张静态图像，无法确定哪种运动是"正确的"。模型需要依赖训练数据中学到的运动先验来做出选择。

这种欠约束性带来了几个具体问题。

第一是运动模糊性（Motion Ambiguity）。模型可能选择了一种运动模式，但这种模式不是用户期望的。例如，用户希望照片中的人物微笑，但模型生成了人物摇头的动作。解决这一问题的一种思路是在输入条件中加入运动描述（如文本提示词），但如何精确控制运动仍然是一个开放问题。

第二是运动幅度控制（Motion Magnitude Control）。即使运动方向正确，运动的幅度也需要合理。过大的运动会导致画面失真和物体变形，过小的运动则使视频看起来像是静止图片的微小抖动。SVD通过在训练时标注运动幅度来解决这一问题，但不同场景下"合适"的运动幅度是不同的。

第三是物理合理性（Physical Plausibility）。生成的运动需要符合物理规律——水应该往下流而不是往上流，物体下落应该有加速度而不是匀速，布料应该有褶皱和摆动而不是僵硬移动。模型需要从训练数据中学习这些物理先验，但学习的覆盖面有限，对于训练数据中罕见的物理现象可能生成不合理的运动。

第四是时间一致性（Temporal Consistency）。视频帧之间的过渡需要平滑，不能出现突然的变化。物体不能在第5帧存在然后在第6帧消失，纹理不能在帧间闪烁或漂移。时间注意力层在一定程度上缓解了这一问题，但对于长视频或快速运动场景，时间一致性仍然是一个难题。

```
运动自然性的病态问题：

输入: 一张静态图像
问题: 同一图像 → 无穷多种合理运动

      ┌─ 微风 → 旗帜轻摆
      │
旗帜 ─┼─ 大风 → 旗帜翻飞
      │
      ├─ 无风 → 旗帜静止
      │
      └─ 异常 → 旗帜反向飘 (物理不合理)

模型需要从训练数据学习运动先验:
├─ 哪些物体通常怎么动? (运动模式先验)
├─ 运动幅度多大才自然? (运动幅度先验)
├─ 什么运动符合物理? (物理规律先验)
└─ 帧间如何过渡? (时间一致性先验)

四大子问题:
1. 运动模糊性 → 需要额外条件控制 (文本/音频)
2. 运动幅度 → 需要幅度参数或训练标注
3. 物理合理性 → 依赖训练数据覆盖
4. 时间一致性 → 时间注意力/长序列建模
```

#### 挑战三：结构保持

结构保持要求生成视频中物体的形状、姿态和拓扑关系不发生不合理的改变。这一问题在包含复杂结构的输入图像中尤为突出——人物有肢体关节的约束，建筑有直线和直角的约束，车辆有对称性的约束。

结构保持的困难根源在于潜空间表示对结构信息的编码是隐式的。VAE编码后的潜空间表示包含了图像的全部信息，但结构信息与外观信息混在一起，模型难以区分哪些部分是结构（不应该改变）哪些部分是外观（可以有所变化）。

当模型在去噪过程中生成新的帧时，它可能在改变外观的同时无意中改变了结构。例如，在生成人物走动的视频时，人物的手臂可能变形为不自然的弯曲角度；在生成建筑的视频时，建筑的直线可能变弯曲；在生成车辆移动的视频时，车辆的对称性可能被破坏。

ControlNet为结构保持提供了有效的解决方案。通过从输入图像中提取显式的结构信息（如边缘图、深度图、姿态关键点等），并将这些信息作为条件注入生成过程，可以约束模型在允许外观变化的同时保持结构不变。

然而，ControlNet需要额外的结构提取网络，这增加了系统的复杂性。而且，不同类型的结构信息适用于不同场景——姿态关键点适用于人物，边缘图适用于建筑和产品，深度图适用于场景。选择合适的结构表示需要领域知识。

另一个策略是在训练中引入结构保持的损失函数。例如，计算生成帧与输入图像之间的结构相似性（SSIM, Structural Similarity Index），或使用预训练的特征提取网络计算感知损失（Perceptual Loss）。这些损失函数引导模型在生成过程中保持结构一致性。

```
结构保持的挑战与解决方案：

问题: 潜空间中结构与外观混合, 难以分离

输入图像包含:
├─ 结构信息: 物体形状, 关节位置, 直线角度, 对称性
├─ 外观信息: 颜色, 纹理, 光照
└─ 语义信息: 物体类别, 场景类型

生成时的问题:
├─ 人物: 肢体变形, 关节反弯, 手指数目变化
├─ 建筑: 直线变弯, 直角变钝角, 透视错误
├─ 车辆: 对称性破坏, 轮胎变形, 比例失调
└─ 场景: 物体凭空出现/消失, 空间关系错乱

解决方案:
┌─────────────────────────────────────────┐
│  方案1: ControlNet (显式结构约束)         │
│  ├─ 提取结构信息 (边缘/深度/姿态)         │
│  ├─ 通过旁路网络注入                      │
│  └─ 优点: 精确控制 / 缺点: 需要提取器     │
├─────────────────────────────────────────┤
│  方案2: 结构损失函数 (隐式约束)           │
│  ├─ SSIM损失: 结构相似性                  │
│  ├─ 感知损失: 深层特征一致性              │
│  └─ 优点: 无需额外网络 / 缺点: 约束较弱   │
├─────────────────────────────────────────┤
│  方案3: I2V Mask (硬性保持)              │
│  ├─ 首帧强制保持                         │
│  ├─ 后续帧以首帧为锚点                   │
│  └─ 优点: 首帧严格一致 / 缺点: 仅限首帧   │
└─────────────────────────────────────────┘
```

### 九、总结与展望

图生视频技术在过去两年取得了飞速发展。从SVD的开源方案到Wan2.1的高效架构，从AnimateDiff的通用框架到Wan2.2-S2V的数字人专用方案，技术在不断成熟，应用场景也在不断扩展。

从技术发展趋势来看，几个方向值得关注。

首先是更高效的视频表示。3D因果VAE代表了这一方向的努力——通过在时间维度上压缩，减少潜空间的数据量，使得模型可以处理更长的视频。未来可能出现更高效的表示方式，如基于神经辐射场（NeRF, Neural Radiance Fields）或3D高斯泼溅（3D Gaussian Splatting）的视频表示。

其次是更精确的运动控制。当前模型对运动的控制还比较粗糙——用户难以指定"让照片中的人物举起右手"或"让云从左向右移动"这样的具体运动。未来可能通过更丰富的条件输入（如姿态序列、运动轨迹、物理仿真参数等）实现精确的运动控制。

第三是更长的视频生成。当前模型通常只能生成几秒到十几秒的视频。生成更长的视频需要解决叙事连贯性、场景转换、运动累积等挑战。自回归生成、分层生成（先生成关键帧再生成中间帧）等策略正在被探索。

第四是实时生成。当前模型的生成速度通常在分钟级别，难以满足实时交互的需求。Flow Matching等高效训练目标、模型蒸馏（Model Distillation）、缓存优化等技术正在推动生成速度的提升。未来实现实时图生视频将为虚拟现实、实时数字人等应用打开新的大门。

图生视频技术正在从研究走向应用，从实验室走向产业。虽然挑战依然存在，但每一次技术迭代都在缩小想象与现实之间的差距。随着模型能力的提升和生态的成熟，图生视频将成为内容创作的重要基础设施。
