## 第一章 视频生成技术概述

### 1.1 什么是AI视频生成

AI视频生成是指利用人工智能技术，根据文本描述、静态图像、现有视频或其他模态的输入，自动生成视觉逼真、时序连贯的视频内容。它是生成式AI（Generative AI）在视频领域的具体应用，代表了当前人工智能最具挑战性和最具想象力的方向之一。

与传统的视频制作流程不同，AI视频生成无需摄像机、演员、后期剪辑等物理生产环节，而是通过深度学习模型直接从数据中学习视觉世界的规律，并在推理阶段"创造"出新的视频内容。这一过程的核心在于：模型不仅要生成空间上逼真的单帧画面，还要在时间维度上保持帧与帧之间的运动连贯性和语义一致性。

### 1.2 三大技术路线

当前AI视频生成主要分为三条技术路线：

#### 1.2.1 文生视频（Text-to-Video, T2V）

用户输入一段自然语言描述（如"一只金毛犬在夕阳下的海滩上奔跑"），模型直接生成与之匹配的视频。这是最具挑战性的路线，因为模型需要同时理解语言的抽象语义和视频的具象视觉表达，完成从"文字想象"到"视觉呈现"的跨模态映射。

#### 1.2.2 图生视频（Image-to-Video, I2V）

用户提供一张静态图片作为起始帧（或参考帧），模型基于该图片生成动态视频。例如将一幅人物肖像"活起来"，使其眨眼、微笑、转头。这条路线的约束更强——生成内容必须在视觉上与输入图像保持一致性，因此可控性优于文生视频。

#### 1.2.3 视频生视频（Video-to-Video, V2V）

以一段现有视频作为输入，模型对其进行风格转换、内容编辑、分辨率提升或其他变换。例如将实拍视频转为动漫风格、将白天的街景转为夜晚、或将语义分割掩码转换为真实场景。这是可控性最强的路线，因为输入视频提供了完整的时空结构信息。

### 1.4 为什么视频生成如此困难

视频生成相比图像生成，面临着指数级增长的挑战：

1. **时空一致性**：视频不是独立的图片序列，而是有内在运动逻辑的连续画面。模型必须保证物体在帧间的运动符合物理规律——人物不能突然消失、水不能倒流、影子不能乱跳。

2. **计算复杂度**：一段10秒、30fps、1080p的视频包含300帧、每帧200万像素，总像素量达6亿。直接在像素空间进行扩散计算是不可行的，需要高效的潜在空间压缩方案。

3. **数据瓶颈**：高质量的视频-文本配对数据极其稀缺。互联网上的视频虽然海量，但大多数缺乏精确的文本描述，且存在水印、低分辨率、画面抖动等质量问题。

4. **长程依赖**：生成长视频时，模型需要"记住"几十秒前出现的人物、场景和事件，避免前后矛盾。这对模型的上下文建模能力提出了极高要求。

5. **可控性**：用户往往希望精确控制视频中的运动、视角、风格等要素，但目前的模型在精细控制方面仍有限。

## 第二章 视频生成的数学与深度学习基础

### 2.1 生成模型基础理论

#### 2.1.1 生成模型 vs 判别模型

判别模型学习的是条件概率 P(y|x)，即在输入 x 的条件下输出 y 的概率，用于分类或回归。生成模型学习的是数据分布 P(x) 或条件分布 P(x|y)，目的是"生成"新的数据样本。

视频生成模型属于生成模型的范畴，其目标是学习真实视频数据的数据分布，并从中采样生成新的视频。

#### 2.1.2 三大生成模型范式

**1. 生成对抗网络（GAN）**

GAN由生成器（Generator）和判别器（Discriminator）组成。生成器尝试生成逼真的假数据欺骗判别器，判别器尝试区分真假数据。两者在对抗中共同进化。

```
min_G max_D V(D, G) = E_{x~p_data}[log D(x)] + E_{z~p_z}[log(1 - D(G(z)))]
```

GAN的优势在于生成速度快、质量高；劣势在于训练不稳定、容易模式崩溃（mode collapse）。代表作品：StyleGAN、pix2pixHD、vid2vid。

**2. 扩散模型（Diffusion Model）**

扩散模型通过两个过程工作：
- **前向扩散**：逐步向真实数据添加高斯噪声，直到变成纯噪声
- **反向去噪**：训练神经网络学习如何逐步去噪，从噪声恢复数据

```
前向：x_t = √(α_t) · x_{t-1} + √(1-α_t) · ε,  ε ~ N(0, I)
反向：学习 ε_θ(x_t, t) ≈ ε，然后 x_{t-1} = (x_t - β_t · ε_θ) / √(α_t)
```

扩散模型的优势在于训练稳定、生成多样性好、理论基础扎实；劣势在于生成速度慢（需多步迭代）。代表作品：DDPM、Stable Diffusion、Sora。

**3. 自回归模型（Auto-regressive Model）**

自回归模型将视频视为序列数据，逐帧（或逐token）预测下一个内容，类似于GPT生成文本的方式。

```
P(x_1, x_2, ..., x_T) = Π_{t=1}^{T} P(x_t | x_1, x_2, ..., x_{t-1})
```

自回归模型的优势在于可生成长序列、与语言模型天然兼容；劣势在于逐帧生成速度慢、误差累积。代表作品：VideoGPT、GAIA。

### 2.2 变分自编码器（VAE）

VAE是扩散模型的重要前置技术。它由编码器（Encoder）和解码器（Decoder）组成，将高维数据压缩到低维潜在空间，再从潜在空间重建数据。

在视频生成中，VAE的核心作用是**降维**：将像素空间的视频（如 256×256×3×16 帧 = 3,145,728 维）压缩到潜在空间（如 32×32×4×16 = 65,536 维），使扩散模型在潜在空间中高效运行。

### 2.3 Transformer架构

Transformer是当前视频生成模型的主流骨架。其核心是自注意力机制（Self-Attention）：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) · V
```

其中 Q（查询）、K（键）、V（值）分别由输入线性变换得到。自注意力让模型能够捕捉序列中任意两个位置之间的依赖关系。

在视频生成中，Transformer需要处理空间和时间两个维度的注意力：

- **空间注意力**：捕捉同一帧内不同区域的关系
- **时间注意力**：捕捉不同帧之间同一区域的关系
- **时空融合注意力**：同时处理空间和时间维度的关系

### 2.4 条件生成机制

视频生成通常是条件生成——根据文本、图像或其他条件信息引导生成过程。主要条件注入方式包括：

1. **交叉注意力（Cross-Attention）**：将条件特征作为Key和Value，与生成内容的Query做注意力计算。这是Stable Diffusion和大多数DiT模型采用的方式。

2. **自适应归一化（AdaLN）**：将条件信息通过MLP网络转换为缩放和偏移参数，作用于Transformer的归一化层。DiT论文中广泛使用。

3. **控制网络（ControlNet）**：将条件信息通过旁路网络注入，保持主干网络不变。适用于精细控制。

4. **拼接注入**：将条件信息直接与噪声输入拼接，作为额外通道送入模型。图生视频常用此方式。

## 第三章 视频生成的核心架构演进

### 3.1 第一代：基于GAN的视频生成

#### 3.1.1 vid2vid（2018）

NVIDIA提出的vid2vid是视频生成的开创性工作。它基于条件GAN，采用分层编码-解码结构：

- **生成器**：基于pix2pixHD架构，输入语义分割图序列，输出逼真视频
- **判别器**：包括图像判别器D_I（判断单帧真实性）和视频判别器D_V（判断光流真实性）
- **光流约束**：利用光流估计保证帧间一致性
- **前景/背景分离建模**：前景物体和背景分别处理，提高生成质量

核心创新是马尔可夫假设：当前帧的生成仅需前L帧的信息（L通常取2），大幅简化了时序建模。

#### 3.1.2 GAN路线的局限

- 训练不稳定，大规模扩展困难
- 生成多样性有限
- 难以处理长视频和复杂场景

### 3.2 第二代：基于U-Net的扩散模型

#### 3.2.1 Video Diffusion Model（VDM, 2022）

Google提出的VDM是首个基于扩散模型的视频生成工作：

- 采用3D U-Net架构，在标准2D U-Net基础上添加时间注意力层
- 支持图像和视频的联合训练
- 使用未公开的1000万带字幕视频数据集

#### 3.2.2 Make-A-Video（2022）

Meta的工作将T2I扩散模型扩展到视频：

- 利用预训练的T2I模型（DALL·E），通过添加时序层实现视频生成
- 采用2+1D卷积（先空间2D卷积，再时间1D卷积）降低计算量
- 级联架构：基础生成器 + 时间超分辨率 + 空间超分辨率

#### 3.2.3 Stable Video Diffusion（SVD, 2023）

Stability AI推出的SVD是首个高质量开源图生视频模型：

- 基于Stable Diffusion 2.1的图像骨架
- 在U-Net噪声预测器中添加时间卷积和注意力层
- 三阶段训练：图像预训练 → 视频大规模预训练 → 高质量数据微调
- 输入一张静态图片，生成14-25帧短视频

#### 3.2.4 U-Net路线的瓶颈

- U-Net的卷积结构对长程依赖建模能力有限
- 难以扩展到更大模型和数据规模
- 架构工程复杂，不同模块需要精细调参

### 3.3 第三代：扩散Transformer（DiT）

#### 3.3.1 DiT架构核心思想

Diffusion Transformer（DiT）用Transformer替换U-Net作为扩散模型的骨干网络：

1. **Patch化**：将输入（图像/视频的潜在表示）切分为固定大小的patch，类似于ViT
2. **序列化**：将patch展开为序列，送入Transformer处理
3. **条件注入**：通过AdaLN或交叉注意力注入时间步和文本条件
4. **输出去噪**：Transformer输出每个patch的噪声预测

DiT的关键优势在于**Scaling Law**：模型越大、数据越多、训练越久，效果越好。这为视频生成的大规模扩展铺平了道路。

#### 3.3.2 Sora的架构创新

OpenAI的Sora是DiT在视频生成领域的标志性应用：

**1. 时空压缩网络（Spacetime VAE）**

Sora训练了一个视频压缩网络，将原始视频在空间和时间维度同时压缩到低维潜在空间：

- 空间压缩：将每帧图像通过VAE编码器压缩
- 时间压缩：沿时间维度进一步下采样
- 输出：时空潜在表示（Spacetime Latent）

**2. 时空Patch（Spacetime Patches）**

将压缩后的潜在表示切分为时空patch，作为Transformer的token。这类似于GPT中的文本token，但承载的是视觉时空信息。

Sora借鉴了NaViT的"Patch n' Pack"技术，可以将不同分辨率、不同时长、不同宽高比的视频统一表示为patch序列。这使得模型可以在原生尺寸下训练，避免缩放和填充带来的信息损失。

**3. DiT扩散Transformer**

- 输入：噪声化的时空patch + 时间步嵌入 + 文本条件
- 处理：多层Transformer Block（自注意力 + 交叉注意力 + AdaLN）
- 输出：每个patch的噪声预测
- 去噪：通过DDPM/DDIM采样逐步去噪

**4. 文本重标注（Re-captioning）**

训练阶段：使用DALL·E 3（CLIP）为训练视频生成详细的描述性文本
推理阶段：使用GPT-4将用户的简短提示扩展为详细描述

#### 3.3.3 DiT路线的全面胜利

Sora之后，几乎所有主流视频生成模型都转向DiT架构：

- **可灵Kling**：扩散Transformer，支持2分钟视频
- **Runway Gen-3**：时空解耦的DiT，空间注意力和时间注意力分离计算
- **万相Wan2.1**：DiT + Flow Matching + 3D因果VAE
- **CogVideoX**：3D RoPE + 专家Transformer
- **HunyuanVideo**：大规模DiT，腾讯开源

### 3.4 架构对比总结

| 维度 | GAN (vid2vid) | U-Net扩散 (SVD) | DiT扩散 (Sora) |
|------|:---:|:---:|:---:|
| 生成质量 | 中等 | 高 | 最高 |
| 训练稳定性 | 差 | 好 | 好 |
| 可扩展性 | 差 | 中 | 优 |
| 生成速度 | 快 | 慢 | 慢（可优化） |
| 长视频能力 | 差 | 差 | 中-优 |
| 多样性 | 低 | 高 | 高 |
| 主流地位 | 已淘汰 | 逐渐被替代 | 当前主流 |

## 第四章 文生视频（Text-to-Video）

### 4.1 基本原理

文生视频的目标是学习一个映射函数 F: (text) → video，使得生成的视频在语义上与输入文本一致，在视觉上逼真，在时序上连贯。

形式化定义：给定文本描述 c，模型学习条件分布 P(video | c)，并通过采样从该分布中生成视频。

### 4.2 文本编码

文生视频的第一步是将自然语言文本编码为模型可理解的特征向量：

#### 4.2.1 CLIP文本编码器

CLIP（Contrastive Language-Image Pre-training）是OpenAI提出的图文对比学习模型。其文本编码器可以将自然语言映射到与图像特征对齐的向量空间。早期视频生成模型（如SVD）主要使用CLIP文本编码器。

#### 4.2.2 T5/UMT5编码器

T5（Text-to-Text Transfer Transformer）是Google提出的通用文本编码器，支持多语言。万相Wan2.1使用UMT5（多语言版本）作为文本编码器，支持中文提示词。

#### 4.2.3 LLM增强提示

现代文生视频系统通常先用大语言模型（如GPT-4）将用户的简短提示扩展为详细的场景描述，包含主体、动作、环境、光照、镜头运动等信息，再送入视频生成模型。

### 4.3 生成流程

标准文生视频生成流程：

```
用户提示 → [LLM扩展] → 文本编码器 → 文本特征
                                          ↓
随机噪声 → [DiT去噪(多步)] → 潜在表示 → [VAE解码] → 视频帧
                    ↑
              文本特征(交叉注意力)
              时间步(AdaLN)
```

### 4.4 关键技术挑战

#### 4.4.1 语义对齐

确保生成的视频内容忠实反映文本描述。挑战包括：
- 复杂场景（多物体、多动作）
- 抽象概念（如"孤独"、"喜悦"）
- 空间关系（"A在B的左边"）
- 数量精确控制（"三只猫"）

#### 4.4.2 运动合理性

生成的运动需要符合物理规律：
- 重力、碰撞、流体动力学
- 物体刚性/柔性变形
- 光影变化与运动同步

#### 4.4.3 长视频生成

生成长视频时的核心问题：
- **误差累积**：自回归方式逐帧生成，错误逐级放大
- **内容遗忘**：长视频前后场景不一致
- **计算爆炸**：时长增加带来计算量指数增长

主流解决方案：
- **分块生成 + 重叠**：将长视频分为多个短片段，片段间重叠保证连贯
- **滑动窗口**：以已生成内容为条件，滑动生成新内容
- **层次化生成**：先生成关键帧，再插值生成中间帧

### 4.5 典型文生视频模型

## 第五章 图生视频（Image-to-Video）

### 5.1 基本原理

图生视频以一张静态图片作为条件输入，生成一段从该图片"延续"出的动态视频。其核心约束是：**生成视频的第一帧（或关键帧）必须与输入图片在视觉上高度一致**。

### 5.2 条件注入方式

#### 5.2.1 拼接注入

将输入图片通过VAE编码后，与噪声潜在表示在通道维度拼接，作为DiT的输入。这是最简单直接的方式，SVD采用此方法。

```
输入：[噪声潜在表示(4ch) + 图片潜在表示(4ch)] → 8通道输入 → DiT
```

#### 5.2.2 参考帧注意力

将输入图片的特征作为额外的Key-Value对，送入DiT的自注意力层。模型在生成每一帧时都能"参考"输入图片的信息。

#### 5.2.3 ControlNet注入

通过旁路网络提取输入图片的结构信息（如深度图、边缘图），注入主干网络。

#### 5.2.4 AdaLN条件注入

将输入图片的全局特征通过MLP转换为AdaLN的缩放和偏移参数，调节DiT各层的归一化。

### 5.3 SVD的图生视频方案

Stable Video Diffusion是图生视频的代表性开源模型，其方案如下：

**训练三阶段**：

1. **图像预训练**：以Stable Diffusion 2.1为图像骨架，学习高质量的图像生成能力
2. **视频预训练**：在U-Net中添加时间卷积和注意力层，使用大规模视频数据训练
3. **高质量微调**：使用精心筛选的小规模高质量视频数据集微调

**推理过程**：

1. 输入图片通过VAE编码器编码为潜在表示
2. 生成与目标帧数相同的噪声潜在表示
3. 将图片潜在表示作为第一帧的条件，通过拼接注入
4. DiT迭代去噪，生成所有帧的潜在表示
5. VAE解码器将潜在表示解码为视频帧

### 5.4 万相Wan2.1的图生视频方案

阿里万相2.1的图生视频采用了更先进的技术：

- **3D因果VAE**：实现256倍无损视频隐空间压缩
- **Flow Matching**：替代传统DDPM，训练更高效
- **I2V Mask机制**：对输入图片帧施加掩码约束，保证一致性
- **特征缓存机制**：避免对长视频的直接端到端处理

### 5.5 图生视频的应用场景

1. **照片活化**：让人物肖像眨眼、微笑、说话
2. **AI数字人**：一张照片+音频生成说话视频（如Wan2.2-S2V）
3. **插画动化**：将静态插画、漫画变为动画
4. **产品展示**：将产品照片转为360°展示视频
5. **场景延伸**：从一张风景照片生成动态视频
6. **影视前期**：从分镜画稿生成动态预览

### 5.6 核心挑战

#### 5.6.1 首帧一致性

生成的视频必须从输入图片"自然延伸"，不能出现突变。这要求模型在保持首帧像素级一致的同时，为后续帧生成合理的运动。

#### 5.6.2 运动自然性

从单张图片推断合理的运动方向和速度是一个病态问题——同一张图片可能有多种合理的运动方式。模型需要学习"最自然"的运动模式。

#### 5.6.3 结构保持

运动过程中物体的形状、颜色、纹理应保持稳定，不能出现变形、消失或凭空出现。

## 第六章 视频生视频（Video-to-Video）

### 6.1 基本原理

视频生视频以一段现有视频作为输入，通过AI模型对其进行变换，输出新的视频。变换可以是风格转换（如真人转动漫）、内容编辑（如换装、换背景）、分辨率提升（如480p转4K）等。

形式化定义：学习映射函数 G: (source_video, condition) → target_video，使输出视频在保持输入视频时空结构的同时，满足目标变换要求。

### 6.2 技术路线分类

#### 6.2.1 基于GAN的V2V（vid2vid路线）

NVIDIA的vid2vid是V2V的开山之作，采用条件GAN架构：

**生成器结构**：
- 分层编码-解码网络
- 输入：当前帧条件 s_t + 前L帧条件 s_{t-L:t-1} + 前L帧生成结果 x̃_{t-L:t-1}
- 输出：当前帧生成结果 x̃_t

**判别器**：
- 图像判别器 D_I：判断单帧 (s_t, x̃_t) 的真实性
- 视频判别器 D_V：判断光流序列的真实性

**光流约束**：
利用光流估计确保帧间一致性。生成第t帧时，用前帧的光流信息约束当前帧，使运动区域的像素预测更加准确。

**前景/背景分离**：
- 背景通常运动简单（如平移），用低分辨率网络处理
- 前景运动复杂，用高分辨率网络精细处理
