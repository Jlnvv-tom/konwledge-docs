## 第四章 文生视频（Text-to-Video, T2V）

### 一、文生视频的基本原理与形式化定义

文生视频（Text-to-Video, T2V）是指给定一段自然语言文本描述，由AI模型自动生成与文本语义一致的视频序列。这一任务是AIGC（Artificial Intelligence Generated Content，人工智能生成内容）领域中最具挑战性的方向之一，它融合了自然语言处理、计算机视觉和时序建模三大领域的技术。

从概率建模的角度来看，文生视频的核心目标是学习一个条件分布 P(video | text)。具体而言，给定文本条件 c，模型需要生成一个视频样本 V，使得 V 服从条件分布 P(V | c)。这里的视频 V 可以表示为一个四维张量 V ∈ R^{T×H×W×C}，其中 T 为帧数（时间维度），H 和 W 分别为每帧图像的高度和宽度（空间维度），C 为通道数（通常为3，对应RGB三通道）。

与之相对比，文生图（Text-to-Image, T2I）的任务是学习 P(image | text)，其输出仅为二维图像，不包含时间维度。正是这一额外的时间维度，使得文生视频的难度呈指数级增长。模型不仅要保证每一帧图像的质量和文本对齐度，还要保证帧与帧之间的时序连贯性和运动合理性。

从信息论的角度分析，视频的信息熵远高于图像。一段 T 帧的视频，其可能的状态空间是单帧图像的 T 次方量级。这意味着模型需要处理和生成更加庞大的数据分布，对模型的容量、训练数据和计算资源都提出了极高要求。

形式化地，文生视频的生成过程可以表述为：从先验噪声分布中采样初始噪声 z_T，然后在文本条件 c 的引导下，通过去噪过程逐步将其转化为干净的视频 z_0。在扩散模型框架下，这个过程可以写为：

正向过程：q(z_t | z_{t-1}) = N(z_t; √(1-β_t) z_{t-1}, β_t I)

逆向过程：p_θ(z_{t-1} | z_t, c) = N(z_{t-1}; μ_θ(z_t, t, c), Σ_θ(z_t, t, c))

其中 β_t 是预设的噪声调度参数，μ_θ 和 Σ_θ 是由神经网络参数化的均值和方差。文本条件 c 通过交叉注意力（Cross-Attention）机制注入到去噪网络的每一层中，引导生成过程朝着与文本语义一致的方向进行。

除了扩散模型框架，文生视频还可以基于自回归（Autoregressive）框架实现。在自回归框架中，视频被表示为离散的token序列，模型按照时序顺序逐token预测，即 P(V) = ∏ P(v_i | v_{<i}, c)。这种方式天然适合时序建模，但存在推理速度慢、误差累积等问题。

值得注意的是，无论是扩散模型还是自回归模型，文本条件的编码方式都至关重要。文本编码的质量直接决定了生成视频的语义准确度。接下来，我们将详细讨论文生视频中的文本编码方案。

### 二、文本编码方案详解

文本编码是文生视频的第一步，也是决定生成质量的关键环节。模型需要将自然语言文本转化为高维向量表示，使其能够有效引导视频生成过程。目前主流的文生视频模型采用了三种主要的文本编码方案。

#### 2.1 CLIP文本编码器

CLIP（Contrastive Language-Image Pre-training，对比语言-图像预训练）是OpenAI于2021年提出的多模态预训练模型。它的核心思想是通过对比学习，将文本和图像映射到同一个语义空间中，使得匹配的图文对在向量空间中距离更近，不匹配的距离更远。

CLIP的训练过程如下：首先构建大规模的图文对数据集（如LAION-400M），每个样本包含一张图像和对应的描述文本。在每个训练批次中，取N个图文对，构成N×N的相似度矩阵。对比损失函数要求对角线上的相似度（正样本对）尽可能大，非对角线上的相似度（负样本对）尽可能小。这种训练方式被称为InfoNCE损失。

CLIP的文本编码器采用Transformer架构。具体来说，文本首先经过BPE（Byte-Pair Encoding，字节对编码）分词，转化为subword token序列。然后加上位置编码和特殊的[SOS]（Start of Sequence）和[EOS]（End of Sequence）标记。经过多层Transformer编码后，取[EOS]位置的输出向量作为整个文本句子的表示。

在文生视频中的应用方面，CLIP文本编码器被广泛应用于基于扩散模型的生成框架中。例如，OpenAI的Sora模型、Stability AI的Video模型等都采用了CLIP作为文本编码器。CLIP编码的文本向量通过交叉注意力机制注入到视频扩散模型的去噪网络中，在每个空间和时间位置上对生成过程进行语义引导。

CLIP的优势在于其强大的跨模态对齐能力。由于训练时同时看到了图像和文本，CLIP的文本表示天然包含视觉语义信息，这使得它特别适合引导视觉生成任务。此外，CLIP预训练模型开源且易于使用，大大降低了文生视频模型的开发门槛。

然而，CLIP也存在一些局限。首先，CLIP的文本编码器参数量相对较小（通常为63M到123M），对于复杂的长文本描述，其编码能力有限。其次，CLIP的训练数据以英文为主，对其他语言的支持较弱。最后，CLIP的对比学习目标更关注全局语义对齐，对细粒度的属性控制（如具体数量、空间位置等）能力不足。

#### 2.2 T5与UMT5文本编码器

T5（Text-to-Text Transfer Transformer，文本到文本转换Transformer）是Google于2019年提出的统一自然语言处理框架。T5将所有NLP任务统一为"文本到文本"的格式——输入文本，输出文本。这种统一的框架使得模型可以在大规模多任务数据上进行预训练，获得强大的语言理解能力。

T5的架构基于标准的Encoder-Decoder Transformer。其预训练任务为"span corruption"——随机遮蔽文本中的连续片段，让模型预测被遮蔽的内容。T5的编码器输出为每个token的上下文化表示向量序列，而非单个句子向量。这种序列级的表示保留了文本的细粒度信息，有利于精确的语义控制。

在文生视频领域，T5的编码器部分常被单独提取用作文本编码器。与CLIP的句子级向量不同，T5输出的是token序列的表示，这意味着模型可以通过交叉注意力机制访问文本中每个词的语义信息。这种细粒度的文本表示对于生成包含复杂场景、多个对象和精确属性的视频至关重要。

例如，当文本描述为"一只红色的猫从左边跑过，追着一只蓝色的蝴蝶，背景是绿色的草地"时，T5能够分别编码"红色的猫"、"左边"、"蓝色的蝴蝶"、"绿色草地"等关键语义单元，使视频生成模型能够分别关注不同的对象和属性。

UMT5（Unmasked Multilingual T5，无掩码多语言T5）是T5的多语言增强版本。UMT5在训练时去掉了T5中encoder部分的掩码操作，使编码器能够看到完整的输入文本。同时，UMT5在超过100种语言的数据上进行预训练，具有强大的多语言理解能力。

对于文生视频而言，UMT5的价值在于它能够直接编码非英文文本，无需经过翻译步骤。例如，可灵（Kling）模型和万相（Wan2.1）模型等国产文生视频模型大量采用了UMT5作为文本编码器，直接处理中文输入。这避免了翻译过程中可能产生的语义损失，尤其有利于处理中文特有的文化概念和表达方式。

T5/UMT5编码器的一个技术细节是其序列长度。标准T5支持最大512个token的输入长度，而用于文生视频的版本通常扩展到256甚至更长的序列。较长的文本输入允许用户提供更详细的场景描述，包括镜头运动、光照条件、角色动作等信息。研究表明，更详细和结构化的文本提示能够显著提升生成视频的质量和可控性。

T5/UMT5的参数量通常远大于CLIP文本编码器，从数百M到数B不等。更大的模型容量带来了更强的语言理解能力，但也增加了计算开销和显存占用。在实际应用中，开发者需要在编码质量和计算效率之间寻找平衡。

#### 2.3 LLM增强提示

随着大语言模型（Large Language Model, LLM）的快速发展，一种新兴的做法是利用GPT-4等强大的LLM来增强文生视频的文本输入。这种方法的动机很简单：用户通常只能提供简短模糊的描述，而视频生成模型需要详细精确的场景描述才能生成高质量结果。

LLM增强提示的工作流程通常如下：用户输入简短描述，如"海边的日落"。LLM接收到这个输入后，将其扩展为详细的场景描述："广角镜头下，金色太阳缓缓沉入海平线，天空渐变从橙色到紫红色，海面反射着粼粼金光，远处几只海鸥低飞掠过水面，近处沙滩上留下潮水退去的湿润痕迹，微风吹起细沙。"

这种扩展不仅增加了视觉细节，还可以包含以下维度的信息：

镜头语言：包括镜头类型（广角、特写、跟随等）、镜头运动（推拉摇移）、焦距和景深等摄影学概念。这些信息帮助模型生成更专业、更有电影感的画面。

场景描述：包括时间（白天、黄昏、夜晚）、天气（晴、阴、雨、雪）、光照条件（自然光、人工光源）等环境因素。这些信息影响视频的整体色调和氛围。

角色与动作：详细描述角色的外观（穿着、表情、姿态）和具体动作序列。对于人物生成，还可以包括情绪状态和互动方式。

物理属性：包括物体的材质、透明度、反射率等物理特性。这些信息有助于模型生成物理合理的运动和光影效果。

时序信息：描述事件的先后顺序和持续时间。例如"先看到远处的闪电，两秒后传来雷声，雨水逐渐变大"。

除了LLM扩展，另一种相关技术是提示重写（Prompt Rewriting）。模型内部部署一个小型的语言模型，将用户输入重写为更适合视频生成的格式。这种重写通常包括关键词提取、句式标准化、缺失信息补全等操作。例如，将"一只狗在跑"重写为"一只金色的拉布拉多犬在绿色的草地上奔跑，镜头从侧面跟随拍摄，阳光从右上方照射"。

一些先进的文生视频系统还采用了结构化提示工程。用户通过表单或模板输入结构化信息（如场景类型、角色列表、动作序列、镜头参数等），系统将其转化为自然语言描述后输入视频生成模型。这种方式虽然牺牲了一定的灵活性，但提供了更好的可控性和一致性。

#### 2.4 三种文本编码方案对比

以下表格从多个维度对比CLIP、T5/UMT5和LLM增强提示三种方案的特点：

| 对比维度 | CLIP文本编码器 | T5/UMT5文本编码器 | LLM增强提示 |
|---|---|---|---|
| 模型参数量 | 63M-123M | 250M-5B | 7B-200B（GPT-4级别） |
| 输出形式 | 句子级单一向量 | Token级序列表示 | 扩展后的自然语言文本 |
| 语义粒度 | 全局语义，细粒度不足 | Token级细粒度语义 | 依赖下游编码器 |
| 多语言支持 | 以英文为主，多语言弱 | UMT5支持100+语言 | 取决于LLM本身 |
| 视觉对齐能力 | 强（训练时与图像对齐） | 弱（纯文本预训练） | 间接（需配合下游编码器） |
| 计算开销 | 低 | 中等到高 | 高（需调用外部LLM） |
| 可控性 | 属性控制困难 | 支持细粒度属性控制 | 通过结构化提示实现 |
| 典型应用 | Sora, Stable Video Diffusion | 可灵Kling, 万相Wan2.1, CogVideoX | 多数商用系统的预处理模块 |
| 训练数据需求 | 需大规模图文对 | 纯文本数据即可 | 无需训练，零样本使用 |
| 推理延迟 | 极低（单次前向传播） | 中等 | 高（需多轮LLM调用） |

在实际的文生视频系统中，这三种方案并非互斥的。许多先进的模型采用了组合策略：先用LLM将用户简短提示扩展为详细描述，然后用T5/UMT5或CLIP进行文本编码，最后将编码后的特征注入视频生成网络。这种级联式的文本处理流程能够同时获得详细性、精确性和视觉对齐能力。

### 三、完整的文生视频生成流程

文生视频的完整生成流程涉及多个阶段，从用户输入文本到最终输出视频帧，每个阶段都有特定的技术职责。以下用文字流程图展示完整的端到端流程。

**文生视频全链路流程图：**

```
用户输入阶段
    │
    ▼
[1] 用户文本提示（自然语言描述）
    │
    ▼
文本预处理阶段
    │
    ├──> [2a] LLM提示增强（可选）
    │         将简短描述扩展为详细场景描述
    │         补充镜头语言、光照、动作等细节
    │
    ├──> [2b] 提示安全过滤
    │         检测并过滤违规内容
    │
    └──> [2c] 文本编码
              使用CLIP/T5/UMT5将文本转为向量表示
              输出：文本特征序列 {c_1, c_2, ..., c_n}
    │
    ▼
视频生成阶段
    │
    ├──> [3a] 潜空间初始化
    │         采样高斯噪声 z_T ∈ R^{t×h×w×c}
    │         t: 潜空间时间维度, h×w: 潜空间空间维度
    │
    ├──> [3b] 条件去噪过程（迭代T步）
    │         每步：z_{t-1} = Denoise_θ(z_t, t, c)
    │         文本特征通过交叉注意力注入
    │         时间嵌入编码当前去噪步
    │         输出：潜空间视频表示 z_0
    │
    └──> [3c] 时序一致性处理（可选）
              应用时间注意力层确保帧间连贯
              运动模块调整运动幅度和方向
    │
    ▼
后处理阶段
    │
    ├──> [4a] 潜空间解码
    │         VAE Decoder将 z_0 解码为像素空间视频帧
    │         输出：视频帧序列 {I_1, I_2, ..., I_T}
    │
    ├──> [4b] 超分辨率增强（可选）
    │         将低分辨率帧提升至目标分辨率
    │         使用空间超分模型或时空联合超分
    │
    ├──> [4c] 帧率提升（可选）
    │         通过插帧模型（如RIFE）提升帧率
    │         在相邻帧之间生成中间过渡帧
    │
    └──> [4d] 质量增强
              去噪、锐化、色彩校正
              时序稳定化处理
    │
    ▼
输出阶段
    │
    └──> [5] 最终视频输出
              编码为MP4/WebM等标准格式
              分辨率: 480p / 720p / 1080p / 4K
              帧率: 24 / 30 / 60 fps
```

在上述流程中，条件去噪阶段[3b]是整个流程的核心。以基于扩散模型的文生视频为例，去噪网络通常采用3D U-Net或Transformer架构。3D U-Net在传统2D U-Net的基础上增加了时间维度的卷积和注意力层，能够同时建模空间特征和时序关系。

对于Transformer架构的视频生成模型（如DiT，Diffusion Transformer），视频被划分为3D patch（时空块），每个patch经过线性投影后作为token输入Transformer。文本条件通过交叉注意力机制在每一层与视频token进行交互。这种架构具有更好的可扩展性，在大规模参数和训练数据下表现优异。

潜空间（Latent Space）的使用是现代文生视频模型的另一个关键技术。直接在像素空间进行扩散计算量极大——一段5秒、720p、30fps的视频包含约150帧，每帧有921600个像素，总计算量远超图像生成的150倍。通过VAE（Variational Autoencoder，变分自编码器）将视频压缩到低维潜空间（通常压缩8倍空间、4倍时间），计算量大幅降低，使得高质量视频生成在工程上成为可能。

需要注意的是，上述流程中的每个阶段都可以有多种实现选择。例如，文本编码可以选CLIP或T5；去噪网络可以选3D U-Net或DiT；超分可以选Real-ESRGAN或SwinIR；插帧可以选RIFE或IFNet。不同的选择组合形成了不同的文生视频系统，各有优劣。

### 四、关键技术挑战深入分析

文生视频虽然取得了显著进展，但仍面临诸多技术挑战。这些挑战大致可以分为三类：语义对齐、运动合理性和长视频生成。以下逐一进行深入分析。

#### 4.1 语义对齐

语义对齐是指生成视频的内容与输入文本描述在语义层面的一致性。尽管现代文本编码器已经相当强大，但在复杂场景下，语义对齐仍然是一个难题。

**复杂场景对齐困难。** 当文本描述包含多个对象、复杂背景和丰富细节时，模型容易出现遗漏或混淆。例如，文本描述"一个穿着红色外套的女孩站在左边的树下，右边的长椅上坐着一个戴蓝色帽子的男孩，远处有一辆白色汽车驶过"，模型可能正确生成了女孩和树，但遗漏了男孩或汽车，或者将红色外套和蓝色帽子分配给了错误的角色。这种错误的根源在于交叉注意力机制在处理长文本时，对不同对象和属性的绑定不够精确。

**抽象概念表达困难。** 对于"孤独"、"幸福"、"神秘"等抽象概念，模型很难将其转化为具体的视觉元素。这些概念没有直接的视觉对应物，需要模型理解概念的隐喻和文化内涵。例如，"孤独"可能需要通过空旷的场景、冷色调、单个人物等视觉元素来传达，但这种映射关系并非固定，不同文化和语境下可能有所不同。

**空间关系理解不足。** 文本中的"左边"、"右边"、"前方"、"后方"等空间描述，要求模型在二维画面中准确放置对象。研究表明，当前的文生视频模型对空间关系的理解仍然不够可靠。模型可能将"左边的猫"生成为"右边的猫"，或者将"A在B的前方"生成为"A在B的后方"。这一问题的根源在于文本编码器对空间介词的编码不够精确，以及生成模型对空间位置的细粒度控制能力不足。

**数量控制困难。** 当文本描述指定了具体数量时，如"三只猫在草地上玩耍"，模型往往难以精确生成指定数量的对象。常见的问题包括生成数量偏多或偏少、部分对象被遮挡导致视觉上数量减少、对象之间的边界模糊导致难以区分等。数量控制的困难反映了扩散模型在离散计数任务上的固有局限——扩散过程本质上是连续的，而数量是一个离散的概念。

以下表格总结了语义对齐的主要问题类型和当前的研究方向：

| 问题类型 | 典型表现 | 当前研究方向 |
|---|---|---|
| 复杂场景 | 多对象遗漏或混淆 | 区域级文本控制、布局引导生成 |
| 抽象概念 | 难以视觉化表达 | 概念-视觉映射学习、情感引导生成 |
| 空间关系 | 左右前后错位 | 空间感知编码器、布局条件注入 |
| 数量控制 | 生成数量不准确 | 离散约束扩散、计数损失函数 |
| 属性绑定 | 颜色/大小分配错误 | 属性-对象绑定注意力、细粒度交叉注意力 |

#### 4.2 运动合理性

运动合理性是文生视频区别于文生图的核心挑战。生成视频不仅要保证每帧图像的质量，还要保证帧与帧之间的运动符合物理规律和常识。

**物理规律建模。** 现实世界中的运动遵循物理定律，包括重力、碰撞、流体动力学等。然而，文生视频模型并未显式地学习物理定律，而是通过数据驱动的方式隐式地学习运动模式。这种方式在简单场景下效果尚可，但在复杂物理交互场景下经常出错。

重力是最基本的物理规律。当文本描述"一个球从桌上掉落"时，模型需要生成球在重力作用下加速下落的运动轨迹。理想情况下，球应该做自由落体运动，速度随时间线性增加。然而，实际生成中，球的下落速度可能不均匀，甚至在某些帧出现"悬停"或"上升"的反物理现象。

碰撞是另一个常见的物理交互。当两个物体碰撞时，应该发生动量传递、形变和可能的弹开。但模型可能生成"穿透"现象——两个物体在碰撞时直接穿过对方而不发生相互作用。这种"鬼影穿透"问题是当前文生视频模型的一个典型缺陷。

流体动力学涉及水、烟、火等流体的运动。流体的运动模式复杂，涉及涡旋、湍流、扩散等非线性现象。模型在生成流体运动时，容易出现流体形状不自然、运动方向错误、流速不一致等问题。例如，生成的瀑布水流可能不是连续的流体，而是分段的"跳跃"式流动。

**物体形变控制。** 在运动过程中，物体的形状可能发生变化——弹性物体的压缩和回弹、柔性物体（如布料、毛发）的飘动、刚性物体的旋转等。模型需要根据物体的材质属性和运动状态，生成合理的形变效果。

布料模拟是一个特别困难的领域。当人物行走时，衣服应该随身体运动而产生褶皱和飘动。模型需要理解布料的物理特性（弹性、密度、摩擦系数）以及与身体的交互方式。当前模型生成的布料运动往往不够自然，可能出现"僵硬"（布料像金属板一样不动）或"过度飘动"（布料像没有重力一样乱飘）的问题。

**光影同步。** 当物体运动时，其表面光照和阴影也应该相应变化。这包括物体自身的阴影随运动方向改变、反射高光的位置随视角变化、环境光在物体表面的投射随物体位置变化等。

光影同步的困难在于它是一个全局性的问题——一个物体的运动可能影响整个场景的光照分布。例如，一个人走过窗前会遮挡光线，在地面产生移动的阴影。模型需要同时追踪物体运动和光照变化，确保两者保持同步。实际生成中，阴影"滞后"（阴影位置与物体位置不匹配）或阴影"消失"（运动过程中阴影突然消失）是常见的问题。

以下表格展示了运动合理性的主要挑战和典型表现：

| 物理现象 | 理想表现 | 典型缺陷 | 根本原因 |
|---|---|---|---|
| 重力下落 | 加速运动，轨迹抛物线 | 速度不均匀，轨迹偏移 | 未显式建模物理方程 |
| 物体碰撞 | 动量传递，弹性形变 | 穿透，无交互 | 缺乏碰撞检测机制 |
| 流体运动 | 连续流动，涡旋自然 | 分段跳跃，形状突变 | 流体方程计算复杂度过高 |
| 布料飘动 | 随运动自然褶皱 | 僵硬或过度飘动 | 缺乏布料物理模拟 |
| 阴影同步 | 阴影随物体同步移动 | 阴影滞后或消失 | 全局光照计算困难 |
| 镜面反射 | 反射内容随视角变化 | 反射内容固定或错乱 | 光线追踪计算代价高 |

#### 4.3 长视频生成

短视频生成（5秒以内）已经取得了较好的效果，但长视频生成（30秒以上甚至数分钟）仍然是一个重大挑战。长视频生成面临三个核心问题：误差累积、内容遗忘和计算爆炸。

**误差累积问题。** 在自回归式的视频生成中，每一帧的生成依赖于前面已生成的帧。如果某一帧存在微小的瑕疵，这个瑕疵会被传递到后续帧的生成中，并在传递过程中不断放大。经过数十帧的累积，微小的初始误差可能演变为严重的画面崩坏。

误差累积的数学原理可以通过误差传播链来理解。设第 t 帧的生成误差为 ε_t，则第 t+1 帧的误差为 ε_{t+1} = f(ε_t) + δ_{t+1}，其中 f 是误差传播函数，δ_{t+1} 是新增误差。如果 f 是放大函数（即 |f'(x)| > 1），则误差将指数增长，最终导致画面完全不可识别。

即使在扩散模型框架下，误差累积问题依然存在。虽然扩散模型在生成每一帧时不是严格自回归的，但时序注意力层会将前面帧的信息传递到后续帧的生成中。如果前面帧存在质量缺陷，这些缺陷会通过注意力机制"污染"后续帧的生成。

**内容遗忘问题。** 在长视频生成中，模型需要保持对先前内容的记忆。例如，如果视频开头出现了一个穿红色衣服的角色，在30秒后该角色再次出现时，应该穿着相同的红色衣服。然而，由于注意力机制的有限感受野和模型记忆容量的限制，长程一致性很难维持。

内容遗忘表现为多种形式：角色外观变化（衣服颜色、发型改变）、场景布局变化（房间的门窗位置变化）、物体状态变化（之前打开的书后来变成关闭的）等。这些不一致严重影响了长视频的观赏性和可用性。

内容遗忘的根本原因在于 Transformer 注意力机制的计算复杂度随序列长度平方增长。对于长视频，完整的自注意力计算不可行，模型只能关注有限的上下文窗口，导致超出窗口的信息被"遗忘"。

**计算爆炸问题。** 视频数据量随时长线性增长，而基于注意力机制的视频生成模型的计算量随序列长度平方增长。这意味着将视频时长从5秒延长到60秒（12倍），计算量可能增长144倍（12的平方）。

以下表格量化了不同视频长度下的计算需求（以720p、30fps为例）：

| 视频时长 | 总帧数 | 像素总数 | 潜空间token数 | 相对计算量 |
|---|---|---|---|---|
| 2秒 | 60 | 55.3M | 3,840 | 1x |
| 5秒 | 150 | 138.2M | 9,600 | 6.25x |
| 10秒 | 300 | 276.5M | 19,200 | 25x |
| 30秒 | 900 | 829.4M | 57,600 | 225x |
| 60秒 | 1800 | 1.66B | 115,200 | 900x |

计算爆炸使得长视频生成在当前硬件条件下几乎不可行——60秒视频的生成可能需要数百GB的显存和数小时的计算时间。

#### 4.4 长视频解决方案

针对上述长视频生成挑战，研究者提出了多种解决方案，主要包括分块生成、滑动窗口和层次化生成三种策略。

**分块生成+重叠（Chunk-based Generation with Overlap）。** 核心思想是将长视频分割为多个短视频片段，分别生成后拼接。为了保证拼接处的连续性，相邻片段之间保留一定帧数的重叠区域。

具体流程如下：将长视频分为片段 [1..L], [L-O+1..2L-O], [2L-2O+1..3L-2O]...，其中 L 为片段长度，O 为重叠帧数。每个片段独立生成后，在重叠区域进行加权平均融合，确保平滑过渡。

重叠区域的融合通常采用线性混合（Linear Blending）：对于重叠区域中的第 k 帧，最终输出为 (1-α_k) × frame_A + α_k × frame_B，其中 α_k 从0到1线性变化，实现从片段A到片段B的平滑过渡。

分块生成的优势在于将长视频问题转化为多个短视频问题，计算复杂度从 O((nL)²) 降低到 O(n × L²)，大大降低了计算需求。然而，这种方法也存在局限：各片段独立生成，缺乏全局信息共享，可能导致不同片段之间的风格、内容不一致。重叠区域虽然能保证短程连续性，但无法解决长程一致性问题。

**滑动窗口（Sliding Window）。** 滑动窗口策略是分块生成的改进版本。与分块生成独立处理每个片段不同，滑动窗口在生成新片段时，将已生成的前几个片段作为上下文条件输入模型。

具体来说，生成第 k 个片段时，模型不仅接收文本条件，还接收第 k-1 和 k-2 个已生成片段作为视觉上下文。模型通过时序注意力机制从上下文片段中提取外观、运动和风格信息，用于指导新片段的生成。

滑动窗口的优势在于引入了跨片段的信息流动，有效缓解了内容遗忘问题。已生成片段中的角色外观、场景布局等信息可以通过上下文传递到后续片段，保持长程一致性。

然而，滑动窗口的上下文长度有限（通常为2-3个片段），超出窗口范围的早期信息仍然会被遗忘。此外，随着窗口滑动，误差仍然会沿生成方向累积，虽然速度比分块生成慢，但无法完全消除。

**层次化生成（Hierarchical Generation: Keyframes + Interpolation）。** 层次化生成采用"先粗后细"的策略，将视频生成分为两个层次：首先生成视频的关键帧（Keyframes），然后在关键帧之间进行插值生成过渡帧。

关键帧生成阶段：模型根据文本描述生成若干关键帧，这些关键帧定义了视频的主要场景和叙事节点。例如，对于"一个人从家走到超市，买了水果，然后回家"的文本描述，模型可能生成4个关键帧：出门、在路上、在超市、回到家。

关键帧生成可以采用多种策略。一种方式是让模型直接预测关键帧的时间位置和内容。另一种方式是由用户或LLM指定关键帧的文本描述，模型分别生成每个关键帧。后一种方式提供了更好的可控性，但需要更多的用户输入。

插值阶段：在每对相邻关键帧之间，使用视频插值模型生成过渡帧。插值模型的任务是生成从关键帧A到关键帧B的平滑过渡，包括合理的中途状态、运动轨迹和外观变化。

视频插值模型通常基于光流（Optical Flow）或扩散模型实现。光流方法通过估计两帧之间的像素级运动场，在中间位置进行扭曲和混合来生成过渡帧。扩散模型方法则将两帧作为端点条件，通过条件扩散过程生成中间帧。

层次化生成的优势在于将长视频生成解耦为两个相对简单的子问题：关键帧生成（关注内容规划）和帧间插值（关注运动平滑性）。这种分解有效降低了问题复杂度，同时通过关键帧的全局规划保证了长程一致性。

然而，层次化生成也面临挑战：关键帧的选取需要准确把握视频的叙事结构，选取过少会导致插值困难（关键帧之间差异过大），选取过多则失去层次化优势。此外，当两个关键帧之间差异较大时，插值模型可能生成不自然的过渡——例如，人物"瞬移"或场景"突变"。

以下表格对比了三种长视频生成策略：

| 策略 | 核心思想 | 优势 | 局限 | 适用场景 |
|---|---|---|---|---|
| 分块生成+重叠 | 分段独立生成，重叠区融合 | 计算高效，实现简单 | 长程一致性差，拼接处可能不自然 | 场景变化较少的长视频 |
| 滑动窗口 | 带上下文的分段生成 | 短程一致性好，部分解决遗忘 | 上下文有限，误差仍会累积 | 场景渐变的长视频 |
| 层次化生成 | 关键帧+插值 | 全局规划，长程一致性 | 插值质量受关键帧间距影响 | 叙事性强的长视频 |

在实际应用中，这些策略可以组合使用。例如，先用层次化方法生成关键帧，然后用滑动窗口策略在关键帧之间生成片段，最后通过重叠融合拼接为完整视频。这种多层次的组合策略能够在计算效率、短程连续性和长程一致性之间取得较好的平衡。

### 五、文生视频的典型应用场景

文生视频技术在多个领域展现出广阔的应用前景。以下分析四个主要应用场景。

#### 5.1 影视特效

影视行业是文生视频技术最具变革潜力的应用领域。传统影视特效制作需要专业的特效团队、昂贵的设备和数月的制作周期。文生视频技术能够显著降低特效制作的门槛和成本。

在概念设计阶段，导演和美术指导可以通过文本描述快速生成场景概念视频。例如，输入"一座建在悬崖上的未来城市，飞行汽车在空中穿梭，建筑表面覆盖着发光的植物"，模型可以在几分钟内生成多个版本的概念视频，供创作团队选择和迭代。这比传统的概念画师手绘加3D预览的方式效率高出数个数量级。

在特效镜头制作方面，文生视频可以用于生成难以实拍的场景。例如，火山爆发、行星碰撞、深海生物等危险或不存在场景的镜头，可以通过文本描述直接生成，无需昂贵的特效制作流程。对于科幻和奇幻类影视作品，这意味着更多的创意空间和更低的制作成本。

在镜头测试和预可视化（Previsualization）方面，导演可以通过文本描述快速生成不同镜头效果的视频，评估镜头语言、构图和节奏，在实际拍摄前完成创意验证。这种快速迭代能力可以显著减少拍摄阶段的试错成本。

当前的主要限制在于生成质量和可控性。专业影视制作对画面质量的要求极高（4K以上分辨率、HDR色域、精确的色彩科学），而当前文生视频模型的输出质量尚不能完全满足这些标准。此外，导演对镜头的精确控制（如特定的运镜轨迹、精确的光照设置、角色表演细节）也难以通过文本描述实现。随着技术的不断进步，这些限制有望逐步被克服。

#### 5.2 广告创意

广告行业对视频内容的需求量大、更新频率高、预算敏感度强，是文生视频技术的理想应用场景。

在广告创意原型阶段，创意团队可以通过文本描述快速生成多个广告创意视频原型。例如，运动品牌可以同时测试"运动员在雨中奔跑"、"城市夜景中的篮球对决"、"山间小路上的越野跑"等多个创意方向，快速评估哪个方向最有吸引力。这种快速创意验证能力使广告投放前的A/B测试更加高效。

在个性化广告方面，文生视频技术可以根据用户的画像信息动态生成定制化广告内容。例如，根据用户所在城市的天气、用户的年龄和性别、最近浏览的商品类别，自动生成包含相关元素和场景的广告视频。这种"千人千面"的视频广告在传统制作方式下成本不可控，但在文生视频技术的加持下变得可行。

在社交媒体广告方面，文生视频可以快速生成适合不同平台（抖音、Instagram、YouTube Shorts等）的竖屏/横屏视频内容。同一产品的广告可以通过文本修改，快速生成适合不同平台规格和调性的版本，极大提升了内容生产效率。

#### 5.3 教育内容

教育领域对可视化内容有巨大需求。许多抽象概念如果能够以动态视频形式呈现，将大大提升学习效率。

在科学教育方面，文生视频可以生成各种科学现象的可视化视频。例如，"细胞有丝分裂的完整过程"、"行星围绕太阳的椭圆轨道运动"、"光的折射和色散现象"等。这些视频能够帮助学生直观理解抽象的科学概念，比静态图片或文字描述更有效。

在历史教育方面，文生视频可以重现历史场景。"古罗马角斗场的竞技场景"、"丝绸之路上的商队行进"、"工业革命时期的蒸汽机工厂"等历史场景，通过文本描述生成视频，使学生仿佛身临其境。这种沉浸式学习体验能够显著提升学习兴趣和记忆效果。

在语言教育方面，文生视频可以根据词汇或对话场景生成对应的情景视频。例如，学习"餐厅点餐"的英语对话时，可以生成一个餐厅场景的视频，展示对话双方的互动过程。这种情景化的学习方式比纯文本或音频教材更加生动有效。

#### 5.4 社交媒体

社交媒体内容创作是文生视频最大的消费级应用场景。普通用户可以通过简单的文本描述生成有趣、有创意的短视频内容，分享到社交平台。

在个人创作方面，用户可以生成各种创意视频——"一只穿着太空服的猫在月球上行走"、"彩虹色的瀑布从云端倾泻而下"、"书本中的文字飞出页面组成一座城堡"。这些富有想象力的内容在社交媒体上往往能获得大量关注和互动。

在表情包和GIF创作方面，文生视频可以快速生成各种风格的动态表情和GIF动画。用户只需描述想要的表情和动作，就能获得个性化的动态表情包，丰富了社交媒体的表达方式。

在虚拟主播和数字人内容方面，文生视频技术可以生成虚拟角色的表演视频。虽然当前技术尚不能生成精确的口型和表情同步，但已经可以生成基本的角色动作和场景互动视频，为虚拟内容创作提供了新的工具。

以下表格总结了各应用场景的特点和成熟度：

### 六、主流文生视频模型技术规格对比

2024年至2025年，文生视频领域迎来了爆发式发展。多家科技公司发布了各自的文生视频模型，在架构设计、生成能力和技术路线上呈现出多样化的特点。以下对8个主流模型进行详细的技术规格对比。

#### 6.1 OpenAI Sora

Sora是OpenAI于2024年2月发布的文生视频模型，是引发文生视频技术浪潮的标志性产品。Sora采用了DiT（Diffusion Transformer，扩散Transformer）架构，将视频数据转化为时空patch序列，通过Transformer进行扩散去噪。

Sora的技术特点包括：使用时空patch（Spacetime Patch）作为基本单元，将视频统一为token序列；采用了流匹配（Flow Matching）替代传统的DDPM（Denoising Diffusion Probabilistic Models，去噪扩散概率模型）采样，提升了训练效率和生成质量；支持最长60秒的视频生成，分辨率最高可达1080p。

Sora的文本编码方案采用了CLIP和T5的组合，能够同时获取视觉对齐能力和细粒度语义理解。Sora在物理模拟、长视频一致性和复杂场景理解方面展现了领先的能力，但模型未开源，仅通过OpenAI的API提供服务。

#### 6.2 快手可灵Kling

可灵（Kling）是快手科技于2024年6月发布的文生视频模型，是国产文生视频模型的代表之一。可灵采用了自研的3D时空联合注意力机制，在扩散模型框架下实现了高质量的视频生成。

可灵的技术亮点包括：支持最长2分钟的视频生成，是目前公开模型中生成时长最长的之一；采用了UMT5作为文本编码器，原生支持中文输入；分辨率最高可达1080p；支持多种宽高比（16:9、9:16、1:1等）。

可灵在人物动作生成、物理运动模拟方面表现突出，特别是在中国传统文化场景（如武术、舞狮等）的生成上具有独特优势。模型通过Web平台和API提供服务，部分能力已开放给开发者使用。

#### 6.3 Runway Gen-3

Runway Gen-3 Alpha是Runway公司于2024年6月发布的文生视频模型。Runway是AI视频生成领域的先驱公司，其Gen-1和Gen-2模型在文生视频领域有重要影响力。

Gen-3采用了改进的扩散模型架构，在时空一致性方面进行了优化。Gen-3支持最长10秒的视频生成，分辨率最高可达1280×768。Gen-3的突出特点是生成质量高、运动连贯性好，在真实风格视频生成方面表现优异。

Runway还提供了丰富的视频编辑功能，包括运动笔刷（Motion Brush）、区域文字编辑、视频风格迁移等，为创作者提供了强大的视频创作工具链。

#### 6.4 阿里万相Wan2.1

万相（Wan2.1）是阿里巴巴通义万相团队于2025年2月发布的文生视频模型。万相2.1采用了DiT架构，并在开源策略上做出了重要贡献。

万相2.1的技术规格包括：支持最长15秒的视频生成；分辨率支持720p；采用UMT5文本编码器，支持中英文输入；提供了开源版本（包括1.3B和14B参数量的模型），是目前开源文生视频模型中能力最强的之一。

万相2.1在多项评测基准上达到了开源模型的最好水平，特别是在复杂场景理解和中文语义对齐方面表现优异。其开源策略极大地推动了文生视频技术的普及和研究进展。

#### 6.5 智谱CogVideoX

CogVideoX是智谱AI于2024年8月发布的文生视频模型。CogVideoX采用了3D VAE（3D Variational Autoencoder，三维变分自编码器）和专家Transformer架构，在视频压缩和生成效率方面进行了创新。

CogVideoX支持最长10秒的视频生成，分辨率支持720p。模型采用了T5文本编码器，支持中英文输入。CogVideoX的一个重要特点是提供了完整的开源版本（5B参数量），包括模型权重、推理代码和微调工具，为学术研究和商业应用提供了便利。

CogVideoX在生成效率方面表现突出，通过3D VAE的高压缩比和专家Transformer的稀疏计算，实现了较快的推理速度。在同等硬件条件下，CogVideoX的推理速度优于多数同等规模的模型。

#### 6.6 腾讯混元HunyuanVideo

HunyuanVideo是腾讯混元团队于2024年12月发布的文生视频模型。HunyuanVideo采用了"Dual-stream"（双流）Transformer架构，将视频内容和运动分别建模，提升了运动生成的合理性。

HunyuanVideo的技术特点包括：采用双流架构分别处理空间内容和时序运动；支持最长15秒的视频生成；分辨率支持720p；使用CLIP文本编码器。模型已开源（13B参数量），是目前开源模型中参数量最大的文生视频模型之一。

双流架构的设计理念是将"画什么"（内容）和"怎么动"（运动）分离建模，然后在后期融合。这种分离设计使得模型可以分别优化内容质量和运动质量，在复杂运动场景下表现优于单流架构。

#### 6.7 Pika

Pika是Pika Labs于2023年发布的文生视频模型，是最早进入市场的文生视频产品之一。Pika采用了扩散模型架构，定位于消费级创意视频生成。

Pika支持最长15秒的视频生成，分辨率支持720p。Pika的特点是操作简单、生成速度快，适合非专业用户使用。Pika还提供了丰富的创意功能，如将静态图片动画化、视频局部编辑、风格转换等。

Pika在动漫风格和创意风格视频生成方面具有优势，但在真实风格和复杂物理场景方面相对较弱。

#### 6.8 MiniMax海螺AI

MiniMax的海螺AI视频生成模型于2024年发布。MiniMax采用了自研的视频生成架构，在生成质量和效率方面进行了优化。

海螺AI支持最长6秒的视频生成，分辨率支持1080p。模型支持中英文输入，在人物表情和动作生成方面表现突出。MiniMax的模型在多项国际评测中排名靠前，特别是在真实人物生成和运动自然度方面获得较高评价。

从上述对比可以看出，当前文生视频模型呈现出以下技术趋势：

在架构选择上，DiT架构逐渐成为主流。DiT相比传统的3D U-Net具有更好的可扩展性，在参数量增大时表现出更强的性能提升。Sora和万相2.1都采用了这一架构，代表了技术发展的方向。

在视频时长上，各家模型的能力差异显著。可灵Kling以120秒领先，Sora支持60秒，多数其他模型在5-15秒之间。长视频生成能力正成为模型竞争的核心差异化指标。

在开源策略上，万相Wan2.1、CogVideoX和HunyuanVideo选择了开源路线，为学术界和中小企业提供了高质量的视频生成能力。这一策略虽然可能影响短期的商业收益，但有利于构建开发者生态和推动技术进步。

在文本编码器选择上，UMT5和T5在中文场景中更受欢迎，而CLIP在英文场景中仍然广泛使用。多语言支持正成为国产模型的重要差异化优势。

在分辨率方面，多数模型已经达到720p水平，部分模型支持1080p。4K分辨率目前尚无模型原生支持，通常需要通过后处理超分技术实现。

从应用层面来看，文生视频技术正在从实验室走向产业化。各模型在保持基础生成能力竞争的同时，开始在特定垂直领域（如影视、广告、社交媒体等）构建差异化优势。未来，随着模型能力的持续提升和生成成本的下降，文生视频有望成为内容生产的基础设施级技术。

### 七、总结与展望

文生视频作为AIGC领域的前沿方向，正处于技术快速迭代和产业化落地的关键阶段。本章从基本原理、文本编码、生成流程、技术挑战、应用场景和模型对比六个方面，对文生视频技术进行了系统性的阐述。

从技术层面来看，文生视频的核心是学习条件分布 P(video | text)，在扩散模型框架下通过条件去噪过程将随机噪声转化为语义一致的视频序列。文本编码是生成质量的基础，CLIP、T5/UMT5和LLM增强提示三种方案各有优势，实际系统中常采用组合策略。

生成流程涉及文本预处理、潜空间去噪和后处理三个阶段，每个阶段都有多种技术选择。核心的去噪阶段采用3D U-Net或DiT架构，通过交叉注意力机制将文本条件注入生成过程。潜空间压缩技术使得高质量视频生成在工程上可行。

技术挑战方面，语义对齐、运动合理性和长视频生成是三大核心难题。语义对齐需要解决复杂场景、抽象概念、空间关系和数量控制等问题。运动合理性要求模型隐式或显式地建模物理规律，包括重力、碰撞、流体动力学等。长视频生成面临误差累积、内容遗忘和计算爆炸三重挑战，分块生成、滑动窗口和层次化生成是主要的应对策略。

应用层面，文生视频在影视特效、广告创意、教育内容和社交媒体等领域展现出广阔前景。不同应用场景对生成质量、可控性和效率的需求不同，推动了技术方案的多元化发展。

模型对比方面，Sora、可灵Kling、Runway Gen-3、万相Wan2.1、CogVideoX、HunyuanVideo、Pika和海螺AI等模型在架构设计、生成能力和技术路线上各具特色。开源模型的涌现为技术普及和研究创新提供了重要推动力。

展望未来，文生视频技术可能在以下方向取得突破：更长的生成时长（分钟级甚至小时级）、更高的分辨率（原生4K）、更强的物理模拟能力、更精确的语义控制（支持细粒度属性和空间位置控制）、以及更高效的推理速度（实时生成）。随着这些技术突破的实现，文生视频有望成为数字内容生产的核心基础设施，深刻改变影视、广告、教育和社交等领域的创作方式。
