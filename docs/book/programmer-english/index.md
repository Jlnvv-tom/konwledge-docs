## 关于本书

本书面向有一定英语基础但在技术英语场景中感到吃力的程序员群体。不追求学术英语的严谨，而聚焦于**实际工作中的生存与进阶**——读得懂文档、写得出邮件、说得出方案、混得进外企。

**适合读者：**

- 想进入外企但英语不自信的程序员
- 能读代码但读不懂英文文档的开发者
- 想参与开源项目但不敢用英文交流的 contributor
- 想阅读一手技术博客但依赖翻译工具的学习者
- 任何希望提升技术英语实战能力的 IT 从业者
