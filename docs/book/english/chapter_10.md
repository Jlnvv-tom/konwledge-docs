# 第十章 听力场景专项词汇

雅思听力的核心不是"听懂每个词"，而是"在场景中抓关键信息"。四个Section分别对应不同场景：Section 1-2是生存英语（租房、旅游、咨询），Section 3-4是学术英语（课题讨论、讲座）。每个场景都有自己的高频词汇和常见考点，掌握了场景词汇就等于提前知道了答案可能出现的位置。

我是怕浪猫，系列推进到第10章了。前九章搞定了话题词汇，从本章开始进入技能专项——听力、阅读写作、口语冲刺三轮收官。

### 10.5.5 听力场景预测与预判技巧

**读题时间利用：**

- 利用录音前的读题时间，圈出关键词
- 预测答案的词性（名词/数字/形容词）
- 预测答案的内容类型（人名/地名/时间/价格）
- 注意空格前后的词，这些词在录音中可能被替换

**预判技巧：**

- 看到￡___ → 预测是价格，注意数字和单位
- 看到___% → 预测是百分比，注意数字
- 看到by___ → 预测是截止时间或方式
- 看到maximum___ → 预测是最大数量/人数
- 看到currently___ → 注意可能有变化，后面可能有转折词
- 看到originally___ → 原来的，后面一定有变化
- 看到recommended___ → 推荐的，注意区分推荐的和实际选择的

> 怕浪猫最后提醒：听力不是"听写"，是"信息提取"。你不需要听懂每一个词，但必须抓住答案所在的那句话。训练自己在听到信号词时瞬间集中注意力，这是从6分到7分的关键。
