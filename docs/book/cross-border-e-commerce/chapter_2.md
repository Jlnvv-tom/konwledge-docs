## 2.1 必懂术语词典

跨境电商行业有大量专业缩写，新手最容易在沟通中因为听不懂术语而露怯。以下按类别整理了50+个必懂术语，每个都配有全称英文解释。

## 2.2 国际贸易基础：Incoterms 2020与报关清关流程

### Incoterms 2020国际贸易术语

Incoterms（International Commercial Terms，国际贸易术语）是国际商会（ICC）制定的国际贸易标准术语，定义了买卖双方在交易中的责任、成本和风险划分。Incoterms 2020是目前最新版本，包含11种贸易术语。

跨境电商中最常用的6种术语：

| 术语 | 全称 | 交货地点 | 风险转移点 | 适用场景 |
|------|------|---------|----------|---------|
| EXW | Ex Works | 卖方工厂/仓库 | 卖方工厂交货时 | 买方负责全部运输和风险 |
| FOB | Free on Board | 装运港船上 | 货物越过船舷 | 海运B2B交易最常用 |
| CIF | Cost, Insurance and Freight | 目的港船上 | 装运港船舷（同FOB） | 卖方负责运费和保险 |
| DDP | Delivered Duty Paid | 目的地指定地点 | 目的地交货时 | 卖方承担所有费用和风险（含关税） |
| FCA | Free Carrier | 指定交货地点 | 货物交给承运人时 | 适合各种运输方式 |
| DAP | Delivered at Place | 目的地指定地点 | 目的地交货时 | 卖方负责运到目的地但不负责清关 |

> 在跨境电商B2C中，大多数平台交易实际上是DDP模式：卖家负责将商品送到消费者手中，承担所有运输和关税风险。这就是为什么物流成本核算一定要包含关税预留。

Incoterms 2020的核心原理可以用以下逻辑表达：

```python
# Incoterms责任与成本划分逻辑

def incoterms_responsibility(term, stage):
    """
    判断在特定Incoterms术语下，某一运输阶段的责任归属
    :param term: 贸易术语 (EXW/FOB/CIF/DDP/FCA/DAP)
    :param stage: 运输阶段 (export_clearance/main_transport/import_clearance/last_mile)
    :return: "seller" 或 "buyer"
    """
    responsibility_map = {
        "EXW": {"export_clearance": "buyer", "main_transport": "buyer", 
                "import_clearance": "buyer", "last_mile": "buyer"},
        "FOB": {"export_clearance": "seller", "main_transport": "buyer", 
                "import_clearance": "buyer", "last_mile": "buyer"},
        "CIF": {"export_clearance": "seller", "main_transport": "seller", 
                "import_clearance": "buyer", "last_mile": "buyer"},
        "DDP": {"export_clearance": "seller", "main_transport": "seller", 
                "import_clearance": "seller", "last_mile": "seller"},
        "FCA": {"export_clearance": "seller", "main_transport": "buyer", 
                "import_clearance": "buyer", "last_mile": "buyer"},
        "DAP": {"export_clearance": "seller", "main_transport": "seller", 
                "import_clearance": "buyer", "last_mile": "seller"},
    }
    return responsibility_map.get(term, {}).get(stage, "undefined")

# 示例：查询DDP模式下各阶段责任
for stage in ["export_clearance", "main_transport", "import_clearance", "last_mile"]:
    party = incoterms_responsibility("DDP", stage)
    print(f"DDP - {stage}: {party}")
# 输出: DDP下卖方承担所有阶段的责任
```

### 报关与清关流程

报关是指出口商向海关申报出口货物的过程，清关是指进口商向海关申报进口货物并缴纳关税的过程。

**出口报关流程**

| 步骤 | 操作内容 | 所需单证 | 时间 |
|------|---------|---------|------|
| 1. 准备单证 | 整理报关所需的所有文件 | 发票、装箱单、合同、报关委托书 | 装运前1-2天 |
| 2. 申报 | 通过电子口岸系统向海关申报 | 报关单（通过中国国际贸易单一窗口申报） | 申报后即时 |
| 3. 海关审单 | 海关审核申报内容的真实性 | - | 1-24小时 |
| 4. 查验（概率性） | 海关对货物进行实际查验 | 查验通知 | 如被查验：4-8小时 |
| 5. 放行 | 海关确认无误后放行 | 放行通知 | 审单/查验通过后即时 |

中国国际贸易单一窗口官网：https://www.singlewindow.cn，所有报关操作均通过该平台进行。

**进口清关流程**

| 步骤 | 操作内容 | 所需单证 | 时间 |
|------|---------|---------|------|
| 1. 货物到港 | 货物抵达目的港口/机场 | 到货通知 | 运输完成后 |
| 2. 换D/O | 凭提单换取提货单 | 提单（B/L）、到货通知 | 1-2天 |
| 3. 申报 | 向目的国海关申报进口 | 商业发票、装箱单、原产地证 | 1-2天 |
| 4. 缴纳关税 | 按HS Code（Harmonized System Code，海关编码）缴纳关税和增值税 | 关税缴纳单 | 申报后即时 |
| 5. 海关查验（概率性） | 目的国海关查验货物 | - | 如被查验：1-3天 |
| 6. 放行提货 | 海关放行后提货 | 放行通知 | 缴税/查验通过后即时 |

> 报关清关最大的坑是HS Code归类错误。一个错误的HS Code可能导致多缴税、被海关扣货、甚至面临走私指控。查询正确HS Code请访问：https://www.hsbianma.com 或中国海关总署官网 http://www.customs.gov.cn

## 2.3 跨境支付与结算体系

跨境电商收款是卖家最关心的问题之一。选择合适的支付和结算工具，直接影响到资金周转效率和实际利润。

### 主流跨境支付工具对比

| 工具 | 官方网站 | 支持平台 | 提现费率 | 到账周期 | 最低提现额 | 特色优势 |
|------|---------|---------|---------|---------|----------|---------|
| Payoneer | https://www.payoneer.com | Amazon、eBay、Walmart等 | 1.2% | 1-3个工作日 | $50 | 覆盖最广，支持全球接收 |
| PingPong | https://www.pingpongx.com | Amazon、Shopee、Wish等 | 1% | 1-2个工作日 | $50 | 中国本土服务，费率最低 |
| 万里汇(WorldFirst) | https://www.worldfirst.com.cn | Amazon、eBay等 | 0.3% | 1-2个工作日 | $50 | 蚂蚁集团旗下，到账快 |
| LianLian Pay | https://www.lianlianpay.com | Amazon、Shopee、eBay等 | 0.7% | 1-2个工作日 | $50 | 支持多币种接收 |
| Airwallex | https://www.airwallex.com | 独立站、Amazon等 | 0.5-1% | 1-3个工作日 | $10 | 全球账户，支持多币种 |
| PayPal | https://www.paypal.com/business | 独立站、eBay | 4.4%+$0.3 | 即时 | $1 | 全球通用，消费者支付端 |
| Stripe | https://stripe.com | 独立站 | 2.9%+$0.3 | 2-7个工作日 | $1 | 独立站信用卡收款首选 |

> 支付工具的选择不是"选一个最好的"，而是"选一个最匹配你业务模式的"。做平台B2C选PingPong或万里汇省手续费，做独立站选Stripe覆盖信用卡支付，做高客单价产品加一个Klarna提高转化率。

### 跨境收款的资金流路径

```
消费者支付 → 平台收款 → 平台打款至卖家收款账户 → 提现至国内银行账户 → 结汇为人民币

以亚马逊美国站为例：
消费者信用卡支付 → Amazon Payment → 14天周期打款至Payoneer/PingPong账户 
→ 提现至国内银行 → 结汇人民币到账

以独立站为例：
消费者信用卡支付 → Stripe/PayPal → T+2到账 → 提现至国内银行/万里汇账户 → 结汇人民币
```

### 收款费率对利润的影响

很多新手卖家低估了支付费率对利润的侵蚀。以下是一个实际计算示例：

```python
def calculate_payment_cost(monthly_sales, payment_tool, platform_fee):
    """
    计算不同支付工具的实际成本
    :param monthly_sales: 月销售额（美元）
    :param payment_tool: 支付工具费率
    :param platform_fee: 平台佣金费率
    :return: 实际到手金额
    """
    platform_commission = monthly_sales * platform_fee
    payment_fee = monthly_sales * payment_tool
    actual_receipt = monthly_sales - platform_commission - payment_fee
    total_cost_rate = (platform_commission + payment_fee) / monthly_sales * 100
    
    return {
        "月销售额": f"${monthly_sales:,.2f}",
        "平台佣金": f"${platform_commission:,.2f}",
        "支付费率": f"{payment_tool*100}%",
        "支付费用": f"${payment_fee:,.2f}",
        "实际到手": f"${actual_receipt:,.2f}",
        "总扣费率": f"{total_cost_rate:.1f}%"
    }

# 示例：月销售$10000，亚马逊佣金15%
print("=== PingPong (1%) ===")
print(calculate_payment_cost(10000, 0.01, 0.15))

print("\n=== Payoneer (1.2%) ===")
print(calculate_payment_cost(10000, 0.012, 0.15))

print("\n=== PayPal (4.4%+$0.3, 独立站) ===")
paypal_fee = 10000 * 0.044 + 0.3
print(f"PayPal费用: ${paypal_fee:.2f}")
print(f"实际到手: ${10000 - paypal_fee:.2f}")
```

以月销售额10000美元为例，不同支付工具的费用差异：

| 支付工具 | 费率 | 支付费用 | 实际到手 | 年度差异 |
|---------|------|---------|---------|---------|
| PingPong | 1% | $100 | $9900 | 基准 |
| Payoneer | 1.2% | $120 | $9880 | -$240/年 |
| 万里汇 | 0.3% | $30 | $9970 | +$840/年 |
| PayPal | 4.4%+$0.3 | $440.30 | $9559.70 | -$4843.60/年 |

> 同样卖10000美元，用PayPal比用万里汇一年少赚近5000美元。支付工具的选择不是小事，它直接吃掉你的净利润。

## 2.4 国际物流方式全览

物流是跨境电商最大的成本项之一，也是影响消费者体验的关键因素。选择合适的物流方式，需要平衡时效、成本和可靠性。

### 主要物流方式对比

| 物流方式 | 代表服务商 | 时效（天） | 成本（500g） | 重量限制 | 追踪能力 | 适用场景 |
|---------|---------|----------|------------|---------|---------|---------|
| 邮政小包 | ePacket、中国邮政小包 | 15-30 | $3-6 | 2kg | 基础 | 低价值小件商品 |
| EMS | 各国邮政EMS | 7-15 | $8-15 | 30kg | 良好 | 中等价值商品 |
| 国际快递 | DHL、FedEx、UPS | 3-7 | $15-35 | 无限制 | 优秀 | 高价值/紧急商品 |
| 专线物流 | 燕文、云途、递四方 | 7-15 | $5-12 | 2-30kg | 良好 | 性价比最优选择 |
| 海外仓 | 纵腾、谷仓、万邑通 | 1-3（当地配送） | 仓储费+$3-8 | 无限制 | 优秀 | 稳定销量的大件商品 |
| FBA | 亚马逊AGL | 1-2（Prime配送） | 头程+仓储+$3-8 | 无限制 | 优秀 | 亚马逊卖家首选 |

### 各物流方式详解

**邮政包裹（ePacket）**

ePacket（e邮宝）是中国邮政为跨境电商推出的经济型物流产品，曾是速卖通和Wish卖家的主力物流方式。ePacket的优势是价格低廉、覆盖面广，但时效不稳定，旺季可能超过30天。

中国邮政官网：http://www.ems.com.cn

ePacket的核心限制是重量不超过2kg，且部分国家已停止ePacket服务（如美国在2020年退出万国邮政联盟协议后费率上涨）。

**国际快递（DHL/FedEx/UPS）**

三大国际快递公司提供全球覆盖的快速配送服务。

| 快递公司 | 官方网站 | 优势区域 | 时效 | 特点 |
|---------|---------|---------|------|------|
| DHL | https://www.dhl.com | 欧洲、中东 | 3-5天 | 欧洲清关能力强 |
| FedEx | https://www.fedex.com | 北美、东南亚 | 3-7天 | 北美网络最密 |
| UPS | https://www.ups.com | 北美、欧洲 | 3-7天 | 大件包裹性价比高 |

国际快递适合高客单价商品（$100以上）或样品寄送，对于普通B2C订单来说成本过高。

**专线物流**

专线物流是介于邮政小包和国际快递之间的性价比选择，通过集中发货到目的国后再进行本地配送。

| 服务商 | 官方网站 | 优势航线 | 时效 | 特点 |
|--------|---------|---------|------|------|
| 燕文物流 | https://www.yw56.com | 欧洲、北美 | 7-15天 | 亚马逊认可物流商 |
| 云途物流 | https://www.yunexpress.cn | 全球 | 7-12天 | 速卖通推荐物流 |
| 递四方(4PX) | https://www.4px.com | 全球 | 7-15天 | 阿里巴巴投资 |
| 纵腾集团 | https://www.zongteng.cn | 欧美 | 5-12天 | 海外仓+专线组合 |

> 专线物流是目前自发货卖家的最优选择。它比邮政小包快且可追踪，比国际快递便宜50%以上。选专线物流时一定要确认它是平台认可的物流商，否则可能影响物流时效考核指标。

**海外仓**

海外仓是指将货物提前存储在目的国的仓库中，消费者下单后从当地仓库发货。这种方式可以实现1-3天的本地配送时效，大幅提升消费者体验。

| 海外仓服务商 | 官方网站 | 覆盖国家 | 服务类型 | 适合卖家 |
|------------|---------|---------|---------|---------|
| 纵腾谷仓 | https://www.goodcang.com | 美国、英国、德国等20+ | 一件代发、FBA中转 | 多平台卖家 |
| 万邑通 | https://www.winit.com | 美国、英国、德国等 | 一件代发、退件处理 | eBay、Amazon卖家 |
| 递四方 | https://www.4px.com | 全球30+国家 | 一件代发、FBA中转 | 多平台卖家 |

海外仓的核心决策点是库存周转。如果货物在海外仓滞销，仓储费用会快速侵蚀利润。海外仓适合月销量稳定在300单以上的产品。

**FBA（Fulfillment by Amazon）**

FBA是亚马逊提供的全托管物流服务。卖家将货物发到亚马逊仓库，亚马逊负责存储、拣货、包装、配送、客服和退货处理。

FBA官网：https://sellercentral.amazon.com/fulfillment-by-amazon

FBA的核心费用结构：

| 费用类型 | 计算方式 | 示例（标准件） | 示例（大件） |
|---------|---------|-------------|------------|
| 配送费 | 按重量和尺寸 | $3.06（1lb以下） | $8.26（3lb） |
| 仓储费（1-9月） | 按体积（立方英尺/月） | $0.87/立方英尺 | $0.56/立方英尺 |
| 仓储费（10-12月） | 旺季费率 | $2.40/立方英尺 | $2.40/立方英尺 |
| 长期仓储费 | 超过271天的库存 | $6.90/立方英尺或$0.15/件 | 同左 |
| 入库处理费 | 按件数 | $0.30-0.40/件 | $0.30-0.40/件 |
| 退货处理费 | 按重量和尺寸 | 配送费的50% | 配送费的50% |

FBA费用计算逻辑：

```python
def calculate_fba_cost(weight_lb, length_in, width_in, height_in, 
                       monthly_units, avg_storage_days, month):
    """
    计算FBA单件产品的综合物流成本
    :param weight_lb: 重量（磅）
    :param length_in/width_in/height_in: 尺寸（英寸）
    :param monthly_units: 月销量
    :param avg_storage_days: 平均存储天数
    :param month: 月份（用于判断旺季费率）
    :return: 单件FBA总成本
    """
    # 1. 体积计算（立方英尺）
    volume_cuft = (length_in * width_in * height_in) / 1728
    
    # 2. 判断尺寸层级
    if weight_lb <= 1 and volume_cuft <= 0.3:
        tier = "standard_small"
        fulfillment_fee = 2.67
    elif weight_lb <= 2 and volume_cuft <= 1.0:
        tier = "standard_large"
        fulfillment_fee = 3.06 if weight_lb <= 1 else 3.47
    else:
        tier = "oversize"
        fulfillment_fee = 8.26 + (weight_lb - 3) * 0.38
    
    # 3. 仓储费
    if month in [10, 11, 12]:
        storage_rate = 2.40  # 旺季
    else:
        storage_rate = 0.87 if tier != "oversize" else 0.56
    
    storage_fee = (volume_cuft * storage_rate * avg_storage_days) / 30
    
    # 4. 总FBA成本
    total_fba_cost = fulfillment_fee + storage_fee + 0.35  # 含入库处理费
    
    return {
        "尺寸层级": tier,
        "配送费": f"${fulfillment_fee:.2f}",
        "仓储费": f"${storage_fee:.2f}",
        "入库处理费": "$0.35",
        "单件FBA总成本": f"${total_fba_cost:.2f}",
        "占售价比（$20产品）": f"{total_fba_cost/20*100:.1f}%"
    }

# 示例：手机壳，0.3lb，6x4x1英寸，月销500件，平均存储15天
result = calculate_fba_cost(0.3, 6, 4, 1, 500, 15, 6)
print(result)
# 输出: 单件FBA总成本约$3.02，占$20售价的15.1%
```

## 2.5 关税与VAT基础知识

关税和增值税是跨境电商不可回避的税务问题。不同国家和地区的税收政策差异很大，不合规可能导致货物被扣押、店铺被关闭、甚至面临法律诉讼。

### 欧洲VAT（Value Added Tax，增值税）

VAT是欧盟国家对商品和服务征收的增值税。跨境电商卖家在欧洲销售商品，需要在有库存的国家注册VAT税号并定期申报。

**VAT注册门槛**

| 国家 | 远程销售阈值（年） | 注册要求 | VAT税率 |
|------|-----------------|---------|---------|
| 德国 | 无阈值（有库存即注册） | 有库存就必须注册 | 19% |
| 法国 | 10000欧元 | 超过阈值需注册 | 20% |
| 意大利 | 10000欧元 | 超过阈值需注册 | 22% |
| 西班牙 | 10000欧元 | 超过阈值需注册 | 21% |
| 英国 | 85000英镑 | 超过阈值需注册 | 20% |
| 荷兰 | 10000欧元 | 超过阈值需注册 | 21% |

> 欧洲VAT的核心原则是"库存在哪里，就在哪里注册"。如果你使用了德国的FBA仓库，就必须注册德国VAT税号，无论你的销售额是多少。

**VAT计算逻辑**

```python
def calculate_vat(product_price, vat_rate, shipping_cost=0):
    """
    计算欧洲VAT增值税
    :param product_price: 产品售价（含税）
    :param vat_rate: VAT税率
    :param shipping_cost: 运费
    :return: VAT明细
    """
    total_price = product_price + shipping_cost
    # 不含税金额
    net_amount = total_price / (1 + vat_rate)
    # VAT金额
    vat_amount = total_price - net_amount
    
    return {
        "含税售价": f"€{total_price:.2f}",
        "不含税金额": f"€{net_amount:.2f}",
        "VAT税率": f"{vat_rate*100}%",
        "VAT金额": f"€{vat_amount:.2f}",
        "卖家实收": f"€{net_amount:.2f}"
    }

# 示例：售价€25的手机壳，德国VAT 19%
print(calculate_vat(25, 0.19))
# 输出: 不含税金额€20.42，VAT€4.58
```

### 美国销售税

美国没有联邦层面的VAT，而是由各州征收销售税。销售税的核心概念是Nexus（关联），即卖家在某个州有足够的商业活动存在，就需要在该州收取销售税。

**Nexus的类型**

| Nexus类型 | 触发条件 | 是否需要收税 | 示例 |
|-----------|---------|------------|------|
| 物理Nexus | 在该州有实体存在 | 是 | 仓库、办公室、员工 |
| 经济Nexus | 在该州销售额超过阈值 | 是 | 各州阈值不同（通常$100,000或200笔交易） |
| 库存Nexus | 在该州有库存 | 是 | FBA仓库所在州 |
| 平台代征 | 平台代为收取和缴纳 | 平台负责 | Amazon、eBay等已代征 |

美国各州经济Nexus阈值：

| 州 | 销售额阈值 | 交易笔数阈值 | 销售税率 |
|---|---------|------------|---------|
| 加利福尼亚 | $500,000 | 无 | 7.25% |
| 纽约 | $500,000 | 100笔 | 4.0% |
| 得克萨斯 | $500,000 | 无 | 6.25% |
| 佛罗里达 | $100,000 | 无 | 6.0% |
| 华盛顿 | $100,000 | 无 | 6.5% |

> 美国销售税好消息是亚马逊等主流平台已经代为收取和缴纳销售税（Marketplace Facilitator Tax），大多数FBA卖家不需要自己处理销售税。但如果你做独立站，就需要关注各州的经济Nexus阈值。

### 英国脱欧后的税务变化

英国脱欧后，对跨境电商产生了以下关键影响：

| 变化项 | 脱欧前 | 脱欧后 | 对卖家的影响 |
|--------|--------|--------|------------|
| 英国VAT注册 | 欧盟VAT体系下 | 独立体系 | 需单独注册英国VAT |
| 北爱尔兰 | 属于英国 | 遵循欧盟规则 | 北爱仓库需欧盟VAT |
| 欧盟远程销售 | 含英国 | 不含英国 | 英国和欧盟需分别申报 |
| 低值豁免 | 22欧元以下免税 | 取消 | 所有进口商品均需缴VAT |
| EORI号 | 英国EORI可用于欧盟 | 需分别申请 | 需英国EORI和欧盟EORI |

EORI（Economic Operators Registration and Identification，经济运营者注册和识别号）是海关进出口时需要的编号。英国EORI申请：https://www.gov.uk/eori，欧盟EORI申请需在首站入境国的海关网站申请。
