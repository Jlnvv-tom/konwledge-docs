# 第4章 第二步：角色与场景设定

上一秒女主是黑色长发，下一秒变成了棕色短发。上一集她穿米色风衣，这一集变成了红色外套。这不是剧情需要，是你的角色"漂移"了。

我是怕浪猫，上期讲了剧本与分镜，这期进入流水线第二步：角色与场景设定。这一步解决的是 AI 漫剧最让人头疼的问题，角色一致性（Character Consistency）。

> 角色一致性不是"优化项"，是"及格线"。角色每漂移一次，观众的沉浸感就碎一次。

## 4.1 一致性问题的本质：为什么角色会"漂移"

要解决角色漂移问题，首先得理解它为什么发生。

当前主流的文生图模型，如 Stable Diffusion（SD）、Midjourney 等，底层都是扩散模型（Diffusion Model）。扩散模型的工作原理分为两个阶段：前向扩散和反向扩散。前向扩散阶段，模型逐步向训练图像中添加高斯噪声（Gaussian Noise），直到图像变成纯噪声。反向扩散阶段，模型学习如何从纯噪声中逐步去噪，还原出图像。

当你输入一段提示词让模型生成图片时，模型从随机噪声开始，根据你的提示词引导去噪方向，最终生成一张图片。关键问题在于：这个去噪过程是随机的。每次生成时，初始的随机噪声不同（由种子 Seed 控制），去噪路径也不同，最终生成的图片自然不同。

这就像让 100 个画师根据同一段文字描述画人像。每个画师的理解不同、风格不同、习惯不同，画出来的 100 张画虽然都符合描述，但看起来是 100 个不同的人。

| 漂移类型 | 表现 | 严重程度 | 发生频率 |
|---------|------|---------|---------|
| 发型漂移 | 长发变短发、直发变卷发 | 高 | 极高 |
| 服装漂移 | 颜色变化、款式变化 | 高 | 高 |
| 五官漂移 | 眼睛大小变化、脸型变化 | 中高 | 高 |
| 体型漂移 | 高矮胖瘦变化 | 中 | 中 |
| 风格漂移 | 画风不一致 | 高 | 中 |

角色漂移不是某个工具的 bug，而是扩散模型原理层面的问题。理解了这一点，你就明白为什么不能靠"把提示词写得更详细"来解决。即使你在提示词里写"黑色长发、米色风衣、大眼睛、瓜子脸"，模型每次生成的"黑色长发、米色风衣、大眼睛、瓜子脸"的人依然长得不一样。

> 提示词能约束"属性"，但约束不了"同一性"。告诉模型"画一个黑长发女生"是一回事，让模型每次画"同一个"黑长发女生是另一回事。

## 4.2 角色三视图定妆：正/侧/背 与固定要素

三视图（Three-view Drawing）是角色设定的基础。它指角色的正面（Front View）、侧面（Side View）和背面（Back View）三个角度的定妆图。三视图的作用是给后续所有分镜生图提供"参考标准"。

### 三视图的作用

为什么需要三个角度？因为在不同的镜头里，角色可能面朝镜头（正面），也可能侧身说话（侧面），也可能背对镜头走开（背面）。如果你只有正面参考图，生成分镜图时，侧面和背面的角度就没有参考，模型只能"猜"，猜得不对就是漂移。

| 视图角度 | 用途 | 在分镜中的应用场景 |
|---------|------|------------------|
| 正面（Front View） | 锁定五官、发型正面形态 | 角色面朝镜头的对话、特写 |
| 侧面（Side View） | 锁定侧脸轮廓、发型侧面形态 | 角色侧身说话、行走侧面镜头 |
| 背面（Back View） | 锁定发型背面、服装背面细节 | 角色背对镜头走开、转身镜头 |

### 三大固定要素

三视图定妆的核心是"固定三大要素"：发型、服装、五官。这三个要素是角色的"身份标识"，在全剧所有镜头中必须保持一致。

**发型**是最容易漂移的要素。同样是"黑色长发"，模型可能生成直发、微卷、波浪卷，发尾可能齐肩、及腰、过腰。你需要在角色卡里精确定义：颜色（黑色）、长度（及腰）、形态（直发）、刘海（中分微卷刘海）、发饰（无）。越具体，漂移概率越低。

**服装**是第二容易漂移的要素。同样是"米色风衣"，模型可能生成不同长度、不同版型、不同纽扣数量。你需要定义：颜色（米色）、款式（中长款双排扣风衣）、长度（到膝盖上方）、细节（腰带系紧、翻领）。

**五官**是第三容易漂移的要素，也是最难固定的。同样是"大眼睛、瓜子脸"，模型每次生成的眼睛大小和脸型轮廓都有微妙差异。五官的固定通常需要借助参考图或 LoRA 来实现，纯文字描述的效果有限。

### 三视图提示词模板

以下是三视图生成的提示词模板，你可以直接使用。

```

【正面视图】
{角色名称}正面半身像，{发型描述}，{服装描述}，{五官描述}，{表情描述}，白色背景，角色设定图风格，全身可见

【侧面视图】
{角色名称}侧面半身像，{发型侧面描述}，{服装侧面描述}，侧脸轮廓清晰，白色背景

【背面视图】
{角色名称}背面半身像，{发型背面描述}，{服装背面描述}，白色背景

【通用画风词】
{画风词}，high quality，character design sheet，reference sheet，clean lines，detailed
```

使用这个模板时，把大括号里的变量替换成具体内容。比如：

```

【正面视图】
女主林晚正面全身像，黑色直发及腰，中分微卷刘海，米色中长款双排扣风衣，腰带系紧，翻领，内搭白色衬衫，大眼睛，瓜子脸，薄唇，表情平静，白色背景，角色设定图风格

【侧面视图】
女主林晚侧面全身像，黑色直发及腰侧面可见，米色风衣侧面轮廓清晰，侧脸轮廓锐利，鼻梁挺直，白色背景

【背面视图】
女主林晚背面全身像，黑色直发及腰背面可见，米色风衣背面，可见风衣背面的腰带蝴蝶结，白色背景

【通用画风词】
Japanese anime style，high quality，character design sheet，reference sheet，clean lines，detailed
```

> 三视图是角色的"身份证"。没有身份证的角色，每次出场都是个陌生人。

## 4.3 锁定一致性的三种手段：文字角色卡、参考图、LoRA

三视图定义了角色"长什么样"，但怎么确保每次生图时模型都能画出同一个人？有三种手段，按一致性强度从低到高排列。

### 手段一：文字角色卡（一致性 ★★☆）

文字角色卡是最基础的固定手段。它把角色的所有视觉属性用文字精确描述，作为提示词的前缀固定附加到每次生图请求中。

角色卡的核心字段包括：姓名、性别、年龄、发型（颜色+长度+形态+刘海）、服装（颜色+款式+长度+细节）、五官（脸型+眼睛+鼻子+嘴+眉毛）、体型（身高+胖瘦）、肤色。

```
【角色卡模板】
姓名：林晚
性别：女
年龄：22岁
发型：黑色直发，及腰长度，中分微卷刘海
服装：米色中长款双排扣风衣，腰带系紧，翻领，内搭白色衬衫
五官：瓜子脸，大眼睛（杏仁形），双眼皮，细眉，鼻梁挺直，薄唇
体型：165cm，纤细
肤色：白皙
```

文字角色卡的优点是简单易用，零成本。缺点是固定力有限，因为扩散模型的随机性导致即使提示词完全相同，生成的图像也会有差异。文字角色卡适合新手阶段使用，或者对一致性要求不高的场景。

### 手段二：参考图垫图（一致性 ★★★☆）

参考图（Image Reference / Image Prompt）是比文字角色卡更强的固定手段。它的原理是在生图时，不仅提供文字提示词，还提供一张参考图，让模型以参考图为视觉锚点来生成新图。

不同的工具实现参考图功能的方式不同。即梦 AI 支持"参考图"功能，你可以上传角色的三视图作为参考，生成的图片会尽量保持角色一致。Midjourney 支持"垫图"（Image Prompt），在提示词中加入参考图的 URL。Stable Diffusion 可以使用 ControlNet 的 Reference 模式，用参考图约束生成结果。

| 工具 | 参考图功能 | 操作方式 | 效果 |
|------|-----------|---------|------|
| 即梦 AI | 参考图 | 上传三视图，选择"参考角色" | 中等偏上 |
| Midjourney | 垫图 | 在提示词中加入图片 URL | 中等 |
| SD + ControlNet | Reference 模式 | 加载参考图，设置权重 | 较强 |
| SD + IP-Adapter | IP-Adapter | 加载参考图，调节权重 | 强 |

参考图的优点是比纯文字描述固定力强很多，能大幅降低发型和服装的漂移。缺点是五官的一致性仍然不够稳定，特别是侧面和背面角度。参考图适合中级创作者使用。

### 手段三：LoRA 模型训练（一致性 ★★★★★）

LoRA（Low-Rank Adaptation，低秩适配）是目前固定角色一致性最强的手段。LoRA 是一种轻量级的模型微调技术，它不修改原始模型，而是在模型上叠加一个小的"适配层"，通过训练让模型"记住"特定角色的外观。

训练 LoRA 的基本流程是：准备角色的训练图（20-50 张不同角度、不同表情的图）→ 使用训练工具（如 Kohya、LoRA 训练脚本）进行训练 → 得到 LoRA 权重文件 → 在生图时加载 LoRA 权重，模型就会按训练的角色外观来生成。

| 对比维度 | 文字角色卡 | 参考图垫图 | LoRA 模型 |
|---------|-----------|-----------|----------|
| 一致性强度 | ★★☆ | ★★★☆ | ★★★★★ |
| 学习成本 | 低 | 中 | 高 |
| 使用成本 | 低（每次复制提示词） | 中（每次上传参考图） | 低（加载权重文件） |
| 五官固定力 | 弱 | 中 | 强 |
| 发型服装固定力 | 中 | 强 | 极强 |
| 适用人群 | 新手 | 中级创作者 | 进阶创作者 |
| 需要的素材 | 无 | 三视图 | 20-50张训练图 |
| 硬件要求 | 无 | 无 | 需要独立显卡或云端 GPU |

> 如果说文字角色卡是"口头描述嫌疑人特征"，参考图是"给警察看照片"，那 LoRA 就是"给警察一个 3D 扫描模型"。精度完全不同。

LoRA 的训练门槛近年来在降低。Stable Diffusion 生态中有大量教程和工具，如 LiblibAI、吐司（Tusi）等平台提供在线 LoRA 训练服务，不需要本地显卡也能训练。如果你打算长期做一个系列漫剧，投入时间训练 LoRA 是值得的。

### 三种手段的组合策略

实际操作中，三种手段不是互斥的，而是可以叠加使用的。推荐的组合策略如下。

| 阶段 | 推荐组合 | 理由 |
|------|---------|------|
| 新手期（前 3 集） | 文字角色卡 + 参考图 | 快速跑通流程，不需要训练 LoRA |
| 成长期（4-10 集） | 文字角色卡 + 参考图 + LoRA | 角色确定后训练 LoRA，提升一致性 |
| 稳定期（10 集以上） | LoRA + 参考图 + 角色卡 | 三重保险，最大化一致性 |

## 4.4 场景设定与画风统一

角色设定解决了"人"的一致性，场景设定解决"环境"的一致性，画风统一解决"视觉风格"的一致性。三者合在一起，才能让全剧看起来是"同一部作品"。

### 场景设定图

场景设定图（Scene Setting Image）是主要场景的视觉参考。和角色三视图类似，场景设定图的作用是给分镜生图提供场景参考。

一个 AI 漫剧通常有 3-5 个主要场景。比如一部都市悬疑漫剧，主要场景可能包括：女主的公寓、咖啡厅、公司办公室、雨夜街道。每个场景都需要一张设定图，定义场景的整体布局、光线氛围和关键道具。

场景设定图的生成方式很简单：用文生图工具，写一段场景描述，生成一张全景图。这张图后续作为分镜生图的场景参考。

| 场景 | 提示词要点 | 用途 |
|------|-----------|------|
| 女主公寓 | 现代简约风，落地窗，暖色调灯光，书架和沙发 | 室内对话场景的参考 |
| 咖啡厅 | 日式咖啡厅，木质装修，暖黄灯光，窗边座位 | 约会/等待场景的参考 |
| 公司办公室 | 现代办公室，玻璃隔断，冷色调灯光，办公桌 | 职场场景的参考 |
| 雨夜街道 | 霓虹灯，湿漉漉的路面，雨滴，夜景 | 关键冲突场景的参考 |

### 画风统一策略

画风统一是角色和场景之外的第三个一致性问题。即使角色和场景都对，如果画风不统一，画面看起来就像不同作品拼凑的。

画风统一的关键策略是"固定画风词"。在你的角色卡和分镜提示词中，始终附加同一段画风词。画风词定义了整体视觉风格，包括绘画风格、色调、光影质感等。

常见的画风词组合示例。

| 画风类型 | 画风词组合 | 适用题材 |
|---------|-----------|---------|
| 日系动漫风 | Japanese anime style, cel shading, vibrant colors, clean lines | 甜宠、校园 |
| 韩国网漫风 | Korean webtoon style, soft shading, pastel colors | 都市情感 |
| 水彩插画风 | watercolor illustration, soft edges, warm tones | 治愈、文艺 |
| 暗黑漫画风 | dark comic style, high contrast, dramatic shadows | 悬疑、复仇 |
| 赛博朋克风 | cyberpunk style, neon colors, futuristic, dark atmosphere | 科幻、未来 |

> 画风词就像滤镜。同一个场景、同一个角色，加上不同的画风词，出来的就是不同的世界。

画风词的使用有一个重要原则：一旦确定，全剧不改。如果你第一集用了"Japanese anime style"，第二集改成了"Korean webtoon style"，即使角色外观一致，画风的突变也会让观众感到不适。

如果你确实需要在中途切换画风（比如第一季用日系风，第二季改韩系风），建议在两季之间做一个明确的视觉过渡，而不是突然切换。

## 4.5 角色资产库管理：跨集复用的基础设施

角色设定图、场景设定图、角色卡、画风词，这些素材合在一起构成了你的"角色资产库"。资产库是跨集复用的基础设施，它的质量和组织方式直接决定了你的生产效率。

### 资产库的维护原则

资产库不是建好就不管了，它需要持续维护。以下是几个维护原则。

**及时更新**。角色如果在中途换装（比如第 5 集女主换了造型），需要新增一套三视图和角色卡，而不是覆盖原来的。旧造型保留，因为后面可能还有回忆镜头需要用到。

**版本管理**。LoRA 权重文件建议带版本号（如 v1、v2），当你用更多训练图重新训练后，新版本替代旧版本，但旧版本保留备份。有时候新版本在某些角度反而不如旧版本，需要回退。

**命名规范**。所有资产文件按"角色名_内容_版本"的格式命名，如"林晚_三视图_正面_v1.png"。不要用"最终版""真的最终版"这种命名。

| 维护场景 | 操作 | 注意事项 |
|---------|------|---------|
| 角色换装 | 新增一套三视图和角色卡 | 不覆盖旧造型，标注集号 |
| LoRA 重训 | 新版本文件带新版本号 | 旧版本保留备份 |
| 新增角色 | 先做角色卡和三视图 | 确保与现有画风一致 |
| 新增场景 | 生成场景设定图 | 使用统一画风词 |
| 画风词调整 | 更新画风词库文件 | 全剧同步更新 |

> 资产库就是你的"演员经纪公司"。管理得好，演员随叫随到；管理不好，每次都要重新海选。

### 场景设定的进阶技巧

除了基本的场景设定图之外，还有一些进阶技巧能提升场景的利用效率和一致性。

**多角度场景图**。一个场景不只有全景，还可能有中景和特写。比如咖啡厅场景，你可以生成三张图：全景（整个咖啡厅的布局）、中景（吧台区域的细节）、特写（窗边座位的桌面细节）。这样在分镜生图时，不同景别的镜头都有对应的场景参考。

**不同时段的场景变体**。同一个场景在不同时间段的光线氛围完全不同。雨夜街道在白天和夜晚是两种完全不同的感觉。如果你的剧情涉及同一场景的多个时段，建议为每个时段生成一张设定图，并在文件名中标注时段（如"场景04_雨夜街道_白天.png"和"场景04_雨夜街道_夜晚.png"）。

**场景与角色的适配测试**。在正式开始分镜生图之前，建议先做一轮"场景+角色"的适配测试。把角色卡和场景设定图组合，生成 2-3 张测试图，检查角色在场景中的融合度。如果发现角色的光线和场景的光线不匹配（比如角色是暖色调但场景是冷色调），需要调整提示词或后期处理。

| 适配问题 | 表现 | 解法 |
|---------|------|------|
| 光线不匹配 | 角色偏暖，场景偏冷 | 在提示词中加入统一光线描述 |
| 透视不匹配 | 角色是平视角度，场景是俯视角度 | 统一视角描述 |
| 比例不匹配 | 角色过大或过小 | 在提示词中注明角色与场景的空间关系 |
| 色调不匹配 | 角色饱和度高，场景饱和度低 | 统一色调关键词 |
