## 术语解释示例（首次出现必须全称英文+中文）
- 扩散模型：Diffusion Model，通过逐步去噪生成图像的生成式模型
- 三视图：Three-view Drawing，角色正面、侧面、背面三个角度的定妆图
- LoRA：Low-Rank Adaptation，低秩适配，用于训练固定角色/画风的轻量模型
- 垫图：Image Reference / Image Prompt，以参考图约束生成结果的技术
- 局部重绘：Inpainting，对图像局部区域重新生成的技术
