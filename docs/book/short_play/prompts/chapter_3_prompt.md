# 第3章写作 Prompt

## 任务
以 IP「怕浪猫」的名义，写一篇关于《第一步：剧本与分镜》的系列文章（第 3 章，共 10 章）。文章性质为知识库书籍型技术教程，风格参考掘金/技术博客，严谨务实，第一人称可用"我"和"怕浪猫"交替，禁止用"小编"。

## 写作规范（每章通用，必须严格遵守）
1. 目标字数：10000-12000 字（中文正文）
2. 全文不使用任何 emoji 或图标符号，标题与正文均不出现图标
3. 每个段落尽量短小，不超过 4-5 行
4. 专有缩写名词首次出现时必须给出全称英文 + 中文解释
5. 核心原理尽量用图表呈现：表格、mermaid 流程图、结构化列表均可
6. 不需要程序示例代码；但核心关键"模板/结构"（如结构化脚本 JSON 模板、大模型提示词模板）要完整展示
7. 段落之间不使用 --- 或 ——— 分隔线，用自然过渡衔接
8. 每章 5 个小节，结构完整

## 本章目录
- 3.1 为什么剧本是流水线的源头
- 3.2 结构化脚本：镜头+画面描述+台词+情绪 四要素
- 3.3 三条铁律：单集时长、开头钩子、结尾悬念
- 3.4 用大模型生成分镜：提示词方法与工作流
- 3.5 分镜脚本模板与一集完整示例

## 内容要求
- 3.1 说明剧本质量如何决定后续 5 步的成败，用流程图展示"剧本 → 分镜 → 生图 → 视频"的传递关系
- 3.2 详细解释四要素（镜头 Shot、画面描述 Visual Description、台词 Dialogue、情绪 Emotion）各自的作用，用完整 JSON 模板展示结构化脚本格式，逐字段说明
- 3.3 三条铁律逐条展开：
  - 单集 1-1.5 分钟（60-90 秒）的完播率逻辑
  - 开头 10 秒必须有冲突钩子（Conflict Hook），给出钩子设计方法
  - 结尾必须留悬念（Cliffhanger），给出悬念类型清单
- 3.4 给出可直接套用的大模型提示词模板（完整展示），说明如何约束模型输出固定结构、如何一次生成整集分镜，附大模型选择建议
- 3.5 提供一集完整的分镜脚本示例（8-10 个镜头），每个镜头包含四要素，用表格呈现

## 互动/收藏/涨粉模块（必须全部包含）
1. 开头 3 秒钩子：数字冲击型/反常识型/痛点共鸣型选 1
2. 钩子后紧跟 IP 自我介绍："我是怕浪猫，……"
3. 至少 2-3 个截图级金句（> 引用块）
4. 至少 1 个清单型/模板型/步骤型高收藏结构（本章强烈建议"模板型：结构化脚本 JSON 模板 + 提示词模板"）
5. 每个小节结尾可设互动提问
6. 结尾 3 层 CTA：收藏引导 + 互动引导 + 追更引导（关注怕浪猫）
7. 下章预告（一段话）
8. 系列进度条："系列进度 3/10，下篇：第4章 第二步：角色与场景设定"

## 术语解释示例（首次出现必须全称英文+中文）
- 分镜：Storyboard，将剧本拆分为一个个镜头的画面描述
- 镜头：Shot，一次连续拍摄/生成的最小画面单元
- 钩子：Hook，开头抓住观众注意力的冲突或悬念设计
- 完播率：Completion Rate，完整看完视频的用户占比
- JSON：JavaScript Object Notation，一种轻量级结构化数据格式
