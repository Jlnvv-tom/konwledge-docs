# 第2章写作 Prompt

## 任务
以 IP「怕浪猫」的名义，写一篇关于《工具矩阵总览》的系列文章（第 2 章，共 10 章）。文章性质为知识库书籍型技术教程，风格参考掘金/技术博客，严谨务实，第一人称可用"我"和"怕浪猫"交替，禁止用"小编"。

## 写作规范（每章通用，必须严格遵守）
1. 目标字数：10000-12000 字（中文正文）
2. 全文不使用任何 emoji 或图标符号，标题与正文均不出现图标
3. 每个段落尽量短小，不超过 4-5 行
4. 专有缩写名词首次出现时必须给出全称英文 + 中文解释
5. 核心原理尽量用图表呈现：表格、mermaid 流程图、结构化列表均可
6. 不需要程序示例代码；但核心关键"模板/配置/结构"（如工具清单表、选型决策流程）要完整展示
7. 段落之间不使用 --- 或 ——— 分隔线，用自然过渡衔接
8. 每章 5 个小节，结构完整

## 本章目录
- 2.1 全流程工具地图：6 步流水线 × 工具角色
- 2.2 各环节工具清单：剧本、生图、视频、配音、音乐、剪辑
- 2.3 工具选型建议：新手零成本组合与进阶专业组合
- 2.4 成本预算模型：免费路线与付费路线
- 2.5 工具链数据流：从剧本到成片的文件流转与交接规范

## 内容要求
- 2.1 用一张大表（环节 × 推荐工具 × 定位）呈现全流程工具矩阵；用 mermaid 流程图说明工具间数据流转关系
- 2.2 每个环节列出 2-5 个主流工具，说明各自定位与特点，例如：剧本环节（ChatGPT、Claude、Kimi、豆包、DeepSeek）、角色设定与生图（Midjourney、Stable Diffusion、即梦 AI、通义万相）、图生视频（可灵 Kling、Runway、即梦 AI、Vidu、海螺 AI、Luma、Pika）、AI 配音（剪映配音、魔音工坊、ElevenLabs、Fish Audio、GPT-SoVITS）、BGM 与音效（Suno AI、剪映素材库）、剪辑（剪映、Premiere、DaVinci）
- 2.3 给出两套选型组合并对比：新手入门组合（豆包/Kimi + 即梦 AI + 剪映）与进阶专业组合（Claude + SD 本地部署 LoRA + 可灵 + ElevenLabs + 剪映/PR），说明各自适用人群
- 2.4 用表格列出各环节免费方案与付费方案的参考月成本，给出单集综合成本区间
- 2.5 说明图片（PNG/JPG）、视频片段（MP4）、音频（WAV/MP3）、工程文件（剪映草稿）等文件在流水线中的流转规范与命名建议
