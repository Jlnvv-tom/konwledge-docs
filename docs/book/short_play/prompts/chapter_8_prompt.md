# 第8章写作 Prompt

## 任务
以 IP「怕浪猫」的名义，写一篇关于《第六步：剪辑合成》的系列文章（第 8 章，共 10 章）。文章性质为知识库书籍型技术教程，风格参考掘金/技术博客，严谨务实，第一人称可用"我"和"怕浪猫"交替，禁止用"小编"。

## 写作规范（每章通用，必须严格遵守）
1. 目标字数：10000-12000 字（中文正文）
2. 全文不使用任何 emoji 或图标符号，标题与正文均不出现图标
3. 每个段落尽量短小，不超过 4-5 行
4. 专有缩写名词首次出现时必须给出全称英文 + 中文解释
5. 核心原理尽量用图表呈现：表格、mermaid 流程图、结构化列表均可
6. 不需要程序示例代码；但核心关键"模板/配置"（如导出参数表、剪辑检查清单）要完整展示
7. 段落之间不使用 --- 或 ——— 分隔线，用自然过渡衔接
8. 每章 5 个小节，结构完整

## 本章目录
- 8.1 剪辑工作流总览：从素材到成片
- 8.2 拼接与节奏：卡点与转场
- 8.3 字幕制作：样式统一与自动识别
- 8.4 调色原理：统一色调与情绪表达
- 8.5 导出参数与发布检查清单

## 内容要求
- 8.1 用 mermaid 流程图呈现剪映（CapCut）剪辑工作流：导入素材 → 拼接 → 配音对位 → 字幕 → 调色 → 转场 → 导出，说明每步目的
- 8.2 讲解拼接原则：按分镜顺序拖入、配音时间轴对齐、硬切为主、少量叠化/闪白强化情绪点；讲解卡点剪辑（Beat Sync）与节奏控制
- 8.3 讲解字幕制作：剪映自动识别/手动导入台词字幕，字幕样式统一（字体、字号、描边、位置），说明字幕在漫剧中的重要性（竖屏沉浸感）
- 8.4 通俗解释调色（Color Grading）原理：色温、色调、对比度、饱和度等参数的作用；说明冷色调（悬疑）与暖色调（甜宠）的情绪映射；给出剪映调色参数参考表
- 8.5 给出最终导出参数：分辨率 1920×1080（1080P，竖屏 1080×1920）、帧率 30fps、格式 MP4（MPEG-4 Part 14）/H.264 编码；给出发布前检查清单（钩子、一致性、台词清晰、悬念、封面标题）

## 术语解释示例（首次出现必须全称英文+中文）
- 卡点：Beat Sync，让画面切换与音乐节拍对齐的剪辑手法
- 转场：Transition，两个镜头之间的衔接方式
- 调色：Color Grading，通过调整色彩参数统一画面风格的技术
- 色温：Color Temperature，画面冷暖倾向的度量
- fps：Frames Per Second，每秒帧数，帧率单位
- MP4：MPEG-4 Part 14，一种广泛使用的数字多媒体容器格式
- H.264：一种高效率视频编码标准
