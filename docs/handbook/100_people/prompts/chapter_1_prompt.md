# 第1章写作 Prompt：科技与互联网先驱

## 写作要求

根据下面的章节大纲，以专业技术博客风格写一篇关于"世界上最伟大的科技与互联网先驱"的文章。

### 全局要求
- 字数控制在 8000-10000 字
- 不出现 emoji 或图标符号
- 每个段落不超过 4-5 行，段落简短
- 段落之间不使用分隔线（---）
- 涉及专有缩写名词时，用全称英文解释，例如：CEO (Chief Executive Officer, 首席执行官)、GPU (Graphics Processing Unit, 图形处理器)、IPO (Initial Public Offering, 首次公开募股)
- 多使用表格做人物对比、时间线梳理
- 多使用 ASCII 图表展示人物关系、技术演进、公司架构
- 适当展示关键代码片段（如 PageRank 算法伪代码、推荐算法核心逻辑等），代码不超过 30 行
- 补充和延展知识点，不要仅停留在 index.md 中的简介内容
- 无运营元素、无 IP 名称、无互动钩子/CTA
- 专业技术博客风格，客观严谨
