# 第7章写作 Prompt：社会活动与人权领袖

## 写作要求

根据下面的章节大纲，以专业技术博客风格写一篇关于"世界上最伟大的社会活动与人权领袖"的文章。

### 全局要求
- 字数控制在 8000-10000 字
- 不出现 emoji 或图标符号
- 每个段落不超过 4-5 行，段落简短
- 段落之间不使用分隔线（---）
- 涉及专有缩写名词时，用全称英文解释，例如：UN (United Nations, 联合国)、NGO (Non-Governmental Organization, 非政府组织)、COP (Conference of the Parties, 缔约方大会)
- 多使用表格做运动策略对比、影响力对比
- 多使用 ASCII 图表展示社会运动的传播机制、组织架构
- 适当展示关键数据（如各国碳排放数据、女童教育统计等），用表格呈现
- 补充和延展知识点，深入分析社会运动逻辑
- 无运营元素、无 IP 名称、无互动钩子/CTA
- 专业技术博客风格，客观严谨
