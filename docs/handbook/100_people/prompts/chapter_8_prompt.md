# 第8章写作 Prompt：体育传奇

## 写作要求

根据下面的章节大纲，以专业技术博客风格写一篇关于"世界上最伟大的体育传奇"的文章。

### 全局要求
- 字数控制在 8000-10000 字
- 不出现 emoji 或图标符号
- 每个段落不超过 4-5 行，段落简短
- 段落之间不使用分隔线（---）
- 涉及专有缩写名词时，用全称英文解释，例如：NBA (National Basketball Association, 美国职业篮球联赛)、FIFA (Fédération Internationale de Football Association, 国际足球联合会)、MVP (Most Valuable Player, 最有价值球员)
- 多使用表格做数据对比、荣誉对比、技术特征对比
- 多使用 ASCII 图表展示运动轨迹、战术分析、生涯数据曲线
- 适当展示关键数据统计（如梅西 vs C罗全数据对比、乔丹 vs 詹姆斯荣誉对比等），用表格呈现
- 补充和延展知识点，深入分析运动科学和训练方法
- 无运营元素、无 IP 名称、无互动钩子/CTA
- 专业技术博客风格，客观严谨
