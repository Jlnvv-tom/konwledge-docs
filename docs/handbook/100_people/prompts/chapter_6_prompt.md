# 第6章写作 Prompt：文学与艺术巨匠

## 写作要求

根据下面的章节大纲，以专业技术博客风格写一篇关于"世界上最伟大的文学与艺术巨匠"的文章。

### 全局要求
- 字数控制在 8000-10000 字
- 不出现 emoji 或图标符号
- 每个段落不超过 4-5 行，段落简短
- 段落之间不使用分隔线（---）
- 涉及专有缩写名词时，用全称英文解释
- 多使用表格做作品对比、艺术流派对比、风格演变对比
- 多使用 ASCII 图表展示艺术流派演进时间线、绘画技法分析
- 适当展示关键文学结构分析（如莎士比亚戏剧结构、小说叙事结构等），用结构化形式呈现
- 补充和延展知识点，深入分析艺术原理和创作背景
- 无运营元素、无 IP 名称、无互动钩子/CTA
- 专业技术博客风格，客观严谨
