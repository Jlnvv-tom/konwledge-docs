# 第4章：银行与金融中介 — 钱是如何从储户流向企业的

你以为银行就是存钱取钱的地方？其实银行是人类发明过的最精妙的财富搬运机器，它让你存进去的一块钱变成市面上流通的十块钱。

我是怕浪猫，一个把金融拆到齿轮级别给你看的博主。这个系列我们用100个知识点讲透人类经济活动，今天是第四章，讲银行这个庞大又精密的中介系统。你每天跟银行打交道，但大概率没想过：你的存款是怎么变成企业的贷款的？银行为什么能倒闭？为什么需要人管着？这篇8000字帮你全部理清。

## 4.1 商业银行的经营模式 — 利差为王：低息吸储高息放贷的生意经

银行这门生意说到底特别朴素：低价收钱，高价放钱，中间赚差价。你存一万块进去，银行给你2%的利息；银行把这一万块借给企业，收6%的利息。4个百分点的利差，就是银行的核心利润来源。这个模式已经运转了五百多年，从佛罗伦萨的美第奇家族到今天的中国工商银行，底层逻辑完全一样。

但这里面有一个关键设计：期限错配。储户随时可能来取钱，但银行把钱借给企业要三年五年才能收回来。银行凭什么敢这么干？因为它赌的是"储户不会同时来取钱"。只要取款和存款大致平衡，银行就能稳稳地赚利差。这个赌注一旦输掉，就是挤兑。

> 银行赚的是期限错配的钱，担的是期限错配的险。利润的背面永远写着风险两个字。

来看商业银行的核心资产负债结构：

| 资产端（钱去哪了） | 占比典型值 | 负债端（钱从哪来） | 占比典型值 |
|------|------|------|------|
| 贷款（企业+个人） | 55-65% | 客户存款 | 60-75% |
| 债券投资 | 15-25% | 同业借款 | 10-15% |
| 准备金（央行） | 8-12% | 资本金（股东权益） | 8-12% |
| 现金及同业 | 5-8% | 次级债 | 2-5% |

这个表里藏着银行经营的全部秘密。负债端靠存款低成本融资，资产端靠贷款高收益获利。准备金是上交央行的"保护费"，资本金是股东自己的钱——出了亏损先亏这部分。

银行利差计算的核心逻辑可以用一段伪代码来表达：

```python
# 商业银行利差计算模型
class Bank:
    def __init__(self):
        self.deposits = []      # 存款列表
        self.loans = []         # 贷款列表
        self.reserve_ratio = 0.10  # 法定准备金率10%
    
    def accept_deposit(self, amount, rate, duration):
        self.deposits.append({
            'amount': amount, 'rate': rate, 'duration': duration
        })
    
    def make_loan(self, amount, rate, duration):
        # 检查是否有足够可贷资金
        available = sum(d['amount'] for d in self.deposits) * (1 - self.reserve_ratio)
        committed = sum(l['amount'] for l in self.loans)
        if amount <= available - committed:
            self.loans.append({
                'amount': amount, 'rate': rate, 'duration': duration
            })
            return True
        return False  # 资金不足
    
    def net_interest_margin(self):
        """计算净息差 (Net Interest Margin, NIM)"""
        interest_income = sum(l['amount'] * l['rate'] for l in self.loans)
        interest_expense = sum(d['amount'] * d['rate'] for d in self.deposits)
        earning_assets = sum(l['amount'] for l in self.loans)
        return (interest_income - interest_expense) / earning_assets

# 示例：储户存100万2%利率，银行以6%利率贷出90万（保留10%准备金）
bank = Bank()
bank.accept_deposit(1_000_000, 0.02, 12)   # 100万存款，年化2%
bank.make_loan(900_000, 0.06, 12)           # 90万贷款，年化6%
# 净息差 = (900000*0.06 - 1000000*0.02) / 900000 = 3.78%
print(f"净息差 NIM: {bank.net_interest_margin():.2%}")
```

需求先行还是产品先行？需求先行。银行的出现是因为社会上有两类人：一类有余钱没处用，一类缺钱没法扩大生产。这种"资金供需不匹配"的需求催生了银行这个中介产品。没有银行的古代，富人的钱埋在地窖里贬值，穷人借不到钱只能困在原地。银行把死钱变成活钱，这是它最大的社会价值。

## 4.2 存款保险与银行挤兑 — 信任是最脆弱的东西：挤兑的致命弱点与制度防线

银行最怕的事情只有一个：所有人同时来取钱。这不是理论假设，而是反复发生的历史事实。1930年大萧条期间，美国有超过9000家银行倒闭，大部分不是因为贷款亏损，而是因为储户恐慌挤兑。一家银行谣言四起，第二天门口就排起长队。前面的人取到钱，后面的人更慌，正反馈循环一旦启动就很难停下来。

> 挤兑的本质不是银行没钱，而是所有人同时以为银行没钱。

对付挤兑，人类发明了两道防线。第一道是最后贷款人制度：央行在危机时向商业银行提供紧急流动性。第二道是存款保险：政府承诺即使银行倒闭，储户的存款也能拿回来。美国在1933年成立了Federal Deposit Insurance Corporation (FDIC)，即联邦存款保险公司的 Corporation，最初保障每个储户2500美元，今天这个额度已经提高到25万美元。中国在2015年推出存款保险条例，保障额度为50万元人民币。

存款保险的效果是微妙的。它通过消除储户的恐慌来防止挤兑，但同时也削弱了储户监督银行的动力。这叫"道德风险"：既然有人兜底，储户就懒得关心银行把贷款放给了谁。这就是为什么存款保险必须和银行监管配套使用——你保了我的存款，我就有权管你怎么经营。

新手 vs 老手对银行安全性的理解区别：

| 维度 | 新手的理解 | 老手的理解 |
|------|------|------|
| 银行倒闭原因 | 银行把钱亏光了 | 流动性枯竭，资产可能没问题但变不了现 |
| 存款保险作用 | 保我的钱不丢 | 消除恐慌预期，防止挤兑的正反馈循环 |
| 监管核心目标 | 不让银行做坏事 | 维持公众对银行体系的信心 |
| 挤兑触发因素 | 银行实际亏损 | 储户"认为"银行要完 |

需求先行还是产品先行？需求先行。存款保险制度是踩过大萧条无数银行倒闭的坑之后才被设计出来的。先有挤兑这个痛点，再有存款保险这个产品。有趣的是，存款保险本身又创造了新的需求——银行监管的需求，因为保险带来了道德风险。一个产品的诞生常常孕育下一个产品的需求。

## 4.3 贷款类型与信用评估 — 银行如何决定借不借钱：抵押、信用与5C评估法

银行最核心的能力不是吸储，而是放贷。吸储谁都会——给点利息就行。但放贷是真功夫：你得判断这笔钱借出去能不能收回来。收不回来就是坏账，坏账吃掉资本金，资本金亏完了银行就倒闭。所以信用评估是银行生存的命脉。

银行贷款按担保方式分三类：抵押贷款（有房产土地等实物担保）、质押贷款（有存单债券等金融资产担保）、信用贷款（纯靠借款人信誉，无担保）。抵押贷款最安全，因为万一违约还能卖抵押物。信用贷款风险最高，所以利率也最高。你房贷利率4%出头，信用卡透支利率18%起跳，差的就是这个风险溢价。

银行业有一套经典的信用评估框架叫"5C法"：Character（品格，借款人还款意愿）、Capacity（能力，还款现金流）、Capital（资本，净资产厚度）、Collateral（担保，抵押物价值）、Conditions（条件，宏观行业环境）。五个维度综合打分，决定借不借、借多少、利率多少。

```python
# 5C信用评分算法（简化模型）
def credit_score_5c(character, capacity, capital, collateral, conditions):
    """
    输入：五个维度各0-100分
    输出：综合信用评分及贷款决策
    """
    weights = {
        'character': 0.25,    # 品格权重25%
        'capacity': 0.30,     # 能力权重30%（最重要）
        'capital': 0.15,      # 资本权重15%
        'collateral': 0.15,   # 担保权重15%
        'conditions': 0.15    # 条件权重15%
    }
    score = (character * weights['character'] +
             capacity * weights['capacity'] +
             capital * weights['capital'] +
             collateral * weights['collateral'] +
             conditions * weights['conditions'])
    
    if score >= 80:
        return score, "批准，优惠利率"
    elif score >= 65:
        return score, "批准，标准利率"
    elif score >= 50:
        return score, "有条件批准，需追加担保"
    else:
        return score, "拒绝"

# 案例：小微企业主申请贷款
score, decision = credit_score_5c(
    character=85,    # 信用记录良好
    capacity=60,     # 现金流偏紧
    capital=55,      # 净资产一般
    collateral=70,   # 有房产抵押
    conditions=45     # 行业景气度低
)
print(f"综合评分: {score}, 决策: {decision}")
# 综合评分: 64.5, 决策: 有条件批准，需追加担保
```

需求先行还是产品先行？需求先行。信用评估体系是被坏账教训出来的。每一次大规模违约事件都会推动评估方法的升级。2008年次贷危机之后，5C法中的Collateral被重新审视——原来房产抵押也不是万能的，房价会跌。评估方法永远在追赶最新一轮风险的尾巴。

## 4.4 投资银行 — 企业融资的幕后推手：高盛和摩根士丹利做什么

商业银行赚的是利差，投资银行赚的是手续费。两者做的事情完全不同。商业银行面向大众吸储放贷，投资银行面向企业和机构做两件事：帮企业融资，帮企业并购。

融资这边，投行做的是承销。企业要发股票（股权融资）或发债券（债权融资），投行负责定价、找买家、承担发行风险。一笔10亿美元的IPO，投行收3-7%的承销费，那就是3000万到7000万美元。高盛、摩根士丹利这些名字你经常在新闻里听到，它们干的就是这个。

并购那边，投行做的是财务顾问。买方需要投行帮忙估值、设计交易结构、谈判；卖方也需要投行帮忙找买家、定价格。2008年贝尔斯登被摩根大通收购时，双方都有投行在背后操盘。投行在这类交易中赚的是咨询费和成功费，通常按交易金额的0.5-2%收取。

> 投行不用自己的钱冒险（理想状态下），它用信息不对称赚钱。它知道谁要买、谁要卖、值多少钱、怎么搭桥。

商业银行 vs 投资银行核心对比：

| 维度 | 商业银行 | 投资银行 |
|------|------|------|
| 收入模式 | 利差（存贷利差） | 手续费（承销、咨询、交易） |
| 客户 | 个人+中小企业 | 大企业+机构投资者+政府 |
| 风险承担 | 信用风险（贷款违约） | 市场风险（交易亏损） |
| 资金来源 | 存款 | 自有资本+同业拆借 |
| 监管重点 | 资本充足率、流动性 | 信息披露、市场行为 |
| 代表企业 | 工行、建行、摩根大通 | 高盛、摩根士丹利、中金 |

需求先行还是产品先行？需求先行。企业规模做大之后，靠银行贷款这种间接融资不够用了，需要直接到市场上发股票发债券，这就催生了投行。反过来，投行设计出的复杂金融产品（比如各种衍生品结构）有时也走在需求前面——这就是产品先行了，但往往走得太远就变成风险源头。

## 4.5 影子银行 — 看不见的金融系统：信托、理财、P2P的监管套利

影子银行是金融系统的隐形人。它干着银行的事——吸收资金、发放贷款——但不叫银行，不受银行监管。中国的影子银行主要有三种形态：信托产品、银行理财、P2P网贷。鼎盛时期，中国影子银行规模超过100万亿元，相当于正规银行体系的一半。

影子银行为什么存在？因为监管套利。银行放贷款受很多限制：资本充足率要求、行业限制（比如房地产和地方融资平台限贷）、存贷比上限。但通过信托公司或理财产品绕一圈，这些限制全可以避开。银行把资金通过信托计划放给房地产商，在报表上这笔钱叫"投资"不叫"贷款"，完美绕过监管。

> 影子银行不是金融创新，是监管的影子。光照不到的地方，影子最长。

代价是什么？影子银行没有存款保险兜底，没有央行做最后贷款人，没有资本充足率这道防线。一旦底层资产出问题——房价跌了、企业违约了——投资者直接承担损失。2018年P2P爆雷潮，数百万人血本无归，就是影子银行风险的一次集中释放。

中国在2017年之后开始强力去影子银行。资管新规要求理财产品打破刚兑（不再承诺保本保息），P2P全部清退，信托通道业务压降。到今天，中国的影子银行规模已经大幅收缩。但影子银行不会消失，它只是换了个形式。只要监管存在，套利的动力就存在。

需求先行还是产品先行？这次是产品先行。影子银行是金融机构为了绕开监管而主动设计出来的"产品"，走在真实需求前面。但它满足了真实需求吗？部分满足——中小企业确实借不到钱，影子银行给了它们一条融资渠道。问题在于，这种满足是以风险积累为代价的。

## 4.6 资产证券化 — 把贷款打包卖掉：MBS和ABS的金融工程

银行放出去的贷款会占用自己的资本金。资本金是有限的，用完了就不能再放贷。那有没有办法把贷款"卖掉"腾出资本金继续放贷？有，这就是资产证券化。

资产证券化的逻辑是：把一批贷款打包成一个资产池，以这个资产池的现金流为基础发行证券，卖给投资者。银行收回现金，投资者拿到证券。银行不再持有这些贷款的风险，风险转移给了投资者。

最早的资产证券化是美国的住房抵押贷款。1970年代，美国政府支持的机构开始把住房贷款打包成Mortgage-Backed Securities (MBS)，即住房抵押贷款支持证券。后来这个技术被推广到汽车贷款、信用卡应收款、学生贷款等各种资产，统称Asset-Backed Securities (ABS)，即资产支持证券。

```python
# 资产证券化现金流瀑布分配模型
def securitization_waterfall(available_cash, tranches):
    """
    按优先级顺序分配现金流（瀑布分配）
    tranches: [(名称, 优先级, 应付金额), ...] 按优先级降序排列
    """
    distribution = {}
    remaining = available_cash
    
    for name, priority, amount_due in tranches:
        if remaining >= amount_due:
            distribution[name] = amount_due
            remaining -= amount_due
        elif remaining > 0:
            distribution[name] = remaining
            remaining = 0
        else:
            distribution[name] = 0
    
    # 剩余资金分配给权益层（次级）
    distribution['equity'] = remaining
    return distribution

# 案例：一笔MBS的现金流分配
# 优先A级1000万，优先B级300万，次级层200万
# 本月收回现金流1100万
result = securitization_waterfall(
    available_cash=11_000_000,
    tranches=[
        ('Senior_A', 1, 10_000_000),   # 优先A级：全额优先
        ('Senior_B', 2, 3_000_000),    # 优先B级：次优先
        ('Mezzanine', 3, 2_000_000),   # 中间层
    ]
)
print("现金流分配结果:")
for tranche, amount in result.items():
    print(f"  {tranche}: {amount:,.0f}")
# Senior_A: 10,000,000（全额）
# Senior_B: 1,000,000（仅收到100万，缺口200万）
# Mezzanine: 0（一分没有）
# equity: 0
```

这就是所谓"瀑布分配"。现金流从最高优先级往下流，优先级越高越先拿到钱，优先级越低风险越大但收益率也越高。次级层（权益层）是最先亏钱的，也是赚得最多的——如果底层贷款表现好，年化收益率可能超过20%。

> 资产证券化本身是中性的金融技术，但当你不知道最底层是什么资产时，它就变成了定时炸弹。

2008年金融危机就是资产证券化失控的结果。次贷被打包成MBS，MBS被打包成CDO，CDO又被打包成CDO的平方。层层包装之后，没有人知道最底层是什么资产。当美国房价开始下跌，次贷违约率上升，整个链条从底到顶全部崩塌。

需求先行还是产品先行？需求先行。银行有腾出资本金的需求，投资者有追求高收益资产的需求，资产证券化应运而生。但到了后期，CDO的平方这种产品已经脱离了真实需求，纯粹是华尔街为了赚手续费而设计的。产品跑到了需求前面太远，灾难就来了。

## 4.7 互联网金融 — 技术颠覆传统银行：余额宝和花呗的模式创新

2013年被称为中国互联网金融元年。这一年6月，支付宝上线了一个叫余额宝的产品。它的本质极其简单：把你支付宝账户里的零钱自动买成货币市场基金，每天结息，随时可取可花。但这个简单的产品在一年内吸引了超过1亿用户，规模突破5000亿元，成为全球最大的货币基金。

余额宝做对了什么？它发现了一个被传统银行忽视的需求：小额活期存款的收益。你的活期存款利率是0.35%，但银行拿着这些钱去买货币市场工具能赚3-4%。这个巨大价差被银行吃掉了。余额宝做的事就是绕过银行，让普通人直接享受货币市场的收益。这不是技术创新，是模式创新。

花呗走的是另一条路。它本质上是一张虚拟信用卡，但不需要银行那套繁琐的审批流程。支付宝根据你的消费数据直接给你额度，秒批秒用。它利用的是数据优势——支付宝知道你每个月花多少钱、还多少钱，比银行的信用评估更精准、更实时。

> 互联网金融的本质不是技术更先进，而是把银行吃掉的那部分利差还给了用户。

互联网金融对传统银行的冲击体现在三个层面：获客渠道（线上vs线下）、风控方式（数据模型vs抵押担保）、运营成本（技术平台vs网点人力）。但互联网金融并没有颠覆银行，因为银行有一个互联网公司没有的东西：吸收存款的法定资格和央行的流动性支持。最终格局是融合：银行学互联网的体验，互联网学银行的风控。

需求先行还是产品先行？需求先行。余额宝满足的是普通人零钱理财的需求，花呗满足的是无信用卡人群的消费信贷需求。这些需求一直存在，只是被传统银行忽视或不愿服务。技术让服务这些需求的成本降低了，产品才随之出现。

## 4.8 供应链金融 — 围绕核心企业的信贷模式：一个企业的信用变成一条链的信用

中小企业融资难是个世界级难题。它们没有房产抵押，没有 audited financial statements（经审计的财务报表），银行不敢借钱。但供应链金融想出了个巧妙的办法：利用核心企业的信用为上下游中小企业增信。

举个例子。苹果公司有上千家零部件供应商，这些供应商大部分是中小企业。它们向银行借钱，银行不敢借。但如果苹果公司说"我确认这笔应付账款三个月后一定付"，银行就敢了——因为苹果的信用评级是AA级，比大部分银行还高。这就是供应链金融的核心逻辑：把核心企业的信用延伸到供应链上下游。

供应链金融有三种经典模式：

| 模式 | 核心逻辑 | 参与方 | 风险控制点 |
|------|------|------|------|
| 应收账款融资 | 供应商用核心企业的欠款作质押 | 供应商、银行、核心企业 | 核心企业付款能力 |
| 保兑仓融资 | 经销商以未来入库的商品作质押 | 经销商、银行、核心企业 | 商品价格稳定性 |
| 融通仓融资 | 企业用存货作质押融资 | 企业、银行、物流公司 | 存货变现能力 |

供应链金融流程图（以应收账款融资为例）：

```
[核心企业] --采购--> [供应商]
     |                    |
     | 确认应付账款        | 申请贷款
     v                    v
[银行] <---质押应收---- [供应商]
     |                    |
     | 放款               | 到期还款
     v                    ^
[供应商]                  |
     | 交付货物            |
     v                    |
[核心企业] ---付款---> [银行]（直接还款给银行）
```

需求先行还是产品先行？需求先行。中小企业融资难是长期痛点，核心企业有信用但银行不会自动把这个信用延伸出去。供应链金融是把已有信用资源重新配置的产品创新，需求一直在那里，只是需要一个机制来连接。

## 4.9 消费金融与信用卡 — 刺激消费的双刃剑：提前消费的便利与债务陷阱

信用卡是人类发明的最成功的消费刺激工具，也是最成功的心理操控工具。它让你在刷卡时感受不到花钱的痛苦——因为不是从口袋里掏真金白银。行为经济学研究证实，用信用卡消费的人平均比用现金的人多花12-18%。

信用卡的商业模式有三层收入。第一层是商户手续费，每笔交易银行收1-2%。第二层是分期利息，你选择分期还款时年化利率通常在12-18%。第三层是违约罚息，逾期未还的利率高达18-24%，再加上滞纳金。如果你每月全额还款，银行只赚第一层；如果你分期或逾期，银行赚第二层和第三层。银行最爱的客户不是不还款的，也不是还不上的，而是每个月还一点但还不完的——这叫"循环信用客户"。

> 信用卡赚的不是你的钱，是你对未来的乐观偏差。你以为下个月能还清，银行知道你还不清。

中国的消费金融走了一条不同的路。美国是信用卡先行，中国是移动支付先行。花呗和白条这些产品本质上就是信用卡，但绑在电商场景里，体验比传统信用卡好得多。不过底层逻辑一样：用信用额度刺激你多消费，用分期利息赚你的钱。

消费金融的隐患在于过度负债。韩国在2003年经历过信用卡危机：信用卡公司疯狂发卡，人均持卡4张，信用卡债务占GDP比例超过14%，最终大面积违约，多家信用卡公司破产。中国台湾地区也经历过类似的"卡债风暴"。这些教训告诉我们，消费金融是把双刃剑——适度促进消费，过度则摧毁消费能力。

需求先行还是产品先行？需求先行。消费者有提前消费的需求，商家有促进销售的需求。信用卡是为了满足这些需求而设计的产品。但信用卡被设计出来之后，它本身也在创造需求——那些你本来不会买的东西，因为有了信用卡你就买了。产品开始反向塑造需求。

## 4.10 金融监管 — 为什么银行需要被管：巴塞尔协议与系统性风险防范

金融监管的核心问题只有一个：为什么银行需要被管，而餐厅不需要？答案是系统性风险。一家餐厅倒闭，最多影响几条街的吃货。一家银行倒闭，可能引发连锁反应——它欠其他银行的钱还不了，其他银行也跟着出问题，信心崩溃，全行业挤兑。这就是为什么银行需要特殊监管。

全球银行监管的基石是Basel Accords（巴塞尔协议）。1988年的巴塞尔I要求银行资本充足率不低于8%，即每放100块贷款至少要有8块自有资本。2004年的巴塞尔II增加了市场风险和操作风险的资本要求。2010年的巴塞尔III是在2008年金融危机教训基础上制定的，提高了资本充足率标准，新增了流动性覆盖率（Liquidity Coverage Ratio, LCR）和净稳定资金比率（Net Stable Funding Ratio, NSFR）两个指标。

银行监管的三大支柱：

| 支柱 | 内容 | 核心目标 |
|------|------|------|
| 第一支柱：最低资本要求 | 资本充足率>=8%，核心一级资本>=6% | 确保银行有足够缓冲吸收亏损 |
| 第二支柱：监管审查 | 监管机构评估银行风险管理 | 确保内控体系有效 |
| 第三支柱：市场约束 | 强制信息披露 | 让市场参与者监督银行 |

监管永远在追赶创新的脚步。银行发明影子银行绕开监管，监管出台资管新规堵住漏洞。银行用资产证券化腾出资本金，监管提高证券化产品的风险权重。这场猫鼠游戏永远不会结束，因为金融创新的动力（利润）远比监管的动力（安全）强烈。

> 监管不是防止银行犯错，而是确保银行犯错之后系统不崩。目标不是零风险，是可控风险。

需求先行还是产品先行？需求先行。每一次监管升级都是踩着危机的尸体前进的。1929年大萧条催生了存款保险和分业经营，2008年金融危机催生了巴塞尔III。监管永远是滞后的——先有产品创新，再有风险暴露，最后才有监管补丁。这个顺序不会改变，因为没有人能预知所有风险。

## 本章小结：需求与产品的博弈

回顾这10个知识点，我们可以清晰地看到银行与金融中介的发展脉络：

**需求先行的知识点（8个）：**
- 商业银行、存款保险、信用评估、投资银行、供应链金融、消费金融、互联网金融、金融监管——都是先有真实需求，后有制度或产品创新来满足。

**产品先行的知识点（2个）：**
- 影子银行和资产证券化（后期）——金融机构为了绕开监管或赚取手续费而主动设计的产品，走在真实需求前面。当产品跑得太远，就变成了系统性风险的源头。

> 金融的历史就是一部"需求创造产品、产品创造新需求、新需求创造新风险、新风险创造新监管"的循环史。怕浪猫总结一句话：理解银行，就是理解信任如何被制度化和价格化。
