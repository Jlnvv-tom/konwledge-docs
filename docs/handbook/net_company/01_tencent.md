# 01 腾讯 — 社交与内容的护城河

> 一句话定位：以微信和QQ为超级入口，通过游戏、内容、金融科技和云服务实现多元变现的中国互联网巨头。

---

## 1. 公司速写

- **成立时间**：1998年
- **总部**：深圳
- **上市**：港股 0700.HK
- **核心基本盘**：微信(WeChat)月活13亿+，是中国最大的社交基础设施

## 3. 运营模式

### 3.1 获客与留存
- **社交流量自循环**：微信/QQ天然流量池，新业务可通过社交关系链冷启动
- **内容粘性**：游戏+视频+音乐+阅读构建高停留时长
- **小程序生态**：吸引B端入驻，形成"微信即操作系统"的用户习惯

### 3.2 活跃策略
- 微信生态联动：公众号→视频号→小程序→微信支付，形成闭环
- 游戏电竞化：KPL、LPL赛事体系拉长游戏生命周期
- IP跨媒介开发：网文→动漫→游戏→影视

### 3.3 B端运营
- 企业微信打通微信，实现"私域流量"运营
- 腾讯云打包C端流量资源吸引企业客户
- 投资公司互相导流(如美团、京东入口)

## 4. 盈利模式

### 4.1 收入结构(2024年)
| 业务板块 | 收入(亿元) | 占比 |
|---------|-----------|------|
| 增值服务(游戏+社交) | 3200+ | 52% |
| 金融科技及企业服务 | 2100+ | 34% |
| 网络广告 | 1200+ | 19% |
| **合计** | **6600+** | **100%** |

### 4.2 核心利润引擎
- **游戏**：高毛利(70%+)，王者荣耀单产品年贡献数百亿
- **微信广告**：朋友圈广告+视频号广告，高毛利
- **金融科技**：支付手续费+信贷+理财分润

### 4.3 变现路径
```
用户(微信) ──→ 社交(免费) ──→ 流量分发
                            ├──→ 游戏内购(增值服务)
                            ├──→ 广告曝光(广告收入)
                            ├──→ 支付费率(金融科技)
                            └──→ 云服务(企业服务)
```

## 6. 战略观察

### 当前重点方向
- **视频号商业化**：短视频广告+直播电商，承接抖音外溢流量
- **游戏出海**：Level Infinite品牌全球发行
- **AI大模型**：混元大模型+元宝App，追赶百度/字节
- **微信电商**：小程序+视频号+微信支付构建电商闭环

### 潜在风险
- 游戏版号依赖政策
- 抖音对用户时长的持续挤压
- 金融科技监管收紧
- 投资版图收缩导致生态协同减弱
