# 中国头部互联网公司产品手册

> 本手册系统梳理中国头部互联网公司的产品线布局、运营模式与盈利模式，并提炼关键数据指标，帮助读者快速建立对每家公司业务全貌的结构化认知。
>
> 编写原则：一只眼睛看产品，一只眼睛看商业模型。产品是骨架，运营是血脉，盈利是心脏，数据是体检报告。

## 阅读说明

每家公司按统一结构展开：

```
1. 公司速写      — 一句话定位 + 基本盘
2. 产品线全景图   — 按业务板块梳理核心产品矩阵
3. 运营模式       — 如何获客、如何留存、如何活跃
4. 盈利模式       — 钱从哪里来，各业务收入占比
5. 关键数据指标   — 衡量业务健康度的核心北极星
6. 战略观察       — 当前重点方向与潜在风险
```

## 行业地图视角

### 按赛道归类

```
┌─ 社交/内容 ─── 腾讯、字节跳动、快手
├─ 电商 ─────── 阿里巴巴、京东、拼多多
├─ 本地生活 ─── 美团
├─ 搜索/AI ─── 百度
├─ 游戏 ─────── 腾讯、网易
└─ 硬件+IoT ─── 小米
```

### 按商业模式归类

```
┌─ 广告驱动 ─── 字节跳动、百度、快手
├─ 交易/佣金 ── 阿里巴巴、京东、拼多多、美团
├─ 增值服务 ─── 腾讯、网易
├─ 硬件销售 ─── 小米
└─ 混合模式 ─── 腾讯(广告+增值+金融)、美团(佣金+广告+配送)
```
