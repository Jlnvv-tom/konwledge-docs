## 3. 运营模式

### 3.1 双边网络效应
- **用户端**：通过补贴+丰富供给获取用户
- **商家端**：通过订单量吸引商家入驻
- **骑手端**：700万+骑手构建履约网络

### 3.2 高频打低频战略
```
外卖(高频) ──→ 建立用户习惯和骑手网络
  ├──→ 闪购(中频) ──→ 扩品类
  ├──→ 到店(中频) ──→ 高毛利变现
  ├──→ 酒旅(低频高毛利) ──→ 利润贡献
  └──→ 买菜/优选(高频) ──→ 零售纵深
```

### 3.3 到店业务运营
- 商家入驻：提供团购、代金券、预订工具
- 流量分发：美团App+大众点评App双平台
- 内容化：点评UGC内容+美团直播

### 3.4 即时配送网络
- 700万+骑手构成"分钟级"配送能力
- 超脑调度系统：实时调度千万级订单
- 无人机+自动配送车构建未来履约

## 4. 盈利模式

### 4.1 收入结构(2024年)
| 业务板块 | 收入(亿元) | 占比 |
|---------|-----------|------|
| 核心本地商业(外卖+到店+酒旅) | 2500+ | 75% |
| 新业务(优选/单车/买菜等) | 800+ | 25% |
| **合计** | **3300+** | **100%** |

### 4.2 外卖变现
```
用户支付餐费
  ├──→ 商家佣金(6-8%)
  ├──→ 用户配送费
  ├──→ 商家广告(竞价排名)
  └──→ 配送差价(用户付配送费 vs 骑手成本)
```

### 4.3 到店业务变现
- 商家佣金：团购券交易额5-10%
- 广告收入：商家竞价排名、信息流广告
- 高毛利业务：到店经营利润率30%+

### 4.4 利润结构
- 外卖：微利(单均利润1-2元)，靠规模
- 到店+酒旅：利润奶牛
- 新业务：亏损(社区团购为主)

## 6. 战略观察

### 当前重点方向
- **即时零售**：闪购+小象超市，将外卖履约能力扩展至全品类
- **AI+本地生活**：美团大模型+智能调度
- **到店防御**：应对抖音本地生活的竞争
- **出海**：Keeta在港澳/沙特试水外卖

### 潜在风险
- 抖音本地生活对到店业务的分流
- 骑手成本上升与权益保障压力
- 社区团购持续亏损
- 新业务探索(打车/充电宝)ROI不确定
- 监管：平台经济、劳动用工
