第10章 税务问题：个体户交税完全手册

个体户不是"不交税"，只是交税的方式和金额跟公司不一样。算不清楚这笔账的人，要么多交冤枉钱，要么少交被罚款。

我是怕浪猫，今天把个体户税务这件事讲到你能自己算税。

先说个真事。我认识一个做奶茶店的个体户，开了两年，一直以为自己月收入不到10万就不用交税。结果有一天收到税务局通知，要他补缴两年的个人所得税——他确实免了增值税，但经营所得的个人所得税是另一个税种，跟增值税免不免征没有关系。两年下来连补带罚交了小四万。他跟我说"早知道我就好好记账了"，但事后的教训总是比事前的提醒更贵。

这章我不仅要告诉你交什么税、怎么算税，还要帮你理清楚哪些税可以免、哪些税不能省、怎么在合法合规的前提下把税负降到最低。看完这章，你至少能自己估算出一年该交多少税，不会被税务局通知的时候一脸懵。

举例计算：某餐饮个体户年营业收入80万，成本费用50万，利润30万。

增值税（小规模，月均6.67万<10万）= 0元（免征） 经营所得 = 800000 - 500000 = 300000元 个人所得税 = 300000 × 20% - 10500 = 49500元 城建税及附加 = 0（增值税为0） 印花税 = 视合同情况，假设约500元

总税负 = 49500 + 500 = 50000元 税负率 = 50000 / 800000 ≈ 6.25%

个体户的税负率通常在3%-15%之间，取决于利润率和征收方式。远低于公司的综合税负（25%企业所得税+20%分红税），但保障范围也更窄。

再来拆解一个更复杂的案例。假设一个批发零售个体户，年销售额300万（月均25万），进货成本210万，房租水电人工等费用40万，利润50万。

增值税（小规模，月均25万>10万，不免税）= 300万 × 1%（2024年减按1%征收）= 3万 城建税及附加 = 3万 × 12%（城建税7%+教育附加3%+地方教育附加2%）= 3600元 经营所得 = 300万 - 210万 - 40万 - 3万 - 0.36万 = 46.64万 个人所得税 = 466400 × 30% - 40500 = 99420元 印花税 = 购销合同300万 × 0.03% = 900元

总税负 = 30000 + 3600 + 99420 + 900 = 133920元 税负率 = 133920 / 3000000 = 4.46%

同样收入规模如果是公司： 企业所得税 = 466400 × 5%（小微优惠）= 23320元 增值税 = 同上3万 城建税及附加 = 3600元 分红个税 = (466400 - 23320) × 20% = 88616元 总税负 = 30000 + 3600 + 23320 + 88616 + 900 = 146436元

可以看到在年收入300万的规模下，个体户的税负仍然略低于公司，但差距已经很小了。而且公司有有限责任保护，个体户没有。当收入进一步增长到500万以上，公司反而可能更优——因为公司可以做更多的税务筹划，比如合理列支工资、公益捐赠、研发费用加计扣除等。

查账征收 vs 核定征收的差异：

维度查账征收核定征收
计税依据实际利润（收入-成本-费用）核定利润率×收入或固定税额
账务要求必须规范建账简易记账或无需记账
适用对象账务健全的个体户账务不健全的小规模个体户
税负特点利润高则税高，利润低则税低无论盈亏都按固定比例交
优势亏损不交税简单省事
劣势账务成本高赚钱时可能多交税

核定征收看似省事，但不一定省钱。如果你利润率高于核定利润率，查账征收更划算。比如核定利润率10%，但你实际利润率30%，查账征收可以扣除更多成本。反之，如果你实际利润率低于核定利润率，核定征收就更划算。

Q47: 小规模纳税人和一般纳税人怎么选？​

维度小规模纳税人一般纳税人
年销售额≤500万>500万（或自愿登记）
增值税征收率/税率3%（或1%/免征）6%/9%/13%
进项抵扣不可抵扣可抵扣进项税
发票可开普票和专票（需申请）可开专票
适合进货少、利润率高的生意进货多、利润率低的生意

选择标准：看你的进项税额占比。

如果 进项税额 / 销项税额 > 征收率 / 税率 → 选一般纳税人更省税
如果 进项税额 / 销项税额 < 征收率 / 税率 → 选小规模更省税

举例：年销售额200万的服务业个体户。

小规模：增值税 = 200万 × 3% = 6万（或1% = 2万或免税） 一般纳税人：增值税 = 200万 × 6% - 进项税额。如果进项税额2万，增值税 = 12万 - 2万 = 10万。

这种情况下小规模明显更划算。但如果你是商贸类，进货成本占收入70%，进项税额很高，一般纳税人可能更省。

进项占收入比小规模税负（3%）一般纳税人税负（13%商品）哪个划算
0%（纯服务）3%13%小规模
30%3%9.1%小规模
50%3%6.5%小规模
70%3%3.9%小规模
80%3%2.6%一般纳税人
90%3%1.3%一般纳税人

服务型个体户通常选小规模，商贸型个体户在进货占比超过80%时选一般纳税人更省。

一般纳税人登记后不能随意转回小规模。根据现行政策，登记为一般纳税人后，不能再转回小规模纳税人（特殊政策窗口期除外）。所以做这个决定之前一定要算清楚，不要因为"听说一般纳税人好听"就草率登记。

登记一般纳税人的隐性成本也要考虑：

隐性成本项说明预估年成本
财务规范必须规范建账，需要专业会计6000-12000元
发票管理需购买税控设备、领用专票500-1000元
申报复杂度增值税进销项抵扣、多税种申报时间成本增加
审计风险被稽查概率高于小规模隐性风险

有个实际案例：一个做五金批发的朋友，年销售额400万，进货成本320万（占80%），他选择了一般纳税人。增值税 = 400万×13% - 320万×13% = 52万 - 41.6万 = 10.4万。如果选小规模（1%征收率）：400万×1% = 4万。表面看小规模更省，但他下游客户都要求开13%的专票用于抵扣，如果只能开1%的普票，客户就不跟他合作了。所以一般纳税人不仅仅是税负问题，还是业务合作的问题。

选型考量因素小规模优势一般纳税人优势
税负低利润率时税负低高进货占比时税负低
客户需求个人客户无影响企业客户需专票
供应商无影响能取得专票可抵扣
财务成本低高
业务形象小规模更正规
转回灵活性可转一般纳税人不可转回

Q49: 个体户注销怎么处理？有哪些注意事项？​

个体户注销比公司简单，但也有流程。

注销流程：

1. 清算 → 结清税款、债务、员工工资
2. 税务注销 → 申报最后一期税款，取得清税证明
3. 工商注销 → 提交注销申请，交回营业执照
4. 银行账户注销 → 注销对公账户
5. 印章缴销 → 交回公章等
注销类型条件时间复杂度
简易注销未开业/无债权债务/未涉税1-2周低
一般注销正常经营过2-4周中
异常注销被列入经营异常名录1-3个月高

注意事项：税务注销是最关键的一步。如果有未申报的税款或欠税，必须先补缴才能注销。税务清算不干净的个体户，即使工商注销了，后续仍可能被追缴。

简易注销的条件比较严格，适合那些注册了但实际没有经营过的个体户。如果你已经开了票、报过税、有银行流水，就只能走一般注销流程。

注销过程中最容易被忽略的环节是社保和公积金。如果你以个体户名义缴纳了社保或者雇佣了员工并缴纳了社保，注销前必须到社保局办理停缴和清算。否则社保系统会继续生成欠费记录，影响个人征信。

注销环节常见问题解决方案时间影响
税务注销有未申报税款补报补缴+1-2周
税务注销发票未缴销交回未使用发票+1-3天
工商注销执照遗失先登报挂失+1周
银行注销账户有余额先提取余额+1-3天
社保注销有欠缴记录补缴后注销+1-2周
印章缴销印章遗失登报声明作废+1周

很多人注销个体户的原因不是生意做不下去了，而是"不想再报税了"。但即使你不经营了，只要个体户还在登记状态，就必须按期申报——哪怕是零申报。长期不申报会被罚款、列入异常名录，最终影响的是你个人的信用记录。如果真的不做了，尽早注销，干净利落。

不注销也不报税的后果时间线：

时间后果
逾期1个月罚款200元+滞纳金
逾期3个月罚款1000-2000元+滞纳金
逾期6个月被列入税务非正常户
逾期1年工商列入经营异常名录
逾期2年罚款加重，可能被吊销执照
逾期3年列入严重违法失信名单
逾期5年+法人/经营者3年内不得注册新企业

Q50: 个体户被税务稽查了怎么办？​

税务稽查的常见触发原因：

触发原因说明预防方法
金税系统预警个人卡大额收款、发票异常经营款走对公账户
举报员工、客户、竞争对手合规经营
随机抽查定期双随机抽查平时做好合规
行业专项整治某行业集中稽查关注政策动态
数据异常收入骤增骤减、利润率异常保持合理波动

被稽查后的应对：

第一，不惊慌。配合检查是法定义务，但不配合不会让问题消失，只会加重处罚。

第二，准备材料。近3年的账本、发票、银行流水、合同、库存记录。

第三，如实陈述。隐瞒或虚报会从"过失"升级为"故意"，处罚力度加倍。

第四，申请从轻处理。主动补缴税款和滞纳金的，可以争取减轻罚款。

第五，必要时请税务师或律师协助。涉及金额较大时，专业帮助值得花钱。

税务稽查不可怕，可怕的是被查到后才发现自己一直违规。平时的合规成本，远低于被查时的罚款成本。

税务稽查的处罚标准参考：

违规类型处罚依据处罚标准
未按期申报税收征管法第62条2000元以下；情节严重2000-10000元
不缴或少缴税款税收征管法第63条补缴+滞纳金+0.5-5倍罚款
偷税漏税税收征管法第63条补缴+滞纳金+0.5-5倍罚款
抗税税收征管法第67条补缴+滞纳金+1-5倍罚款；可能追究刑责
骗税税收征管法第66条追缴+1-5倍罚款；可能追究刑责

滞纳金计算：每日万分之五，从滞纳之日起计算。

滞纳金 = 未缴税款 × 0.0005 × 滞纳天数

例：欠税10000元，逾期90天
滞纳金 = 10000 × 0.0005 × 90 = 450元

看起来滞纳金不多，但它是按天累加的，而且和罚款是叠加的。欠税1万，逾期半年，可能最终要交：1万本金 + 900元滞纳金 + 5000-50000元罚款。合规的成本远低于被查的成本。
