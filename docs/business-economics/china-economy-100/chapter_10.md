# 第10章 税务问题：个体户交税完全手册

个体户不是"不交税"，只是交税的方式和金额跟公司不一样。算不清楚这笔账的人，要么多交冤枉钱，要么少交被罚款。

我是怕浪猫，今天把个体户税务这件事讲到你能自己算税。

先说个真事。我认识一个做奶茶店的个体户，开了两年，一直以为自己月收入不到10万就不用交税。结果有一天收到税务局通知，要他补缴两年的个人所得税——他确实免了增值税，但经营所得的个人所得税是另一个税种，跟增值税免不免征没有关系。两年下来连补带罚交了小四万。他跟我说"早知道我就好好记账了"，但事后的教训总是比事前的提醒更贵。

这章我不仅要告诉你交什么税、怎么算税，还要帮你理清楚哪些税可以免、哪些税不能省、怎么在合法合规的前提下把税负降到最低。看完这章，你至少能自己估算出一年该交多少税，不会被税务局通知的时候一脸懵。

## Q46: 个体户需要交哪些税？

| 税种 | 税率 | 是否必须缴纳 | 计算方式 |
|------|------|-----------|---------|
| 增值税 | 3%（小规模）或6%/9%/13%（一般纳税人） | 是（月销<10万免征） | 销售额×征收率 |
| 城建税及附加 | 增值税×7%/5%/1% | 是（随增值税缴纳） | 增值税×附加税率 |
| 个人所得税（经营所得） | 5%-35%五级累进 | 是 | (收入-成本-费用)×税率-速算扣除数 |
| 印花税 | 0.03%-0.1% | 按合同类型 | 合同金额×税率 |

经营所得五级超额累进税率表：

| 级数 | 全年应纳税所得额 | 税率 | 速算扣除数 |
|------|----------------|------|----------|
| 1 | 不超过30000元 | 5% | 0 |
| 2 | 30000-90000元 | 10% | 1500 |
| 3 | 90000-300000元 | 20% | 10500 |
| 4 | 300000-500000元 | 30% | 40500 |
| 5 | 超过500000元 | 35% | 65500 |

举例计算：某餐饮个体户年营业收入80万，成本费用50万，利润30万。

增值税（小规模，月均6.67万<10万）= 0元（免征）
经营所得 = 800000 - 500000 = 300000元
个人所得税 = 300000 × 20% - 10500 = 49500元
城建税及附加 = 0（增值税为0）
印花税 = 视合同情况，假设约500元

总税负 = 49500 + 500 = 50000元
税负率 = 50000 / 800000 ≈ 6.25%

> 个体户的税负率通常在3%-15%之间，取决于利润率和征收方式。远低于公司的综合税负（25%企业所得税+20%分红税），但保障范围也更窄。

再来拆解一个更复杂的案例。假设一个批发零售个体户，年销售额300万（月均25万），进货成本210万，房租水电人工等费用40万，利润50万。

增值税（小规模，月均25万>10万，不免税）= 300万 × 1%（2024年减按1%征收）= 3万
城建税及附加 = 3万 × 12%（城建税7%+教育附加3%+地方教育附加2%）= 3600元
经营所得 = 300万 - 210万 - 40万 - 3万 - 0.36万 = 46.64万
个人所得税 = 466400 × 30% - 40500 = 99420元
印花税 = 购销合同300万 × 0.03% = 900元

总税负 = 30000 + 3600 + 99420 + 900 = 133920元
税负率 = 133920 / 3000000 = 4.46%

同样收入规模如果是公司：
企业所得税 = 466400 × 5%（小微优惠）= 23320元
增值税 = 同上3万
城建税及附加 = 3600元
分红个税 = (466400 - 23320) × 20% = 88616元
总税负 = 30000 + 3600 + 23320 + 88616 + 900 = 146436元

| 对比项 | 个体户 | 公司（一人有限） |
|-------|------|----------|
| 增值税 | 3万 | 3万 |
| 城建税及附加 | 3600元 | 3600元 |
| 所得税 | 99420元 | 23320元 |
| 分红个税 | 无 | 88616元 |
| 印花税 | 900元 | 900元 |
| 总税负 | 13.39万 | 14.64万 |
| 税负率 | 4.46% | 4.88% |
| 实际到手 | 50万-13.39万=36.61万 | 50万-14.64万=35.36万 |

可以看到在年收入300万的规模下，个体户的税负仍然略低于公司，但差距已经很小了。而且公司有有限责任保护，个体户没有。当收入进一步增长到500万以上，公司反而可能更优——因为公司可以做更多的税务筹划，比如合理列支工资、公益捐赠、研发费用加计扣除等。

查账征收 vs 核定征收的差异：

| 维度 | 查账征收 | 核定征收 |
|------|---------|-------- |
| 计税依据 | 实际利润（收入-成本-费用） | 核定利润率×收入或固定税额 |
| 账务要求 | 必须规范建账 | 简易记账或无需记账 |
| 适用对象 | 账务健全的个体户 | 账务不健全的小规模个体户 |
| 税负特点 | 利润高则税高，利润低则税低 | 无论盈亏都按固定比例交 |
| 优势 | 亏损不交税 | 简单省事 |
| 劣势 | 账务成本高 | 赚钱时可能多交税 |

> 核定征收看似省事，但不一定省钱。如果你利润率高于核定利润率，查账征收更划算。比如核定利润率10%，但你实际利润率30%，查账征收可以扣除更多成本。反之，如果你实际利润率低于核定利润率，核定征收就更划算。

## Q47: 小规模纳税人和一般纳税人怎么选？

| 维度 | 小规模纳税人 | 一般纳税人 |
|------|-----------|----------|
| 年销售额 | ≤500万 | >500万（或自愿登记） |
| 增值税征收率/税率 | 3%（或1%/免征） | 6%/9%/13% |
| 进项抵扣 | 不可抵扣 | 可抵扣进项税 |
| 发票 | 可开普票和专票（需申请） | 可开专票 |
| 适合 | 进货少、利润率高的生意 | 进货多、利润率低的生意 |

选择标准：看你的进项税额占比。

```
如果 进项税额 / 销项税额 > 征收率 / 税率 → 选一般纳税人更省税
如果 进项税额 / 销项税额 < 征收率 / 税率 → 选小规模更省税
```

举例：年销售额200万的服务业个体户。

小规模：增值税 = 200万 × 3% = 6万（或1% = 2万或免税）
一般纳税人：增值税 = 200万 × 6% - 进项税额。如果进项税额2万，增值税 = 12万 - 2万 = 10万。

这种情况下小规模明显更划算。但如果你是商贸类，进货成本占收入70%，进项税额很高，一般纳税人可能更省。

| 进项占收入比 | 小规模税负（3%） | 一般纳税人税负（13%商品） | 哪个划算 |
|-----------|---------------|---------------------|---------|
| 0%（纯服务） | 3% | 13% | 小规模 |
| 30% | 3% | 9.1% | 小规模 |
| 50% | 3% | 6.5% | 小规模 |
| 70% | 3% | 3.9% | 小规模 |
| 80% | 3% | 2.6% | 一般纳税人 |
| 90% | 3% | 1.3% | 一般纳税人 |

> 服务型个体户通常选小规模，商贸型个体户在进货占比超过80%时选一般纳税人更省。

一般纳税人登记后不能随意转回小规模。根据现行政策，登记为一般纳税人后，不能再转回小规模纳税人（特殊政策窗口期除外）。所以做这个决定之前一定要算清楚，不要因为"听说一般纳税人好听"就草率登记。

登记一般纳税人的隐性成本也要考虑：

| 隐性成本项 | 说明 | 预估年成本 |
|----------|------|----------|
| 财务规范 | 必须规范建账，需要专业会计 | 6000-12000元 |
| 发票管理 | 需购买税控设备、领用专票 | 500-1000元 |
| 申报复杂度 | 增值税进销项抵扣、多税种申报 | 时间成本增加 |
| 审计风险 | 被稽查概率高于小规模 | 隐性风险 |

有个实际案例：一个做五金批发的朋友，年销售额400万，进货成本320万（占80%），他选择了一般纳税人。增值税 = 400万×13% - 320万×13% = 52万 - 41.6万 = 10.4万。如果选小规模（1%征收率）：400万×1% = 4万。表面看小规模更省，但他下游客户都要求开13%的专票用于抵扣，如果只能开1%的普票，客户就不跟他合作了。所以一般纳税人不仅仅是税负问题，还是业务合作的问题。

| 选型考量因素 | 小规模优势 | 一般纳税人优势 |
|-----------|---------|-------------|
| 税负 | 低利润率时税负低 | 高进货占比时税负低 |
| 客户需求 | 个人客户无影响 | 企业客户需专票 |
| 供应商 | 无影响 | 能取得专票可抵扣 |
| 财务成本 | 低 | 高 |
| 业务形象 | 小规模 | 更正规 |
| 转回灵活性 | 可转一般纳税人 | 不可转回 |

## Q48: 个体户有哪些免税政策可以享受？

| 免税政策 | 条件 | 免税额度 | 有效期 |
|---------|------|---------|-------|
| 小规模月销10万以下免征增值税 | 月销售额≤10万（季≤30万） | 全免 | 持续有效 |
| 小规模征收率减按1% | 小规模纳税人 | 3%→1% | 政策延续中 |
| "六税两费"减半 | 小规模纳税人/个体户 | 城建税、印花税等减半 | 持续有效 |
| 重点群体创业税费减免 | 高校毕业生/脱贫人口等 | 每年最高24000元 | 政策延续中 |
| 退役士兵创业税费减免 | 退役士兵 | 每年最高24000元 | 政策延续中 |
| 军转干部创业免税 | 自主择业军转干部 | 3年内免征 | 持续有效 |

> 政策会更新，具体以当地税务局最新公告为准。建议每季度查看一次税务局官网或公众号。

重点群体创业税费减免的申请流程：

```
1. 确认身份 → 是否属于高校毕业生/脱贫人口/登记失业半年以上人员
2. 取得《就业创业证》→ 到人社部门办理
3. 注册个体户 → 取得营业执照
4. 税务登记时选择享受减免 → 填报相关表格
5. 按期申报减免 → 在个税申报时勾选减免项
```

减免额度计算示例：

| 适用人群 | 年减免上限 | 实际减免计算 | 三年累计可减免 |
|---------|----------|-----------|----------|
| 高校毕业生 | 24000元/年 | 当年应纳税额按24000元为限扣减 | 最高7.2万元 |
| 脱贫人口 | 24000元/年 | 同上 | 最高7.2万元 |
| 退役士兵 | 24000元/年 | 同上 | 最高7.2万元 |
| 军转干部 | 3年内免征 | 全额免征增值税、城建税、个税 | 视实际税负而定 |

> 注意：减免的是增值税、城建税、教育附加、地方教育附加和个人所得税，不是所有税种都免。印花税不在减免范围内。

个体户税收申报周期一览：

| 申报项目 | 申报频率 | 截止时间 | 逾期后果 |
|---------|---------|---------|----------|
| 增值税 | 月报或季报 | 月报:次月15日;季报:季后15日 | 罚款+滞纳金（每日万分之五） |
| 个人所得税（经营所得） | 季报+年报 | 季报:季后15日;年报:次年3月31日 | 罚款+滞纳金 |
| 印花税 | 按次或汇总 | 按次:凭证签订后15日内 | 罚款+滞纳金 |
| 工商年报 | 每年一次 | 每年6月30日 | 列入异常名录 |

> 季报比月报省事很多。小规模纳税人如果选择按季申报增值税，每季度只需要申报一次。但个人所得税经营所得无论增值税怎么报，都需要按季预缴。

## Q49: 个体户注销怎么处理？有哪些注意事项？

个体户注销比公司简单，但也有流程。

注销流程：

```
1. 清算 → 结清税款、债务、员工工资
2. 税务注销 → 申报最后一期税款，取得清税证明
3. 工商注销 → 提交注销申请，交回营业执照
4. 银行账户注销 → 注销对公账户
5. 印章缴销 → 交回公章等
```

| 注销类型 | 条件 | 时间 | 复杂度 |
|---------|------|------|--------|
| 简易注销 | 未开业/无债权债务/未涉税 | 1-2周 | 低 |
| 一般注销 | 正常经营过 | 2-4周 | 中 |
| 异常注销 | 被列入经营异常名录 | 1-3个月 | 高 |

注意事项：税务注销是最关键的一步。如果有未申报的税款或欠税，必须先补缴才能注销。税务清算不干净的个体户，即使工商注销了，后续仍可能被追缴。

简易注销的条件比较严格，适合那些注册了但实际没有经营过的个体户。如果你已经开了票、报过税、有银行流水，就只能走一般注销流程。

注销过程中最容易被忽略的环节是社保和公积金。如果你以个体户名义缴纳了社保或者雇佣了员工并缴纳了社保，注销前必须到社保局办理停缴和清算。否则社保系统会继续生成欠费记录，影响个人征信。

| 注销环节 | 常见问题 | 解决方案 | 时间影响 |
|---------|---------|---------|-------- |
| 税务注销 | 有未申报税款 | 补报补缴 | +1-2周 |
| 税务注销 | 发票未缴销 | 交回未使用发票 | +1-3天 |
| 工商注销 | 执照遗失 | 先登报挂失 | +1周 |
| 银行注销 | 账户有余额 | 先提取余额 | +1-3天 |
| 社保注销 | 有欠缴记录 | 补缴后注销 | +1-2周 |
| 印章缴销 | 印章遗失 | 登报声明作废 | +1周 |

> 很多人注销个体户的原因不是生意做不下去了，而是"不想再报税了"。但即使你不经营了，只要个体户还在登记状态，就必须按期申报——哪怕是零申报。长期不申报会被罚款、列入异常名录，最终影响的是你个人的信用记录。如果真的不做了，尽早注销，干净利落。

不注销也不报税的后果时间线：

| 时间 | 后果 |
|------|------|
| 逾期1个月 | 罚款200元+滞纳金 |
| 逾期3个月 | 罚款1000-2000元+滞纳金 |
| 逾期6个月 | 被列入税务非正常户 |
| 逾期1年 | 工商列入经营异常名录 |
| 逾期2年 | 罚款加重，可能被吊销执照 |
| 逾期3年 | 列入严重违法失信名单 |
| 逾期5年+ | 法人/经营者3年内不得注册新企业 |

## Q50: 个体户被税务稽查了怎么办？

税务稽查的常见触发原因：

| 触发原因 | 说明 | 预防方法 |
|---------|------|---------|
| 金税系统预警 | 个人卡大额收款、发票异常 | 经营款走对公账户 |
| 举报 | 员工、客户、竞争对手 | 合规经营 |
| 随机抽查 | 定期双随机抽查 | 平时做好合规 |
| 行业专项整治 | 某行业集中稽查 | 关注政策动态 |
| 数据异常 | 收入骤增骤减、利润率异常 | 保持合理波动 |

被稽查后的应对：

第一，不惊慌。配合检查是法定义务，但不配合不会让问题消失，只会加重处罚。

第二，准备材料。近3年的账本、发票、银行流水、合同、库存记录。

第三，如实陈述。隐瞒或虚报会从"过失"升级为"故意"，处罚力度加倍。

第四，申请从轻处理。主动补缴税款和滞纳金的，可以争取减轻罚款。

第五，必要时请税务师或律师协助。涉及金额较大时，专业帮助值得花钱。

> 税务稽查不可怕，可怕的是被查到后才发现自己一直违规。平时的合规成本，远低于被查时的罚款成本。

税务稽查的处罚标准参考：

| 违规类型 | 处罚依据 | 处罚标准 |
|---------|---------|-------- |
| 未按期申报 | 税收征管法第62条 | 2000元以下；情节严重2000-10000元 |
| 不缴或少缴税款 | 税收征管法第63条 | 补缴+滞纳金+0.5-5倍罚款 |
| 偷税漏税 | 税收征管法第63条 | 补缴+滞纳金+0.5-5倍罚款 |
| 抗税 | 税收征管法第67条 | 补缴+滞纳金+1-5倍罚款；可能追究刑责 |
| 骗税 | 税收征管法第66条 | 追缴+1-5倍罚款；可能追究刑责 |

滞纳金计算：每日万分之五，从滞纳之日起计算。

```
滞纳金 = 未缴税款 × 0.0005 × 滞纳天数

例：欠税10000元，逾期90天
滞纳金 = 10000 × 0.0005 × 90 = 450元
```

> 看起来滞纳金不多，但它是按天累加的，而且和罚款是叠加的。欠税1万，逾期半年，可能最终要交：1万本金 + 900元滞纳金 + 5000-50000元罚款。合规的成本远低于被查的成本。

个体户常见的税务风险点：

| 风险点 | 具体表现 | 稽查发现方式 | 纠正建议 |
|-------|---------|-----------|--------- |
| 个人账户收款 | 经营收入进入个人微信/支付宝/银行卡 | 银行流水比对 | 使用商户收款码 |
| 虚开发票 | 为他人代开/虚开增值税发票 | 发票流向分析 | 拒绝代开请求 |
| 隐瞒收入 | 部分收入不申报 | 成本与收入倒挂分析 | 全额申报 |
| 虚增成本 | 虚构进货、虚列费用 | 发票真伪核实 | 保留真实凭证 |
| 关联交易 | 与经营者个人或关联方的不公允交易 | 关联关系筛查 | 按公允价格交易 |

> 其中"个人账户收款"是目前最高发的稽查触发点。全电发票和金税四期上线后，税务局对资金流的监控能力大幅提升。你的个人卡里突然多了几十万，而你的个体户申报收入只有几万块，系统会自动预警。从第一天起，就把经营收入和 personal 收入分开。
