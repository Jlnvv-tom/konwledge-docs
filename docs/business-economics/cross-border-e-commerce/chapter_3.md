### 欧洲联合账户

### KYC审核应对

KYC（Know Your Customer，客户身份认证）是欧洲站的强制审核流程，美国站也可能触发。审核要求提交以下材料：

| 材料 | 具体要求 | 提交格式 |
|------|---------|---------|
| 公司注册证明 | 营业执照原件扫描件 | PDF/JPG |
| 公司受益人信息 | 持股25%以上的股东信息 | 在线填写 |
| 受益人身份证件 | 身份证正反面扫描件 | PDF/JPG |
| 银行账户证明 | 收款银行账户对账单 | PDF（3个月内） |
| 公司地址证明 | 水电费账单或银行对账单 | PDF（3个月内） |
| 授权书 | 如非法人本人操作需授权委托书 | PDF |

> KYC审核被拒的Top 3原因：地址不一致（营业执照地址与银行账单地址不匹配）、文件模糊、文件过期。提交前务必检查所有地址信息完全一致，文件清晰度达到300dpi以上。

### 视频验证流程

| 步骤 | 操作 | 时间 | 注意事项 |

## 3.3 FBA vs FBM模式选择

### 两种模式核心对比

| 对比项 | FBA（Fulfillment by Amazon） | FBM（Fulfillment by Merchant） |
|--------|---------------------------|------------------------------|
| 仓储 | 亚马逊仓库 | 卖家自行存储 |
| 配送 | 亚马逊配送（Prime） | 卖家自行发货 |
| 客服 | 亚马逊负责 | 卖家负责 |
| 退货 | 亚马逊处理 | 卖家处理 |
| 费用 | 配送费+仓储费+入库费 | 自行承担物流费 |
| Buy Box权重 | 高 | 较低 |
| 适用场景 | 标准化产品、稳定销量 | 大件/重件、冷门产品 |
| 资金压力 | 较高（需备货到FBA） | 较低（按需发货） |

> 经验法则：如果FBA费用占售价比不超过25%，选FBA；如果超过25%，需要认真考虑FBM。但这不是绝对的——FBA带来的Buy Box权重提升和Prime标志可能带来更多销量，足以覆盖额外费用。

### FBA费用结构与利润计算

FBA费用包含三大块：配送费、仓储费和入库处理费。以下是一个完整的FBA利润计算模型。

```python
def calculate_fba_profit(selling_price, product_cost, shipping_cost_headstream,
                         amazon_commission_rate, weight_lb, length_in, width_in, 
                         height_in, avg_storage_days, month, other_costs=0):
    """
    亚马逊FBA完整利润计算
    :param selling_price: 售价（美元）
    :param product_cost: 采购成本（美元）
    :param shipping_cost_headstream: 头程运费（美元/件）
    :param amazon_commission_rate: 亚马逊佣金率
    :param weight_lb: 重量（磅）
    :param length_in/width_in/height_in: 尺寸（英寸）
    :param avg_storage_days: 平均存储天数
    :param month: 月份
    :param other_costs: 其他成本（包装、标签等）
    """
    # 1. 亚马逊佣金
    commission = selling_price * amazon_commission_rate
    
    # 2. FBA配送费（简化版）
    volume_cuft = (length_in * width_in * height_in) / 1728
    if weight_lb <= 1:
        fulfillment_fee = 3.06
    elif weight_lb <= 2:
        fulfillment_fee = 3.47
    elif weight_lb <= 3:
        fulfillment_fee = 4.95
    else:
        fulfillment_fee = 4.95 + (weight_lb - 3) * 0.38
    
    # 3. 仓储费
    if month in [10, 11, 12]:
        storage_rate = 2.40
    else:
        storage_rate = 0.87
    storage_fee = (volume_cuft * storage_rate * avg_storage_days) / 30
    
    # 4. 入库处理费
    inbound_fee = 0.35
    
    # 5. 总成本
    total_cost = (product_cost + shipping_cost_headstream + commission + 
                  fulfillment_fee + storage_fee + inbound_fee + other_costs)
    
    # 6. 利润
    profit = selling_price - total_cost
    profit_margin = profit / selling_price * 100
    roi = profit / total_cost * 100
    
    return {
        "售价": f"${selling_price:.2f}",
        "采购成本": f"${product_cost:.2f}",
        "头程运费": f"${shipping_cost_headstream:.2f}",
        "亚马逊佣金": f"${commission:.2f} ({amazon_commission_rate*100}%)",
        "FBA配送费": f"${fulfillment_fee:.2f}",
        "仓储费": f"${storage_fee:.2f}",
        "入库处理费": f"${inbound_fee:.2f}",
        "其他成本": f"${other_costs:.2f}",
        "总成本": f"${total_cost:.2f}",
        "净利润": f"${profit:.2f}",
        "利润率": f"{profit_margin:.1f}%",
        "投资回报率": f"{roi:.1f}%"
    }

# 示例1：手机壳 - $19.99
print("=== 手机壳 $19.99 ===")
print(calculate_fba_profit(19.99, 1.5, 0.8, 0.15, 0.3, 6, 4, 1, 15, 6))

# 示例2：蓝牙耳机 - $49.99
print("\n=== 蓝牙耳机 $49.99 ===")
print(calculate_fba_profit(49.99, 8, 2.5, 0.15, 0.5, 5, 4, 3, 20, 6))

# 示例3：瑜伽垫 - $29.99
print("\n=== 瑜伽垫 $29.99 ===")
print(calculate_fba_profit(29.99, 4, 3, 0.15, 2, 24, 6, 3, 30, 6, 0.5))
```

## 3.4 Listing优化实战

Listing（产品页面）是消费者了解你产品的唯一渠道。一个好的Listing可以让同样的产品多卖3倍。

### 标题撰写公式

亚马逊标题的黄金公式：

```
[品牌名] + [核心关键词] + [核心卖点/特性] + [适用场景] + [规格参数]
```

字符限制：200字符以内（移动端通常只显示前70-80字符，核心信息要前置）

| 标题要素 | 字符占比 | 作用 | 示例 |
|---------|---------|------|------|
| 品牌名 | 10-15% | 品牌建设 | Anker |
| 核心关键词 | 30-40% | 搜索排名 | Wireless Earbuds |
| 核心卖点 | 20-25% | 转化提升 | Active Noise Cancelling |
| 适用场景 | 10-15% | 精准流量 | for iPhone Android |
| 规格参数 | 10-15% | 减少退货 | Bluetooth 5.3, 30H Playtime |

> 标题不是写得越长越好，而是让算法和消费者在0.5秒内理解"这是什么产品、有什么不同、适不适合我"。核心关键词一定要出现在前70个字符内，因为移动端只显示这么多。

### 五点描述写作技巧

五点描述（Bullet Points）是Listing中仅次于标题的转化要素。每点控制在200-250字符。

| 五点结构 | 内容 | 示例 |
|---------|------|------|
| 第1点 | 核心卖点（最大差异化） | 主动降噪技术，沉浸式音质体验 |
| 第2点 | 第二卖点（功能特性） | 30小时超长续航，Type-C快充 |
| 第3点 | 兼容性与适用场景 | 广泛兼容iOS/Android/Windows设备 |
| 第4点 | 佩戴体验与设计 | 人体工学设计，单耳仅4.5g |
| 第5点 | 品质保障与服务 | 18个月质保，7x24小时客服 |

### 产品描述与A+页面

产品描述（Product Description）在没有品牌备案时使用纯文本格式。品牌备案后可以使用A+ Content（Enhanced Brand Content，增强品牌内容），通过图文模块展示产品。

A+页面的核心模块类型：

| 模块类型 | 用途 | 最佳实践 |
|---------|------|---------|
| 标准图片+文字 | 产品介绍 | 左图右文，图片宽度970px |
| 对比表格 | 竞品对比 | 突出自身优势，不贬低竞品 |
| 品牌故事 | 品牌展示 | 讲述品牌使命和价值观 |
| 大图横幅 | 视觉冲击 | 高质量生活方式图 |
| 问答模块 | 疑虑解答 | 预判消费者常见问题 |

### 主图与附图设计规范

亚马逊对图片有严格的规范要求：

| 图片类型 | 尺寸要求 | 内容要求 | 常见违规 |
|---------|---------|---------|---------|
| 主图 | 1000x1000px以上（建议1600x1600px） | 纯白背景、产品占比85%以上 | 添加文字、水印、多角度 |
| 附图1 | 同上 | 使用场景图 | 背景非白色OK |
| 附图2 | 同上 | 尺寸对比图 | - |
| 附图3 | 同上 | 功能细节图 | - |
| 附图4 | 同上 | 包装内容物 | - |
| 附图5 | 同上 | 生活方式/对比图 | - |
| 附图6 | 同上 | 信息图/FAQ | - |

> 主图是影响CTR（Click-Through Rate，点击率）最重要的因素。在搜索结果页面，消费者首先看到的是主图缩略图。一个清晰、有吸引力的主图可以让CTR从3%提升到8%以上。

### 后台Search Terms优化

Search Terms是亚马逊后台的隐藏关键词字段，消费者看不到，但会影响搜索排名。

Search Terms优化规则：

| 规则 | 说明 | 示例 |
|------|------|------|
| 不重复 | 不要重复标题和五点中已出现的词 | 标题已有"wireless earbuds"，Search Terms不写 |
| 不用逗号 | 用空格分隔，不需要逗号 | 正确：noise cancelling headphones |
| 不用竞品名 | 写竞品品牌名会被判侵权 | 错误：AirPods alternative |
| 长度限制 | 250字节以内 | 超出部分不被索引 |
| 含长尾词 | 放入长尾关键词 | bluetooth earphones for running |
| 含同义词 | 加入同义词和相关词 | earbuds, earphones, headphones |

| SB（Sponsored Brands） | 搜索结果顶部 | CPC | 成长期 | $1/天 | 品牌备案卖家 |
| SD（Sponsored Display） | 亚马逊站内外 | CPC或vCPM | 成熟期 | $1/天 | 品牌备案卖家 |
| DSP | 亚马逊站外全网络 | CPM | 品牌建设 | 通常$35,000/月 | 通过亚马逊或代理商 |

### SP广告核心设置

SP（Sponsored Products，商品推广）是绝大多数卖家使用的广告类型，它通过关键词或商品定位来展示广告。

| 设置项 | 选项 | 建议值 | 说明 |
|--------|------|--------|------|
| 投放方式 | 自动/手动 | 先自动后手动 | 自动跑2周收集数据 |
| 匹配方式 | 广泛/词组/精确 | 精确匹配为优 | 从精确到广泛逐步扩展 |
| 竞价策略 | 动态竞价-仅降低/提高和降低/固定 | 动态-仅降低（初期） | 根据数据表现自动调价 |
| 竞价金额 | $0.25-$5+ | 建议起始$0.5-1 | 根据品类竞争程度调整 |
| 每日预算 | $1-$1000+ | $10-30（初期） | 逐步增加，避免超支 |
| 投放定位 | 关键词/商品 | 关键词优先 | ASIN定位用于抢占竞品流量 |

SP广告的自动投放有四种匹配类型：

| 匹配类型 | 流量大小 | 转化率 | 用途 |
|---------|---------|--------|------|
| Close Match（紧密匹配） | 低 | 高 | 转化最好的自动流量 |
| Loose Match（宽泛匹配） | 中 | 中 | 发现新关键词 |
| Substitutes（同类商品） | 高 | 中-低 | 竞品流量拦截 |
| Complements（互补商品） | 中 | 低 | 交叉销售机会 |

### ACOS与TACOS优化策略

ACOS（Advertising Cost of Sales，广告销售成本比）和TACOS（Total ACOS，总广告销售成本比）是衡量广告效率的两个核心指标。

| 指标 | 公式 | 健康范围 | 说明 |
|------|------|---------|------|
| ACOS | 广告花费 / 广告销售额 × 100% | 10-30% | 越低越好，但新品期可容忍高ACOS |
| TACOS | 广告花费 / 总销售额 × 100% | 5-15% | 衡量广告对整体销售的影响 |
| ROAS | 广告销售额 / 广告花费 | 3-10x | ACOS的倒数，越高越好 |

> ACOS不是越低越好。一个ACOS 50%但带来大量自然排名提升的广告，可能比ACOS 10%但只依赖广告出单的情况更好。判断广告效果的核心指标是TACOS——如果TACOS在持续下降，说明自然流量占比在提升，广告正在帮你建立自然排名。

ACOS优化决策树：

```python
def optimize_acos(acos, tacos, conversion_rate, cr_history, ad_spend_ratio):
    """
    ACOS优化决策树
    :param acos: 当前ACOS
    :param tacos: 当前TACOS
    :param conversion_rate: 广告转化率
    :param cr_history: 历史转化率
    :param ad_spend_ratio: 广告花费占总销售额比
    """
    if tacos < 0.10:
        if acos < 0.20:
            return "优秀：保持当前策略，考虑增加预算放大效果"
        else:
            return "良好：广告效率尚可，但ACOS偏高，优化关键词匹配方式"
    elif tacos < 0.20:
        if conversion_rate < 0.10:
            return "需改进：转化率低，检查Listing质量和价格竞争力"
        elif ad_spend_ratio > 0.50:
            return "需改进：过度依赖广告，加强自然排名建设（SEO、评价）"
        else:
            return "一般：调整竞价策略，否词优化，减少低转化关键词"
    else:
        if conversion_rate < cr_history * 0.7:
            return "警告：转化率大幅下降，检查是否有差评、断货或竞品降价"
        else:
            return "警告：TACOS过高，暂停低效广告组，重新评估选品和定价"
```

### SB和SD广告设置要点

**SB（Sponsored Brands，品牌推广）**

SB广告出现在搜索结果页顶部，包含品牌Logo、自定义标题和产品集合。

| SB要素 | 要求 | 最佳实践 |
|--------|------|---------|
| 品牌Logo | 400x400px | 简洁清晰，无文字 |
| 自定义标题 | 50字符以内 | 包含核心卖点和行动号召 |
| 落地页 | 店铺页面或产品页面 | 建议用Store页面提升体验 |
| 产品数量 | 3个以上 | 展示品牌产品矩阵 |

**SD（Sponsored Display，展示推广）**

SD广告基于受众定位，可以展示在亚马逊站内其他产品页面和站外网站。

| SD定位方式 | 说明 | 适用场景 |
|-----------|------|---------|
| 商品定位 | 定位特定ASIN或品类 | 抢占竞品流量 |
| 受众定位-浏览 | 浏览过你产品未购买的消费者 | 弃购挽回 |
| 受众定位-购买 | 购买过你产品的消费者 | 复购和新品推广 |
