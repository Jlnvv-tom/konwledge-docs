# 第6章：基金与资产管理 — 让专业的人帮你管钱

你以为把钱交给基金经理就能躺平赚钱？其实85%的主动基金经理连续10年都跑不赢指数，而真正让你亏钱的不是市场，是你选基金的方式。

我是怕浪猫，一只在金融市场里摸爬滚打多年的猫。今天继续更新「人类经济活动的100个核心知识点」系列第六章，聊聊基金与资产管理这件事。这一章会从1868年的第一只基金讲起，一直聊到ESG投资，帮你把基金这个工具彻底搞明白。

## 6.1 基金的起源与基本模式 — 集合投资、专业管理、分散风险：从1868年说起

基金这个东西，说到底就是"凑钱找人管"。但这个简单的想法，花了人类一百多年才完善。

1868年，英国伦敦成立了海外及殖民地政府信托（Foreign and Colonial Government Trust），这是公认的第一只投资基金。当时的英国正处于工业革命鼎盛期，国内资本过剩，投资者想买海外殖民地债券但又不懂海外市场。于是有人想出个办法：把大家的钱凑到一起，交给懂行的人去投资，收益按份额分配。这就是基金的雏形。

到了1924年，美国波士顿成立了马萨诸塞投资者信托（Massachusetts Investors Trust），这是第一只现代意义上的开放式共同基金。它引入了两个关键创新：一是随时可以按净值赎回，二是投资组合以股票为主而非债券。这两点奠定了现代公募基金的基本框架。

基金的基本模式可以用下面这个结构来理解：

```
投资者A --+
投资者B --+--> 基金管理人(管理投资组合) --> 股票/债券/衍生品等
投资者C --+         |
                    |-- 管理费(通常0.5%-2%/年)
                    |-- 申购赎回机制(开放式)或二级市场交易(封闭式)
                    +-- 托管银行(资金安全监督)
```

基金的核心价值主张有三点：集合投资（小额资金也能买一篮子股票）、专业管理（由全职基金经理做研究决策）、分散风险（持有多只证券降低单一标的暴雷影响）。这三点至今未变。

> 基金的本质不是"专家帮你赚钱"，而是"用制度化的方式把散户的钱变成机构的钱"。

那么问题来了：基金是需求先行还是产品先行？答案是需求先行。1868年第一只基金诞生，根本原因是英国投资者对海外投资有强烈需求，但缺乏专业能力和信息渠道。需求在那里，产品只是回应需求的形式。每一次基金形态的演进——从封闭式到开放式、从主动到被动、从国内到全球——都是投资者需求驱动的结果。

## 6.2 公募基金与私募基金 — 谁能买、怎么管：监管严格vs策略灵活

公募基金和私募基金，就像公共交通和私人专车。一个面向所有人、规则严格但胜在安全透明；另一个面向少数人、灵活自由但门槛高、风险也大。

公募基金（Public Fund）是指向不特定公众公开发行的基金，受证券监管机构严格监管。在中国，公募基金由证监会监管，必须公开披露净值、持仓、费率等信息。任何人都可以用很低的门槛（通常1元起）购买。正因为面向大众，监管对公募基金的投资范围、杠杆比例、单一持仓上限都有严格限制。

私募基金（Private Fund）则是面向合格投资者非公开募集的基金。合格投资者在中国需要满足金融资产不低于300万元或最近三年年均收入不低于50万元等条件。私募基金的信息披露要求低很多，不需要公开净值和持仓，但策略灵活度高得多——可以用衍生品、可以做空、可以加杠杆、可以投未上市股权。

下面这个对比表可以直观看出两者的区别：

| 维度 | 公募基金 | 私募基金 |
|------|---------|---------|
| 募集对象 | 不特定公众 | 合格投资者(300万金融资产起) |
| 投资门槛 | 1元起 | 100万元起(常见) |
| 监管机构 | 证监会，严格监管 | 中基协备案，监管较松 |
| 信息披露 | 每日净值、季报、年报 | 月度或季度净值，不公开持仓 |
| 投资策略 | 限制多：不能做空、杠杆受限 | 灵活：可做空、可加杠杆、可用衍生品 |
| 费率结构 | 管理费0.5%-1.5%/年 + 托管费 | 管理费1%-2%/年 + 20%业绩报酬 |
| 流动性 | 高(开放式可每日赎回) | 较低(常有锁定期6-12个月) |
| 适合人群 | 普通投资者 | 高净值人群、机构投资者 |

私募基金最显著的特征是业绩报酬机制——基金经理提取利润的20%作为报酬（也叫"2/20"费率结构：2%管理费+20%业绩分成）。这意味着基金经理只有在赚钱时才能拿到大头收入，理论上激励更强。但反过来，这种机制也可能激励基金经理冒更大风险去追求高收益。

> 公募基金是"交规严格的公交车"，私募基金是"没有限速的私家车"——不是谁都需要私家车，但能坐私家车的人，也未必开得比公交车快。

这一节的需求先行还是产品先行？怕浪猫认为这一轮是产品先行。私募基金的出现，最初并不是投资者主动要求的，而是金融从业者发现公募基金的限制太多，于是设计出一种更灵活的产品结构来吸引高净值客户。产品创造了需求——很多人是在知道私募基金存在之后，才意识到自己有"需要更灵活策略"的需求。

## 6.3 股票型、债券型与混合型基金 — 风险收益的阶梯：不同偏好不同选择

不同类型的基金，本质上是不同风险收益特征的组合。选基金的第一步，不是选哪只基金，而是选哪一类基金。

股票型基金（Equity Fund）要求基金资产80%以上投资于股票。它的长期收益预期最高，但波动也最大。适合投资期限长（5年以上）、能承受较大回撤（可能-30%甚至更多）的投资者。股票型基金又可细分为价值型（投资低估值股票）、成长型（投资高增长股票）、指数型（跟踪特定指数）等。

债券型基金（Bond Fund）要求80%以上资产投资于债券。收益预期较低但稳定，波动小。适合追求稳健收益、投资期限较短（1-3年）的投资者。债券基金的风险主要来自利率风险（利率上升时债券价格下跌）和信用风险（发债主体违约）。

混合型基金（Hybrid Fund）则同时投资股票和债券，比例灵活。根据股债比例不同，又可分为偏股型（股票60%以上）、偏债型（债券60%以上）、平衡型（股债大致各半）和灵活配置型（比例不固定，基金经理自行调整）。

下面这个风险收益矩阵能帮你快速定位适合自己的基金类型：

```
预期收益率    高 |  股票型          混合偏股型
                 |    ####            ###
                 |    ###             ##
                 |    ##              ##
                 |    #               #
                 |  混合平衡型        混合偏债型
                 |    #               #
                 |    #               #
            低   |  债券型           货币市场基金
                 |    #               |
                 +--------------------------------
                 低                    高
                      流动性/稳定性
```

理解风险收益匹配原则有一个简单公式：你能承受的最大亏损 = 你的投资期限 乘以 市场平均年化波动率。如果你只能承受10%的亏损，而股票市场年均波动率约20%，那你的纯股票配置不应超过50%。

来看一段计算不同类型基金预期收益和风险的简化代码：

```python
import numpy as np

# 不同资产类的预期年化收益率和波动率
asset_classes = {
    'stock': {'return': 0.10, 'volatility': 0.20},
    'bond':  {'return': 0.04, 'volatility': 0.05},
    'cash':  {'return': 0.02, 'volatility': 0.01},
}

def calculate_fund_metrics(stock_w, bond_w, cash_w=0):
    """计算混合基金组合的预期收益和波动率"""
    assert abs(stock_w + bond_w + cash_w - 1.0) < 0.01
    # 组合预期收益率(加权平均)
    port_return = (stock_w * asset_classes['stock']['return'] +
                   bond_w * asset_classes['bond']['return'] +
                   cash_w  * asset_classes['cash']['return'])
    # 组合波动率(简化: 假设股债相关系数0.1)
    corr = 0.1
    port_var = (stock_w**2 * asset_classes['stock']['volatility']**2 +
                bond_w**2  * asset_classes['bond']['volatility']**2 +
                2 * stock_w * bond_w *
                asset_classes['stock']['volatility'] *
                asset_classes['bond']['volatility'] * corr)
    port_vol = np.sqrt(port_var)
    return port_return, port_vol

# 不同基金类型的典型配置
fund_types = {
    '股票型基金':    (0.85, 0.10, 0.05),
    '混合偏股型':    (0.65, 0.30, 0.05),
    '混合平衡型':    (0.45, 0.45, 0.10),
    '混合偏债型':    (0.25, 0.65, 0.10),
    '债券型基金':    (0.05, 0.85, 0.10),
}

print(f"{'基金类型':<12} {'预期年化':>10} {'年化波动':>10} {'估算最大回撤':>14}")
print("-" * 52)
for name, w in fund_types.items():
    ret, vol = calculate_fund_metrics(*w)
    # 简化: 最大回撤约等于2倍年化波动率(95%置信区间)
    max_dd = 2 * vol
    print(f"{name:<12} {ret:>10.2%} {vol:>10.2%} {max_dd:>14.2%}")
```

运行这段代码你会发现，股票型基金的预期收益约9.1%，但最大回撤可能超过40%；债券型基金预期收益约3.5%，最大回撤不到10%。这就是风险收益对等——没有免费午餐。

> 选基金的第一步不是看排名，而是看自己的心跳能承受多少回撤。收益是市场的馈赠，风险是你自己买单。

需求先行还是产品先行？这一节是需求先行。不同投资者有不同的风险偏好和投资期限，这是客观存在的需求差异。基金公司不过是把这些需求分层，设计出不同风险等级的产品来匹配。先有"我不能接受太大波动"的需求，后有债券型基金；先有"我要追求高增长"的需求，后有股票型基金。

## 6.4 指数基金与ETF — 被动投资的崛起：博格的革命和为什么85%的基金经理跑不赢指数

约翰·博格（John Bogle）在1976年做了件当时华尔街都觉得疯狂的事：他创立了第一只面向个人投资者的指数基金——第一指数投资信托（First Index Investment Trust），跟踪标普500指数。这只基金刚募集时只拿到1100万美元，被同行嘲笑为"博格的蠢事"（Bogle's Folly）。

四十年后，这只基金变成了先锋500指数基金（Vanguard 500 Index Fund），管理规模超过8000亿美元。而博格创立的先锋集团（Vanguard Group）成为全球第二大资产管理公司，管理资产超过8万亿美元。博格用事实证明了被动投资的力量。

被动投资的逻辑很简单：既然大部分主动基金经理长期跑不赢市场指数，那为什么不直接买指数？这里的关键数据是：标普指数公司每年发布的SPIVA报告显示，在15年周期内，约85%-90%的美国大盘主动基金跑输标普500指数。这不是个别现象，而是全球市场的普遍规律。

> "不要在干草堆里找针，把整个干草堆买下来。" ——约翰·博格

主动基金跑不赢指数的核心原因有两个。第一，费用拖累。主动基金平均管理费1%-1.5%，加上交易成本，每年要跑赢指数1.5%-2%才能打平。长期来看，这1.5%的复利效应是毁灭性的。第二，市场有效性。随着信息传播速度加快和机构投资者占比提升，市场越来越有效，靠信息优势或选股能力持续跑赢市场越来越难。

Exchange Traded Fund（ETF）是指数基金的进化版本。1993年，美国推出第一只ETF——标普存托凭证（SPDR S&P 500 ETF，代码SPY）。ETF结合了开放式基金的申购赎回机制和股票的二级市场交易机制，投资者可以像买卖股票一样在交易日内买卖ETF。

ETF相比传统开放式指数基金有几个优势：交易成本低（免申购赎回费，只交佣金）、交易灵活（可盘中买卖、可融资融券）、持仓透明（每日公布成分股）、税收效率高（赎回机制减少资本利税实现）。这些优势让ETF在全球范围内爆发式增长，截至2024年全球ETF资产规模超过12万亿美元。

下面这个对比表清晰展示了主动基金、被动指数基金和ETF的区别：

| 维度 | 主动管理基金 | 指数基金(开放式) | ETF |
|------|------------|----------------|-----|
| 管理目标 | 跑赢基准 | 跟踪指数 | 跟踪指数 |
| 管理费率 | 1.0%-1.5%/年 | 0.15%-0.5%/年 | 0.03%-0.5%/年 |
| 交易方式 | 申购赎回(每日一次) | 申购赎回(每日一次) | 二级市场买卖(盘中随时) |
| 持仓透明度 | 季度披露 | 季度披露 | 每日披露 |
| 交易成本 | 申购费0.8%-1.5% | 申购费0-0.12% | 佣金(通常免5) |
| 资金效率 | T+1确认,T+3到账 | T+1确认,T+3到账 | T+0买卖,T+1交收 |
| 适合人群 | 相信基金经理能力者 | 长期定投者 | 灵活交易+长期持有者 |

当然，被动投资也有其风险。当大量资金涌入指数基金和ETF时，会产生"指数化陷阱"：资金被动流入大盘股，推高权重股估值，造成指数内部结构性泡沫。2020年以来标普500前十大权重股占比超过35%，部分原因就是被动资金的机械流入。这是博格当年没有预见到的副作用。

> 被动投资最大的悖论是：当所有人都放弃选股去买指数时，市场就失去了价格发现功能，而价格发现正是指数有效的前提。

需求先行还是产品先行？这一节的情况比较特殊——是理念先行。博格不是回应投资者需求才发明指数基金，恰恰相反，投资者最初并不想要指数基金。博格是先有了"主动管理长期跑不赢市场"这个认知，然后强行推出产品，再花几十年教育市场。这是一个"产品创造需求"的典型案例。

## 6.5 对冲基金 — 不管涨跌都赚钱的策略：索罗斯和绝对收益

说到对冲基金，很多人第一反应是乔治·索罗斯（George Soros）1992年做空英镑赚了10亿美元，或者2007年约翰·保尔森（John Paulson）做空次贷赚了150亿美元。这些故事让对冲基金蒙上了一层神秘色彩，仿佛对冲基金经理都是天才。

实际上，对冲基金（Hedge Fund）的核心定义很简单：一种以绝对收益为目标、使用多元化投资策略（包括做空、杠杆、衍生品等）的私募投资基金。所谓"绝对收益"，就是不管市场涨跌都追求正收益，不跟基准比较。

1949年，阿尔弗雷德·琼斯（Alfred Winslow Jones）创立了第一只对冲基金。他的策略是：做多被低估的股票，同时做空被高估的股票，用做空收益对冲做多风险。这样组合的市场暴露降低，收益更多来自选股能力而非市场涨跌。这就是"对冲"（hedge）一词的由来——本意是风险管理，不是激进投机。

但后来的发展偏离了琼斯的初衷。现代对冲基金策略已经远超简单的多空对冲，形成了多个策略流派：

| 策略类型 | 核心逻辑 | 典型杠杆 | 市场相关性 | 代表人物 |
|---------|---------|---------|-----------|---------|
| 股票多空 | 做多优质股+做空劣质股 | 1-2倍 | 中等(0.3-0.6) | 琼斯 |
| 全球宏观 | 基于宏观经济判断做股债汇商品 | 3-10倍 | 低到中等 | 索罗斯、达里奥 |
| 事件驱动 | 利用并购、分拆、破产等事件套利 | 1-3倍 | 低 | 保尔森 |
| 相对价值套利 | 利用价格扭曲做均值回归 | 5-30倍 | 很低 | LTCM |
| 管理期货(CTA) | 趋势跟踪策略，多市场多品种 | 2-5倍 | 低 | 大卫·哈丁 |
| 固定收益套利 | 利用收益率曲线扭曲套利 | 10-50倍 | 很低 | LTCM |

从上表可以看出，不同策略的杠杆和市场相关性差异巨大。低相关性的策略理论上可以在市场下跌时提供正收益，但高杠杆策略一旦判断错误，损失也是毁灭性的。1998年长期资本管理公司（Long-Term Capital Management, LTCM）的崩盘就是最好的例子——两位诺贝尔经济学奖得主掌舵，用25倍杠杆做固定收益套利，最终因俄罗斯债务危机导致流动性枯竭，亏掉46亿美元，差点引发系统性金融危机。

> 对冲基金不是"对冲掉风险"，而是"把风险从不想承担的地方转移到想承担的地方"——前提是你判断对了风险的方向。

对冲基金的费率结构是经典的"2/20"：2%管理费+20%业绩提成，通常设有高水位线（High Water Mark），即只有在净值超过历史最高点时才提取业绩报酬。这意味着基金经理如果某年亏了20%，必须先涨回原来的高点才能再提业绩费。这个机制理论上保护了投资者，但也可能导致亏损后的基金经理选择关闭基金重开新基金，避免高水位线约束。

需求先行还是产品先行？对冲基金是产品先行。琼斯发明多空对冲策略时，并不是投资者提出"我要一个不管涨跌都赚钱的产品"。是琼斯先设计出策略，证明可行后，才逐渐吸引投资者。全球宏观、事件驱动等策略也是如此——先有策略创新，后有资金追捧。

## 6.6 货币市场基金 — 现金管理的替代品：余额宝的本质

2013年6月，支付宝上线余额宝。这个产品在一年内吸引了一亿用户，管理规模巅峰时达到近2万亿元。很多人觉得这是金融创新，但实际上余额宝的本质就是一只货币市场基金（Money Market Fund, MMF）。

货币市场基金投资于短期（通常一年以内）、高信用等级的货币市场工具，包括国债、央行票据、银行定期存单、商业票据、回购协议等。这些资产的共同特点是：期限短、信用风险低、流动性好。因此货币基金的安全性接近银行存款，但收益率通常略高于活期存款。

货币市场基金的起源可以追溯到1971年。当时美国利率管制（Q条例）限制了银行存款利率上限，但市场利率在通胀推动下持续走高。布鲁斯·本特（Bruce Bent）和亨利·布朗（Henry Brown）创立了第一只货币市场基金——储备基金（Reserve Fund），让普通投资者也能享受货币市场的高利率。

余额宝对接的天弘余额宝基金就是同样的逻辑。2013年中国银行间市场利率高企（钱荒时期），货币基金收益率一度超过6%，而活期存款利率只有0.35%。这中间巨大的利差就是货币基金爆发的土壤。

货币基金的净值计算方式比较特殊。大部分货币基金采用"摊余成本法"计价，净值固定为1元，收益以每日"万份收益"的形式分配。这种方式让投资者心理上感觉像存款——本金不变，每天有利息。但这种计价方式也有风险：当基金投资的债券出现违约或利率急剧上升导致浮亏时，摊余成本法可能掩盖真实亏损，引发挤兑。2008年美国储备基金就因雷曼兄弟倒闭导致商业票据亏损，净值跌破1美元（"破一块"），引发货币基金恐慌性赎回。

```python
# 货币基金收益率计算示例：7日年化收益率
def calculate_7day_annualized(daily_returns):
    """
    计算7日年化收益率
    daily_returns: 最近7天每万份收益(元)
    """
    total_7day_return = sum(daily_returns)
    annualized = (total_7day_return / 10000) * (365 / 7) * 100
    return annualized

# 示例：某货币基金最近7天每万份收益
recent = [0.45, 0.48, 0.52, 0.46, 0.50, 0.47, 0.49]
result = calculate_7day_annualized(recent)
print(f"7日总收益: {sum(recent):.2f}元/万份")
print(f"7日年化收益率: {result:.3f}%")

# 对比活期存款
demand_rate = 0.35
print(f"活期存款年利率: {demand_rate}%")
print(f"超额收益: {result - demand_rate:.3f}个百分点")
```

理解了货币基金的本质，你就明白余额宝不是什么颠覆性创新，而是利率管制下的套利产品。当银行间市场利率和存款利率之间的利差缩小，货币基金的吸引力就会下降。2023年以来中国货币基金收益率普遍在1.5%-2%之间，远低于2013年的6%，就是这个原因。

> 余额宝教会中国人的不是金融知识，而是一个行为习惯：闲钱也可以理财。这个习惯一旦养成，比任何金融产品本身都有价值。

需求先行还是产品先行？货币基金是典型的需求先行。1971年美国投资者需要绕过利率管制，2013年中国投资者需要活期存款的替代品。需求一直在那里，货币基金只是提供了满足需求的工具。余额宝的成功不在于产品创新，而在于渠道创新——把货币基金的购买门槛降到了1元，把操作嵌入到日常支付场景中。

## 6.7 养老金与社保基金 — 所有人的未来保障：代际转移与人口老龄化挑战

养老金可能是和每个人都关系最密切的基金。不管你关不关心金融市场，你的养老金都在市场中运作。

全球养老金体系基本遵循"三支柱"模型，这是世界银行在1994年提出的框架：

```
第一支柱：公共养老金(政府主导，现收现付制)
    |   中国：基本养老保险
    |   美国：Social Security
    |   特点：强制参加，代际转移，保基本
    |
第二支柱：职业养老金(雇主主导，积累制)
    |   中国：企业年金/职业年金
    |   美国：401(k)计划
    |   特点：雇主员工共同缴费，投资增值
    |
第三支柱：个人养老金(个人主导，积累制)
        中国：个人养老金账户(2022年启动)
        美国：Individual Retirement Account (IRA)
        特点：自愿参加，税收优惠，自主投资
```

第一支柱的"现收现付制"（Pay-As-You-Go, PAYG）是最关键的设计——当前工作的人缴费，当前退休的人领取。这个制度在人口结构年轻时运转良好，但遇到人口老龄化就出问题了。中国的情况尤其严峻：2023年60岁以上人口占比已达20%，预计2035年超过30%。抚养比（劳动人口/退休人口）从2010年的5:1下降到2023年的2.5:1，预计2050年将降至1.5:1。

这意味着什么？简单算：2010年5个工作人养1个退休人，每人分担20%；2050年1.5个工作人养1个退休人，每人分担67%。如果保持现有缴费率和替代率不变，养老金体系将面临巨大缺口。

养老金基金的投资运作有一个核心矛盾：安全性与收益性的平衡。养老金是"养命钱"，不能承受大波动；但养老金是长期资金（投资周期30-40年），如果只投债券和存款，长期收益率跑不赢通胀，实际购买力会缩水。

来看一组数据：假设初始养老金积累100万元，30年后退休时：

| 年化收益率 | 30年后金额 | 实际购买力(假设3%通胀) |
|-----------|-----------|---------------------|
| 2%(存款/债券) | 181万 | 75万(缩水25%) |
| 5%(均衡配置) | 432万 | 178万(增值78%) |
| 8%(偏股配置) | 1006万 | 415万(增值315%) |
| 10%(全股票) | 1745万 | 720万(增值620%) |

这个表格说明一个残酷的事实：用"最安全"的方式管理养老金，长期来看反而是最危险的。通胀是养老金最大的敌人，而只有权益资产才能长期跑赢通胀。

> 养老金管理的核心不是"不亏钱"，而是"30年后还有差不多的购买力"。短期安全感和长期安全感，往往是矛盾的。

各国养老金基金的投资实践也印证了这一点。加拿大养老金计划投资委员会（CPPIB）的年化收益率约10%，其配置中超过50%是权益资产。挪威政府养老基金（GPFG）股票配置约70%。中国的全国社保基金理事会，权益类资产配置比例也在30%-40%之间，过去20年年化收益率约8%。

需求先行还是产品先行？养老金是需求先行。养老是人类最基本的需求之一，先有"老有所养"的社会需求，才有了养老金制度的建立和养老金基金的投资运作。人口结构的变化正在倒逼养老金体系改革，第三支柱个人养老金的推出就是回应这一需求。

## 6.8 主权财富基金 — 国家资本的投资工具：挪威模式和中投公司

如果说养老金基金是"代际储蓄"，那主权财富基金（Sovereign Wealth Fund, SWF）就是"国家储蓄"。两者逻辑相似：把当下的盈余存起来，留待未来使用。区别在于，主权财富基金管理的是国家层面的财政盈余，通常来自自然资源出口收入或外汇储备。

主权财富基金的起源可以追溯到1953年。科威特投资局（Kuwait Investment Authority）成立了第一只主权财富基金——科威特投资局，用石油出口收入进行长期投资。此后，阿布扎比投资局（ADIA，1976年）、新加坡政府投资公司（GIC，1981年）、挪威政府养老基金（GPFG，1990年）相继成立。

截至目前，全球主权财富基金管理资产总规模超过11万亿美元。其中挪威政府养老基金全球（Government Pension Fund Global, GPFG）规模约1.5万亿美元，是全球最大的主权财富基金。中国投资有限责任公司（China Investment Corporation, CIC，简称中投公司）成立于2007年，管理资产约1.3万亿美元，是全球第二大。

挪威模式被广泛认为是主权财富基金管理的标杆。它的核心特征有三个：第一，高度透明，基金每日公布市值，季度披露全部持仓；第二，严格限制投资范围，不投资烟草、煤炭、争议性武器等；第三，严格的支出规则，基金每年最多向财政提取3%的市值（2017年调整为3%的实际回报率），避免石油收入被挥霍。

中投公司的模式有所不同。中投下设三个主要业务板块：中投国际（负责海外多元化投资）、中投海外（负责海外直接投资）和中央汇金（负责国内金融机构注资）。中投的透明度相对较低，不公开全部持仓，但每年发布年报披露总体业绩。

主权财富基金的投资策略通常分为两类：稳定型基金（Stabilization Fund）和储蓄型基金（Savings Fund）。稳定型基金目标是在商品价格低迷时为财政提供缓冲，流动性要求高，配置以债券为主。储蓄型基金目标是将不可再生资源转化为长期金融资产，可以承受更高波动，权益配置比例更高。

> 主权财富基金的本质是"把地下的石油变成桌上的股票"——把不可再生的自然资源财富，转化为可持续的金融资产收益。

需求先行还是产品先行？主权财富基金是需求先行。国家有了财政盈余（通常是资源出口收入），面临的问题是：钱怎么管才能保值增值、不被通胀侵蚀？主权财富基金就是回应这个需求的工具。挪威在发现北海油田后，议会花了多年讨论如何管理石油收入，最终决定设立基金。需求先于产品，产品只是执行需求的载体。

## 6.9 基金评级与业绩评价 — 如何选基金：晨星评级、夏普比率与最大回撤

知道了基金的种类，下一个问题是：怎么选具体哪只基金？这一节怕浪猫来教你几个核心的评价指标和选基方法论。

先说新手最常犯的错误：看排行榜选基金。很多平台会展示"近一年收益率排名"，投资者看到第一名就买。问题是，去年的冠军基金今年很可能垫底。这种现象在金融学中叫"持续性缺失"——基金业绩的持续性远比人们想象的弱。

真正有用的基金评价工具是以下几个指标：

**晨星评级（Morningstar Rating）**。晨星公司开发的星级评价体系，用1-5星评价基金的历史风险调整后收益。评级方法是将同类基金过去3年、5年、10年的风险调整后收益排名，前10%得5星，接下来22.5%得4星，中间35%得3星，再接下来22.5%得2星，最后10%得1星。晨星评级的核心价值在于"同类比较"——它不会拿债券基金和股票基金比，而是在同一类别内排名。

但晨星评级有一个重要局限：它是回溯性的，反映的是过去业绩，不代表未来表现。晨星自己的研究显示，5星基金未来1年仍然保持5星的概率只有约30%。

**夏普比率（Sharpe Ratio）**是衡量风险调整后收益的核心指标，由诺贝尔奖得主威廉·夏普（William Sharpe）提出。计算公式为：

```python
# 夏普比率计算逻辑
def sharpe_ratio(returns, risk_free_rate=0.02, periods=252):
    """
    计算年化夏普比率
    returns: 日收益率序列
    risk_free_rate: 年化无风险利率
    periods: 一年交易日天数(252用于股票市场)
    """
    import numpy as np
    
    # 超额收益(日)
    excess_returns = returns - risk_free_rate / periods
    
    # 年化夏普比率 = 年化超额收益 / 年化标准差
    annual_excess_return = np.mean(excess_returns) * periods
    annual_volatility = np.std(excess_returns, ddof=1) * np.sqrt(periods)
    
    sharpe = annual_excess_return / annual_volatility
    return sharpe

# 示例：两只基金对比
# 基金A：年化收益15%，年化波动20%
# 基金B：年化收益12%，年化波动12%
# 无风险利率2%
sharpe_A = (0.15 - 0.02) / 0.20  # = 0.65
sharpe_B = (0.12 - 0.02) / 0.12  # = 0.83
# 基金B收益更低但夏普比率更高，说明风险效率更好
print(f"基金A夏普比率: {sharpe_A:.2f}")
print(f"基金B夏普比率: {sharpe_B:.2f}")
print(f"结论：基金B的风险调整后收益优于基金A")
```

夏普比率的解读标准：低于1.0算一般，1.0-2.0算不错，2.0以上算优秀。但夏普比率也有局限：它假设收益率服从正态分布，而实际市场有明显的肥尾效应（极端事件比正态分布预测的更频繁）。在极端行情下，夏普比率可能高估策略的真实风险水平。

**最大回撤（Maximum Drawdown, MDD）**衡量的是从历史最高点到最低点的最大跌幅。这个指标直击痛点：投资者最怕的不是年化波动率，而是"我的账户最多能亏多少"。

> 新手看收益率选基金，老手看夏普比率选基金，高手看最大回撤选基金。区别在于：新手只看收益不看风险，老手懂得风险调整后的收益才有意义，高手知道极端情况下的生存比常态下的表现更重要。

下面这个表汇总了基金评价的核心指标体系：

| 指标 | 含义 | 优点 | 局限 | 适用场景 |
|------|------|------|------|----------|
| 绝对收益率 | 一定时期内的总回报 | 直观易懂 | 不考虑风险 | 初筛参考 |
| 夏普比率 | 单位风险的超额收益 | 风险调整，可比性强 | 假设正态分布 | 同类基金横比 |
| 最大回撤 | 峰到谷的最大跌幅 | 反映极端风险 | 依赖历史区间 | 评估持有体验 |
| 晨星评级 | 综合星级评价 | 简单直观，同类可比 | 纯回溯性 | 辅助参考 |
| 信息比率 | 超额收益/跟踪误差 | 衡量主动管理能力 | 需要明确基准 | 评价主动基金 |
| 卡尔玛比率 | 年化收益/最大回撤 | 兼顾收益和极端风险 | 依赖历史 | 评估下行风险 |

需求先行还是产品先行？基金评价体系是需求先行。投资者先有了"怎么判断基金好坏"的需求，然后才有了晨星评级、夏普比率等评价工具。值得注意的是，评价体系本身也是一种"产品"，好的评价体系能反过来引导投资者行为，比如夏普比率的普及让投资者开始关注风险而非只看收益。

## 6.10 ESG投资 — 赚钱与价值观的平衡：不是做慈善而是规避长期风险

ESG是近年来资产管理行业最热门的概念之一。Environmental Social Governance（ESG）即环境、社会和公司治理三个维度的缩写。ESG投资是指在投资决策中除财务因素外，还考虑企业的环境表现、社会责任和治理水平。

ESG投资不是做慈善。它的核心逻辑是：ESG因素实质上是长期风险的代理变量。环境表现差的企业面临监管处罚、碳排放成本上升的风险；社会责任缺失的企业面临声誉风险和消费者抵制；治理混乱的企业面临经营风险和诉讼风险。把这些风险量化到投资决策中，不是为了道德，而是为了规避长期风险。

ESG理念的起源可以追溯到2006年联合国责任投资原则（United Nations Principles for Responsible Investment, UN PRI）的发布。PRI提出了六条负责任投资原则，号召机构投资者将ESG因素纳入投资分析和决策。截至2024年，全球PRI签署方管理资产超过120万亿美元。

ESG投资的具体策略可以分为几个层次：

| 策略类型 | 做法 | 举例 |
|---------|------|------|
| 排除筛选 | 剔除特定行业或公司 | 不投烟草、煤炭、武器 |
| 积极筛选 | 在同类中优选ESG表现好的 | 选ESG评分前30%的公司 |
| 主题投资 | 专注ESG相关主题 | 清洁能源基金、水资源基金 |
| 整合策略 | 将ESG因素融入传统财务分析 | 调整现金流模型中的风险溢价 |
| 股东参与 | 用投票权推动企业改善ESG | 提交股东提案、投票反对董事 |

ESG投资在实践中面临几个核心争议。第一是"漂绿"（Greenwashing）问题——有些基金贴上ESG标签只是为了营销，实际持仓和普通基金差异不大。第二是评级标准不统一——不同ESG评级机构对同一家公司的评分可能差异巨大。第三是收益争议——ESG投资到底能不能跑赢市场？学术研究的结论并不一致，部分研究显示高ESG评分公司长期收益更好，但也有研究认为差异不显著。

> ESG投资的终极矛盾：如果ESG真的能带来超额收益，那它已经反映在价格中，未来不会有超额收益；如果ESG不能带来超额收益，那投资者为什么要为它牺牲分散化？

尽管有争议，ESG投资的趋势不可逆转。一个重要推动力是监管要求。欧盟2021年实施的可持续金融披露条例（Sustainable Finance Disclosure Regulation, SFDR）要求基金产品按ESG程度分级披露。中国也在推进ESG信息披露要求，证监会和交易所陆续出台了上市公司ESG报告指引。监管推动意味着ESG不再只是"可选项"，而是逐渐成为"必选项"。

需求先行还是产品先行？ESG投资是需求先行。最早的ESG投资来自宗教团体（不投烟草、赌博、武器）和北欧养老金（要求长期可持续投资），先有价值观驱动的需求，后有ESG产品体系。但近年来的爆发式增长中，监管推动和产品创新也在反向创造需求——很多投资者是在ESG基金出现后，才意识到投资可以兼顾价值观。

## 本章小结：需求先行 vs 产品先行

回顾本章十个知识点，我们可以画一张清晰的分类表：

| 知识点 | 需求先行 or 产品先行 | 核心驱动力 |
|-------|---------------------|-----------|
| 6.1 基金起源 | 需求先行 | 投资者需要专业管理和分散投资 |
| 6.2 公募vs私募 | 产品先行 | 金融从业者突破公募限制的创新 |
| 6.3 股票/债券/混合型 | 需求先行 | 不同风险偏好的投资者分层需求 |
| 6.4 指数基金与ETF | 产品先行(理念先行) | 博格的认知创新引领产品创造 |
| 6.5 对冲基金 | 产品先行 | 策略创新先于资金需求 |
| 6.6 货币市场基金 | 需求先行 | 利率管制下的套利需求 |
| 6.7 养老金与社保 | 需求先行 | 养老是最基本的社会需求 |
| 6.8 主权财富基金 | 需求先行 | 国家财政盈余的管理需求 |
| 6.9 基金评级与评价 | 需求先行 | 投资者需要判断基金好坏的工具 |
| 6.10 ESG投资 | 需求先行(初期) | 价值观驱动的投资需求 |

从这张表可以看出一个规律：**大多数基金产品创新是需求驱动的**。当投资者有了某种未被满足的需求（更高收益、更低风险、更多流动性、更符合价值观），金融市场就会设计出相应的产品。但也有少数重要创新是产品先行的——指数基金和对冲基金是典型例子，从业者的认知和策略创新领先于投资者需求。

> 金融产品创新的本质只有两种：要么回应已有的需求，要么创造新的需求。前者是填空题，后者是作文题。作文题更难，但一旦做对，影响也更大。

基金和资产管理行业一百多年的发展史，就是一部"需求与产品互相驱动"的历史。投资者提出需求，从业者设计产品，产品创造新的需求，新需求催生新的产品。这个循环不会停止。下一章我们会聊什么？先卖个关子。
