# 02 阿里巴巴 — 电商生态的商业操作系统

> 一句话定位：以电商为核心、云计算为第二增长曲线、菜鸟物流为基础设施的商业操作系统。

---

## 1. 公司速写

- **成立时间**：1999年

- **上市**：美股BABA / 港股9988.HK

## 3. 运营模式

### 3.1 平台运营
- **流量分发**：搜索+推荐双引擎，搜索承载购物流量，推荐承担内容化
- **商家分层**：天猫品牌商家(佣金+广告)、淘宝C店(免费+广告)、1688批发(会员费)
- **大促节点**：双11、618造节，集中释放消费需求

### 3.2 商家服务体系
- 经营工具：千牛卖家中心、生意参谋数据工具
- 金融服务：网商银行提供商家贷款
- 物流服务：菜鸟仓配+第三方快递
- 营销工具：直通车(搜索广告)、引力魔方(推荐广告)、万相台

### 3.3 内容化转型
- 淘宝直播：李佳琦等头部主播，直播带货
- 淘宝逛逛：种草内容社区
- 淘宝短视频：短视频导购

## 4. 盈利模式

### 4.1 收入结构(2024财年)
| 业务板块 | 收入(亿元) | 占比 |
|---------|-----------|------|
| 中国商业(淘天) | 5800+ | 65% |

| 本地生活/大文娱等 | 800+ | 9% |
| **合计** | **9400+** | **100%** |

### 4.2 淘天核心变现
```
商家入驻天猫
  ├──→ 软件服务费(年费+佣金，2-5%)
  ├──→ 广告费(直通车CPC、引力魔方CPM、品牌广告)
  └──→ 增值服务(装修、数据、营销工具)

淘宝C店
  └──→ 广告费为主要变现

天猫超市/天猫国际
  └──→ 自营模式：商品差价
```

### 4.3 各业务利润贡献
- **淘天**：利润奶牛，EBITA利润率60%+
- **云**：已扭亏，利润率持续改善
- **菜鸟**：微利，战略价值大于财务
- **本地生活/大文娱**：仍亏损

## 6. 战略观察

### 当前重点方向
- **用户为先**：DAU导向，从GMV导向转向用户粘性导向
- **AI驱动**：通义大模型全面接入淘天、云、钉钉
- **出海**：速卖通Choice频道+Lazada+Trendyol组合拳
- **云业务**：AI算力驱动云收入增速回升

### 潜在风险
- 拼多多对下沉市场和价格敏感用户的持续蚕食
- 抖音电商对品牌广告预算的分流
- 京东在3C家电品类的竞争
- 监管：平台经济反垄断、数据安全
