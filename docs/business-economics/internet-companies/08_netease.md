## 3. 运营模式

### 3.1 游戏精品化运营
- **自研为主**：强研发能力，IP长线运营(梦幻西游20年+)
- **品类矩阵**：MMO、二次元、休闲、竞技多品类覆盖
- **出海日本**：荒野行动/第五人格在日本市场成功

### 3.2 音乐差异化
- **社区氛围**：评论区UGC文化，"音乐+社交"差异化
- **原创音乐人**：扶持独立音乐人，构建版权护城河
- **云贝/黑胶VIP**：付费会员+社交功能变现

### 3.3 有道教育
- 工具+内容+硬件三位一体
- 学习硬件(词典笔)成为新增长点

### 3.4 严选DTC
- 工厂直连消费者，去除品牌溢价
- 自有品牌品质背书

## 4. 盈利模式

### 4.1 收入结构(2024年)
| 业务板块 | 收入(亿元) | 占比 |
|---------|-----------|------|
| 游戏 | 800+ | 78% |
| 有道(教育) | 60+ | 6% |
| 云音乐 | 90+ | 9% |
| 创新业务(严选等) | 80+ | 7% |
| **合计** | **1030+** | **100%** |

### 4.2 游戏变现
```
游戏研发 ──→ 上线运营
  ├──→ 游戏内购(道具/通行证/皮肤)
  ├──→ 广告收入(部分休闲游戏)
  └──→ IP授权(影视/周边)
```

### 4.3 各业务利润贡献
- 游戏：高毛利(60%+)，利润绝对主力
- 云音乐：内容成本高，已小幅盈利
- 有道：教育硬件微利
- 严选：微利

## 6. 战略观察

### 当前重点方向
- **AI+游戏**：伏羲AI大模型赋能游戏NPC/美术/测试
- **全球化**：永劫无间手游全球发行、日本市场深耕
- **新品类拓展**：蛋仔派对之后的休闲赛道布局
- **云音乐盈利**：控制版权成本，提升付费率

### 潜在风险
- 游戏行业政策依赖(版号)
- 腾讯游戏强势竞争
- 新爆款不确定性强(蛋仔之后待验证)
- 云音乐版权成本压力
- 有道教育"双减"后转型阵痛
