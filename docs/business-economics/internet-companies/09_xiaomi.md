## 3. 运营模式

### 3.1 硬件铁三角
```
手机(入口) ──→ IoT设备(生态) ──→ 汽车(第二入口)
     │              │                │
     └── 互联网服务变现 ←── 数据+用户+流量 ←──┘
```

### 3.2 性价比模式
- **硬件综合净利率≤5%承诺**(2018年做出)
- 低毛利硬件获客 → 互联网服务高毛利变现
- 生态链"投资+孵化"模式：参股不控股，输出品牌+渠道+供应链

### 3.3 新零售渠道
- 小米之家：坪效行业领先
- 线上线下一体化：小米商城+京东/天猫旗舰店+线下门店
- 渠道下沉：县城门店覆盖

### 3.4 汽车业务运营
- 直营模式：小米汽车App+小米之家展示
- 人车家全生态：手机/车机/IoT互联
- 产能爬坡：北京工厂二期建设中

### 3.5 全球化运营
- 手机海外出货占比55%+
- 印度/东南亚/欧洲/拉美多区域布局
- 本地化生产+本地化营销

## 4. 盈利模式

### 4.1 收入结构(2024年)
| 业务板块 | 收入(亿元) | 占比 |
|---------|-----------|------|
| 智能手机 | 1900+ | 53% |
| IoT与生活消费 | 1000+ | 28% |
| 互联网服务 | 450+ | 12% |
| 智能汽车 | 300+ | 8% |
| **合计** | **3650+** | **100%** |

### 4.2 利润结构特征
- 硬件(手机+IoT)毛利低：15-20%
- 互联网服务毛利高：70%+
- 互联网服务收入占比12%，但贡献利润50%+
- 汽车业务短期亏损(研发+产能投入)

### 4.3 互联网服务变现
```
硬件用户(免费/低价)
  └──→ MIUI/HyperOS用户
       ├──→ 广告收入(系统广告+浏览器+应用商店)
       ├──→ 游戏分发(联运分成)
       ├──→ 会员订阅(小米会员)
       └──→ 互联网金融服务(分期/保险)
```

## 6. 战略观察

### 当前重点方向
- **高端化**：小米14/15系列冲击4000-6000元价位
- **汽车放量**：SU7 Pro/YU7等新车型，产能爬坡
- **AI全生态**：小爱同学大模型升级+人车家互联
- **自研芯片**：澎湃SoC/ISP/通信芯片
- **全球化深耕**：欧洲高端市场+东南亚/拉美渗透

### 潜在风险
- 手机毛利率提升困难
- 汽车业务资金消耗大
- 芯片/供应链地缘政治风险
- 国内手机市场存量竞争
- IoT生态竞争(华为全屋智能)
