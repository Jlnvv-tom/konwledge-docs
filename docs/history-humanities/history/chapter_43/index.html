第43章 徐阶倒严，廓清朝堂

一个人在仇人手下隐忍十余年，每天陪着笑脸、写着颂词、把亲孙子送到仇人家里当孙子的玩伴，甚至眼睁睁看着自己的学生被仇人害死而不敢吭声——这不是懦夫，这是大明官场最顶级的猎手。徐阶，用十五年的隐忍，等来了一个扶乩的道士、一道弹劾的奏疏，就把权倾天下二十年的严嵩掀翻在地，连根拔起。严嵩八十岁罢官归乡，寄食墓舍而死；严世蕃斩首西市，严党灰飞烟灭。这场大明嘉靖朝最惊心动魄的政治绞杀战，教科书上不会教你，但官场上每天都在上演。

我是怕浪猫，今天带你走进大明通史第四十三章——徐阶如何隐忍十五年，一步步扳倒严嵩父子，廓清嘉靖朝最后的政治迷雾。这一章的信息量极大，建议先收藏再阅读。

43.1 徐阶隐忍：严嵩阴影下的韬光养晦​

43.1.1 徐阶入阁与隐忍策略​

要讲徐阶倒严，得先从徐阶这个人说起。

徐阶，字子升，号少湖，南直隶松江府华亭县人（今上海市松江区）。生于弘治十六年（1503年），嘉靖二年（1523年）进士第三名——探花及第。这个成绩相当了不得，全国第三，直接授翰林院编修，入了储相之路。

徐阶的早年并不顺遂。嘉靖九年（1530年），世宗朱厚熜想要改革孔庙祭祀礼仪，张璁（时任礼部尚书，后任首辅）附和世宗，主张降低孔子祭祀规格。徐阶当时只是翰林院一个小小的编修，却上疏坚决反对。据《明史·徐阶传》记载，徐阶在奏疏中引经据典，论证孔子祭祀之礼不可更改，言辞颇为激切。世宗大怒，将徐阶廷杖后贬为延平府推官——从京城翰林院一下子踢到福建延平府（今福建南平）当了一个基层司法官。

这一贬，对徐阶来说既是打击也是磨砺。他在地方上任上兢兢业业，处理政务、平反冤狱，逐步升迁。从延平推官到湖广按察佥事，再到江西按察副使，辗转多地，积累了丰富的地方行政经验。更重要的是，这段经历让他深刻明白了一个道理：在嘉靖朝的官场上，硬碰硬是会死人的。

嘉靖十八年（1539年），徐阶被召回京城，任司经局洗马兼翰林院侍讲。此后逐步升迁，嘉靖二十六年（1547年）升任礼部尚书，嘉靖二十八年（1549年）以礼部尚书兼文渊阁大学士，入阁参预机务。

而此时内阁的首辅，正是严嵩。

严嵩，字惟中，号介溪，江西分宜县人。弘治十八年（1505年）进士，比徐阶早了十八年。严嵩从嘉靖二十一年（1542年）入阁，嘉靖二十三年（1544年）升任首辅，到徐阶入阁时已经当了五年首辅，权势正盛。更要命的是，严嵩有一个比他更难对付的儿子——严世蕃。

严世蕃，号东楼，是严嵩的独子。此人没有通过科举考试（靠恩荫入仕），但智商极高，号称"嘉靖朝第一聪明人"。据《明史·奸臣传》记载，严世蕃"颇通国典，晓畅时务"，而且有一种特殊本事——他能精准揣摩世宗的心思。世宗深居西苑，不上朝，通过传旨和批折处理政务，很多时候旨意写得含糊不清，满朝文武看不懂，只有严世蕃能准确解读。严嵩年纪大了，精力不济，很多奏折的拟稿和批答实际上都是严世蕃代劳的。严嵩曾对人坦言："朝廷上那些事，我老夫是靠儿子撑着的。"

徐阶入阁时面对的就是这样一个对手：首辅严嵩根深蒂固，其子严世蕃聪明绝顶，父子联手把持朝政，顺我者昌逆我者亡。此前已经有多少人试图挑战严嵩？沈鍊上疏弹劾严嵩十大罪，被贬谪后又遭严嵩构陷，最终被杀。杨继盛上疏弹劾严嵩十大罪五奸，被廷杖下狱，三年后处死。王宗茂、赵锦、吴时来……一个个弹劾严嵩的官员，要么被贬谪，要么被下狱，要么被处死，无一善终。

政治斗争的第一法则不是"能不能打赢"，而是"能不能活到打赢的那一天"。徐阶深谙此道。他入阁后的第一个策略，就是两个字：隐忍。

徐阶的隐忍不是被动的忍气吞声，而是一套精心设计的政治策略。据《明史·徐阶传》记载，徐阶入阁后"事嵩益谨"——侍奉严嵩更加恭敬谨慎。凡内阁议事，徐阶总是最后一个发言，且从不当面反驳严嵩的意见。严嵩拟定的票拟，徐阶照着批红，一字不改。严嵩做出的决定，徐阶坚决执行，从不掣肘。

这种低姿态让严嵩逐渐放松了对徐阶的警惕。严嵩此人虽然奸诈，但有一个弱点：他判断人的标准很简单——顺我者就是好人，逆我者就是坏人。徐阶既然表现得如此恭顺，严嵩便觉得此人可用，甚至开始把一些不太重要的政务交给徐阶处理。

但徐阶在暗地里做了三件事，这三件事最终成为扳倒严嵩的关键。

43.1.2 暗中搜集严嵩罪证​

第一件事：暗中搜集严嵩父子的罪证。

徐阶深知，要扳倒严嵩，光有弹劾奏疏是没用的——此前那么多人弹劾都失败了，因为世宗信任严嵩，不信言官。必须搜集到铁证如山的罪证，在合适的时机一举出击，才能一击致命。

徐阶搜集罪证的方式极为隐蔽。他不亲自出面，而是通过自己的门生故旧，在各个衙门中安插眼线，长期监控严党的一举一动。严世蕃贪赃枉法的事太多了——卖官鬻爵、侵占民田、收受贿赂、干预司法，几乎无恶不作。据《国榷》记载，严世蕃通过其妻弟严鹄等人，在老家江西分宜以及京畿一带大肆兼并土地，良田数万顷，家产富可敌国。这些罪证，徐阶一条一条都记在心里，但不急，时机未到。

同时，徐阶还密切关注严嵩在内阁中的行事轨迹——哪些奏折被严嵩压下了，哪些人事任命是严嵩暗箱操作的，哪些军事决策是严嵩干预的。这些信息看似零散，但汇总起来就是一张严嵩以权谋私的完整拼图。

43.1.3 迎合世宗与麻痹严嵩​

第二件事：迎合世宗，获取皇帝信任。

这是徐阶隐忍策略中最精妙也最危险的一环。严嵩之所以能横行二十年，根本原因在于世宗朱厚熜的信任。要扳倒严嵩，首先要动摇世宗对严嵩的信任，而要动摇这份信任，徐阶自己必须先获得世宗的信任。

世宗中后期痴迷道教，长居西苑修道，朝廷政务几乎全靠内阁和司礼监运转。世宗最关心的事情有两件：一是青词（道教斋醮时焚烧的祝文，用朱砂写在青藤纸上），二是祥瑞。

青词这东西，说白了就是写给神仙的信，要求文辞华美、对仗工整。世宗极其看重青词的质量，甚至以青词写得好不好来评判大臣的才干。严嵩之所以得宠，一个重要原因就是他写的青词极好——史称"青词宰相"。据《明史·严嵩传》记载，严嵩"为诗古文辞，皆典雅瑰丽"，尤其擅长撰写青词，深得世宗欢心。

徐阶入阁后，也开始刻苦钻研青词写作。据《明史·徐阶传》记载，徐阶"乃益精心斋醮，有所撰述，帝辄善之"——他更加用心地撰写斋醮文书，每有所作，世宗都很满意。徐阶本来就是探花出身，文笔一流，稍加用心就能写出极好的青词。渐渐地，世宗开始觉得徐阶的青词比严嵩写得还好——毕竟严嵩年纪大了，思维和文笔都有所退化。

除了青词，徐阶还敏锐地抓住了世宗的另一个心理需求：祥瑞。世宗修道，最盼祥瑞降临以证道法灵验。徐阶在担任礼部尚书期间，凡有祥瑞报告——比如哪里出现了白鹿、哪里长出了嘉禾——他都亲自拟写贺表，极尽颂扬之能事。据《明实录·世宗实录》记载，嘉靖二十九年以后，世宗收到的祥瑞贺表大多出自徐阶之手。

你以为写青词、报祥瑞只是拍马屁？在嘉靖朝的政治语境下，这是跟皇帝建立沟通渠道的唯一方式。世宗不上朝、不见大臣，你连面都见不上，怎么进言？怎么展示才干？青词就是通行证，祥瑞就是敲门砖。徐阶用这些"虚活儿"换来了世宗的信任，而信任，是政治斗争中最稀缺的资源。

43.1.4 徐阶与严嵩表面合作​

第三件事：维持与严嵩的表面合作关系。

这一步最为考验人的心理素质。徐阶不仅要对严嵩恭敬有加，还要在关键时刻配合严嵩的决策，甚至不惜牺牲自己的政治声誉。

最典型的例子是嘉靖二十九年（1550年）的"庚戌之变"。这一年，蒙古俺答汗率军大举入侵，兵临北京城下。严嵩主张不抵抗，认为蒙古人抢够了自然会走。兵部尚书丁汝夔请示严嵩如何应敌，严嵩说："塞上败，可掩也；京城下败，谁掩之？不如坚壁勿战。"——边关打败仗可以隐瞒，京城下打败仗怎么隐瞒？不如坚守不战。结果丁汝夔听从严嵩的建议，不发兵迎敌，任由俺答汗在北京郊外抢掠了八天，满载而去。

事后，朝野震怒，要求追究责任。严嵩为了推卸责任，把丁汝夔抛出去当替罪羊。丁汝夔被下狱处死。而徐阶在这个过程中，没有公开反对严嵩，也没有为丁汝夔说话。他选择了沉默。

这不是怯懦，这是战略。徐阶很清楚，在严嵩权势最盛的时候跳出来反对，只会重蹈杨继盛的覆辙。他需要等待——等待严嵩犯错，等待世宗对严嵩心生厌倦，等待一个合适的时机。

再比如沈鍊事件。沈鍊是锦衣卫经历，嘉靖三十年（1551年）上疏弹劾严嵩十大罪，言辞极为激烈。严嵩大怒，将沈鍊廷杖后贬至保安州（今河北涿鹿）。后来严嵩又指使党羽诬陷沈鍊谋反，将其杀害。沈鍊是徐阶的旧交，但徐阶在整个过程中没有出手相救。这件事后来被很多人批评，认为徐阶太过冷血。但如果站在徐阶的角度想——他如果出手救沈鍊，就等于暴露了自己反严的立场，严嵩必然会先对他下手，那日后还有谁能为沈鍊报仇？

还有杨继盛事件。杨继盛是徐阶担任国子监祭酒时的门生，嘉靖三十二年（1553年）上疏弹劾严嵩十大罪五奸，震惊朝野。杨继盛被下狱廷杖，打得皮开肉绽，在狱中关了三年。据《明史·杨继盛传》记载，杨继盛在狱中曾写过血书，言辞悲壮。徐阶在这三年里暗中照顾过杨继盛的家人，但始终没有公开为杨继盛求情。嘉靖三十四年（1555年），杨继盛被处死。

杨继盛之死，对徐阶的刺激极大。据后来的史料记载，徐阶在杨继盛死后更加坚定了扳倒严嵩的决心。但他依然选择了隐忍——因为他知道，杨继盛的死不是终点，而是起点。每一滴直言者的血，都在侵蚀世宗对严嵩的信任基础。徐阶要做的，是在这个基础上再加上最后一块石头。

43.1.5 徐阶隐忍多年的政治智慧​

我们来梳理一下徐阶隐忍策略的核心逻辑。

可以用一张"隐忍博弈模型"来概括：

隐忍博弈三要素：
┌─────────────┬──────────────────────────────────────┐
│ 要素         │ 内涵                                  │
├─────────────┼──────────────────────────────────────┤
│ 1. 弱势伪装  │ 表现恭顺，消除对手警惕                │
│ 2. 暗蓄力量  │ 收集罪证，培植人脉，获取皇帝信任       │
│ 3. 等待战机  │ 不主动出击，等对手犯错或外部条件变化    │
└─────────────┴──────────────────────────────────────┘

这三个要素缺一不可。没有弱势伪装，严嵩早就对他下手了；没有暗蓄力量，就算等到机会也抓不住；没有等待战机的耐心，就会像沈鍊、杨继盛一样功亏一篑。

徐阶的隐忍，从嘉靖二十八年（1549年）入阁算起，到嘉靖四十一年（1562年）严嵩倒台，整整十三年。十三年里，他每一天都在演戏，每一天都在等待，每一天都在暗暗积蓄力量。这种心理素质，已经超越了普通政治家的范畴，堪称一种近乎变态的定力。

有人说徐阶是"大明第一影帝"。这话虽是戏言，却不无道理。在嘉靖朝那个波诡云谲的政治舞台上，能在大反派面前演十三年好人而不露破绽的，除了徐阶，你找不出第二个。但别忘了一句老话：会演的不如会等的，会等的不如会算的。徐阶不仅会演、会等，更会算——他算准了严嵩的命门，算准了世宗的心理，也算准了时机到来的那一刻。

43.2 蓝道行扶乩：世宗对严嵩心生疑虑​

43.2.1 蓝道行扶乩降仙语​

徐阶隐忍了十三年，终于等来了一个意想不到的突破口——一个道士。

嘉靖四十一年（1562年）春，世宗朱厚熜已经步入暮年，修道修了几十年，越来越痴迷于方术。他最信任的方士之一，名叫蓝道行。

蓝道行，山东人，以扶乩术闻名。扶乩，又称"飞鸾"，是道教的一种占卜方式：在沙盘上放一个丁字形的乩笔，由两人扶住乩笔两端，神灵"降附"后乩笔会自行在沙盘上写字，所写之字即为神灵的旨意。当然，以现代眼光看，扶乩无非是扶乩者的潜意识驱动（或有意操控），但在嘉靖朝的语境下，世宗对此深信不疑。

据《明史·佞幸传》及《国榷》记载，嘉靖四十一年春，世宗在西苑斋醮时，让蓝道行扶乩请仙。蓝道行在沙盘上写出了几句话，大意是："贤不竞用，不肖不退尔。"——贤臣不被重用，不肖之臣不被退黜。世宗追问："谁为贤，谁为不肖？"乩仙答："贤者如徐阶，不肖者如严嵩。"

43.2.2 仙语暗指严嵩奸臣​

世宗又问："严嵩既然是不肖之臣，为何上天不诛之？"乩仙的回答极为巧妙："留待皇帝自诛。"

这句话看似简单，实则暗藏玄机。第一层意思：严嵩确实是奸臣，上天已经认定了；第二层意思：上天不杀他，是给皇帝留面子，让皇帝自己处置。这等于在不直接指责皇帝的前提下，把处置严嵩的责任推给了世宗。

那么问题来了：蓝道行扶乩写出的这些话，到底是真的"仙语"，还是有人事先安排的？

据后世史学家考证，蓝道行与徐阶有着密切的联系。《明史·徐阶传》中虽然没有直接说徐阶指使蓝道行，但多处暗示徐阶事先知道扶乩的内容。而《国榷》的作者谈迁则更直接地指出，蓝道行扶乩的内容是徐阶授意的。谈迁在《国榷》中写道，徐阶"阴使蓝道行扶乩"——暗中指使蓝道行借扶乩之机说出那番话。

无论真相如何，有一点是确定的：蓝道行扶乩事件，是徐阶隐忍多年后发出的第一击。他选择的武器不是弹劾奏疏，不是廷议辩论，而是一个道士的沙盘——因为他太了解世宗了。世宗不信群臣的谏言，不信弹劾的罪状，但他信神仙。通过扶乩之口说出"严嵩是奸臣"，比一百道弹劾奏疏都管用。

43.2.3 世宗信扶乩与态度转变​

扶乩事件对世宗的心理冲击是巨大的。

世宗修了几十年道，对"仙语"有着近乎宗教般的虔诚。当"仙语"指出严嵩是奸臣时，世宗的第一反应不是愤怒，而是震惊——连神仙都说严嵩是奸臣，难道严嵩真的是奸臣？

据《明实录·世宗实录》记载，扶乩之后，世宗召见严嵩时的态度明显发生了变化。此前世宗对严嵩几乎言听计从，扶乩事件后，世宗开始有意无意地疏远严嵩。严嵩呈上的青词，世宗不再像以前那样赞不绝口；严嵩拟定的票拟，世宗有时会驳回要求重拟；严嵩推荐的人选，世宗有时会否决。

对于严嵩来说，这种变化是致命的。因为他的全部权力基础就是世宗的信任，一旦信任动摇，他的权力就如同沙堡一般脆弱。

更让严嵩不安的是，世宗开始越来越多地召见徐阶。据《明史·徐阶传》记载，扶乩事件后，"帝渐亲阶而远嵩"——世宗渐渐亲近徐阶而疏远严嵩。世宗经常单独召见徐阶讨论政务，有时候甚至跳过严嵩直接让徐阶拟旨。这在以前是不可想象的——严嵩当首辅时，所有圣旨都要经过他的手。

43.2.4 严嵩失宠与求救无门​

严嵩意识到了危险，开始设法自救。但他的自救方式，恰恰暴露了他的老迈和无力。

据《明史·严嵩传》记载，严嵩此时已经年过八十（严嵩生于1480年，嘉靖四十一年时已八十二岁），精力严重衰退。他"老病日甚，不能久立"——老病日益严重，连站立都困难。更要命的是，他最依赖的儿子严世蕃此时因为母亲欧阳氏病故，按照礼制必须回江西老家守制——虽然严嵩通过活动让严世蕃留在京城，但严世蕃不能再到内阁值房为父亲代拟奏折了。

没有了严世蕃的脑子，严嵩的政务处理能力急剧下降。据《国榷》记载，严嵩呈给世宗的青词"文理不通，帝颇厌之"——写出来的青词文理不通，世宗很厌烦。要知道，青词质量曾经是严嵩得宠的核心竞争力，如今连这个优势都丧失了。

严嵩还试图通过贿赂蓝道行来挽回局面。据一些史料记载，严嵩派人送去重金，请蓝道行再扶乩时为他说好话。但蓝道行拒绝了——或者说，徐阶不允许蓝道行接受。

严嵩又试图直接向世宗求情。据《明史·严嵩传》记载，严嵩有一次在世宗召见时跪地痛哭，说自己年老力衰，恳请皇帝体恤。世宗的反应很冷淡——对于修道几十年的世宗来说，一个八十老翁的眼泪，远不如"仙语"有说服力。

43.2.5 扶乩事件的政治作用​

我们来分析一下扶乩事件在政治上的作用。

扶乩事件政治传导链：

蓝道行扶乩 → 世宗信"仙语" → 对严嵩心生疑虑
→ 疏远严嵩、亲近徐阶 → 严嵩失宠、无法掌控朝政
→ 为弹劾创造条件 → 严党倒台

关键节点：世宗的心理转变
├── 信神仙 > 信群臣 → 扶乩比弹劾更有效
├── 信任转移：严嵩 → 徐阶
└── 权力转移：首辅实权从严嵩流向徐阶

扶乩事件的核心作用，不在于它揭示了什么新信息——严嵩是奸臣这事，满朝文武都知道。它的作用在于突破了世宗的心理防线。世宗可以无视一百道弹劾奏疏，但他无法无视"神仙"的判语。这就是徐阶的高明之处：他找到了世宗心理防御的薄弱环节，用一个最不可能被拒绝的信息渠道，把"严嵩是奸臣"这个判断植入了世宗的脑海。

在信息战中，信息本身不重要，信息的来源才重要。同样一句"严嵩是奸臣"，杨继盛说了，换来得杖刑和死刑；蓝道行的沙盘上写了，却动摇了皇帝的信任。区别在于：杨继盛是"臣子在说"，蓝道行是"神仙在说"。徐阶深谙此道——他不跟世宗讲道理，他跟世宗的神仙讲道理。

43.3 邹应龙弹劾：严世蕃伏诛，严嵩罢官​

43.3.1 邹应龙上疏弹劾严世蕃​

扶乩事件打开了缺口，但真正给严党致命一击的，是一道弹劾奏疏。

嘉靖四十一年五月，御史邹应龙上疏弹劾严嵩之子严世蕃。邹应龙，字思卿，陕西西安人，嘉靖三十五年（1556年）进士，时任御史。据《明史·邹应龙传》记载，邹应龙的上疏直指严世蕃，列举其"纵淫无度、僭越不法、贪赃枉法、交通夷狄"等罪行，并特别指出严世蕃在其母丧期间"不守制、不理丧，日与群妾宴饮"——在母亲丧期不仅不守孝，还和妾侍们饮酒作乐，这在以孝治天下的明代是极为严重的罪行。

邹应龙的奏疏中有一段极为有名的话："严世蕃罪恶滔天，积秽满道，臣愿以一字一血为疏，伏望陛下大奋乾刚，将严世蕃明正典刑，以谢天下。"——这段话后来被广泛引用，成为明代弹劾文的经典段落。

值得注意的是，邹应龙弹劾的对象是严世蕃而非严嵩。这是徐阶精心设计的策略。为什么不直接弹劾严嵩？因为严嵩毕竟是首辅，且世宗对严嵩还有一定的感情基础——毕竟伺候了二十年。直接弹劾严嵩，世宗可能会下意识维护。但弹劾严世蕃就不一样了——严世蕃不是朝廷命官（他的官职是恩荫所得），严世蕃的罪行都是实实在在的（贪赃枉法有据可查），而且严世蕃在守丧期间淫乐这件事，在道德上完全站不住脚，世宗无法为之辩护。

据《国榷》记载，邹应龙上疏之前，曾秘密见过徐阶。徐阶对他说："此事非言之难，言之而能全其身之为难。"——弹劾不难，难的是弹劾之后还能保住性命。徐阶暗示邹应龙，弹劾严世蕃而非严嵩，这样既能打击严党，又不至于触怒世宗。邹应龙依计行事。

43.3.2 严世蕃下狱与审讯​

邹应龙的奏疏呈上后，世宗的反应出人意料地迅速。据《明实录·世宗实录》记载，世宗看完奏疏后当即下旨："严世蕃着革职下狱，严嵩着回私宅养病。"——严世蕃革职下狱，严嵩勒令退休回家"养病"。

这个处置非常微妙。世宗没有直接处置严嵩，而是让他"回私宅养病"——这等于保留了严嵩的面子，同时剥夺了他的权力。对于严世蕃，世宗则毫不客气地"革职下狱"——这说明在世宗心里，严世蕃的问题比严嵩严重得多。

严世蕃下狱后，案件的审理由三法司（刑部、都察院、大理寺）负责。但三法司的官员大多是严嵩的旧党，审理过程拖拖拉拉。据《明史·邹应龙传》记载，严世蕃在狱中通过贿赂狱卒，与外界保持联系，甚至还在遥控指挥严党的营救活动。

徐阶对此早有预料。他向世宗建议，由刑部尚书黄光升、都察院左都御史张永明、大理寺卿张守直三人会审，同时派锦衣卫全程监审。这一安排确保了审理过程不受严党干扰。

43.3.3 严世蕃以通倭谋反罪处死​

案件的转折点出现在审讯过程中。

三法司原本拟定的罪名主要是贪赃枉法、僭越不法等常规罪名。但徐阶在审阅案卷后，做出了一个关键修改：他建议加入"通倭谋反"的罪名。

据《明史·严世蕃传》记载，严世蕃在与倭寇首领汪直（即王直，明代著名海盗）的通信中被发现有意勾结倭寇，图谋不轨。严世蕃曾派人与汪直联络，意图在东南沿海制造事端，借机要挟朝廷。此外，严世蕃还在江西老家私造府第，"拟逾王者"——规格超过了亲王府邸，这在明代被视为有谋反之心。

徐阶为什么要加入"通倠谋反"的罪名？因为贪赃枉法可死可不死，世宗未必愿意杀严世蕃——毕竟严嵩伺候了二十年，留个后代也是人之常情。但"通倭谋反"就不一样了，这是十恶不赦的大罪，世宗再念旧情也不能容忍谋反。

据《国榷》记载，徐阶亲自修改了三法司的定罪文书，将"通倭谋反"放在最前面，加重了罪名的严重性。然后他命人将定罪文书呈送世宗。

世宗看到"通倭谋反"四字，果然勃然大怒。嘉靖四十一年（1562年）五月，世宗下旨：严世蕃以通倭谋反罪论斩，立决不待时。据《明实录·世宗实录》记载，严世蕃被押赴西市斩首示众，时年五十三岁。临刑前，严世蕃据说面如死灰，与其父严嵩在狱中做最后诀别。严嵩跪在地上，老泪纵横，却无能为力。

严世蕃一死，严党的核心支柱轰然倒塌。严世蕃不仅是严嵩的儿子，更是严嵩的智囊和代理人。严党的日常运作——卖官鬻爵、收受贿赂、打压异己——大部分是严世蕃在操盘。严世蕃死了，严党就成了一盘散沙。

43.3.4 严嵩罢官归乡与寄食墓舍​

严世蕃被处死后，世宗对严嵩的处置也随即到来。嘉靖四十一年五月下旬，世宗下旨：严嵩罢官，勒令回乡。

据《明史·严嵩传》记载，严嵩被革去一切官职和恩荫，遣送回江西分宜老家。曾经权倾天下的首辅，如今成了一个八十多岁的弃翁。更凄惨的是，严嵩的家产被抄没——据《国榷》记载，抄家所得金银珠宝、古玩字画、田产宅第，价值数百万两白银。严嵩连养老的钱都没了。

严嵩回到分宜后，无处安身。据《明史·严嵩传》记载，严嵩"寄食墓舍以死"——寄居在祖宗墓地的守墓房里，靠别人施舍度日。想象一下这个画面：曾经住着京城豪宅、出入有仪仗的首辅，如今住在阴森森的墓舍里，吃了上顿没下顿，身边连个伺候的人都没有。嘉靖四十五年（1566年），严嵩在墓舍中凄凉死去，享年八十六岁。死时身边无亲人，无旧友，甚至连一口像样的棺材都没有。

严嵩的结局，是权力游戏中最经典的反面教材。他从一个小小的翰林院编修起步，靠着写青词和揣摩圣意，爬到首辅的高位，权倾天下二十年。但他忘记了权力最基本的规则：权力是皇帝借给你的，不是你的。皇帝要收回的时候，你连还手的资格都没有。

43.3.5 严嵩倒台过程与教训​

我们来梳理严嵩倒台的完整链条：

严嵩倒台五步走：

第一步：徐阶隐忍（1549-1562）
├── 表面恭顺，麻痹严嵩
├── 暗中收集罪证
└── 获取世宗信任（青词、祥瑞）

第二步：蓝道行扶乩（1562春）
├── 借"仙语"指出严嵩是奸臣
└── 突破世宗心理防线

第三步：邹应龙弹劾（1562五月）
├── 弹劾严世蕃而非严嵩（策略性选择）
└── 罪名：贪赃枉法、僭越不法、守丧淫乐

第四步：严世蕃下狱审讯（1562五月至六月）
├── 徐阶加入"通倭谋反"罪名
└── 世宗大怒，立决不待时

第五步：严嵩罢官归乡（1562五月下旬）
├── 革职抄家
└── 寄食墓舍，凄凉而死（1566）

这五步走，每一步都经过精心设计，每一步都踩在严党的命门上。从隐忍到扶乩，从弹劾到加罪，从处死严世蕃到罢免严嵩，环环相扣，步步紧逼，不给严党任何喘息的机会。这就是徐阶十三年隐忍换来的成果——一击致命，不留后患。

严嵩倒台的教训是什么？表面上看，严嵩输给了徐阶的权谋。但深层看，严嵩输给了自己的贪婪和傲慢。他以为自己能永远掌控世宗的信任，殊不知世宗的信任是最不可靠的东西——它建立在青词和祥瑞这种虚幻的基础上，一旦有更厉害的青词写手出现，一旦有更震撼的"仙语"降临，这份信任就会瞬间转移。严嵩的权力没有制度保障，没有军功支撑，没有民意基础，完全依附于皇帝个人的好恶。这种权力，来得快，去得更快。

43.4 徐阶执政：清算严党，安抚朝野​

43.4.1 徐阶接任首辅与清理严党​

严嵩罢官后，徐阶顺理成章地接任首辅。嘉靖四十一年（1562年）五月，徐阶以武英殿大学士兼吏部尚书的身份正式出任内阁首辅，时年六十岁。

徐阶上任后的第一件事，就是清理严党残余。但他的清理方式非常讲究策略——不是一刀切地全部清洗，而是区分首恶和从犯，有步骤地分批处理。

据《明史·徐阶传》记载，徐阶将严党成员分为三类：第一类是核心成员，即严世蕃的嫡系心腹，如罗龙文、牛信等，这些人参与严世蕃的通倭谋反活动，以谋反罪论处；第二类是中层骨干，即依附严党获取官职但未参与核心犯罪的人，这些人革职查办，但保住性命；第三类是被动附严的普通官员，这些人只要写出检讨、交代问题，就予以宽大处理，继续留任。

这种分层处理的方式，既有效瓦解了严党，又避免了大规模清洗引发的朝局动荡。据《国榷》记载，严党核心被处死和下狱的不到十人，被革职的约三十余人，而被动附严但获得宽大的则有上百人。这个数字相比于严嵩当权时动辄杀人的做法，已经是相当克制了。

43.4.2 平反冤狱与起用直言臣​

徐阶上任后的第二件事，是平反严嵩时期制造的大量冤狱。

严嵩当权二十年，制造了多少冤案？这个数字已经很难精确统计，但可以列举几个重要的：沈鍊案，沈鍊被诬陷谋反而死；杨继盛案，杨继盛因弹劾严嵩被处死；王宗茂案，王宗茂因弹劾严嵩被贬谪；赵锦案，赵锦因弹劾严嵩被下狱……据后世学者统计，因弹劾严嵩而受到处罚的官员超过四十人，其中被处死的至少有五人。

徐阶上台后，逐一为这些冤案平反。据《明实录·世宗实录》记载，嘉靖四十一年六月至十二月间，徐阶主持平反的冤狱包括：沈鍊追赠光禄寺少卿，谥忠愍；杨继盛追赠太常寺少卿，谥忠愍；王宗茂复职；赵锦复职。其他被贬谪的言官也大多被召回京城，重新安排官职。

同时，徐阶还大力起用直言敢谏之臣。他深知，严嵩时期言路堵塞是政治腐败的重要原因。他上任后即上疏世宗，请求"广开言路，以通下情"。据《明史·徐阶传》记载，徐阶建议世宗"凡有建白，不问其言之当否，皆当优容"——凡是进言的，不管说的对不对，都应该宽容对待。世宗同意了这个建议（虽然以世宗的性格，执行起来肯定要打折扣，但至少在制度层面恢复了言路畅通）。

43.4.3 安抚民心与恢复秩序​

徐阶上任后的第三件事，是安抚民心、恢复社会秩序。

严嵩当权时期，朝政腐败，民不聊生。严党在全国各地侵占民田、横征暴敛，百姓怨声载道。据《明史·食货志》记载，严嵩家族在江西、南京、京畿等地侵占的良田达数十万亩，严世蕃在老家分宜的府第占地数百亩，奢华程度超过亲王府。这些被侵占的土地，徐阶下令全部退还给原主。

同时，徐阶还着手整顿赋税制度。严嵩时期，各地官员为了讨好严党，纷纷加派赋税，导致百姓负担沉重。徐阶下令清查各地赋税，严禁加派，违者严惩。据《明实录》记载，嘉靖四十二年（1563年），徐阶主持清查了南直隶、浙江、江西等地的赋税加派情况，革除了大量不合理收费。

在军事方面，徐阶延续了此前胡宗宪、戚继光等人在东南沿海的抗倭策略。严嵩时期虽然也支持抗倭，但严党往往把军事功劳据为己有，或者以军事需要为名搜刮民财。徐阶上台后，明确将抗倭功劳归于前线将士，据《国榷》记载，戚继光在嘉靖四十二年（1563年）平定福建倭患的军功得到公正评价和奖赏。

43.4.4 徐阶执政风格与成效​

徐阶执政的时间不长——从嘉靖四十一年（1562年）五月到嘉靖四十五年（1566年）十二月世宗驾崩，大约四年半。在这四年半里，他的执政风格可以用三个词概括：稳重、务实、克制。

稳重，体现在他处理政务时不急不躁，步步为营。清理严党不是一刀切，平反冤狱不是一哄而上，赋税改革不是一蹴而就。每件事都分清轻重缓急，有序推进。

务实，体现在他注重解决实际问题而非追求虚名。他不像张璁那样热衷于制度变革，也不像严嵩那样沉迷于青词祥瑞。他关心的是具体问题：哪个地方闹匪患，哪个边境有军情，哪个官员贪腐，哪项税收不合理。据《明史·徐阶传》记载，徐阶"每遇事必详审再三，务求至当"——每件事都要反复审核，务求最妥当的处理。

克制，体现在他对权力的自我约束。严嵩当首辅时，把内阁变成了自己的权力工具，一切政务由他一人说了算。徐阶则不同，他恢复了内阁集体议事制度，重大决策由内阁成员共同商议，而非首辅一人独断。据《国榷》记载，徐阶在内阁中"和而不同，群策群力"——能与同事和睦相处但保留不同意见，共同商议决策。

可以用一个对比表来概括徐阶与严嵩执政风格的不同：

│ 比较维度      │ 严嵩执政            │ 徐阶执政            │
├──────────────┼────────────────────┼────────────────────┤
│ 权力运作方式  │ 独断专行，排斥异己  │ 集体议事，求同存异  │
│ 对待言官      │ 打压迫害，堵塞言路  │ 宽容对待，广开言路  │

43.4.5 徐阶与严嵩对比评价​

最后，我们来做一个总体评价。

严嵩和徐阶，是嘉靖朝政治舞台上最引人注目的一对对手。他们有很多相似之处：都是南方人（严嵩是江西人，徐阶是松江人），都是进士出身（严嵩弘治十八年进士，徐阶嘉靖二年进士），都擅长写青词，都通过迎合世宗获取权力。但他们的结局截然不同：严嵩寄食墓舍而死，徐阶功成身退（虽然后来在隆庆朝被高拱清算，但那是另一段故事了）。

区别在哪里？

第一，严嵩的权力建立在"术"上——揣摩帝心、控制言路、打压异己。这种权力没有根基，完全依附于皇帝的宠信。一旦宠信消失，权力就归零。徐阶的权力虽然也依附于皇帝信任，但他在获取信任的同时还做了两件事：一是建立自己的人脉网络（门生故旧遍布朝野），二是做出实际政绩（平反冤狱、清理严党、安抚民心）。这两样东西是严嵩没有的。

第二，严嵩有一个致命的软肋——严世蕃。严世蕃的聪明才智是严嵩的利器，但也是严嵩的枷锁。严世蕃的嚣张跋扈、贪赃枉法，给严党埋下了覆灭的种子。而徐阶没有这样的软肋——他的儿子徐璠虽然也做官，但低调得多，没有成为政敌攻击的靶子。

第三，严嵩是一个纯粹的政客，他追求的只有权力和财富。而徐阶虽然也追求权力，但他同时还有政治理想——他要做一个好首辅，要让朝政清明，要让百姓安居。这种理想虽然不算崇高，但至少让他在行使权力时有所顾忌。

据《明史·徐阶传》的评价，徐阶"性颖敏，有权略，而内持正"——天资聪颖敏慧，有权谋略略，但内心持守正道。这个评价比较中肯。徐阶不是完人——他的隐忍过程中也做了不少违心的事（比如不为杨继盛求情），他执政后也有自己的私心（比如提拔门生、经营势力）。但总体而言，他比严嵩好得多。在嘉靖朝那个极端恶劣的政治环境下，能做到徐阶这个程度，已经是难能可贵了。

历史不要求完人，历史只要求在关键时刻，有人站出来做正确的事。徐阶在嘉靖四十一年站了出来，扳倒严嵩，廓清朝堂。这件事本身的意义，超过了他个人的一切缺点和争议。

写到这里，这一章就要结束了。严嵩的倒台标志着嘉靖朝政治的一个重大转折——从严党专政到徐阶执政，朝政从一个极端走向了相对正常。但嘉靖朝的问题远未解决：世宗依然修道不上朝，边患依然严峻，财政依然困难。徐阶能在这四年半里做到的，只是修补而非重建。真正的重建，要等到隆庆朝和万历朝的前十年，由高拱和张居正来完成。

那是一个更波澜壮阔的时代，我们下章再见。

系列进度 43/64

怕浪猫说： 隐忍不是懦弱，是最高级的猎手本能。徐阶用了十三年等一个机会，用了一击就掀翻了二十年权臣。严嵩的故事告诉我们：依附于个人宠信的权力，终究是空中楼阁。而徐阶的故事则告诉我们：在黑暗中行走的人，只要方向没错，终会走到光亮处。历史的有趣之处就在这里——它不总是正义战胜邪恶，但至少在这一回合，赢的那个人，恰好是更好的那一个。

下章预告： 第44章将讲述嘉靖朝的落幕——世宗驾崩与隆庆即位。修道四十五年的嘉靖帝最终走向人生的终点，而接替他的隆庆帝朱载坖，将在徐阶和高拱的辅佐下开启一个新的时代。只是这个新时代的权力交接，远没有想象中那么平稳。
