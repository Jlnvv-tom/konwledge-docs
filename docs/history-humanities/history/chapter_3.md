# 第3章 经略江南，立足江东

一个放牛娃出身的起义军首领，在1356年做了一件事——把集庆改名应天。这个看似简单的改名动作，背后却藏着定鼎江南、终结元朝的完整战略蓝图。更让人意想不到的是，真正帮朱元璋站稳脚跟的，不是某场惊天大战，而是一个老秀才给出的九个字。

我是怕浪猫，今天我们继续大明通史系列，走进朱元璋经略江南的关键岁月。这一章，你会看到一支流民武装如何蜕变为建国力量，一群读书人如何重塑一个政权的精神底色，以及一片饱经战火的江南土地如何在短短数年间恢复了生机。

## 3.1 攻取集庆：更名应天，定鼎江南根据地

### 3.1.1 渡江战役与采石矶突破

元至正十五年（1355年）初，朱元璋面临一个生死攸关的战略抉择。

此时他驻兵和州（今安徽和县），兵不满两万，粮草将尽。和州地处长江北岸，城小民贫，既无险可守，也无粮可继。更要命的是，东西两翼皆有强敌——东面是占据集庆路（今南京）的元将蛮子海牙，西面是盘踞芜湖、池州一带的义军首领赵普胜。继续留在和州，等于坐以待毙。

朱元璋的目光投向了长江南岸。

《明太祖实录》卷三记载了这次渡江决策的背景："上谓诸将曰：和州弹丸之地，不可久居。今日之计，非渡江不可。"

但渡江需要水师，而朱元璋恰恰没有水船。这时，巢湖的水寨武装成了破局的关键。

巢湖位于今安徽中部，湖面辽阔，元末乱世中，当地渔民和豪强结寨自保，形成了以廖永安、俞通海为首的水上武装集团，拥有大小船只千余艘。朱元璋派人与巢湖水寨联络，廖永安、俞通海率部来归，朱元璋一夜之间获得了渡江所需的水上力量。

> 《国榷》卷一载："廖永安、俞通海以巢湖水寨来降，得船千余艘，军声大振。"

有了水师，朱元璋将渡江第一战的目标锁定在采石矶。

采石矶，位于今安徽马鞍山市西南的翠螺山麓，是长江下游最著名的渡口之一。自古便是兵家必争之地，南宋虞允文曾在此大败金完颜亮。采石矶江面相对狭窄，南岸地势险峻，易守难攻，但一旦突破，便可直扑太平路（今当涂），进而威逼集庆。

元至正十五年六月（1355年7月），朱元璋率军渡江。他以廖永安、俞通海率水师为先锋，自率主力跟进。采石矶守军为元朝河南行省平章蛮子海牙所部，在江岸列阵，弓弩齐发，矢石如雨。

《明太祖实录》详细记录了这场突破战的过程。常遇春，这个日后名震天下的猛将，在此时崭露头角。他单乘一舟，挺矛率先登岸，冲入元军阵中，所向披靡。元军阵脚大乱，朱元璋大军随后涌上南岸，采石矶一战而下。

> 《明史·常遇春传》载："乘舫抵采石，遇春操戈奋前，先登，元军败走。"

采石矶突破的战略意义远超一场普通战斗的胜利。它意味着朱元璋第一次在长江南岸获得了落脚点，从此不必再隔着长江望南兴叹。更重要的是，此战缴获了大量粮草军资，解决了困扰已久的补给问题。

朱元璋随即挥师东进，攻克太平路（今安徽当涂）。太平路的拿下，为进攻集庆打开了通道。
### 3.1.2 集庆城攻坚战与元军溃败

太平路既下，集庆便暴露在朱元璋的兵锋之下。但集庆不是采石矶，它是元朝在江南的政治军事重镇，城防坚固，驻有重兵。

集庆路，古称金陵、建康，五代十国时为南唐都城，城池高大，背倚钟山，面临大江，虎踞龙盘，形胜天下。元朝在此设江南行御史台，置兵屯守，是控扼长江下游的核心据点。守将为元朝南台御史大夫福寿、行省平章蛮子海牙。

朱元璋攻集庆的过程并非一蹴而就，而是经历了反复拉锯。

第一次进攻发生在至正十五年（1355年）秋。朱元璋遣将攻集庆外围州县，试图切断集庆的援军通道。但蛮子海牙率水师在长江上设阵，截断朱元璋的补给线，迫使朱军退回太平。

转折出现在至正十六年（1356年）春。朱元璋重新部署，先命赵继祖、郭天禄等将攻占集庆外围的句容、溧水、溧阳等县，对集庆形成包围态势。然后亲率主力，水陆并进，再攻集庆。

蛮子海牙试图再次用水师阻断江面，但这一次朱元璋早有准备。他命廖永安率水师迎战，在江面上大败蛮子海牙舰队。蛮子海牙弃船遁逃，元军水师全军覆没。

失去水上屏障后，集庆城便成了孤城。朱元璋大军兵临城下，发起总攻。

《明太祖实录》卷四载："三月丙戌朔，上率诸军进攻集庆路。癸巳，克之。"

至正十六年三月癸巳日（1356年4月10日），集庆城破。守将福寿在城中巷战殉国，《明史·福寿传》载其死状甚烈："城破，福寿犹督兵巷战，遂死之。"蛮子海牙先已遁走，集庆路元军彻底溃散。

集庆之战的胜利，是朱元璋军事生涯中第一个重大转折点。从此，他不再是蜗居和州的一支小股武装首领，而是拥有江南重镇的一方诸侯。

以下为集庆之战的关键节点梳理：

| 时间 | 事件 | 战略意义 |
|------|------|----------|
| 1355年6月 | 采石矶突破，获渡江立足点 | 首次跨越长江天险 |
| 1355年秋 | 首攻集庆受挫，退回太平 | 暴露补给线脆弱问题 |
| 1356年春 | 扫清外围，合围集庆 | 切断集庆外援通道 |
| 1356年3月 | 蛮子海牙水师覆灭 | 元军失去长江制水权 |
| 1356年4月10日 | 集庆城破，福寿殉国 | 朱元璋占领江南核心城市 |

### 3.1.3 更名应天与江南根据地确立

集庆城破后，朱元璋做的第一件事不是犒赏三军，而是改名字。

至正十六年四月，朱元璋下令将集庆路改名为"应天府"。

这个改名绝非随性而为。"应天"二字，取"顺应天命"之意。在中国古代政治语境中，"天命"是政权合法性的终极来源。朱元璋此时名义上仍是韩林儿宋政权（龙凤政权）的部属，使用的是龙凤年号，但他改集庆为"应天"，这释放了一个极为微妙的政治信号——他在为自己建构独立的政治合法性。

> 《明太祖实录》卷四载："改集庆路为应天府。"

注意这个时间节点。1356年，天下大势尚未明朗。北方红巾军刘福通拥戴韩林儿建宋称帝，号龙凤政权；徐寿辉在蕲水称帝，国号天完；张士诚据高邮、平江（今苏州），自号周王；陈友谅尚在徐寿辉麾下蛰伏。此时的朱元璋，虽然实力不及上述数人，但他通过"应天"这个地名，向天下宣告了自己与众不同——他不只是造反，他要"应天"而立。

应天府的设立，标志着朱元璋政权的性质发生了根本转变。此前，他的军队本质上是一支流动作战的武装力量，走到哪里吃到哪里，没有固定根据地，没有稳定后方。有了应天之后，他终于拥有了一个可以长期经营的战略核心。

朱元璋随即在应天建立江南行中书省，自任行省平章政事，以李善长为参议，初步搭建起了一个地方政权的行政框架。他颁布军令、安抚百姓、恢复生产，应天府及周边州县开始从战乱中恢复秩序。

### 3.1.4 应天城防体系构建

占领一座城池和守住一座城池，是两个完全不同的命题。朱元璋深谙此理。

应天府地处长江下游平原，虽有钟山、大江之险，但周边平原开阔，一旦遭遇大规模进攻，城防压力极大。朱元璋在占领应天后，立即着手构建一套立体的城防体系。

首先是城墙。应天旧城为南唐所筑，城墙周长不过二十五里，且年久失修。朱元璋命人加固加高旧城，同时在战略要冲处修筑新的防御工事。钟山脚下设大营，屯驻精兵；龙江关（今下关一带）设水寨，扼守长江水道；雨花台、聚宝山等城南制高点设瞭望哨和弓弩阵地。

其次是外围防线。朱元璋在应天外围设置了三道防线：第一道以太平路（当涂）、宁国路（宣城）为前哨，预警南方来敌；第二道以镇江、常州为东翼，防备张士诚方向；第三道以滁州、和州为江北屏障，监控北方元军动向。

这套城防体系的核心原理可以用一个简洁的模型概括：

```
应天城防三层模型

内层：城墙 + 钟山大营 + 龙江水寨
  └─ 核心防御，确保城池不失

中层：太平-宁国（南）+ 镇江-常州（东）+ 滁州-和州（北）
  └─ 外围预警与阻击，迟滞敌军

外层：采石矶-芜湖江防 + 广德-长兴陆防
  └─ 前出哨探，主动拒敌于远方
```

这种"三层防御、逐次抵抗"的布局，使应天在日后面对多方威胁时始终稳如磐石。无论是陈友谅的东进还是张士诚的西扩，都未能撼动应天的根基。

### 3.1.5 定都应天的战略意义

朱元璋定都应天，是明初历史上最关键的战略决策之一。其意义远超一城一地之得失，而是关乎全局的战略定位。

从地理维度看，应天据长江中下游之交，上控荆楚，下扼吴越，北望中原，南制闽广，是整个江南地区的地理枢纽。占有应天，就等于掌握了江南的门户。

从经济维度看，应天所在的长江下游平原，是中国最富庶的农业区。太湖流域、宁绍平原的粮食产量冠绝天下，苏松地区的赋税收入占全国之大半。控制了应天，就控制了江南财赋的流通命脉。

从军事维度看，应天背依长江，有水运之利，兵员粮草可以快速调配。钟山、石头城等天然屏障提供了坚固的防御条件。长江天险既是军事屏障，也是后勤通道。

从政治维度看，应天（金陵）是六朝古都，孙吴、东晋、刘宋、南齐、梁、陈相继在此建都，具有深厚的政治象征意义。在此建都，可以借古都之名凝聚人心，彰显政权的正统性。

> 《明史·地理志》载："应天府，元集庆路，属江南行省。太祖丙申年三月曰应天府。"

当然，定都应天也有其短板——偏居江南，远离北方边防前线，日后"天子守国门"的呼声与此有关。但在1356年的战略环境下，定都应天无疑是最优选择。它让朱元璋获得了一个稳固的大后方，为后续平定南方、北伐中原奠定了坚实的根基。

> 怕浪猫说一句掏心窝子的话：定都这件事，从来不是"选个好地方"那么简单。它是军事、经济、政治、历史四重因素交叉博弈后的最优解。朱元璋在1356年选了应天，这个选择在十二年后结出了果实——1368年，他在应天称帝，建国号大明。
## 3.2 礼贤下士：朱升、李善长献立国之策

### 3.2.1 朱升高筑墙广积粮缓称王九字策

至正十七年（1357年），朱元璋攻下徽州（今安徽歙县）。在这里，他遇到了一个改变他命运走向的人——朱升。

朱升，字允升，号枫林，徽州休宁人。此人年近六旬，是一位饱读经史的老秀才，在当地颇有名望。他并非科举高第，也非显赫世家出身，只是一个在乡间教书育人的儒生。但正是这样一个看似平凡的老者，给朱元璋献上了中国历史上最著名的九字战略方针。

"高筑墙，广积粮，缓称王。"

这九个字，字字千钧。

《明史·朱升传》载："太祖下徽州，以邓愈荐，召问之。对曰：'高筑墙，广积粮，缓称王。'太祖善之。"

让我们逐字拆解这九字策的深层逻辑：

**高筑墙**——不是简单地修城墙，而是构建坚固的防御体系。在群雄并起的乱世中，生存是第一要务。只有确保根据地不被攻破，才有资格谈发展。这一条对应的是"守"——守住已有地盘，不盲目扩张。

**广积粮**——不是单纯多种粮食，而是建立稳固的经济基础和后勤保障体系。军队打仗需要粮草，百姓安居需要粮食，政权运转需要赋税。粮食是农业社会最核心的战略资源。这一条对应的是"蓄"——积蓄实力，厚植根基。

**缓称王**——这是最具政治智慧的一条。当时天下义军首领纷纷称王称帝，韩林儿称帝建宋，徐寿辉称帝建国天完，张士诚自号周王。但"木秀于林，风必摧之"，谁先称王，谁就成为众矢之的，也最先引起元朝的集中打击。朱元璋在实力不足时暂不称王，保持低调，既避免了成为元军主力围剿的目标，也避免了过早与其他义军势力产生正面冲突。这一条对应的是"忍"——忍住虚名诱惑，等待时机成熟。

> 怕浪猫在读这段史料时总忍不住感慨：九个字，三个维度——防御、经济、政治。中国历史上多少英雄豪杰，能征善战者不在少数，但同时把这三件事做对的，寥寥无几。朱升的伟大不在于他提出了什么新奇理论，而在于他用最简洁的语言，把乱世生存与发展的底层逻辑说透了。

朱元璋深以为然，此后数年的战略布局，基本围绕这九字方针展开。他不急于称王（直到1364年才称吴王），不急于扩张（先巩固应天周边），把大量精力投入到城防建设和粮食生产中。九字策成为朱元璋从"造反首领"蜕变为"开国君主"的战略指南针。

### 3.2.2 李善长投奔与谋主地位确立

朱升的九字策是战略层面的指引，而在日常政务和行政管理的层面，朱元璋最依赖的谋士是李善长。

李善长，字百室，定远（今安徽定远）人。他出生于一个地方士绅家庭，自幼读书，精通法家之学，尤其擅长吏治和制度设计。《明史·李善长传》称其"少读书，有智计，习法家言，明习前代故事"。

李善长投奔朱元璋的时间，比朱升更早。至正十四年（1354年），朱元璋南下攻取滁州途中，李善长前来拜谒。两人一见如故，朱元璋问他："天下何时可定？"李善长回答："秦乱，汉高祖起布衣，豁达大度，知人善任，不嗜杀人，五载成帝业。今元政既紊，天下土崩瓦解。公濠产，距沛不远，山川王气，公当受之。效汉高祖所为，天下不足定也。"

这段话出自《明史·李善长传》，核心意思很明确：你朱元璋的出身和处境与汉高祖刘邦极为相似，只要你效法刘邦的行事风格——豁达大度、知人善任、不嗜杀人，天下就可以拿下。

李善长的高明之处在于，他没有就军事谈军事，而是直接给朱元璋指出了一个历史模板——刘邦。这个模板不仅是一套行为指南，更是一种政治身份的暗示。朱元璋出身底层、起于行伍，与刘邦的背景高度契合。以汉高祖为标杆，既给了朱元璋一个可以模仿的榜样，也暗中为他的事业赋予了历史合法性。

朱元璋大悦，留李善长掌书记，参与机密谋议。从此，李善长成为朱元璋集团中最早的核心文臣。

在应天政权初创阶段，李善长的角色相当于"大管家"。他负责的不只是出谋划策，更包括制度建设、人事安排、军需调配、赋税征收等一切行政事务。《明太祖实录》多次提到李善长"参预机务"、"总理府事"，可见其职责之广。

李善长在制度层面的最大贡献，是帮助朱元璋建立了一套有效的行政管理体系。在占领应天之前，朱元璋的军队更像是一个军事集团，没有成型的文官系统。李善长以汉唐制度为蓝本，结合实际情况，为朱元璋设计了一套简练实用的行政框架：行省之下设府、州、县，各设官员掌管民政、赋税、刑名；军队实行卫所编制，军政分离，互不统属。这套制度虽然粗糙，但已经具备了一个国家政权的基本雏形。

> 《明史·李善长传》载："太祖为吴王，拜善长右相国。"可见其在朱元璋集团中地位之尊崇，堪比汉初之萧何。

### 3.2.3 徽州访贤与士人归附

朱元璋在徽州不仅仅见到了朱升。徽州之行，实际上开启了他系统性地招揽江南士人的进程。

徽州自古文风鼎盛，宋元以来更是理学重镇。朱熹的故乡婺源便属徽州（今属江西），徽州士人深受程朱理学影响，注重忠义名节，在元末乱世中多持观望态度。他们并不天然地认同任何一支义军，而是要看这支力量是否值得辅佐。

朱元璋深知，要争取士人支持，不能靠武力胁迫，必须以礼相待。他在徽州期间，多次微服走访乡间学者，恭恭敬敬地请教治道。除了朱升之外，他还招揽了汪广洋、陶安等人。

陶安，字主敬，当涂人，元末举人。朱元璋攻下太平路时，陶安率父老出迎，朱元璋问他如何治理江南，陶安回答："今四海鼎沸，豪杰并争。然皆屠戮之师，非救民之师也。明公渡江，纪律严明，人心悦服。以此定天下，不难也。"朱元璋对其大加赞赏。

汪广洋，字朝宗，高邮人。此人博学多才，工于诗文，后官至丞相。他在朱元璋初期主要参与文书起草和制度参议。

徽州访贤的战略意义在于：它打破了元末士人对义军的固有偏见。在此之前，大多数读书人视红巾军等义军为"贼寇"，不屑与之为伍。朱元璋以礼贤下士的姿态出现，赢得了部分士人的好感。这些士人一旦归附，不仅带来了治国理政的专业知识，更重要的是带来了"道统"的加持——有了读书人的认可，朱元璋的政权就不再是"草寇武装"，而开始具备"正统力量"的政治光环。

### 3.2.4 儒士集团对朱元璋政权的塑造

随着朱升、李善长、陶安、汪广洋等人的相继归附，朱元璋身边逐渐形成了一个以儒生为主体的文臣集团。这个集团对朱元璋政权的塑造作用，体现在三个层面。

第一层面：制度构建。儒士们按照儒家经典中的治国理想，为朱元璋设计行政制度。李善长参照汉唐旧制，建立行省-府-州-县的行政体系；陶安参与制定军纪条令，规范军伍行为；汪广洋负责文书制度，建立了一套行之有效的公文运转机制。这些制度使朱元璋的政权从一个军事集团逐步转型为一个有模有样的地方政权。

第二层面：文化认同。儒士们将儒家的政治理念注入朱元璋政权的意识形态中。他们向朱元璋讲解经史，以历代兴亡为鉴，引导朱元璋从一个农民起义领袖向儒家意义上的"有道之君"转变。这种文化认同的建构，对于政权的长期稳定至关重要。

第三层面：人才吸引力。儒士集团本身就是一个庞大的人际网络。一个名士归附，往往会带动一批门生故旧前来投效。朱升推荐了刘基、宋濂等人；李善长引荐了多位安徽同乡。这种"滚雪球"效应使朱元璋的人才库迅速扩大。

可以用一个简单的正反馈模型来描述这个过程：

```
儒士归附循环模型

礼贤下士 → 名士归附 → 制度完善 → 政权规范化
    ↑                                    ↓
    └── 声誉提升 ←── 吸引更多士人 ←──┘
```

这个正反馈循环是朱元璋最终胜出的深层原因之一。陈友谅残暴嗜杀，士人避之不及；张士诚优柔寡断，士人难以施展；唯有朱元璋，既有力量的硬度，又有礼贤的温度，士人纷纷来归。

### 3.2.5 战略方针从流寇转向建国

儒士集团的加入，促成了朱元璋政权最根本的转型——从流寇模式转向建国模式。

所谓"流寇模式"，是指元末大多数义军的运作方式：没有固定根据地，走到哪里抢到哪里，以战养战，不事生产。这种模式在起义初期有极强的机动性和爆发力，但无法持久。黄巢、李自成都是典型的流寇型起义，虽能横扫半壁江山，最终却功亏一篑。

朱元璋在占领应天之前，也带有一定的流寇色彩。他的军队长期处于运动战中，后勤补给主要靠攻城掠地获取，没有建立起稳定的生产-赋税体系。但应天根据地的确立和儒士集团的辅佐，使他实现了关键性的战略转型。

转型的核心标志有三：

一是建立了固定的行政中心。应天府成为政令所出的中枢，各级官员在此办公，制度在此制定，这是流寇绝不可能拥有的。

二是建立了赋税征收体系。不再是简单的"打粮"（即武力征收），而是按照田亩征收正式赋税，使财政收入稳定化、制度化。

三是建立了屯田生产体系。军队不再纯粹依赖征发，而是通过军屯实现部分自给。这一点将在3.4节详述。

> 这一战略转型的意义，怕浪猫认为怎么估计都不过分。中国历史上农民起义何止千百，但真正完成从"造反"到"建国"转型的，屈指可数。朱元璋之所以能成事，不是因为他最能打，而是因为他最早想明白了"打天下"和"坐天下"是两回事——而后者才是最终胜负的关键。
## 3.3 三顾刘基：浙东谋士集团归附

### 3.3.1 刘基出山与朱元璋诚意

在朱元璋招揽的众多谋士中，刘基（刘伯温）是最具传奇色彩的一位。

刘基，字伯温，处州青田（今浙江文成）人。元朝元统元年（1333年）进士，曾任高安县丞、江浙儒学副提举等职。此人博通经史，精于天文、兵法、术数，被后人附会为"诸葛亮式"的神机妙算人物。但剥去后世演义的神话外衣，真实的刘基同样是一位杰出的政治家和战略家。

刘基的出山过程，与朱升、李善长有所不同。他并非主动投奔，而是经过了朱元璋的多方延请。

《明史·刘基传》载："及太祖下金华，定括苍，闻基及宋濂等名，以币聘。基未应。"

朱元璋攻下金华（至正十八年，1358年）和处州（至正十九年，1359年）后，得知刘基、宋濂等浙东名士的名声，派人以礼物聘请。但刘基最初并未应召。

这并非刘基清高或者忠于元朝。事实上，刘基在元朝官场屡遭排挤，对元朝已彻底失望。他之所以犹豫，一是在观望朱元璋是否值得辅佐——毕竟当时义军首领多如牛毛，良禽择木而栖，不可不慎；二是因为他身为元朝旧臣，从名义上直接投奔义军，需要一个合适的台阶。

朱元璋没有因为刘基的拒绝而放弃。他再次遣使敦请，表现出十足的诚意。据《明太祖实录》和《国榷》的记载，朱元璋前后多次派人延请刘基，其诚意最终打动了这位浙东名士。

至正二十年（1360年）春，刘基终于应天来奔。与他同来的，还有宋濂、叶琛、章溢三人。朱元璋专门在应天设立礼贤馆，安置这四位浙东名士，以示尊崇。

> 《明史·刘基传》载："基至，陈时务十八策。太祖大喜，筑礼贤馆以处基等，宠礼甚至。"

朱元璋之所以对刘基如此执着，原因在于他深知刘基在浙东士人中的影响力。刘基不仅是进士出身，更在天文、兵法等领域享有盛名。争取到刘基，就等于打开了浙东士人集团的大门，其价值远超一人之智。

### 3.3.2 宋濂、叶琛、章溢同步归附

与刘基一同出山的还有三位重要人物，他们与刘基并称为"浙东四先生"。

宋濂，字景濂，号潜溪，浦江（今浙江浦江）人。被后世誉为"开国文臣之首"，是明初文坛的领军人物。宋濂学问渊博，尤长于经史和古文，其文章被推为"明初第一"。他日后主持编修《元史》，在中国史学史上留下浓墨重彩的一笔。《明史·宋濂传》载："濂少颖悟强记，就学于闻人梦吉，受《春秋》于吴莱学。"

叶琛，字景渊，丽水人。曾任元朝青田县尹，有实际的行政治理经验，擅长民政和吏治。

章溢，字三益，龙泉人。豪侠好义，元末曾组织乡兵保卫地方，有军事组织经验。他与刘基是旧交，关系密切。

这四人各有专长：刘基长于战略谋划和天文术数，宋濂长于文学和史学，叶琛长于行政实务，章溢长于军事组织。朱元璋将他们一并收入麾下，等于一次性地获得了战略、文化、行政、军事四个维度的智力补充。

> 《明太祖实录》载朱元璋语："我为天下屈四先生，今天下纷纷，何时定乎？"

这句话意味深长。"为天下屈四先生"，意思是说我以天子之尊来礼遇你们四位，不是为了我自己，是为了天下苍生。这既是礼贤下士的姿态，也是对四人的期许——你们不是来帮我打天下的，你们是来帮天下人结束乱世的。

### 3.3.3 浙东谋士与淮西武将的制衡

浙东谋士集团的到来，在朱元璋政权内部形成了一个微妙的权力格局。

在此之前，朱元璋的核心团队以淮西人为主——李善长（定远人）、徐达（濠州人）、常遇春（怀远人）、汤和（濠州人）等，文臣武将多出自淮西一带。这个"淮西集团"是朱元璋起家的班底，功勋卓著，但也存在明显的弊端：地域色彩浓厚，容易形成利益固化；武将骄横，有时不遵法度。

浙东谋士集团到来后，形成了一种天然的制衡关系。浙东人以文才见长，淮西人以武功著称；浙东人注重制度和法度，淮西人倾向于实力至上。两个集团之间既有合作，也有摩擦，朱元璋居中调度，使两者互相补充、互相制约。

这种制衡格局可以用以下对比来理解：

| 维度 | 淮西集团 | 浙东集团 |
|------|----------|----------|
| 核心人物 | 李善长、徐达、常遇春 | 刘基、宋濂、章溢 |
| 专长领域 | 武功、行政实务 | 战略、文化、制度 |
| 行事风格 | 务实强硬 | 理性审慎 |
| 政治倾向 | 功臣利益 | 法治精神 |
| 与朱元璋关系 | 旧部、同乡 | 后至、客宾 |

朱元璋对这种制衡格局是有意为之的。他深知，任何一个集团一家独大，都会对权力构成威胁。淮西武将手握兵权，若有异心则危及政权；浙东文臣掌握话语权，若不受节制则影响军心。两派并存、互相监督，朱元璋才能稳坐钓鱼台。

> 怕浪猫在读这段权力博弈时，总想到一句话：一个成熟的政治家，从不指望消灭矛盾，他只追求管理矛盾。朱元璋让淮西和浙东并立，不是因为他喜欢内斗，而是因为他需要一个动态平衡的决策环境——有人主战时有人主稳，有人重利时有人重义，决策才不会走极端。

### 3.3.4 刘基陈时务十八策

刘基到应天后，向朱元璋上了著名的"时务十八策"。

《明史·刘基传》载："基至，陈时务十八策。太祖大喜。"惜乎十八策的具体内容在正史中没有完整记录，散见于各种史料和刘基文集中的部分内容，大致涵盖以下几个方面：

一为战略判断。刘基分析了当时天下大势，指出陈友谅据长江上游，威胁最大；张士诚据下游，虽有财力但胸无大志。他建议朱元璋先攻陈友谅，再取张士诚，避免两线作战。这一战略判断成为后来鄱阳湖之战的理论基础。

二为制度建议。刘基主张革除元朝弊政，建立规范的行政和司法体系。他强调"治国以德为本，治军以严为先"，建议朱元璋完善军纪，禁止杀掠。

三为民生政策。刘基提出轻徭薄赋、休养生息的建议，认为民心的向背是争夺天下的根本。他引用孟子"得道多助，失道寡助"之理，劝朱元璋以仁政争取江南百姓的支持。

四为用人方针。刘基建议朱元璋不拘地域、不论出身，广揽天下人才。他自己就是浙东人，而朱元璋的核心班底是淮西人，刘基此举既是在为朱元璋谋划，也是在为浙东士人争取更大的发展空间。

时务十八策的历史意义在于：它是朱元璋政权从一个地方性武装集团向全国性政权过渡的纲领性文件。如果说朱升的九字策解决了"怎么活下去"的问题，那么刘基的十八策则回答了"怎么赢下去"的问题。

> 后世有人将刘基比作诸葛亮，怕浪猫觉得这个比方不太准确。诸葛亮出山时，刘备不过是一个寄人篱下的落魄军阀；而刘基出山时，朱元璋已经是坐拥江南的一方诸侯。刘基面对的问题比诸葛亮更复杂——他不仅要帮朱元璋打赢外敌，还要在内部复杂的派系博弈中找到平衡。从某种意义上说，刘基的处境更像是张良辅佐刘邦：在群雄并争中，为君主提供最清醒的战略判断。

### 3.3.5 谋士集团对江南战略的贡献

刘基等浙东谋士的加入，极大地提升了朱元璋集团的战略水平。他们的贡献主要体现在三个层面。

第一，完善了战略决策机制。此前朱元璋的决策主要依靠自己和李善长等少数人的商议，视角偏向安徽本土。刘基等人加入后，带来了更开阔的视野和更多元的分析框架。朱元璋在重大决策前，开始有意识地征询多方意见，形成了"集思广益、主帅裁决"的决策模式。

第二，提供了关键的战略判断。刘基"先陈后张"的战略建议，是这一时期最重要的战略贡献。当时张士诚离应天更近，许多人主张先打张士诚。但刘基力排众议，指出陈友谅野心勃勃、实力最强，若先打张士诚，陈友谅必从上游偷袭，腹背受敌；反之先灭陈友谅，张士诚守土之犬不足为虑。后来的历史完全验证了这一判断。

第三，提升了政权的文化品格。宋濂等人的到来，使应天政权有了自己的"文胆"。他们起草文书、制定礼仪、教授经史，将一个起于草莽的军事政权逐步改造成一个具有儒家气象的政治实体。这种文化层面的提升虽然不像军事胜利那样立竿见影，但对于政权的长期凝聚力和合法性至关重要。
## 3.4 休养生息：江南安民、屯田固本

### 3.4.1 军屯制度推行与粮草自足

朱升"广积粮"的建议，在实践中首先体现为军屯制度的推行。

军屯，即军队在驻扎地区从事农业生产，实现粮草的半自给或自给。这一制度并非朱元璋首创，汉代赵充国在河湟屯田、三国曹操的"屯田制"、唐代府兵制中的"寓兵于农"，都是军屯的不同形式。但在元末乱世的特定环境下，朱元璋将这一制度发挥到了新的水平。

至正二十三年（1363年）前后，朱元璋正式在应天及周边地区大规模推行军屯。他命令各卫驻军在训练之余，分拨田地耕种。每个军户分配一定数量的土地，收获的粮食除留作口粮外，其余上缴官仓作为军储备。

《明太祖实录》记载了朱元璋对军屯的指导思想："兵食足，则士气充；士气充，则战无不胜。"

军屯制度的运作原理可以用以下流程来理解：

```
军屯运作模型

分配田地 → 军户耕种 → 收获粮食
                          ↓
                    ┌─────┴─────┐
                    ↓           ↓
              留作口粮     上缴军仓
                            ↓
                      战时后勤保障
```

这一制度的优势在于：第一，减轻了百姓的赋税负担——军队自己种粮，不必全部从民间征收；第二，保证了军队的粮食供应——不依赖后勤运输线，减少了被敌军截断补给的风险；第三，使军队与土地产生联系，军户定居一处，有利于地方治安的稳定。

据史料记载，军屯推行数年后，应天地区驻军的粮食自给率大幅提升，部分卫所甚至实现了完全自给。这为朱元璋后来的大规模军事行动——鄱阳湖之战、平定张士诚、北伐中原——提供了坚实的后勤基础。

### 3.4.2 减轻赋税与安抚百姓

军屯解决了军队的口粮问题，但百姓的负担同样需要减轻。元朝末年，赋税繁重，苛捐杂税多如牛毛，加之连年战乱，百姓流离失所，田地荒芜。

朱元璋在占领应天后，立即着手改革赋税制度。他采取了几个关键措施：

第一，减免租税。对新占领地区，朱元璋通常宣布免除当年或数年的田赋，让百姓有喘息之机。《明太祖实录》多次记载朱元璋下令"免某处田租"的诏令。这种"让利于民"的做法，在当时的各路义军中极为罕见，迅速赢得了民心。

第二，清查田亩。朱元璋命人清查应天及周边地区的田地面积和产权状况，按照实际田亩数确定税额。这既防止了豪强隐瞒田产、逃避赋税，也避免了普通百姓代缴超额税赋的不公。

第三，简化税种。元朝的税目繁杂，有丁税、地税、科差、额外摊派等数十种。朱元璋大幅简化税目，以田赋为主、丁赋为辅，取消了大部分额外摊派，使赋税制度透明化。

> 《明太祖实录》载朱元璋语："民者，国之本也。本固则国宁，本摇则国危。"

这套减税安民政策的核心逻辑可以用一个简洁的因果链来表达：



表面上看，减税会减少财政收入。但长期来看，减税使百姓有能力扩大生产，税基随之扩大，最终财政收入不降反增。这就是经济学中"拉弗曲线"在元末江南的朴素实践——朱元璋当然不知道拉弗曲线，但他凭直觉把握住了这个原理。

### 3.4.3 水利兴修与农业恢复

农业生产的恢复，离不开水利设施的建设。江南地区虽然水网密布、雨量充沛，但元末战乱导致大量水利设施年久失修，河渠淤塞，堤坝崩塌，旱涝灾害频繁。

朱元璋在巩固应天根据地后，将水利兴修作为恢复农业的重中之重。他命地方官府组织民力，疏浚河道、修筑堤坝、开挖灌渠。

《明太祖实录》中有多条关于这一时期水利建设的记载。其中最引人注目的是对太湖流域水利系统的修复。太湖流域是江南最重要的粮食产区，但其水利系统极为复杂——太湖上游承接天目山来水，下游经吴淞江、浏河等水道入海。一旦下游水道淤塞，太湖就会泛滥成灾；一旦上游来水不足，就会发生旱灾。

朱元璋下令疏浚吴淞江下游淤塞段，加固太湖堤防，整修各支渠灌网。这些工程调动了大量民夫，历时数月乃至数年，但效果显著——太湖流域的农田灌溉面积大幅增加，水患频率明显下降。

水利建设与农业恢复之间存在一个正反馈循环：

```
水利兴修 → 灌溉保障 → 农田增产 → 粮食充裕
    ↑                                    ↓
    └── 税收增加 ←── 人口回流 ←──┘
```

水利修好了，农业产出增加；农业产出增加，百姓愿意留下来种地；人口稳定下来，税基就稳固了；税收增加，又有更多财力投入水利建设。这个正反馈循环一旦启动，就会持续推动经济恢复。

### 3.4.4 民兵合一与地方治安

在恢复生产的同时，朱元璋还需要解决一个迫切问题：地方治安。

元末乱世，兵匪难分。各路武装你来我往，百姓苦不堪言。即使朱元璋的军队占领了某一地区，也难以在每一个村庄都驻扎正规军。如何在兵力有限的情况下维持广大农村地区的治安？朱元璋的答案是民兵合一。

所谓民兵合一，就是在农村基层组织民兵队伍，由本地青壮年组成，平时务农，有事则拿起武器自卫。这些民兵不脱离生产，不需要额外的军费开支，但能有效维护地方秩序，防范小股流寇和盗贼。

民兵制度的组织架构如下：

```
民兵组织层级

应天行省（总管）
  ├── 府（设民兵统领）
  │   ├── 州（设民兵千户）
  │   │   ├── 县（设民兵百户）
  │   │   │   ├── 乡（设民兵什长）
  │   │   │   │   └── 村（十户一甲，抽丁充民兵）
```

这套体系实际上是后来明代"里甲制"和"卫所制"的雏形。它将军事组织与行政组织嵌套在一起，形成了一个从中央到村庄的垂直管控网络。这种设计的精妙之处在于：平时，民兵务农，不增加财政负担；战时，民兵可以迅速转化为辅助军事力量，配合正规军作战。

### 3.4.5 江南经济恢复为争霸奠基

经过数年的休养生息，应天及周边地区的经济状况有了显著改善。

农业方面，军屯和民田的生产逐步恢复，粮食产量稳步增长。据《明太祖实录》记载，至正二十年代后期，应天府的粮仓已经积累了足以支撑数年战争的储备粮。

人口方面，社会秩序的稳定吸引了大量流民回归。从外地逃来的百姓在应天安家落户，劳动力供给增加，进一步推动了农业生产的恢复。

财政方面，规范的赋税制度使财政收入稳定化、可预期化。朱元璋不再需要靠"打粮"来维持军队，这对于一个试图从义军首领转型为国家创建者的人来说，意义非凡。

商业方面，社会安定带来了商业的复苏。应天作为江南重镇，商旅往来逐渐恢复，市集重新繁荣。商税成为赋税收入的一个补充来源。

以下为休养生息政策的综合成效评估：

| 领域 | 措施 | 效果 |
|------|------|------|
| 军事后勤 | 推行军屯 | 驻军粮食半自给，减轻后方压力 |
| 财政税收 | 减免赋税、清查田亩 | 民心归附，税基稳固 |
| 农业生产 | 兴修水利 | 灌溉面积扩大，旱涝减轻 |
| 地方治安 | 民兵合一 | 农村秩序稳定，流寇难以渗透 |
| 人口增长 | 安民政策 | 流民回归，劳动力增加 |
| 商业贸易 | 社会安定 | 市集复苏，商税补充财政 |

> 怕浪猫在梳理完这段历史后，有一个强烈的感受：真正的战略家，不是那个能想出最精妙战术的人，而是那个能在正确的时间做正确的事的人。朱元璋在1356年到1360年这四年间，没有打什么惊天动地的大仗，但他做的每一件事——定都、招贤、屯田、减税、修水利——都在为未来的胜利积累能量。这就是"广积粮"的真正含义：不是积累粮食，而是积累国力。

朱升的九字策、刘基的十八策、李善长的制度建设，三股力量在应天交汇，将一个泥腿子起义军改造成了一个初具规模的国家政权。江南的经济恢复为朱元璋提供了充足的粮草和稳定的大后方，而儒士集团的辅佐则为政权注入了制度和文化灵魂。

这一切准备就绪之后，朱元璋即将面对他人生中最大的挑战——与陈友谅的生死决战。
