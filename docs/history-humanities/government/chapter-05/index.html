第五章：国务院（中央人民政府）

5.1 国务院的宪法地位与组成​

宪法地位​

国务院，即中央人民政府，是最高国家权力机关的执行机关，也是最高国家行政机关。这一双重定位源自《中华人民共和国宪法》第八十五条的明确规定，赋予了国务院在国家机构体系中独特而关键的地位。

作为最高国家权力机关的执行机关，国务院对全国人民代表大会负责并报告工作；在全国人大闭会期间，对全国人民代表大会常务委员会负责并报告工作。这一关系体现了"议行合一"的政体特征——国家行政机关由权力机关产生、受其监督、向其负责。国务院的全部职权均源于全国人大及其常委会的授予，不得越权行事。

作为最高国家行政机关，国务院统一领导全国地方各级行政机关的工作，有权改变或撤销地方各级国家行政机关的不适当的决定和命令。这种"统一领导"体制确保了国家行政管理的协调性与一致性，避免了政出多门、各自为政的局面。

组成人员​

根据《宪法》第八十六条和《国务院组织法》的规定，国务院由下列人员组成：

  • 总理一人
  • 副总理若干人
  • 国务委员若干人
  • 各部部长（现任26个组成部门）
  • 各委员会主任
  • 中国人民银行行长
  • 审计长
  • 秘书长一人

国务院总理由国家主席提名，经全国人民代表大会投票决定，由国家主席任命。国务院其他组成人员的人选由总理提名，经全国人民代表大会（或在其闭会期间经全国人大常委会）决定，由国家主席任命。

国务院每届任期与全国人民代表大会每届任期相同，均为五年。总理、副总理、国务委员连续任职不得超过两届——这一限制性规定旨在防止权力过度集中，保障领导层的有序更替。

法律依据​

  • 《中华人民共和国宪法》第八十五条至第九十二条
  • 《中华人民共和国国务院组织法》（2024年修订版）
  • 《国务院工作规则》

5.2 总理、副总理、国务委员、秘书长的职责分工​

总理​

总理是国务院的最高行政首长，对国务院工作负总责。总理的主要职责包括：

  1. 全面领导：领导国务院全面工作，召集和主持国务院全体会议、国务院常务会议。
  2. 人事提名：向全国人大或其常委会提名国务院其他组成人员人选。
  3. 签署发布：签署国务院令，发布行政法规、决定和命令。
  4. 预算编制：组织编制和执行国民经济和社会发展计划及国家预算。
  5. 对外代表：在对外事务中代表中央人民政府进行高层交往。

总理负责制的核心在于"集中统一"——各副总理、国务委员协助总理工作，对总理负责；各部门工作中的重大问题须及时向总理报告。这一制度设计确保了行政效率与责任明确。

副总理​

副总理协助总理工作，按分工负责特定领域。当前实践中，副总理通常按经济、社会、外交、科技等领域进行分工，各自联系若干部委。副总理可在总理授权下主持部分国务院会议，代行部分总理职权。在总理缺位时，由排名第一的副总理代行总理职务。

副总理的分工安排具有较强的灵活性，通常根据国民经济和社会发展的重点任务进行动态调整。例如，一位副总理可能同时分管发展改革、财政、金融等多个经济核心领域，另一位则分管教育、科技、卫生等社会事业。

国务委员​

国务委员的行政级别与副总理相同（副国级），但其地位略低于副总理。国务委员同样协助总理工作，但通常承担更为具体的专项职责。部分国务委员兼任部部长（如国防部长、外交部长、公安部长等），兼任部长的国务委员直接领导所在部门的工作，同时参与国务院全局性重大事项的讨论决策。

国务委员的设置体现了国务院领导层"精干高效"的原则——既保证了高层决策的参与度，又避免了副总理职数过多导致的协调成本上升。

秘书长​

国务院秘书长在总理领导下，负责处理国务院的日常工作，领导国务院办公厅的工作。秘书长的主要职责包括：

  1. 日常运转：协调国务院各组成部门之间的日常工作，确保政令畅通。
  2. 会议组织：协助总理组织国务院全体会议、常务会议，负责会议议题的审核与编排。
  3. 文件管理：审核以国务院名义发布的文件，把关公文质量。
  4. 信息汇总：汇集各部委及地方政府的重要信息，向国务院领导提供决策参考。
  5. 接待联络：负责国务院的对外联络和重要接待工作。

秘书长是国务院运转的"中枢节点"——上传下达、协调左右，其角色类似于大型企业的首席运营官（COO），虽不直接决策重大事项，但对国务院日常运作的效率与质量起着至关重要的作用。

5.3 国务院全体会议与常务会议制度​

国务院全体会议​

国务院全体会议是国务院最高层次的会议形式，由总理召集和主持。根据《国务院工作规则》，全体会议的主要参加人员包括：

  • 正式成员：总理、副总理、国务委员、各部部长、各委员会主任、中国人民银行行长、审计长、秘书长
  • 列席人员：根据议题需要安排有关部门、单位负责人列席

全体会议的主要任务包括：

  1. 讨论决定国务院工作中的重大事项，如国民经济和社会发展计划草案、国家预算草案等；
  2. 部署国务院的重要工作；
  3. 通报国内外重大形势，统一各部门的认识和行动；
  4. 讨论需要由全体会议决定的其他事项。

全体会议通常每半年召开一次，必要时可临时召开。全体会议的议题由总理确定，或由分管副总理、国务委员提出建议后报总理审定。

国务院常务会议​

国务院常务会议是国务院经常性的决策会议，由总理召集和主持。参加人员包括：

  • 正式参加：总理、副总理、国务委员、秘书长
  • 固定列席：国务院副秘书长、办公厅主任等
  • 按需列席：有关部门、单位负责人根据议题需要列席

常务会议的主要任务包括：

  1. 讨论通过向全国人大常委会提请的议案；
  2. 审议行政法规草案；
  3. 讨论决定国务院工作中的重要事项；
  4. 通报和讨论其他重要事项。

常务会议一般每月召开2-3次，频率远高于全体会议，是国务院日常决策的核心机制。会议实行民主集中制原则——与会人员充分发表意见，由总理最后做出决定。对于意见分歧较大的事项，总理可决定暂缓表决、另行研究。

会议制度的运作特点​

国务院会议制度体现了"民主集中、效率优先"的运作逻辑：

  • 议题筛选机制：并非所有事项都上会讨论。一般事项由分管领导审批处理，重要事项提交常务会议，重大事项提交全体会议，确保会议聚焦于真正需要集体决策的问题。
  • 文件预审机制：上会议题须提前提交相关材料，经国务院办公厅审核后分发与会人员预读，提高会议效率。
  • 决策留痕机制：会议纪要如实记录讨论过程和决定事项，作为执行依据和 archival 记录。
  • 会前协调机制：对涉及多个部门的事项，会前由分管副总理或国务委员召开协调会，力求达成一致意见后再上会。

5.4 国务院办公厅的职能与运作​

机构定位​

国务院办公厅是协助国务院领导处理日常工作的机构，不列入国务院组成部门序列，但在实际运转中发挥着不可替代的枢纽作用。如果说国务院是国家行政管理的"大脑"，那么办公厅就是确保指令有效传递的"神经系统"。

主要职能​

根据《国务院办公厅职能配置、内设机构和人员编制规定》（即"三定"方案），办公厅的主要职能包括：

（一）公文处理

负责国务院及办公厅各类公文的起草、审核、运转和管理工作。具体包括：

  • 起草国务院领导讲话稿、政府工作报告等重要文稿；
  • 审核各部门报送国务院的请示、报告，提出拟办意见；
  • 起草以国务院或国务院办公厅名义发布的文件；
  • 负责公文的登记、分发、传阅、催办和归档。

（二）会议服务

负责国务院全体会议、常务会议及各类专题会议的组织服务工作，包括议题收集、材料准备、会议记录、纪要起草和决定事项的督查落实。

（三）信息处理

汇集、分析、报送国内外重要信息，为国务院领导提供决策参考。办公厅设有专门的信息机构，通过多种渠道收集经济社会运行数据、社情民意、国际动态等信息，编报各类信息刊物。

（四）督查督办

对党中央、国务院重大决策部署的落实情况进行督促检查。办公厅设有督查室，对国务院常务会议决定事项、领导批示件、重要会议部署等跟踪督办，确保"政令出得了中南海、落得到实处"。

（五）协调联络

在国务院领导与各部委、地方政府之间发挥桥梁纽带作用，协调跨部门事项，安排领导活动，处理来文来访。

内设机构​

国务院办公厅内设多个职能司局，主要包括：秘书一局至秘书四局（按分工对口服务不同领域的副总理/国务委员）、综合司、文电司、会议司、信息司、督查室、人事司、行政司等。此外，国务院研究室作为直属机构承担政策研究和文稿起草职能，与办公厅密切协作。

运作机制​

办公厅的运作遵循"分级负责、归口办理"的原则：

  • 来文按内容归口到相应秘书局提出拟办意见，报分管副秘书长审批后呈送分管副总理/国务委员；
  • 重大事项由秘书长协调后报总理审定；
  • 需要多部门协商的事项，由办公厅召开协调会，形成一致意见后上报。

这种层层把关、逐级负责的运作模式，既保证了公文处理的质量和效率，又避免了对国务院领导时间的过度占用。

5.5 国务院议事协调机构与临时机构​

设立目的与法律依据​

国务院议事协调机构和临时机构是为解决跨部门、跨领域的重大问题而设立的特别机制。根据《国务院行政机构设置和编制管理条例》，国务院议事协调机构承担跨国务院行政机构的重要业务工作的组织协调任务。

这些机构的设立反映了现代国家治理的一个基本现实：政府职能日益复杂、交叉，单一部门难以独自应对重大问题，需要建立高于部门层级的协调机制来统筹推进。

议事协调机构的主要类型​

（一）委员会型

以"委员会"命名的议事协调机构，通常由国务院领导担任负责人，相关部门负责人为成员。例如：

  • 国家防汛抗旱总指挥部：负责全国防汛抗旱工作的组织指挥，总指挥通常由国务院副总理担任。
  • 全国绿化委员会：负责全国造林绿化工作的统筹协调。
  • 国务院安全生产委员会：负责全国安全生产工作的指导协调，主任通常由国务院副总理担任。
  • 国家禁毒委员会：负责全国禁毒工作的组织领导。

（二）领导小组型

以"领导小组"命名的议事协调机构，通常围绕特定重大战略或任务设立。例如：

  • 国家应对气候变化及节能减排工作领导小组
  • 国务院推进政府职能转变和"放管服"改革协调小组
  • 国家教材委员会

（三）指挥部型

以"指挥部"命名的机构，通常针对应急处置任务设立。如重大自然灾害发生后成立的救灾指挥部、重大疫情防控期间成立的联防联控机制等。

议事协调机构的运作特点​

  1. 不取代部门：议事协调机构不替代组成部门的职能，各部门在各自职责范围内开展工作，协调机构负责解决部门间的分歧和衔接问题。
  2. 办事机构依托：议事协调机构一般不设实体办事机构，其日常工作由某个相关部门承担（即"办事机构设在XX部"）。这种"虚设实办"的模式既保证了协调力度，又避免了机构膨胀。
  3. 定期会议机制：通过全体会议、专题会议等形式开展工作，重大事项集体研究决定。
  4. 动态调整：议事协调机构根据实际需要设立或撤销，具有较强的灵活性。历次机构改革中，都会对议事协调机构进行清理和整合。

临时机构​

临时机构是针对特定阶段性任务而设立的，任务完成后即行撤销。常见的临时机构包括：

  • 重大活动组织委员会（如奥运会工作领导小组）
  • 专项治理工作组（如各类专项整治行动领导小组）
  • 临时性调查组（如重大事故调查组）

临时机构的设置期限通常在设立时即予以明确，如需延长须经国务院批准。

规范与管理​

近年来，国务院对议事协调机构和临时机构进行了持续规范：

  • 严控新设：确需设立的，须严格论证、按程序报批，不得擅自设立。
  • 定期清理：对已完成任务、长期未开展工作的机构及时撤销；对职能相近的机构予以合并。
  • 明确职责：每个机构须有明确的职责范围、工作规则和议事程序，避免"虚化"或"越位"。
  • 控制规格：议事协调机构一般不设实体编制，负责人和成员均为兼职，防止机构"实体化"导致编制扩张。

这种动态管理机制确保了议事协调机构"因事而设、事毕即撤"的灵活性，有效避免了机构臃肿和职能重叠。

官方依据​

  1. 《中华人民共和国宪法》第八十五条至第九十二条
  2. 《中华人民共和国国务院组织法》（2024年修订）
  3. 《国务院工作规则》
