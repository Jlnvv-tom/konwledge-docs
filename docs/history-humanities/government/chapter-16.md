# 第十六章：经济管理部门

经济管理部门是中国政府治理体系的核心支柱，承担着宏观调控、财政收支、金融监管、内外贸易统筹以及国有经济管理等关键职能。这些部门共同构成了社会主义市场经济体制下的"宏观调控之手"，其职能设置和权力边界直接关系到国民经济运行的质量与效率。2023年以来的机构改革进一步优化了经济管理部门的职能配置，特别是金融监管体制的重大调整，标志着中国特色宏观经济治理体系进入新阶段。

---

## 16.1 国家发改委：从计划经济到宏观调控的转型

### 核心职责

国家发展和改革委员会（简称"国家发改委"）是国务院组成部门，前身为1952年成立的国家计划委员会。从"计划"到"发展"再到"发展和改革"的名称变迁，折射出中国经济管理体制从指令性计划向战略规划与宏观调控转型的深刻变革。

国家发改委的核心职责可概括为"五大职能"：

1. **宏观调控**：研究拟定国民经济和社会发展战略、中长期规划和年度计划，监测宏观经济运行态势，提出宏观调控政策建议。
2. **投资管理**：审批、核准、备案固定资产投资项目，安排中央财政性建设资金，管理国际金融组织和外国政府贷款。
3. **经济体制改革**：研究经济体制改革重大问题，组织拟订综合性产业政策，协调经济与社会发展的重大比例关系。
4. **价格管理**：监测预测价格总水平变动，实施价格调控，管理重要商品和服务价格。
5. **能源与粮食安全**：承担国家能源局、国家粮食和物资储备局的管理职能，统筹能源安全与粮食安全保障。

### 组织架构

国家发改委内设机构众多，主要包括：政策研究室、发展规划司、国民经济综合司、经济运行调节局、固定资产投资司、利用外资和境外投资司、地区经济司、西部开发司、东北振兴司、基础设施发展司、产业经济与技术经济司、创新和高技术发展司、资源节约和环境保护司、社会发展司、经济贸易司、财政金融和信用建设司、价格司、法规司、体制改革综合司等。

国家发改委还管理国家能源局、国家粮食和物资储备局两个副部级机构。此外，国家国防动员办公室也挂靠在国家发改委。

### 关键政策领域

**五年规划编制与实施**是国家发改委最具标志性的职能。从"一五"计划到"十四五"规划，国家发改委（及其前身国家计委）始终是国民经济和社会发展中长期规划编制的核心部门。"十四五"规划纲要首次设置了安全保障篇章，体现了发展和安全并重的新理念。

**投资项目审批**是国家发改委影响经济运行最直接的权力杠杆。根据《政府投资条例》（国务院令第712号）和《企业投资项目核准和备案管理条例》（国务院令第673号），国家发改委负责审批政府投资项目、核准重大项目、备案一般项目。近年来，投资审批制度改革持续推进，"放管服"改革大幅简化了审批流程。

**区域协调发展战略**的统筹推进也是国家发改委的重要职责，包括京津冀协同发展、长江经济带发展、粤港澳大湾区建设、长三角一体化发展、黄河流域生态保护和高质量发展等重大区域战略。

**"双碳"目标协调**：国家发改委承担碳达峰碳中和工作领导小组办公室职责，统筹推进"1+N"政策体系建设。

### 职能转型趋势

国家发改委的职能转型体现了三个重要趋势：一是从直接配置资源向营造制度环境转变，审批事项大幅精简；二是从单纯经济增长目标向高质量发展综合目标转变，引入能耗"双控"、碳排放强度等约束性指标；三是从国内视角向全球视野转变，积极参与"一带一路"建设、国际产能合作等全球治理议题。

## 16.2 财政部与税务总局：财政收支与税制

### 财政部

**核心职责**

财政部是国务院组成部门，主管国家财政收支、财税政策和国有资本经营预算。其核心职能包括：

1. 拟订财税发展战略、规划、政策和改革方案并组织实施。
2. 财政收支管理：编制年度中央预决算草案并组织执行，管理中央财政收入和支出。
3. 税收政策管理：提出税收政策建议，参与税收法律法规起草，管理关税政策。
4. 国有资本经营预算：管理国有资本收益，推动国有资本经营预算与一般公共预算的统筹衔接。
5. 政府债务管理：管理国债和地方政府债券，控制政府债务风险。
6. 会计与注册会计师行业管理：制定国家统一的会计制度，管理注册会计师行业。

**组织架构**

财政部内设机构包括：办公厅、综合司、条法司、税政司、关税司、预算司、国库司、国防司、行政政法司、科教和文化司、经济建设司、农业农村司、社会保障司、自然资源和生态环境司、金融司、资产管理司、对外财经交流司、会计司、监督评价局等。此外，财政部还在各地派驻财政监管局（原专员办），负责中央财政事项的属地监管。

**关键政策领域**

*现代财政制度建设*：推进中央与地方财政事权和支出责任划分改革，建立权责清晰、财力协调、区域均衡的中央与地方财政关系。
*政府债务风险防控*：建立地方政府债务限额管理制度和风险预警机制，坚决遏制隐性债务增量。
*减税降费*：作为积极财政政策的重要抓手，近年来大规模减税降费政策由财政部牵头制定。

### 国家税务总局

国家税务总局是国务院直属机构，负责税收征管工作。2023年机构改革后，税务总局职能进一步优化。

**核心职责**：拟定税收法律法规草案，组织实施税收征收管理体制改革，负责各项税收的征收管理，开展税务稽查和纳税服务。

**关键政策领域**：

- **金税工程**：以信息化手段实现税收征管的现代化，金税四期工程推动"以票控税"向"以数治税"转型。
- **个人所得税改革**：2018年个税改革引入综合征收、专项附加扣除等制度创新，实现从分类税制向综合与分类相结合的税制转变。
- **减税降费落实**：大规模增值税留抵退税、小型微利企业税收优惠等政策的落地执行。
- **国际税收合作**：参与BEPS（税基侵蚀和利润转移）行动计划，推进"一带一路"税收征管合作机制。

财政部与税务总局的关系是"政策制定"与"征收执行"的分工关系。财政部负责税收政策设计，税务总局负责税收征管执行。在关税领域，财政部关税司负责关税政策，海关总署负责关税征管。

## 16.3 中国人民银行：货币政策与金融稳定

### 核心职责

中国人民银行（简称"央行"或"人行"）是国务院组成部门，是中华人民共和国的中央银行。根据《中华人民共和国中国人民银行法》（1995年通过，2003年修正），中国人民银行的核心职责包括：

1. **货币政策制定与执行**：依法制定和执行货币政策，运用存款准备金率、利率、再贷款、公开市场操作等货币政策工具，保持币值稳定。
2. **金融宏观审慎管理**：建立和完善金融宏观审慎框架，防范系统性金融风险。
3. **人民币发行与管理**：发行人民币，管理人民币流通。
4. **支付清算体系**：维护支付、清算系统的正常运行。
5. **外汇管理**：实施外汇管理，监督管理银行间外汇市场。
6. **金融统计**：负责金融业的统计、调查、分析和预测。
7. **征信管理**：管理征信业，推动社会信用体系建设。

### 组织架构

中国人民银行总行设在北京，内设机构包括：办公厅、条法司、货币政策司、宏观审慎管理局、金融市场司、金融稳定局、调查统计司、会计财务司、支付结算司、科技司、货币金银局、国库局、国际司、征信管理局、反洗钱局等。

中国人民银行在全国设立分支机构，实行跨区域分行体制（上海、天津、沈阳、南京、济南、武汉、广州、成都、西安九大分行）。此外，中国人民银行还在境外设立代表处，如驻美洲代表处、驻欧洲代表处等。

中国人民银行管理国家外汇管理局（副部级）。

### 关键政策领域

**货币政策框架转型**：从数量型调控向价格型调控转变，完善以公开市场操作利率为短期政策利率、以中期借贷便利（MLF）利率为中期政策利率的利率体系，推动贷款市场报价利率（LPR）形成机制改革。

**金融稳定与风险防范**：2023年机构改革后，中国人民银行剥离了金融控股公司日常监管和消费者权益保护等职能，更加聚焦于货币政策和宏观审慎"双支柱"调控框架。金融稳定保障基金的设立和完善为系统性风险防范提供了制度性工具。

**数字人民币（e-CNY）**：作为全球主要经济体中最早启动央行数字货币研发的机构，中国人民银行推动的数字人民币已在多个城市开展试点，覆盖零售支付、政务服务等场景。

**人民币国际化**：推动人民币在跨境贸易投资中的使用，建设人民币跨境支付系统（CIPS），签署双边本币互换协议。

## 16.4 商务部：内外贸易与国际合作

### 核心职责

商务部是国务院组成部门，统筹国内国际贸易和国际经济合作。其核心职责包括：

1. **国内贸易管理**：拟定国内贸易发展规划，推进流通产业结构调整，管理商品市场体系建设和商贸服务业发展。
2. **对外贸易管理**：拟定对外贸易发展规划，管理货物贸易、服务贸易和技术贸易，实施进出口商品配额和许可证管理。
3. **外商投资管理**：指导和管理外商投资，负责外商投资企业设立及变更备案管理。
4. **对外投资合作**：管理对外直接投资、对外承包工程和对外劳务合作。
5. **国际经贸谈判**：组织协调反倾销、反补贴、保障措施等进出口公平贸易相关工作，参与多双边经贸谈判。
6. **特殊经济区域管理**：管理国家级经济技术开发区、边境经济合作区、跨境经济合作区等。

### 组织架构

商务部内设机构包括：办公厅、人事司、综合司、政研室、条约法律司、财务司、市场体系建设司、流通业发展司、市场运行和消费促进司、对外贸易司、服务贸易和商贸服务业司、产业安全与进出口管制局、外国投资管理司、对外投资和经济合作司、贸易救济调查局、国际经贸关系司、世界贸易组织司（中国政府世界贸易组织通报咨询局）、亚洲司、西亚北非司、美洲大洋洲司、欧洲司、台港澳司、电子商务司、投资促进事务局等。

### 关键政策领域

**自贸试验区建设**：自2013年上海自贸试验区率先设立以来，全国已设立22个自贸试验区（截至2024年），形成覆盖东西南北中的改革开放新格局。自贸试验区的核心任务是制度创新，包括投资管理体制改革（"准入前国民待遇+负面清单"）、贸易便利化改革、金融开放创新等。

**"一带一路"经贸合作**：推动贸易畅通，建设经贸合作区，推动重大项目落地。

**消费促进**：组织实施"消费促进年"等系列活动，推进城市一刻钟便民生活圈建设，促进汽车、家电等大宗消费。

**跨境电商发展**：推动跨境电商综合试验区建设，目前全国已设立165个跨境电商综试区（截至2024年），成为外贸新业态的重要载体。

## 16.5 国家金融监督管理总局：综合金融监管

### 核心职责

国家金融监督管理总局（简称"金融监管总局"）是2023年机构改革中新设立的国务院直属机构，在中国银保监会基础上组建，整合了中国人民银行对金融集团日常监管、消费者权益保护等职责以及证监会的投资者保护职责。这标志着中国金融监管体制从"一委一行两会"（国务院金融稳定发展委员会、人民银行、银保监会、证监会）向"一行一局一会"（人民银行、金融监管总局、证监会）的新格局转变。

金融监管总局的核心职责包括：

1. **统一监督管理**：依法对除证券业之外的金融业实行统一监督管理，强化机构监管、行为监管、功能监管、穿透式监管、持续监管。
2. **系统性风险防范**：统筹负责金融消费者权益保护，加强风险分析和研判，建立健全金融风险早期纠正机制。
3. **金融消费者权益保护**：承担金融消费者权益保护职责，制定金融消费者保护制度，开展金融知识普及和投资者教育。
4. **小微信贷服务监管**：加强对小微企业、"三农"等普惠金融领域的服务监管。

### 组织架构

金融监管总局内设机构包括：办公厅（党委办公室）、政策研究司、法规司、统计与风险监测司、公司治理监管司、普惠金融司、机构检查局、非银机构检查局、重大风险事件与案件处置局、消费者权益保护局、打击非法金融活动局、内审司等。

金融监管总局在全国设立省级监管局（31个省/自治区/直辖市加5个计划单列市），实行垂直管理。

### 关键政策领域

**"五大监管"体系**：机构监管、行为监管、功能监管、穿透式监管、持续监管——这是金融监管总局成立后确立的核心监管理念，强调"长牙带刺、有棱有角"的监管风格。

**中小金融机构风险化解**：重点推进中小银行、信托公司、保险机构等的风险处置，完善金融机构风险处置的法治化市场化机制。

**房地产金融监管**：实施房地产金融审慎管理制度，落实"金融16条"等政策，促进房地产市场平稳健康发展。

**消费者权益保护**：统一行使银行业、保险业、信托等领域的消费者权益保护职能，强化金融消费者八项基本权利保障。

### 改革意义

金融监管总局的成立解决了长期以来金融监管中的"九龙治水"问题——过去银保监会管银行保险、证监会管证券、人民银行管金融集团和部分消费者保护，存在监管空白和监管套利。新体制下，除证券业外所有金融业态均纳入统一监管框架，人民银行专注于货币政策与宏观审慎，证监会专注于资本市场，金融监管总局负责全面微观审慎监管和行为监管。

## 16.6 证监会与外汇管理局

### 中国证券监督管理委员会

**核心职责**

证监会是国务院直属机构，依法对全国证券期货市场进行集中统一监督管理。根据《中华人民共和国证券法》（2019年新修订）和《中华人民共和国证券投资基金法》，证监会核心职责包括：

1. **市场监管**：监督管理股票、债券、期货、期权等证券期货品种的发行、交易、登记结算。
2. **机构监管**：监督管理证券公司、基金管理公司、期货公司等证券期货经营机构。
3. **上市公司监管**：监督管理上市公司信息披露、公司治理、并购重组等。
4. **执法稽查**：查处证券期货违法违规行为，包括内幕交易、操纵市场、虚假陈述等。
5. **投资者保护**：承担证券期货投资者保护职责。

**组织架构**

证监会内设机构包括：办公厅、综合业务司、发行监管司、公众公司监管司、私募基金监管司、市场监管一司、市场监管二司、非上市公众公司监管司、证券基金机构监管司、期货监管司、稽查局、法律部、行政处罚委员会、投资者保护局等。在全国设有36个证监局和2个专员办（深圳专员办、上海专员办）。

**关键政策领域**：

- **全面注册制改革**：2023年2月，全面实行股票发行注册制正式实施，从科创板、创业板试点推广到主板，这是中国资本市场30年来最重大的基础性制度改革。
- **上市公司质量提升**：推动提高上市公司质量行动计划，完善退市制度，实现"应退尽退"。
- **私募基金监管**：加强对私募投资基金的登记备案管理和事中事后监管。
- **跨境监管合作**：与美国PCAOB就中概股审计监管达成合作安排。

### 国家外汇管理局

**核心职责**

国家外汇管理局是国务院直属机构，由中国人民银行管理。根据《中华人民共和国外汇管理条例》（2008年修订），其主要职责包括：

1. **国际收支管理**：编制国际收支平衡表，监测国际收支状况。
2. **外汇市场管理**：监督管理银行间外汇市场，维护人民币汇率基本稳定。
3. **外汇储备管理**：经营管理国家外汇储备，实现外汇储备的安全、流动和保值增值。
4. **跨境资金流动监管**：监测和管理跨境资金流动，防范跨境资金流动风险。
5. **外汇检查与执法**：查处外汇违法违规行为。

**组织架构**

外汇局内设机构包括：综合司、国际收支司、经常项目管理司、资本项目管理司、管理检查司、外汇业务中心等。在全国设立分支机构，与人民银行分支机构合署办公。

**关键政策领域**：

- **外汇储备经营管理**：中国拥有全球最大的外汇储备（约3.2万亿美元），外汇局坚持"安全性、流动性、收益性"原则进行多元化配置。
- **跨境贸易投资便利化**：推进货物贸易外汇收支便利化试点，简化外汇业务办理流程。
- **资本项目可兑换**：稳妥推进资本项目开放，完善跨境融资宏观审慎管理框架。
- **人民币汇率形成机制**：完善以市场供求为基础、参考一篮子货币进行调节的有管理的浮动汇率制度。

## 16.7 国资委：国有经济布局与国企改革

### 核心职责

国务院国有资产监督管理委员会（简称"国务院国资委"）是国务院直属特设机构。根据《中华人民共和国企业国有资产法》（2008年）和《企业国有资产监督管理暂行条例》（国务院令第378号），国资委根据授权依法履行出资人职责，负责监督管理中央企业（不含金融类企业）国有资产。

国资委的核心职责包括：

1. **出资人职责履行**：负责中央企业国有资产的基础管理，指导推进国有企业改革和重组。
2. **国有经济布局优化**：推动国有资本向关系国家安全、国民经济命脉的重要行业和关键领域集中，向前瞻性战略性新兴产业集中。
3. **业绩考核与分配管理**：完善中央企业负责人经营业绩考核制度，确定企业负责人薪酬。
4. **国有资产保值增值**：建立和完善国有资产保值增值指标体系，防止国有资产流失。
5. **央企党建**：指导中央企业党的建设。

### 组织架构

国资委内设机构包括：办公厅（党委办公厅）、综合研究局、政策法规局、规划发展局、财务监管与运行评价局、产权管理局、考核分配局、科技创新局、企业改革局、公司治理局、企业领导人员管理一局/二局、党建工作局（党委组织部）、宣传局、群众工作局（党委统战部）、国际合作局、社会责任局、监督追责局、巡视办公室等。

截至2024年，国务院国资委监管的中央企业共97家，涵盖能源、通信、军工、航天航空、装备制造、交通运输、钢铁、建筑等领域。

### 关键政策领域

**国企改革三年行动（2020-2022年）**：以"可量化、可考核"的指标体系推动国企改革落地，重点完成中国特色现代企业制度建设、国有经济布局优化和结构调整、混合所有制改革、市场化经营机制改革等任务。

**新一轮国企改革深化提升行动（2023-2025年）**：在三年行动成果基础上，围绕"增强核心功能、提升核心竞争力"两大目标，重点推进科技创新、产业控制、安全支撑"三大作用"。

**"压减"与"瘦身健体"**：大幅压缩央企管理层级和法人数量，从最多时的5级以上压缩至4级以内，减少法人户数超过1.5万户。

**混合所有制改革**：在充分竞争领域稳妥推进混改，引入积极股东参与公司治理，以"混"促"改"。

**央企专业化整合**：通过无偿划转、有偿收购、股份合作等方式，推进央企在同质化领域的专业化整合，如中国宝武重组马钢、太钢，中化集团与中国化工合并等。

### 国资监管体制的演进

从2003年国资委成立时"管资产与管人管事相结合"的体制，到以管资本为主的国资监管体制改革，国资委的职能定位经历了深刻转变。"管资本"改革的核心是：从直接管理企业经营行为向管理国有资本投资运营转变，通过组建国有资本投资公司和国有资本运营公司两类公司，实现所有权与经营权的分离。
