第十章：中共中央机构与党政关系

10.1 中国共产党领导的多党合作和政治协商制度​

制度内涵​

中国共产党领导的多党合作和政治协商制度是中国的一项基本政治制度，也是中国政党制度的核心特征。这一制度与西方多党竞争制和一党制均有本质区别，体现了"共产党领导、多党派合作，共产党执政、多党派参政"的基本格局。

在这一制度框架下：

  • 中国共产党是唯一执政党，处于领导核心地位，对国家政权实行全面领导。
  • 八个民主党派是参政党，不是在野党，也不是反对党，而是与共产党通力合作的伙伴。
  • 人民政协是制度载体，多党合作和政治协商主要通过人民政协（中国人民政治协商会议）来实现。

八个民主党派​

中国的八个民主党派分别是：

  1. 中国国民党革命委员会（民革）：主要由原中国国民党人士及其他爱国民主人士组成。
  2. 中国民主同盟（民盟）：主要由文化教育界和科学技术界的中高级知识分子组成。
  3. 中国民主建国会（民建）：主要由经济界人士和相关专家学者组成。
  4. 中国民主促进会（民进）：主要由教育、文化、出版、科学技术领域的中高级知识分子组成。
  5. 中国农工民主党（农工党）：主要由医药卫生、人口资源、生态环境领域的中高级知识分子组成。
  6. 中国致公党：主要由归侨、侨眷中的中上层人士和与海外有联系的代表性人士组成。
  7. 九三学社：主要由科学技术界的中高级知识分子组成。
  8. 台湾民主自治同盟（台盟）：由台湾省人士组成。

合作与协商方式​

多党合作的主要形式包括：

  1. 政治协商：中共中央就重大方针政策和重要人事安排与各民主党派中央进行协商，协商于决策之前和决策实施之中。
  2. 民主监督：各民主党派对共产党和国家机关的工作进行民主监督，提出批评和建议。
  3. 参政议政：民主党派成员在各级人大、政府、政协中担任职务，参与国家事务管理。
  4. 政党协商：中共中央主要负责同志定期与各民主党派中央负责人举行座谈，就重大问题进行协商。

10.2 中央委员会、中央政治局及其常务委员会​

党的中央组织体系​

根据《中国共产党章程》，党的中央组织包括：

  • 全国代表大会：党的最高领导机关，每五年举行一次。
  • 中央委员会：由全国代表大会选举产生，在全国代表大会闭会期间执行全国代表大会的决议，领导党的全部工作，对外代表中国共产党。
  • 中央政治局：由中央委员会全体会议选举产生，在中央委员会全体会议闭会期间行使中央委员会的职权。
  • 中央政治局常务委员会：由中央政治局选举产生，是党的最高领导机构。

中央委员会​

中央委员会委员和候补委员由全国代表大会直接选举产生。中央委员会一般每年召开一次全体会议（全会），研究决定党和国家重大问题。中央委员会的职责包括：

  • 向全国代表大会负责并报告工作
  • 选举中央政治局、中央政治局常务委员会和中央委员会总书记
  • 根据中央政治局常务委员会的提名，通过中央书记处成员
  • 决定中央军事委员会组成人员
  • 在全国代表大会闭会期间，决定个别中央委员的增补和递补

中央政治局​

中央政治局在中央委员会全体会议闭会期间行使中央委员会的职权，是党的日常最高决策机构。中央政治局一般每月召开一次会议，讨论决定党和国家重大问题。

中央政治局常务委员会​

中央政治局常务委员会（简称"中央政治局常委会"）是党的最高领导核心。常委会由5至7人组成，包括：

  • 中央委员会总书记：主持中央委员会工作
  • 国务院总理
  • 全国人大常委会委员长
  • 全国政协主席
  • 中央纪委书记
  • 其他常委（通常包括负责书记处日常工作的书记、负责宣传或组织工作的书记等）

中央政治局常委会实行集体领导制度，重大问题集体讨论决定。总书记在常委会中处于核心地位，但重大决策须经集体讨论。

"两个确立"与"两个维护"​

新时代强调"两个确立"（确立习近平同志党中央的核心、全党的核心地位，确立习近平新时代中国特色社会主义思想的指导地位）和"两个维护"（坚决维护习近平总书记党中央的核心、全党的核心地位，坚决维护党中央权威和集中统一领导），这是当前党的政治建设的核心要求。

10.3 中央书记处、中央纪律检查委员会​

中央书记处​

中央书记处是中央政治局和它的常务委员会的办事机构。其成员由中央政治局常务委员会提名，中央委员会全体会议通过。

中央书记处的职责包括：

  1. 日常工作处理：处理中央日常工作，落实中央政治局的决策。
  2. 综合协调：协调中央各工作部门的工作，确保中央各项部署有效推进。
  3. 文稿起草：起草中央重要文件和领导讲话稿。
  4. 信息汇总：汇总各方信息，向中央政治局及其常委会报告。
  5. 督查落实：对中央重大决策部署的落实情况进行督促检查。

中央书记处书记通常兼任中央办公厅主任、中央组织部部长、中央宣传部部长、中央统战部部长等关键职务，是连接决策层与执行层的关键纽带。

中央纪律检查委员会​

中央纪律检查委员会（简称"中央纪委"）是党的最高纪律检查机关，由党的全国代表大会选举产生。中央纪委的主要职责是：

  1. 维护党章和其他党内法规：检查党的路线、方针、政策和决议的执行情况。
  2. 协助党的委员会推进全面从严治党：加强党风建设和组织协调反腐败工作。
  3. 纪律审查：对党员干部违纪违法问题进行审查调查。
  4. 巡视巡察：组织开展党内巡视工作，发现问题、形成震慑。

如前章所述，中央纪委与国家监察委员会合署办公，履行纪检和监察双重职责。中央纪委书记在党的层级中位列中央政治局常委，体现了纪检工作在党的全局中的重要地位。

中央纪委下设多个监督检查室和审查调查室，按地域和领域分工负责。此外，中央纪委向中央一级党和国家机关派驻纪检组，实现"派驻监督全覆盖"。

10.4 中央决策议事协调机构​

机构类型与功能​

中央决策议事协调机构是党中央为加强对重大工作的统筹协调而设立的特别机制。2018年机构改革后，中央设立了多个委员会和领导小组，作为党中央决策议事协调机构，在中央政治局及其常委会领导下开展工作。

这些机构的共同特征是：

  • 规格高：通常由中央政治局常委担任负责人
  • 跨部门：协调党政军多个部门的工作
  • 决策性：不仅协调，还承担重大决策职能
  • 不替代部门：不取代具体执行部门的职能，而是在更高层面统筹

主要委员会和领导小组​

（一）中央全面深化改革委员会

统筹协调全面深化改革工作，负责改革总体设计、统筹协调、整体推进和督促落实。主任由总书记担任。

（二）中央国家安全委员会

统筹协调涉及国家安全的重大事项和重要工作。这是国家安全领域的最高决策机构，整合了政治安全、国土安全、军事安全、经济安全、文化安全、社会安全、科技安全、信息安全、生态安全、资源安全、核安全等多个领域的安全工作。

（三）中央网络安全和信息化委员会

统筹协调网络安全和信息化工作，是网信领域的最高决策议事协调机构。

（四）中央财经委员会

对经济领域重大工作实行集中统一领导，研究确定经济社会发展重大战略和政策。

（五）中央外事工作委员会

统筹协调外事工作，研究制定外交战略和重大外交政策。

（六）中央全面依法治国委员会

统筹协调全面依法治国工作，是法治建设的最高决策议事协调机构。

（七）中央审计委员会

加强党中央对审计工作的领导，研究提出审计领域重大方针政策。

（八）中央教育工作领导小组

统筹协调教育工作，研究确定教育领域重大事项。

（九）中央机构编制委员会

统筹考虑党和国家机构设置，管理机构编制工作。

运作机制​

各委员会一般下设办公室（设在相关部委），负责日常工作。例如：

  • 中央深改办设在中央政策研究室
  • 中央网信办（中央网络安全和信息化委员会办公室）是独立设置的中央工作机关
  • 中央财办设在中央财经委员会办公室
  • 中央依法治国办设在司法部
  • 中央外办设在中央外事工作委员会办公室

这些办公室作为委员会的办事机构，承担议题准备、文件起草、协调督促等职能，确保委员会决策的有效落实。

10.5 党政关系与合署办公​

党政关系的核心特征​

中国的党政关系不同于西方"政党-国家"二元分立模式。在中国体制下，中国共产党是国家政权的领导核心，党政关系本质上是"党领导国家"的关系。这种领导不是简单的"以党代政"，而是通过以下方式实现：

（一）政治领导

党通过制定路线、方针、政策，为国家机关确定工作方向。党的全国代表大会和中央全会的决议，是国家机关工作的根本遵循。

（二）思想领导

党通过理论创新和思想引领，统一全党全国人民的思想认识。习近平新时代中国特色社会主义思想是全党全国必须坚持的指导思想。

（三）组织领导

党通过向国家机关推荐重要干部人选，实现组织上的领导。"党管干部"原则是干部工作的根本原则——各级人大选举或任命的政府组成人员，其人选由党委研究推荐。

合署办公模式​

"党政合署办公"是近年来党政关系调整的重要制度安排。2018年《深化党和国家机构改革方案》明确提出，对职能相近、联系紧密的党政机构实行合署办公或一套机构两块牌子。主要形式包括：

（一）一个机构两块牌子

部分机构同时承担党内和行政职能，以两个名称对外开展工作。例如：

  • 中央网络安全和信息化委员会办公室/国家互联网信息办公室：中央网信办与国家网信办为一个机构两块牌子。
  • 中央台湾工作办公室/国务院台湾事务办公室：一个机构两个名称。
  • 中央档案馆/国家档案局：一个机构两个名称。
  • 中央保密委员会办公室/国家保密局：一个机构两个名称。

（二）合署办公

两个机构在同一地点办公，共享人员和资源，但保留各自名称。最典型的是中央纪委与国家监察委员会的合署办公。

（三）并入整合

将行政机构的职能并入党的机构，行政机构名义保留或撤销。例如：

  • 中央组织部统一管理公务员工作（国家公务员局并入中央组织部）
  • 中央宣传部统一管理新闻出版和电影工作（国家新闻出版广电局的新闻出版和电影管理职责划入中央宣传部）
  • 中央统战部统一领导国家民族事务委员会、国家宗教事务局工作

"加强党的全面领导"导向​

2018年和2023年两轮机构改革的核心逻辑是加强党对一切工作的领导。改革方案的特点包括：

  1. 强化党中央决策议事协调职能：新设或升级多个中央委员会，确保重大工作由党中央集中决策。
  2. 党政联动改革：党的机构改革与国家机构改革同步推进、统筹实施。
  3. 优化党政职责配置：将一些由政府部门承担的宏观管理职能调整为党中央统一管理，政府机构承担执行职能。
  4. 减少党政职能交叉：通过合署办公和职能整合，解决党政机构设置重叠、职责交叉问题。

党政关系的未来走向​

当前党政关系调整的基本方向是"构建系统完备、科学规范、运行高效的党和国家机构职能体系"。在保持党的领导核心地位的前提下，注重以下平衡：

  1. 党的领导与政府效率的平衡：既要坚持党对一切工作的领导，又要保证政府机关的行政效率和专业能力。
  2. 决策与执行的平衡：党中央侧重于重大决策和统筹协调，政府部门侧重于执行落实和日常管理。
  3. 政治领导与专业管理的平衡：在坚持党管干部的同时，尊重专业人才的专业判断，避免外行领导内行。
  4. 监督与支持的平衡：党的纪检监察监督和政府的自主管理之间保持适度张力，既防止权力失控，又不束缚行政活力。

本章小结：中共中央机构与党政关系构成了中国政治体制的核心架构。中国共产党通过中央委员会、中央政治局及其常委会行使最高领导权，通过中央书记处处理日常工作，通过中央纪委推进全面从严治党。中央决策议事协调机构在新时代大幅强化，确保党对重大工作的集中统一领导。"党政合署办公"模式在保持党的领导核心地位的同时，通过机构整合减少了职能交叉和机构重叠。中国党政关系的独特之处在于：党不是独立于国家政权之外的政治组织，而是嵌入国家政权结构内部、通过法定程序实现领导的执政力量。理解这一体制特征，是理解中国国家治理体系运作逻辑的前提和基础。

第二篇总结：本篇第六至第十章系统梳理了中国中央政府组织架构的全貌——从国务院（中央人民政府）的行政中枢职能，到各组成部门和直属机构的专业化管理分工；从国家监察委员会的独立监察权，到最高人民法院和最高人民检察院的司法权运行；再到中共中央机构与党政关系的体制特征。这一组织架构体现了"党的领导、人民当家作主、依法治国"有机统一的制度逻辑，构成了中国国家治理体系的制度基础。
