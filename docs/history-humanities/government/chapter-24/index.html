第二十四章：公务员职务与职级并行制度

本章导读​

2019年，中国公务员管理制度迎来了一次里程碑式的改革——全面推行职务与职级并行制度。这项改革打破了过去"千军万马挤独木桥"的单一职务晋升通道，为基层公务员开辟了不依赖领导职数的职级晋升新通道。本章将系统解析职务序列与职级序列的构成、双通道并行的核心逻辑、2019年改革后的职级体系、职级晋升的条件与年限要求，以及职级与待遇的对应关系。

24.1 职务序列：领导职务与非领导职务​

24.1.1 领导职务序列​

根据《公务员法》和《公务员职务与职级并行规定》，公务员领导职务序列分为十个层次，从最高层次到最低层次依次为：

层次领导职务典型岗位举例
1国家级正职国务院总理、全国人大常委会委员长
2国家级副职国务院副总理、国务委员
3省部级正职省委书记、省长、部长
4省部级副职省委副书记、副省长、副部长
5厅局级正职地市委书记、市长、厅长
6厅局级副职市委副书记、副市长、副厅长
7县处级正职县委书记、县长、处长
8县处级副职县委副书记、副县长、副处长
9乡科级正职乡镇党委书记、乡镇长、科长
10乡科级副职乡镇党委副书记、副乡镇长、副科长

领导职务的核心特征是有明确的职数限制——每个单位的领导职数由编制部门核定，不能超配。这就意味着，领导职务的晋升受制于"位子"的数量，竞争非常激烈。

24.1.2 非领导职务（改革前）​

在2019年改革之前，公务员设有"非领导职务"序列，包括：巡视员、副巡视员、调研员、副调研员、主任科员、副主任科员、科员、办事员。这一序列存在的问题是：

  1. 非领导职务实际上与领导职务一一对应，并非真正的独立通道；
  2. 非领导职数同样受限制，且越往基层越少；
  3. 基层公务员"到点退休还是科员"的现象普遍存在。

2019年改革后，原有的非领导职务序列被废除，取而代之的是全新的职级序列。

24.2 职级序列：巡视员、调研员、主任科员、科员​

24.2.1 职级的概念​

职级是公务员的等级序列，是与领导职务并行的晋升通道。职级不对应具体的领导职责，但与工资待遇、住房补贴、医疗等福利挂钩。公务员可以通过职级晋升提高待遇，而不必等待领导岗位空缺。

24.2.2 职级序列的构成​

2019年改革后的综合管理类公务员职级序列共12个层级：

序号职级名称对应的领导职务层次（参考）
1一级巡视员厅局级正职
2二级巡视员厅局级副职
3一级调研员县处级正职
4二级调研员县处级正职（偏低）
5三级调研员县处级副职
6四级调研员县处级副职（偏低）
7一级主任科员乡科级正职
8二级主任科员乡科级正职（偏低）
9三级主任科员乡科级副职
10四级主任科员乡科级副职（偏低）
11一级科员科员
12二级科员办事员

24.2.3 职级序列的设计逻辑​

职级序列的设计遵循以下逻辑：

  1. 细分级差：将原有的8个非领导职务细分为12个职级，使晋升阶梯更密、步子更小，增加晋升频次；
  2. 拉长通道：最高职级（一级巡视员）对应厅局级正职待遇，使基层公务员也有机会通过职级晋升获得较高待遇；
  3. 与职务解耦：职级晋升不依赖领导职数，而是依据规定的职级名额（比例）控制，名额比例向基层倾斜。

24.3 职务与职级并行的核心逻辑（双通道晋升）​

24.3.1 双通道的含义​

职务与职级并行制度的核心是建立两条并行的晋升通道：

  • 职务通道：通过担任更高层次的领导职务实现晋升，获得更大的权力和责任；
  • 职级通道：通过提升职级等级实现晋升，获得更高的待遇和荣誉，但不增加领导职责。

公务员可以选择其中一条通道发展，也可以两条通道交叉发展——担任领导职务的公务员可以同时晋升职级，晋升职级的公务员也可以后续转任或提拔领导职务。

24.3.2 双通道的制度价值​

传统制度（单通道）职务与职级并行制度（双通道）
只有职务晋升一条路职务晋升 + 职级晋升两条路
领导职数有限，多数人无法晋升职级名额按比例核定，覆盖面更广
基层公务员"天花板"低基层公务员可通过职级晋升提高待遇
千军万马争领导岗位分流减压，各通道各有优势

24.3.3 并行规则​

职务与职级的并行遵循以下规则：

  1. 一人一职级：每名公务员只能有一个职级，不能同时兼多个职级；
  2. 职务与职级可兼有：担任领导职务的公务员，同时具有职级。例如，某处长（正处级领导职务）可以同时是二级调研员或一级调研员；
  3. 职级是晋升基础：担任领导职务一般须具备相应的最低职级。例如，提拔处长一般须任三级调研员以上；
  4. 职级待遇独立：职级晋升后，即使职务不变，待遇也相应提高。

24.3.4 职级名额（比例）管理​

职级晋升受名额限制，各单位按规定的比例核定可用职级数量：

机关层级一级巡视员二级巡视员一至四级调研员一至四级主任科员
中央机关不超过5%不超过10%不超过40%适当比例
省级机关不超过2%不超过5%不超过30%适当比例
市级机关—不超过2%不超过25%适当比例
县级机关——不超过15%不超过60%
乡镇机关——不超过10%不超过60%

这一比例设计体现了向基层倾斜的原则——虽然基层公务员难以达到巡视员等高职级，但在主任科员层级，基层的名额比例更高，确保大多数基层公务员有职级晋升的机会。

24.4 2019年改革后的职级序列（一级巡视员→二级科员）​

24.4.1 改革背景​

职务与职级并行制度经历了"试点—扩大—全面推行"的过程：

  • 2015年：在县以下机关开始试点职务与职级并行制度；
  • 2017年：试点范围扩大到部分市地级以上机关；
  • 2019年3月：中共中央办公厅印发《公务员职务与职级并行规定》，自2019年6月1日起在全国全面实施；
  • **2018年修订的《公务员法》**为该制度提供了法律依据。

24.4.2 改革前后对比​

比较维度改革前（非领导职务）改革后（职级序列）
序列层级8级12级
最高层级巡视员（正厅级）一级巡视员（正厅级）
最低层级办事员二级科员
与职务关系一一对应，实质是"影子职务"相对独立，有独立的晋升规则
名额管理受非领导职数限制按比例核定，向基层倾斜
晋升条件主要看任职年限年限+考核+名额综合考量
基层覆盖面基层名额极少基层名额比例较高

24.4.3 新旧职级套转​

2019年改革实施时，原有非领导职务人员需要进行"套转"：

原非领导职务套转后职级
巡视员一级巡视员
副巡视员二级巡视员
调研员二级调研员
副调研员四级调研员
主任科员二级主任科员
副主任科员四级主任科员
科员一级科员
办事员二级科员

套转后，公务员可在新职级体系内继续晋升。部分人员符合条件可在套转同时晋升一级。

24.4.4 专业技术类和行政执法类职级​

除综合管理类外，专业技术类和行政执法类公务员也有各自的职级序列：

专业技术类职级（共11级）：一级总监→二级总监→一级高级主管→二级高级主管→三级高级主管→四级高级主管→一级主管→二级主管→三级主管→四级主管→专业技术员

行政执法类职级（共11级）：督办→一级高级主办→二级高级主办→三级高级主办→四级高级主办→一级主办→二级主办→三级主办→四级主办→一级行政执法员→二级行政执法员

24.5 职级晋升的条件与年限要求​

24.5.1 基本晋升条件​

职级晋升应当具备以下基本条件：

  1. 政治素质好；
  2. 工作能力较强；
  3. 群众公认度较高；
  4. 符合规定的任职年限要求；
  5. 在规定名额内。

24.5.2 任职年限要求​

根据《公务员职务与职级并行规定》，职级晋升的最低任职年限如下：

晋升职级需任下一级职级最低年限需任下两级职级最低年限
一级巡视员任二级巡视员2年以上—
二级巡视员任一级调研员3年以上—
一级调研员任二级调研员3年以上—
二级调研员任三级调研员2年以上—
三级调研员任四级调研员2年以上—
四级调研员任一级主任科员2年以上—
一级主任科员任二级主任科员2年以上—
二级主任科员任三级主任科员2年以上—
三级主任科员任四级主任科员2年以上—
四级主任科员任一级科员2年以上—
一级科员任二级科员2年以上—

24.5.3 年限计算的特别规定​

  1. 累计计算：晋升职级所需的任职年限可以累计计算。例如，从四级主任科员晋升三级主任科员需2年，从三级主任科员晋升二级主任科员又需2年，累计4年可从四级主任科员晋升到二级主任科员。

  2. 考核优秀缩短年限：年度考核结果为"优秀"的，晋升职级所要求的任职年限可以缩短半年。但每晋升一次只能使用一次"优秀"缩短年限。

  3. 考核基本称职及以下不计年限：年度考核结果为"基本称职"及以下的，该年度不计入职级晋升的任职年限。

  4. 试用期计入年限：新录用公务员的试用期计入职级晋升年限。

24.5.4 职级晋升的程序​

职级晋升一般按照以下程序进行：

  1. 提出方案：机关组织人事部门根据名额和符合条件人员情况，提出晋升方案；
  2. 民主推荐：在一定范围内进行民主推荐；
  3. 考察：对拟晋升人选进行考察；
  4. 讨论决定：按照干部管理权限，由党委（党组）集体讨论决定；
  5. 公示：公示不少于5个工作日；
  6. 审批：按照规定办理审批手续。

职级晋升的程序相比职务晋升有所简化，不进行民主测评和个别谈话（但根据实际情况可适当简化或增加程序）。

24.5.5 职级晋升的限制​

  1. 名额限制：各单位各类职级名额不得超过规定比例；
  2. 年度限制：一般每年集中办理一次或两次职级晋升；
  3. 退休限制：距法定退休年龄不足2年的，一般不再晋升职级（各地执行略有差异）；
  4. 处分限制：受处分期间不得晋升职级。

24.6 职级与待遇的对应关系​

24.6.1 职级决定工资待遇​

职级并行改革后，公务员的工资待遇主要由**职务（职级）**决定，而非仅由领导职务决定。具体而言：

  • 基本工资：由职务（职级）工资和级别工资构成。职级晋升后，职务（职级）工资相应提高；
  • 津贴补贴：部分地区和单位的津贴补贴与职级挂钩；
  • 住房公积金：缴存基数与职级挂钩；
  • 住房补贴：部分地区的住房补贴按职级标准发放；
  • 医疗待遇：不同职级对应不同的医疗待遇标准。

24.6.2 职级与领导职务的待遇比较​

同层次的职级与领导职务在基本工资上基本相当，但在其他方面存在差异：

待遇项目领导职务职级说明
基本工资按职务标准按职级标准同层次基本相当
津贴补贴含领导职务津贴不含领导职务津贴领导职务略高
车补按职务标准按职级标准一般持平
年终奖金按职务标准按职级标准基本持平
办公用房按职务标准配给不享受领导标准职级较低者差距明显
政治待遇列席相关会议、阅件范围无差异较大
退休待遇按职务对应退休待遇按职级对应退休待遇基本持平

24.6.3 职级并行改革对基层公务员的影响​

职级并行改革对基层公务员的待遇提升效果显著。以一名县直机关的普通公务员为例：

改革前：

  • 25岁考入公务员，任科员；
  • 科员岗位无领导职数空缺，到退休仍为科员；
  • 退休时工资水平与入职时差距有限。

改革后：

  • 25岁考入公务员，任一级科员；
  • 27岁晋升四级主任科员；
  • 29岁晋升三级主任科员；
  • 31岁晋升二级主任科员；
  • 33岁晋升一级主任科员；
  • 35岁晋升四级调研员（如有名额）；
  • 38岁晋升三级调研员（如有名额）；
  • 退休时至少可达一级或二级调研员待遇，相当于处级干部工资水平。

这一改革有效解决了基层公务员"晋升无望、待遇不变"的困境，是公务员管理制度的重大进步。

24.6.4 职级与级别的对应​

除职务（职级）外，公务员还有"级别"这一维度。级别共27级（一级最高，二十七级最低），与职务（职级）对应关系如下（部分）：

职务/职级对应级别范围
一级巡视员八至十三级
二级巡视员十至十五级
一级调研员十二至十八级
二级调研员十四至二十级
三级调研员十五至二十一级
四级调研员十六至二十二级
一级主任科员十八至二十四级

级别工资随级别提升而增加，级别晋升通常与年度考核结果挂钩——连续考核称职以上的，一般每5年可在对应级别范围内晋升一级。

本章小结​

职务与职级并行制度是2019年公务员管理制度改革的标志性成果。它将传统的单一职务晋升通道改造为"职务+职级"双通道，通过12级职级序列的细密阶梯和向基层倾斜的名额比例，使广大基层公务员不再"一辈子当科员"。

职级晋升以任职年限为基础，以考核结果为调节，以名额比例为控制，程序规范而灵活。职级与工资待遇紧密挂钩，虽然没有领导职务的政治待遇和权力，但对于改善公务员物质待遇、拓宽职业发展空间具有重要意义。

理解了职务与职级并行制度的基本框架后，下一章将更进一步，全面解析公务员晋升的三个维度——职务晋升、职级晋升和级别晋升的具体路径、年限要求和考核标准。

官方依据：《中华人民共和国公务员法》（2018年修订）第十七至二十一条；《公务员职务与职级并行规定》（中办发〔2019〕10号）；《公务员职务、职级与级别管理办法》（中共中央组织部2019年）。
