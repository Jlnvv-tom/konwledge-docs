第二十一章：外交与国防部门

外交与国防是国家主权和安全的两根支柱。在百年未有之大变局加速演进的背景下，中国的外交与国防体系正经历深刻转型：外交布局从"大国为关键"向"全球伙伴关系网络"拓展，国防建设从"机械化信息化复合发展"向"智能化"迈进，对外援助从"规模扩张"向"高质量共建'一带一路'"升级。本章详解五个关键部门的职能定位与政策实践，揭示中国外交国防体制的独特之处——党政军一体化的外交国防指挥体系。

21.1 外交部：外交政策与领事保护​

核心职责​

外交部是国务院组成部门，主管国家对外事务。根据《中华人民共和国宪法》和《中华人民共和国领事保护与协助条例》（2023年通过），外交部核心职责包括：

  1. 外交政策：拟定外交政策，处理双边和多边外交事务。
  2. 外交代表：代表国家和政府进行外交活动，管理外交代表机构和领事机构。
  3. 国际组织：参与联合国及其他国际组织活动，管理多边外交。
  4. 条约法律：处理国家间条约和法律事务，拟定条约和重要协定草案。
  5. 领事保护：保护海外中国公民、法人的合法权益，提供领事保护与协助。
  6. 礼宾：管理国家礼宾工作，安排外国领导人的接待和访问。
  7. 涉外安全：协调处理涉外安全事务，参与国际安全合作。
  8. 新闻发布：就重大外交问题发布信息和阐述政策立场。

组织架构​

外交部内设机构包括：办公厅、政策规划司、亚洲司、西亚北非司、非洲司、欧亚司、欧洲司、北美大洋洲司、拉丁美洲司、国际司（国际经济司）、军控司、条约法律司、边界与海洋事务司、新闻司、礼宾司、领事司（领事保护中心）、涉外安全事务司、新闻司、翻译司、外事管理司、港澳台司、离退休干部局、机关党委等。

外交部在全球设有280多个驻外外交机构，包括大使馆、总领事馆、领事馆和常驻国际组织代表团。

关键政策领域​

中国特色大国外交：推进构建新型国际关系，构建人类命运共同体。坚持"大国是关键、周边是首要、发展中国家是基础、多边是重要舞台"的外交布局。

"一带一路"国际合作：外交部是"一带一路"国际合作高峰论坛的重要参与方，协调推进"一带一路"沿线国家的外交关系和合作项目。截至2024年，已有150多个国家、30多个国际组织签署共建"一带一路"合作文件。

全球发展倡议、全球安全倡议、全球文明倡议：三大全球倡议是中国为全球治理提供的重要公共产品。外交部负责统筹协调倡议的推进落实。

领事保护与协助：随着中国公民大规模"走出去"，海外领事保护需求急剧增长。外交部建立"外交部全球领事保护与服务应急呼叫中心"（12308热线），24小时为海外中国公民提供领事保护。年均处理领事保护与协助案件数万起。

公共外交：通过外交部发言人制度、蓝厅论坛等平台，向国内外公众阐释中国外交政策。推进"大国外交"叙事传播，讲好中国外交故事。

21.2 国防部：国防政策与军事外交​

核心职责​

国防部是国务院组成部门，但其职能与一般政府组成部门有显著区别。根据《中华人民共和国国防法》（2020年修订），国防部的主要职责是"管理国防事务"，具体包括：

  1. 国防动员：编制国防动员建设发展规划，管理人民武装动员、国民经济动员、人民防空等。
  2. 军事外交：管理与外国的军事外交活动，包括军事互访、联合军演、军事援助等。
  3. 兵役工作：管理征兵和民兵预备役工作。
  4. 国防教育：组织开展全民国防教育。
  5. 军地协调：协调军地关系，处理军地之间的相关事务。

需要特别说明的是，中国国防部的实际军事指挥职能由中央军事委员会行使，国防部更多承担军地协调和对外军事外交的职能。在对外交往中，国防部是代表中国军队的"窗口"部门。

组织架构​

国防部不设独立的内设机构，其日常事务由中央军事委员会相关职能部门承担。国防部设国防部新闻局，负责军事外交新闻发布和对外宣传。

国防部在北京设有国防部维和事务中心，负责维和培训和国际维和事务协调。

关键政策领域​

新时代国防政策：中国奉行防御性国防政策，2020年发布的《新时代的中国国防》白皮书系统阐述了新时代国防政策。国防开支保持适度合理增长，2024年国防预算约1.67万亿元人民币，占GDP约1.3%。

军事外交：开展多层次军事外交，包括高层军事互访、中俄联合军事演习、中蒙"草原伙伴"联演、中柬"金龙"联演等。中国已与150余个国家建立军事关系，设有40余个驻外武官处。

国际维和：中国是联合国安理会常任理事国中派出维和人员最多的国家，累计派出维和军事人员5万余人次。中国维和部队在南苏丹、马里、黎巴嫩等地执行任务。

国防教育：2024年修订《中华人民共和国国防教育法》，将国防教育纳入国民教育体系，设立"全民国防教育日"（每年9月第三个星期六）。

军民融合：推动军民融合深度发展，在海洋、太空、网络空间、生物、新能源等新兴领域推进军民融合。

21.3 中央军事委员会：武装力量指挥体系​

核心职责​

中央军事委员会（简称"中央军委"）是中国共产党和中华人民共和国的最高军事领导机关，领导全国武装力量。根据《中华人民共和国宪法》第九十三条，中央军委实行主席负责制。

中央军委的核心职责包括：

  1. 统一指挥：统一指挥全国武装力量，包括人民解放军现役部队和预备役部队、武装警察部队、民兵。
  2. 国防建设：领导国防建设事业，制定军事战略方针。
  3. 军队建设：领导军队政治建设、组织建设、作风建设、纪律建设。
  4. 军事斗争：组织指挥军事斗争准备和军事行动。
  5. 军官管理：管理军官的选拔、任用、考核和退役。

组织架构​

2016年军改后，中央军委实行"军委管总、战区主战、军种主建"的新格局：

军委机关：中央军委设15个职能部门，包括：军委办公厅、联合参谋部、政治工作部、后勤保障部、装备发展部、训练管理部、国防动员部、纪律检查委员会（监委）、政法委员会、科学技术委员会、战略规划办公室、改革和编制办公室、国际军事合作办公室、审计署、机关事务管理总局。

五大战区：东部战区、南部战区、西部战区、北部战区、中部战区。战区承担本战略方向的联合作战指挥职能。

军种：陆军、海军、空军、火箭军、战略支援部队（2024年改革中信息支援部队取代战略支援部队）和联勤保障部队。

武警部队：中国人民武装警察部队由中央军委统一领导指挥，2018年改革后实现了"军是军、警是警、民是民"的体制重塑。

关键政策领域​

新时代军事战略方针：适应世界新军事革命趋势，推进机械化和信息化融合发展，加快智能化发展，构建能够打赢信息化智能化战争的人民军队。

军事科研体制改革：2017年组建军事科学院、国防大学、国防科技大学"三位一体"新型军事科研体系。推进军事科研创新，发展非对称作战能力。

军事训练：推进实战化军事训练，常态化开展跨区域机动演习、实兵对抗演习和联合作战演练。

军队反腐败：中央军委纪律检查委员会（监委）持续开展军队反腐败工作，查处了一批高级军官违纪违法案件。

21.4 中共中央对外联络部：党际外交​

核心职责​

中共中央对外联络部（简称"中联部"）是党中央直属机构，负责中国共产党与外国政党的交往和联络工作。中联部是中国外交体系中的独特组成部分，体现了"政党外交"在中国总体外交中的特殊地位。

中联部核心职责包括：

  1. 党际交往：负责中国共产党与外国政党的联络交往工作，包括执政党、参政党、合法在野党和重要政党国际组织。
  2. 政党外交：通过党际渠道开展对外交往，增进政治互信，促进国家关系发展。
  3. 理论交流：与外国政党进行治党治国经验交流，开展理论对话。
  4. 政策调研：研究国际形势和外国政党政治，向党中央提供决策参考。
  5. 民间外交：通过政党渠道推动民间外交和人文交流。

组织架构​

中联部内设机构包括：办公厅、研究室、一局（亚洲一局）、二局（亚洲二局）、三局（西亚北非局）、四局（非洲局）、五局（拉美局）、六局（东欧中亚局）、七局（美大北欧局）、八局（西欧局）、国际交流中心、信息传播局、礼宾局等。

关键政策领域​

新型政党关系：中国共产党与世界上160多个国家的500多个政党和政治组织保持着不同形式的联系。倡导"求同存异、相互尊重、互学互鉴"的新型政党关系理念。

"政党+"外交模式：创新政党外交形式，开展"政党+经贸""政党+人文""政党+地方"等复合型交流活动。举办"中国共产党与世界政党领导人峰会"等大型活动。

治国理政经验交流：与外国政党分享治国理政经验，特别是减贫、发展、治理等方面的中国经验。设立"中共干部学院"培训项目，面向发展中国家政党干部提供培训。

区域政党外交：针对不同区域特点开展政党外交——与非洲政党开展"中非政党理论研讨会"，与拉美政党开展"中拉政党论坛"，与阿拉伯国家政党开展"中阿政党对话会"等。

中联部与外交部的关系​

中联部与外交部的关系是中国外交体制的一大特色。外交部负责政府间外交，中联部负责政党间外交。两者相互配合、互为补充——政党外交有时可以发挥政府外交的"探路者"和"助推器"作用，在一些没有正式外交关系的国家，政党交往可以成为建立关系的桥梁。

21.5 国际发展合作署：对外援助​

核心职责​

国家国际发展合作署（简称"国际合作署"）是国务院直属机构，2018年机构改革中新设立，整合了外交部对外援助协调职责和商务部对外援助执行职责。这是中国首次设立专门负责对外援助工作的政府机构，标志着对外援助从"外交配套"向"国际发展合作"的战略升级。

国际合作署核心职责包括：

  1. 援助战略：拟定对外援助战略方针和规划，制定对外援助政策。
  2. 援助计划：编制对外援助项目年度计划并组织执行。
  3. 援助方式：统筹管理援助资金，创新援助方式（无偿援助、无息贷款、优惠贷款等）。
  4. 援助监督：监督评估对外援助项目实施情况。
  5. 国际合作：开展国际发展合作交流，参与国际发展合作规则制定。

组织架构​

国际合作署内设机构包括：办公厅、综合司、政策和改革司、地区一司（亚洲司）、地区二司（西亚北非司）、地区三司（非洲司）、地区四司（拉美和加勒比司、欧亚司、美大司）、监督评估司、国际合作司等。

关键政策领域​

对外援助体制改革：2018年设立国际合作署后，对外援助实现了"决策与执行分离"——国际合作署负责援助决策和政策制定，具体项目执行逐步交由相关企业和机构承担，商务部承担部分执行职能。

"一带一路"援助项目：在"一带一路"框架下实施一批标志性援助项目，包括中老铁路配套项目、非洲疾病预防控制中心总部大楼、中非合作论坛"八大行动"援助项目等。

全球发展倡议（GDI）落实：2021年习近平在联合国大会提出的全球发展倡议是国际合作署的核心工作框架。围绕减贫、粮食安全、抗疫、气候变化、绿色发展、工业化、数字经济、互联互通八大领域推进合作项目。

南南合作援助基金：设立南南合作援助基金，支持其他发展中国家落实2030年可持续发展议程。中国-联合国和平与发展基金、全球发展和南南合作基金等机制为国际发展合作提供资金支持。

紧急人道主义援助：在自然灾害、公共卫生事件等紧急情况下，快速向受灾国提供人道主义援助。例如2023年土耳其地震、2024年缅甸洪灾等紧急救援行动。

援外培训：组织实施对外人力资源开发合作项目，每年为发展中国家培训数万名各类人才。设立"中国政府奖学金"资助外国留学生来华学习。

援助规模与特点​

中国对外援助具有以下特点：一是以基础设施建设为主要特色，通过援助和优惠贷款支持受援国交通、能源、通信等基础设施建设；二是注重"造血式"援助，强调"授人以渔"，帮助受援国提升自主发展能力；三是坚持不附带政治条件，尊重受援国自主选择发展道路。2013年至2023年，中国对外援助和国际发展合作资金规模稳步增长，累计实施援助项目数千个，惠及120多个发展中国家。

  5. 《中华人民共和国兵役法》（2021年修订）——兵役制度依据。
  6. 《中华人民共和国预备役人员法》（2022年通过）——预备役制度依据。
