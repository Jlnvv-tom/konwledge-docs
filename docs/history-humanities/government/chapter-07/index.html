第七章：国务院直属特设机构与直属机构

7.1 概述与法律定位​

机构序列与层级​

在国务院组织体系中，除组成部门外，还设有直属特设机构、直属机构、办事机构、直属事业单位等。这些机构与组成部门共同构成了国务院的完整职能网络，但各自的法律定位、设立程序和领导管理体制有所不同。

  • 直属特设机构：仅设有一个，即国务院国有资产监督管理委员会（国资委），是为特定目的而特设的机构。
  • 直属机构：主管各项专门业务，具有独立的行政管理职能，规格为正部级或副部级。直属机构的设立由国务院自行决定，无需报全国人大审批，这与组成部门的设立程序不同。

根据《国务院行政机构设置和编制管理条例》，国务院直属机构主管国务院某项专门业务，具有独立的行政管理职能。这一法律定位明确了直属机构与组成部门的区别：组成部门负责国务院的基础性、综合性职能，而直属机构负责特定领域的专门性业务。

现行机构设置​

经过2018年和2023年两轮机构改革，国务院目前设有：

  • 直属特设机构（1个）：国务院国有资产监督管理委员会
  • 直属机构（约15个）：包括海关总署、国家税务总局、国家市场监督管理总局、国家金融监督管理总局、中国证券监督管理委员会、国家广播电视总局、国家体育总局、国家信访局、国家统计局、国家知识产权局、国家国际发展合作署、国家医疗保障局、国务院参事室、国家机关事务管理局等

7.2 国务院国有资产监督管理委员会（国资委）​

设立背景​

国资委是国务院唯一的直属特设机构，成立于2003年。其设立背景是：在社会主义市场经济体制下，国有经济占据主导地位，但此前的国有资产管理体制存在"五龙治水"、出资人缺位等突出问题——多个部门分别行使国有资产的不同管理职能，导致责任不清、效率低下。

国资委的组建实现了"管资产、管事、管人"相统一的出资人制度，代表国家履行出资人职责，对所监管企业国有资产的保值增值进行监督。

主要职责​

根据国资委的三定方案，其主要职责包括：

  1. 出资人职责：根据国务院授权，依照《公司法》等法律和行政法规履行出资人职责，监管中央所属企业（不含金融类企业）的国有资产。
  2. 指导推进改革：指导推进国有企业改革和重组；推进国有企业的现代企业制度建设；完善公司治理结构。
  3. 国资保值增值：推动国有经济布局和结构的战略性调整；指导和促进国有企业可持续发展。
  4. 考核与分配：建立和完善国有资产保值增值指标体系，制定考核标准；通过统计、稽核对所监管企业国有资产的保值增值情况进行监管。
  5. 人事管理：按照管理权限，通过法定程序对所监管企业负责人进行任免、考核并根据其经营业绩进行奖惩。

运作特点​

国资委的特殊性在于其"特设"地位——它既不同于一般的行政管理机构，也不同于纯粹的企业股东。国资委在管理中遵循"政企分开、政资分开"原则，不直接干预企业的生产经营活动，而是通过派出董事、监事等市场化方式行使出资人权利。

截至2023年底，国资委监管的中央企业（简称"央企"）约90余家，涵盖能源、通信、军工、交通、建筑等关系国家安全和国民经济命脉的关键领域。央企的经营绩效直接关系到国有经济的整体效益和国民经济的稳定运行。

7.3 海关总署​

机构定位​

海关总署是国务院直属机构，规格为正部级，实行垂直管理体制——全国海关统一接受海关总署的领导，不受地方政府干预。

主要职责​

  1. 进出境监管：对进出境运输工具、货物、行李物品、邮递物品和其他物品进行监管。
  2. 征收关税：依法征收进出口关税及其他税费（包括增值税、消费税的进出口环节征收）。
  3. 缉私：依法查缉走私，打击走私违法犯罪活动。海关缉私警察队伍承担刑事执法职能。
  4. 海关统计：编制进出口海关统计数据，开展统计分析。
  5. 检验检疫：2018年机构改革后，原出入境检验检疫职能划入海关，海关总署统一承担进出口商品检验、动植物检疫、卫生检疫职能。
  6. 知识产权海关保护：在进出口环节保护知识产权，查处侵犯知识产权的货物。

垂直管理体制​

海关总署下设广东分署、天津特派办、上海特派办等派出机构，以及全国各口岸海关。全国海关约50个直属海关单位、数百个隶属海关，统一执行海关法律法规，确保了执法标准的全国一致性。

7.4 国家税务总局​

机构定位​

国家税务总局是国务院直属机构，规格为正部级，主管全国税收工作。与海关类似，税务系统实行垂直管理体制——国家税务总局对省级税务局实行业务领导，确保税收执法的统一性和规范性。

主要职责​

  1. 税收征管：组织实施税收征收管理，管理各项税收收入（增值税、企业所得税、个人所得税、消费税等）。
  2. 税收政策：参与拟定税收法律法规草案，研究提出税制改革建议。
  3. 税务稽查：组织税务稽查，查处税收违法行为。
  4. 纳税服务：推进纳税服务体系建设，优化税收营商环境。
  5. 社会保险费和非税收入征管：2018年机构改革后，各项社会保险费交由税务部门统一征收，税务部门的征管范围大幅扩展。

国地税合并​

2018年机构改革中，实行了24年的国税局、地税局合并，组建新的税务局，实现了"一个机构管税收"的目标。这一改革大幅降低了征纳成本，提高了征管效率，也减轻了纳税人的遵从负担。

7.5 国家金融监督管理总局​

设立背景​

国家金融监督管理总局（简称"金融监管总局"或"金监总局"）是2023年机构改革中新组建的国务院直属机构，规格为正部级。其设立是中国金融监管体制改革的重大举措。

在金监总局成立之前，中国金融监管实行"一委一行两会"体制（国务院金融稳定发展委员会、中国人民银行、银保监会、证监会）。2023年改革后，银保监会撤销，在其基础上组建金监总局，同时将央行对金融集团的日常监管职责、证监会投资者保护职责等划入金监总局，形成了"一行一局一会"（央行、金监总局、证监会）的新格局。

主要职责​

  1. 机构监管：依法对除证券业之外的金融业（银行业、保险业、信托业等）实行统一监督管理。
  2. 行为监管：强化机构监管、行为监管、功能监管、穿透式监管、持续监管。
  3. 消费者权益保护：统筹负责金融消费者权益保护。
  4. 风险防控：负责金融业风险防控和处置，维护金融稳定。
  5. 功能监管：对金融控股公司等金融集团进行监管。

改革意义​

金监总局的组建解决了此前分业监管体制下的监管空白和监管套利问题，强化了"统一监管"和"穿透式监管"理念，体现了"管合法更要管非法、管行业必须管风险"的综合监管思路。

7.6 中国证券监督管理委员会​

机构定位​

中国证券监督管理委员会（简称"证监会"）是国务院直属机构，规格为正部级，依法对全国证券期货市场实行集中统一监督管理。

主要职责​

  1. 市场准入：负责股票、债券、期货等证券发行上市的注册或核准。
  2. 机构监管：对证券公司、基金管理公司、期货公司等市场中介机构进行监管。
  3. 市场监管：监督证券期货市场交易行为，查处内幕交易、操纵市场、虚假陈述等违法违规行为。
  4. 信息披露：监督上市公司信息披露，保护投资者知情权。
  5. 投资者保护：2023年改革后，投资者保护职责部分划入金监总局，但证监会仍承担证券领域投资者保护的具体工作。
  6. 期货市场监管：监控大宗商品期货和金融期货市场运行。

注册制改革​

2019年科创板试点注册制以来，中国资本市场基础制度改革持续推进。全面注册制的实施使证监会的职能从"实质性审核"向"以信息披露为核心"转变，工作重心更加聚焦于事中事后监管和投资者保护。

7.7 其他直属机构概述​

国家市场监督管理总局​

2018年机构改革中组建，整合了原工商总局、质检总局、食药监总局、发改委的价格监督检查和反垄断职责等。负责市场综合监管、质量监管、食品安全监管、反垄断执法、知识产权管理等（国家知识产权局由其管理）。

国家广播电视总局​

负责广播电视行业管理，包括广播电视播出机构的审批、节目内容管理、网络视听节目管理等。

国家体育总局​

负责体育事业管理，统筹全民健身、竞技体育和体育产业发展。与中国奥委会合署办公。

国家信访局​

负责处理群众来信来访，协调解决信访突出问题，维护群众合法权益和社会和谐稳定。

国家统计局​

负责全国统计工作，组织实施人口普查、经济普查等重大国情国力调查，发布国民经济和社会发展统计数据。

国家医疗保障局​

2018年组建，负责医疗保险、医疗救助、药品和医疗服务价格管理、药品集中采购等职责。医保局的组建实现了"三保合一"（城镇职工医保、城乡居民医保、医疗救助统一管理），并在药品集采改革中发挥了关键作用。

国家国际发展合作署​

负责对外援助政策的拟定和执行，统筹协调对外援助工作。

国务院参事室​

具有统战性、咨询性的机构，组织参事开展参政议政、建言献策、咨询国是、民主监督、统战联谊工作。

国家机关事务管理局​

负责中央国家机关的后勤保障和机关事务管理，推进机关事务标准化、信息化建设。

官方依据​

  1. 《国务院行政机构设置和编制管理条例》
  2. 《国务院关于机构设置的通知》（各年度最新版）
  3. 2018年《国务院机构改革方案》
  4. 2023年《党和国家机构改革方案》
  5. 各直属机构"三定"方案

本章小结：国务院直属特设机构和直属机构是国务院组织体系的重要组成部分，承担着专门性管理职能。国资委作为唯一的特设机构，履行国有资产出资人职责；海关总署、税务总局承担国家税费征管职能；金监总局和证监会分别负责金融业和资本市场监管。这些机构与组成部门分工配合，共同构成国务院全面覆盖经济社会各领域的管理网络。2023年金监总局的组建标志着金融监管体制从分业监管向统一监管的重大转型，体现了"优化协同高效"的机构改革方向。
