第十八章：资源环境管理部门

资源环境管理部门是生态文明建设的主力军。从"绿水青山就是金山银山"理念的提出到"双碳"目标的承诺，中国的资源环境治理体系经历了从"开发优先"到"保护优先"、从"多头管理"到"统一行使"的深刻变革。2018年机构改革中，自然资源部和生态环境部的组建标志着中国自然资源资产管理和生态环境保护监管体制进入了统一管理的新时代。本章详解五个关键部门的职能配置与政策实践。

18.1 自然资源部：国土空间规划与用途管制​

核心职责​

自然资源部是国务院组成部门，2018年机构改革中整合了原国土资源部、原国家海洋局、原国家测绘地理信息局职责，以及发改委的组织编制主体功能区规划职责、住建部的城乡规划管理职责、水利部的水资源调查和确权登记职责、农业部的草原资源调查和确权登记职责、林业局的森林和湿地等资源调查和确权登记职责。

这一"大部制"改革的核心目标，是实现**"两统一"**：统一行使全民所有自然资源资产所有者职责，统一行使所有国土空间用途管制和生态保护修复职责。

核心职责具体包括：

  1. 自然资源调查监测：建立自然资源调查监测评价制度，统一组织自然资源调查监测评价。
  2. 自然资源统一确权登记：建立健全自然资源登记制度，组织指导自然资源和不动产登记。
  3. 国土空间规划：建立国土空间规划体系并监督实施，统筹划定"三区三线"（城镇空间、农业空间、生态空间；城镇开发边界、永久基本农田、生态保护红线）。
  4. 国土空间用途管制：建立健全国土空间用途管制制度，管理农用地转用和土地征收。
  5. 自然资源开发利用：拟定自然资源开发利用标准，管理土地、矿产、海洋等自然资源的使用。
  6. 生态保护修复：统筹国土空间生态修复，管理矿山地质环境恢复治理、海洋生态修复等。
  7. 测绘地理信息：管理测绘地理信息工作，监督管理地理信息安全和市场秩序。

组织架构​

自然资源部内设机构包括：办公厅、综合司、法规司、自然资源调查监测司、自然资源确权登记局、自然资源所有者权益司、自然资源开发利用司、国土空间规划局、国土空间用途管制司、国土空间生态修复司、耕地保护监督司、地质勘查管理司、矿业权管理司、矿产资源保护监督司、海域海岛管理司、海洋战略规划与经济司、海洋预警监测司、测绘地理信息管理司、国家测绘档案资料馆等。

自然资源部管理国家林业和草原局（副部级）、中国地质调查局（副部级）。

关键政策领域​

国土空间规划体系构建：2019年《关于建立国土空间规划体系并监督实施的若干意见》发布，标志着中国建立了"五级三类四体系"的国土空间规划框架——国家、省、市、县、乡镇五级；总体规划、详细规划、相关专项规划三类；编制审批、实施监督、法规政策、技术标准四体系。这是继主体功能区规划、土地利用规划、城乡规划"多规合一"之后的重大制度创新。

"三区三线"划定与管控：全国划定生态保护红线面积不少于315万平方公里（含海域），永久基本农田保护面积稳定在15.46亿亩以上，城镇开发边界管控全面实施。

自然资源资产产权制度改革：推进自然资源统一确权登记，探索委托代理机制，明确自然资源资产所有者职责行使方式。

不动产统一登记：2015年实施不动产统一登记制度以来，全国已发放不动产权证书数亿本。2023年起自然资源部推进"带押过户"等便民措施。

围填海管控：实施最严格的围填海管控政策，除国家重大项目外全面禁止新增围填海。

18.2 生态环境部：污染防治与生态保护​

核心职责​

生态环境部是国务院组成部门，2018年机构改革中在原环境保护部基础上组建，整合了发改委的应对气候变化和减排职责、国土部的监督防止地下水污染职责、水利部的编制水功能区划和排污口设置管理职责、农业部的监督指导农业面源污染治理职责、海洋局的海洋环境保护职责等。

根据《中华人民共和国环境保护法》（2014年修订），生态环境部核心职责包括：

  1. 环境监督管理：统一监督管理污染防治、生态保护、核与辐射安全，拟定生态环境政策、规划并组织实施。
  2. 环境标准与监测：制定国家生态环境标准，建立生态环境监测网络，发布国家生态环境状况公报。
  3. 环境影响评价：审查重大开发建设项目的环境影响评价文件，实施"三同时"制度（环保设施与主体工程同时设计、同时施工、同时投产使用）。
  4. 环境执法：统一行使生态和城乡各类污染排放行政执法权，组织开展生态环境保护督察。
  5. 应对气候变化：组织拟定应对气候变化及温室气体减排战略、规划和政策。
  6. 核安全监管：监督管理核安全、辐射安全和放射性废物管理。

组织架构​

生态环境部内设机构包括：办公厅、中央生态环境保护督察办公室、综合司、法规与标准司、行政体制与人事司、科技与财务司、自然生态保护司（生物多样性保护办公室）、水生态环境司、海洋生态环境司、大气环境司（京津冀及周边地区大气环境管理局）、应对气候变化司、土壤生态环境司、固体废物与化学品司、环境影响评价与排放管理司、生态环境监测司、生态环境执法局、核设施安全监管司、核安全协调司（局）、国际合作司等。

关键政策领域​

污染防治攻坚战：2018年启动的污染防治攻坚战是三大攻坚战之一，包括"蓝天、碧水、净土"三大保卫战。2021年深入打好污染防治攻坚战的意见标志着从"坚决打好"向"深入打好"转变，标准更高、力度更大。

中央生态环境保护督察：2016年以来，中央生态环境保护督察完成了两轮全覆盖，成为推动地方落实生态环境保护责任的"利剑"。督察组由中央直接派驻，对省级党委政府进行督察，发现问题、形成震慑。

碳排放权交易市场：2021年7月全国碳市场上线交易，首批纳入发电行业。生态环境部负责碳配额分配、碳排放报告核查和市场运行监管，这是利用市场机制控制温室气体排放的重大制度创新。

生物多样性保护：作为《生物多样性公约》缔约方，2021年承办COP15大会（昆明），推动"昆明—蒙特利尔全球生物多样性框架"通过。

新污染物治理：2022年启动新污染物治理行动，针对持久性有机污染物、内分泌干扰物等新污染物开展调查监测和管控。

18.3 水利部：水资源管理与防汛抗旱​

核心职责​

水利部是国务院组成部门，主管水资源管理、江河治理和防汛抗旱工作。根据《中华人民共和国水法》（2016年修正），水利部核心职责包括：

  1. 水资源管理：统一管理水资源（含地表水和地下水），拟定水资源战略规划和政策，实施水资源统一监督管理。
  2. 防汛抗旱：组织编制重要江河湖泊和重要水工程的防御洪水抗御旱灾调度及应急水量调度方案并监督实施，承担国家防汛抗旱总指挥部日常工作。
  3. 水利工程建设管理：管理水利工程建设的行业管理，审批水利工程建设项目，管理水利建设市场。
  4. 河湖管理：负责河湖水域及其岸线的管理保护，监督管理河道采砂。
  5. 水土保持：组织编制水土保持规划并监督实施，组织实施水土流失的综合防治。
  6. 农村水利：管理农村饮水安全、灌区和泵站工程建设与管理。
  7. 水资源保护：指导饮用水水源保护，指导地下水开发利用和地下水资源管理保护。

组织架构​

水利部内设机构包括：办公厅、规划计划司、政策法规司、水资源管理司、节约用水促进司、财务司、人事司、国际合作与科技司、建设司、运行管理司、河湖管理司、水土保持司、农村水利水电司、水库移民司、监督司、水旱灾害防御司、三峡工程管理司、南水北调工程管理司等。

水利部管理长江水利委员会、黄河水利委员会、淮河水利委员会、海河水利委员会、珠江水利委员会、松辽水利委员会、太湖流域管理局等7个流域管理机构（均为副部级或正厅级）。

关键政策领域​

全面推行河长制：2016年中央全面深化改革领导小组通过《关于全面推行河长制的意见》，建立省、市、县、乡、村五级河长体系。全国共设立省、市、县、乡、村五级河湖长120余万名，实现了河湖管理保护责任全覆盖。2018年起在河长制基础上全面推行湖长制。

防汛抗旱体系：建立以国家防汛抗旱总指挥部为中枢，流域防总为支撑，地方防指为基础的防汛抗旱组织指挥体系。近年来成功应对2020年长江流域性大洪水、2021年郑州"7·20"特大暴雨、2023年海河流域特大洪水等重大洪涝灾害。

国家水网建设：2023年中央印发《国家水网建设规划纲要》，以"四横三纵"（南水北调东中西三线与长江、黄河、淮河、海河四大流域）为国家水网主骨架，推进重大引调水工程和区域水网建设。

最严格水资源管理制度：实施"三条红线"（用水总量控制、用水效率控制、水功能区限制纳污）和"四项制度"，推动用水方式根本性转变。

农村供水保障：实施农村饮水安全巩固提升工程，农村自来水普及率达到90%以上。

18.4 农业农村部：粮食安全与乡村振兴​

核心职责​

农业农村部是国务院组成部门，2018年机构改革中在原农业部基础上组建，整合了发改委的农业投资项目、财政部的农业综合开发项目、国土资源部的农田整治项目、水利部的农田水利建设项目等管理职责。中央农村工作领导小组办公室设在农业农村部。

根据《中华人民共和国农业法》《中华人民共和国乡村振兴促进法》（2021年通过），农业农村部核心职责包括：

  1. 乡村振兴统筹：统筹推动乡村振兴战略实施，拟定乡村振兴战略规划并组织实施。
  2. 粮食安全：管理种植业，组织构建现代农业产业体系，保障国家粮食安全和重要农产品有效供给。
  3. 农业监管：监督管理农产品质量安全，管理农业转基因生物安全。
  4. 畜牧业管理：管理畜牧业、饲料业、兽医医政、兽药药政药检和屠宰行业。
  5. 渔业管理：管理渔业资源、渔政渔港监督管理。
  6. 农业机械化：管理农业机械化发展，监督管理农机安全和农机产品质量。
  7. 农田建设：管理高标准农田建设，承担耕地质量保护和管理。
  8. 农村改革：协调推进农村社会事业发展和农村改革，管理农村集体资产和农民承包地、宅基地改革。

组织架构​

农业农村部内设机构包括：办公厅、人事司、法规司、政策与改革司、发展规划司、计划财务司、乡村产业发展司、农村社会事业促进司、农村合作经济指导司、市场与信息化司、国际合作司、科技教育司、农产品质量安全监管司、种植业管理司（农药管理司）、畜牧兽医局、渔业渔政管理局、农垦局、种业管理司、农业机械化管理司、农田建设管理司等。

农业农村部管理国家乡村振兴局（2023年机构改革后作为部属国家局保留牌子）。

关键政策领域​

粮食安全战略：实施"藏粮于地、藏粮于技"战略，确保谷物基本自给、口粮绝对安全。全国粮食产量连续多年稳定在1.3万亿斤以上（2024年达到1.4万亿斤）。落实粮食安全党政同责，完善粮食主产区利益补偿机制。

高标准农田建设：全国累计建成高标准农田超过10亿亩，占耕地总面积的50%以上，到2030年规划建成12亿亩。

种业振兴行动：实施种业振兴行动方案，加强种质资源保护利用、种业创新攻关、种业企业扶优和种业基地提升。

巩固拓展脱贫攻坚成果同乡村振兴有效衔接：2021年完成脱贫攻坚后，建立防止返贫动态监测和帮扶机制，对832个脱贫县实施过渡期政策，发展乡村特色产业。

农村人居环境整治：推进农村"厕所革命"、生活垃圾和污水治理，建设宜居宜业和美乡村。

18.5 国家林业和草原局（由自然资源部管理）​

核心职责​

国家林业和草原局是自然资源部管理的副部级国家局，2018年机构改革中在原国家林业局基础上组建，整合了草原监督管理职责和住建部、水利部、农业部的自然保护区、风景名胜区、自然遗产、地质公园等管理职责。

根据《中华人民共和国森林法》（2019年修订）和《中华人民共和国草原法》（2021年修正），国家林草局核心职责包括：

  1. 森林资源管理：管理森林资源保护发展，监督森林采伐限额执行，管理森林防火和林业有害生物防治。
  2. 草原管理：监督管理草原保护、建设和利用，管理草原防火。
  3. 湿地管理：监督管理湿地保护，履行《湿地公约》。
  4. 荒漠化防治：组织协调防沙治沙，履行《联合国防治荒漠化公约》。
  5. 野生动植物保护：监督管理陆生野生动植物保护，管理国家公园等自然保护地。
  6. 林草生态修复：组织生态保护和修复重大工程，管理退耕还林还草。
  7. 林草产业：管理林业和草原产业发展。

组织架构​

国家林草局内设机构包括：办公室、生态保护修复司（全国绿化委员会办公室）、森林资源管理司、草原管理司、湿地管理司（国际湿地公约履约办公室）、荒漠化防治司、野生动植物保护司、国家公园管理司、自然保护地管理司、林业和草原改革发展司、规划财务司、科学技术司、国际合作司等。

关键政策领域​

国家公园体系建设：2021年正式设立第一批国家公园（三江源、大熊猫、东北虎豹、海南热带雨林、武夷山），2022年出台《国家公园空间布局方案》，规划到2035年建设49个国家公园候选区。

国土绿化行动：开展大规模国土绿化行动，全国森林覆盖率从改革开放初期的12%提升至24%以上。实施"三北"防护林体系建设工程（1978-2050年），第六期工程于2021年启动。

林长制：2020年中央全面深化改革委员会审议通过《关于全面推行林长制的意见》，建立省、市、县、乡、村五级林长体系，实现森林草原资源管理责任全覆盖。

湿地保护：2022年实施《中华人民共和国湿地保护法》，全国已建立国际重要湿地82处，国家湿地公园900余处。

自然保护地体系：建立以国家公园为主体、自然保护区为基础、各类自然公园为补充的自然保护地体系，全国各类自然保护地面积约占陆域国土面积的18%。
